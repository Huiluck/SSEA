# --- 生产代码依赖 -------------------------------------------------------
# 唯一一个。SSEA/sse_protocols/ 协议层不 import torch（由
# tests/test_serialization.py::TestNoModelDependency 正向守卫，
# test_model_layer_does_import_torch 反向守卫）。
# torch 的 CUDA 构建与本机显卡相关，到 pytorch.org 按机型选装即可，
# 此处不锁版本号。
torch

# --- 测试依赖 -----------------------------------------------------------
pytest

# 顺序不变性的自动守卫：随机化测试顺序后重跑。项目里有若干测试用
# torch.randn 从全局 RNG 取数，且夹具是随机初始化的——不随机化就发现不了
# 顺序依赖。曾有一条测试（test_action_decoder.py::
# test_target_comes_from_candidates）在顺序翻转时报「通道从未开启」。
pytest-randomly
