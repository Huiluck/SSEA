## 1. SSEA 是什么（一句话 + 关键结构）

SSEA（Self-evolving Survival-Embodied Architecture）是一个**非语言的、以生存为组织原则
的演化智能体架构**：不是语言模型套壳，而是「快环 FSL（毫秒级感知—行动）+ 慢环 SEL
（睡眠期离线整理与预演）」双环结构，慢环只**发布结构的新版本**（ΔS 技能 / ΔM 记忆 /
ΔR 规则 / Δθ 参数），经**四级验证门**（格式→沙盒→回归→环境实测）后原子升版；
快环只读不可变快照，不知道慢环存在。可遗传结构打包为 **GenePackage**。

**当前工程状态（2026-09-28）**：915 测试通过；七条验收实验中 1/2/3/6/7 跑通、4/5 因缺
Gene Manager 未开跑；技能固化实验 3 实测 **0/33**（判据形状错，债务 26 已修、数字未变）；
记忆检索命中率 0.5164，危险回避率两臂均 0.9814（**饱和**判据）。

## 2. 十条裁判标准 C1–C10（判定必须能回溯到这里）

| # | 约束 | 速记 |
|---|---|---|
| **C1** | 生存控制架构，非语言生成架构 | 控制环只处理与生存相关的**结构化**信号 |
| **C2** | 自然语言只作观察员接口，不进控制闭环 | 语言只在日志/解释面；「会说」≠「会做」 |
| **C3** | 权重 / 记忆 / 技能**三分离** | 三者来源、生命周期、可遗传性不同，必须分置 |
| **C4** | 低算力、低带宽 | 控制环路上信息少而结构化；缓冲不无界增长 |
| **C5** | 精准回忆历史 | 外置、可检索、可精准写入/检索/遗忘/合并的具体经历 |
| **C6** | 可自主修改自身代码与参数权重 | 自我修改拆四权：提案权 / 边界权 / 验证权 / 应用权 |
| **C7** | 可保存 / 恢复 / 变异 / 继承 | GenePackage；繁衍是「挣来的机会」，淘汰+繁衍才构成达尔文闭环 |
| **C8** | 给基因先验，不给知识语料 | 基因只放**结构性先验（本能）**；后天知识不跨代（防膨胀） |
| **C9** | 不设**外部**评分函数，只有淘汰函数 | 三层信号：① 淘汰函数归环境（模型碰不到）② 模型内部内在驱动（预测误差/内驱，定义不可改）③ 结构提案。验证门**只判合法性、不打分、不排序**；**奖励塑形、观察员评分一律违规** |
| **C10** | 创新在 L2/L3/L4，不在 L1 算子 | L1 算子是借用且可替换的，不构成架构声明 |

**L1–L4 分层**：L1 算子层（GRU/Mamba/SSM，借用）· L2 信息流层（三分离、双环、注入面）
· L3 学习层（自修改、可塑性、技能固化）· L4 演化层（基因包、变异、继承）。

## 4. 取 PDF 全文的命令

在项目根目录 `C:/MyDocs/AGI/SSEA` 下执行（用项目 venv，已装 pypdf）：

```bash
./.venv/Scripts/python.exe docs/papers/_tools/extract_text.py "<文件名关键字>" --max-chars 200000
```

输出按 `===== PAGE n =====` 分页，可直接据此标注页码。
长文可先用 `--head 12` 读前半部分，再用 `--pages 13-25` 读后续；**务必读完摘要、方法、
实验与局限四部分**再下笔。

> 若 PDF 提取为空（扫描件），改用 WebSearch 查该论文 arXiv 摘要页补全事实，并在卡片
> 「待确认问题」中记明「PDF 为扫描件/无文本层，事实来源为摘要页」。

## 5. 写卡纪律（硬性）

1. **不得替论文主张**：论文未提及的一律写「未提及」，不得虚构数据、公式、机制、页码。
2. **所有关键数字必须带出处**（表号/图号/节号/页码），并注明统计口径（n 多少、几个 seed、
   是否均值）。
3. **评分与裁决要给出理由**，区分「实测」（论文里有数字）与「推断」（你的判断）。
4. **C1–C10 逐条判定**，标记 ✓ / ◐ / ✗ / —，冲突的必须给「改造方向」。
5. 全文用**中文**；术语保留英文原文。
6. 文件名命名：`<论文短名>.分析卡片.md`，放在 `docs/papers/cards/`。
7. 卡片**必须填满模板全部 0–9 节 + 附录摘录**，不要留空行占位（确实无内容写「未提及」）。
8. 组合分析必须与第 3 节的已有卡片**点名连接**，不得只写泛泛的「与记忆方法互补」。
