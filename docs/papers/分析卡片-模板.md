# 论文分析卡片 · 空白模板

> 用途：对 `docs/papers/` 中的每篇论文做多维评估，回答两个问题——
> ① **这篇论文能否用于 SSEA、怎么用**；② **它能与哪些论文/组件组合**。
>
> 纪律（同项目 README）：**任何结论若无法回溯到 C1–C10 裁判标准，即视为偏离
> SSEA 立场，不予采纳。** 论文未提及的内容一律标「未提及」，不得替论文主张，
> 不得虚构数据、公式与机制。

**填写约定**

- 标记：✓ 支持 / ◐ 部分支持或需改造 / ✗ 冲突 / — 无关
- 卡片实例存放于 `docs/papers/cards/`，命名：`<论文短名>.分析卡片.md`
- 「搬运方式」四档：**直接移植** / **改造移植** / **仅借思想** / **仅作对照**
