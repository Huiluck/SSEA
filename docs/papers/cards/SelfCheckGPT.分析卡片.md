## 1. 一句话定位

- **论文主张**：若 LLM 真「知道」某概念，**多次随机采样**的回答会彼此相似且事实一致；若某句是幻觉，采样之间会**发散并互相矛盾**——据此提出 SelfCheckGPT：对同 query 采 N 条样本，用 5 种比较器（BERTScore / QA / n-gram / NLI / Prompt）度量「主响应句 vs 各样本」的一致性，得句级幻觉分 S(i)∈[0,1]，**不需外部数据库、不需 token 概率**（摘要 p9004、§5 p9006）。
- **对 SSEA 的意义**：它把「**模型自身的内生统计量**」当检测信号，且**全程无外部标注、无外部评分、不驱动任何参数**——是 C9 第二层「内部性 / 定义不可改 / 不进淘汰」三条的**正面标本**；可作 `surprise_estimator` 的「**跨采样矛盾度**」实现形状候选，但**缺环境锚点**（见 §3.1-专项）。

## 2. 问题 — 机制 — 证据

### 2.1 问题 / 2.2 核心思想
- **问题**（§1 p9004–9005）：LLM 会自信地幻觉；既有检测要么需 **token 概率分布**（闭源 API 不可得），要么需 **外部数据库**（只能相对库内知识判定，覆盖不全）。
- **核心 insight**：① 「**知识=一致性**」——采样发散/矛盾 ⇒ 疑似幻觉；② 只需**黑盒采样**，**zero-resource**，故对任何黑盒 LLM 可用（摘要 p9004、§5 p9006）。
### 2.3 关键机制 / 零件清单
| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| 主响应 + N 采样 | query → R（temp=0，beam）+ {S₁…S_N}（temp=1，N=20） | 制造「同分布多样本」 | §7 p9009 |
| S-BERTScore | r_i vs 各样本 → 1−mean max_k B | 语义相似度一致性 | Eq.1 p9007 |
| S-QA（MQAG） | r_i → 生成 MCQ → 各样本作答匹配率 | 问答式一致性 + Bayes 软计数 | Eq.2–6 p9007；App.B p9015 |
| S-n-gram | 样本+R 训 n-gram → −log p̃ | 用样本近似 LLM 概率 | Eq.7–8 p9007 |
| S-NLI | (r_i, S_n) → P(contradict) | 矛盾度（DeBERTa-v3-MNLI） | Eq.9–10 p9007–9008 |
| S-Prompt | prompt 判 Yes/No → {0,1,0.5} 均值 | LLM 当一致性裁判 | Eq.11、§5.5 p9008 |
### 2.4 关键表示与数据结构
- 主响应 R 按句切为 {r_i}，样本 {S_n} 按句切为 {s_n^k}；**输出句级标量 S(i)**，段落分 = 句分均值（Eq.12 p9010）。**无记忆库、无技能库、无持久态**（全文未见，推断）。
### 2.5 实验证据（GPT-3 text-davinci-003 生成 WikiBio，238 篇/1908 句，Table 1 p9008）
| 任务 / 基准 | 对照基线 | 关键数字 | 口径 |
|---|---|---|---|
| 句级非事实 AUC-PR | Random 72.96；GPT-3 灰盒 Avg(−logp) 83.21 | **S-Prompt 93.42**、S-NLI 92.50、S-1gm(max) 85.63、S-QA 84.26、S-BERT 81.96 | Table 2 p9010 |
| 段落级排序（Spearman） | GPT-3 灰盒 Avg(−logp) 53.93 | **S-Prompt 78.30**、S-NLI 73.78、S-1gm 64.91 | Table 2 p9010 |
| 采样数影响 | — | 随 N 平滑上升、**边际递减**；n-gram 最晚饱和 | Fig.7 p9011 |
| 自检消融（N=4） | — | GPT-3 自检 74.69，优于同 N 下 1gm(max) | Table 4 p9012 |
### 2.6 自陈局限（Limitations p9012）
- 仅 238 篇 WikiBio 人物文本，概念面窄；句级粒度（单句可混事实与非事实）；**S-Prompt 算力很重**（App.C p9016：1908 句×20 样本，GPT-3 约 $200 / ChatGPT 约 $20）。

| **C9** 不设评分函数，只有淘汰函数 | **◐（第二层正向，见专项）** | 信号=**跨采样一致性/矛盾度**（模型内生量）；**无外部标注、无外部评分、不驱动参数**（免训练，§5–7） | 搬运时**钉死在观察员/诊断面**，不得作门/伪标签驱动 Δθ |
| **C10** 创新在 L2/L3/L4 | **◐** | 无新算子（相似度/NLI/采样算子全借用）；创新是**检测信号与比较器设计**，属可替换的度量技巧 | — |

#### 3.1-专项：C9 第二层严格判定——「跨采样矛盾度」是不是合法的内生驱动信号？
沿用 SelfConsistency 卡既有口径（**C9 看的是「信号是不是打分、是否驱动参数」，不是「打分者是不是自己」**；第二层要求**内部性 / 定义不可改 / 不进淘汰**三条）：
1. **内部性 ✓**：信号 = 同一模型对同一 query 的 **N 条采样的相互一致性/矛盾度**（Eq.1–11 p9007–9008），**完全是模型自身的内生统计量**——不读任何外部数据库、不用任何人工标注。**这是它与 WhenNotToTrust 的关键分野**（后者用外部元数据=流行度，C9 ✗）。
2. **定义不可改 ✓**：比较器（BERTScore / NLI / QA / n-gram / prompt）与映射（Yes→0/No→1、β₁=β₂=0.8）**均由研究者固定**，模型无法改写；论文**不用正确性标签校准信号**（标注只用于评测，不回流定义）。对照 ExpSeek：其阈值由 (熵, ground-truth) 的 logistic 标定 → 边界来自外部监督；本篇**无此问题**。
3. **不进淘汰 ✓**：全篇**免训练**，S(i) 只用于**检测与排序**，不进任何梯度、不驱动任何参数、不作门/伪标签。对照 TTCS：**同一族信号**（多采样一致率）被用作 R_cap **奖励驱动 GRPO** → C9 ✗；本篇**只报不改** → 第二层通过。
- **一句话判词**：**内部性 ✓、定义不可改 ✓、不进淘汰 ✓，三条全过**——它是 C9 第二层「内生统计量」的**最干净标本**；但**「是内生量」≠「是预测误差」**（见下）。

#### 3.1-专项补：能否作 SSEA「预测误差/惊奇」的实现候选？——**能作「候选」，但不能独立成立**
- **契合处**：SSEA 的 `surprise_estimator` / `prediction_error` 需「不设外部评分、由模型自身产生」的信号；本篇给出**跨采样矛盾度**这一具体形状（同 query 多样本 → 分歧度），**无需标注、无需评分、不驱动参数**，与 C9 第二层天然对齐，可作 `surprise` 的「**模型自采样分歧**」实现变体。
- **不契合处（决定性）**：① **无环境锚点**——它度量的是「模型自己拿不准（epistemic 不确定性）」，**不是「预测与观测事实不符（prediction error）」**；论文未把任何环境事实引入信号（全篇黑盒采样）。这与 **TTCS 的「自洽性 s 度量不确定、不度量对错」是同一条告诫**——s=1 可以是「**一致地错**」。② **语言域**：采样对象是 token 序列，SSEA 须重建在**结构化动作/状态分布**上。
- **结论**：可作 `surprise_estimator` 的**内生分歧度候选**（与 ExpSeek 的 token 熵、SelfConsistency 的多数投票并列），但**最终 prediction_error 必须锚在环境转移事实上**（见 **EarlyExperience** 的 IWM：以**观测到的下一状态**为监督）。本篇提供「无锚的内生量形状」，EarlyExperience 提供「有锚的预测误差形状」，二者**互补而非替代**。

### 3.2 L1–L4 定位 / 3.3 模块映射 / 3.4 债务对应
- **L1** 无（算子全借用）；**L2** 「同 query 多样本 → 分歧度聚合」的信息流形状，可作 `surprise_estimator` 判据形状参照（信号源须换结构化量 + 环境锚）；**L3/L4** 无（免训练、无演化）。
- **模块映射**：跨采样矛盾度 → `surprise_estimator`（候选实现变体，须改信号域）；**不落**门/伪标签。**债务/验收实验**：不直接回应任何已知债务；仅作 C9 第二层「内生统计量」判据标本与族内基线坐标。

## 5. 冲突、代价与风险
- **硬约束冲突**：C1/C2/C8 ✗；C4 ◐/✗（N=20 采样、Prompt 变体重）；C9 ◐（第二层正向，但用途须钉死观察员面）。
- **隐含假设与失效条件**：① 依赖**同分布多次采样**且采样确有分歧（temperature 足够）；② **一致性 ≠ 正确性**——可能「一致地错」；③ 依赖预训练知识底座；④ 弱模型无法当裁判（论文称 GPT-3 curie / LLaMA 的 prompt 一致性评估失效，§5.5 p9008）。
- **算力代价**：N=20 采样 + Prompt 变体 LLM 裁判（$200/1908 句，App.C p9016）——与 C4 冲突。
- **退化模式**：若把矛盾度引入控制环当**门/伪标签**，会退化为**自我确认**（只巩固模型已一致的东西），并重演 R-Zero/TTCS 的「自举伪标签」违规与 model collapse。

## 6. 组合分析

### 6.1 关系图谱（点名连接）
| 关系 | 对象 | 说明 |
|---|---|---|
| **同族（同信号源）** | **SelfConsistency** | **同一「多采样」家族的两面**：SC=**一致→多数投票（选答案）**，本篇=**矛盾→不一致分（检测）**；两者都是内生量、无外部评分。**口径对齐**：SC 卡判 C9 ◐（用途决定）／✗（驱动参数时），本篇**不驱动参数** → 第二层三条全过，是**同族更干净的标本** |
| **互补（内生信号两实现）** | **ExpSeek** | 都用「模型自身不确定性」当触发/诊断：ExpSeek=**步级 token 熵**（门），本篇=**跨采样矛盾度**（检测分）。ExpSeek 卡已判熵=「合法内在信号、但阈值外部标定」；本篇**连阈值都不用标定** → 是 ExpSeek 的「更纯」对照 |
| **正面对照（外部 vs 内部）** | **WhenNotToTrust** | WhenNotToTrust 的门用**外部元数据（流行度）** → C9 ✗；本篇信号**纯内部** → C9 第二层通过。**并读即「门信号来源：外部元数据 vs 内生统计量」对照臂** |
| **同族反例（用途决定裁决）** | **TTCS** | TTCS 的**自洽性 s** 与本篇**同一族**（多采样一致率），但 TTCS 拿它当 **R_cap 奖励驱动 GRPO** → C9 ✗；本篇**只报不改** → ◐/✓。**同信号、异用途、异裁决**（与 SelfConsistency 卡口径一致） |
| **互补（锚点）** | **EarlyExperience** | EarlyExperience 的 **IWM** 把 prediction_error 锚在**观测到的下一状态（环境事实）**；本篇给「无锚的内生分歧度」。**组合＝「内生分歧度作先验/预筛 + 环境事实锚定最终 prediction_error」** |

### 6.2 推荐组合方案 / 6.3 角色
- **组合**：本篇（跨采样矛盾度）× **ExpSeek**（熵门）× **SelfConsistency**（多数投票）× **EarlyExperience**（IWM 锚）× **TTCS**（无标签前沿带）——构成一份 **「内生不确定性信号」对照表**：同为无外部评分的内部量，**四种操作化**（熵 / 分歧度 / 一致率 / 前沿带）在**同一任务**上谁更能区分正/错帧（先跑 KS/AUC 诊断，同 ExpSeek 纪律）。
- **新增风险**：四种信号若**不加锚点**融合，会集体退化为「一致地错」的自我确认；必须由 EarlyExperience 式**环境事实**提供客观锚。
- **典型角色**：**「内生分歧度信号」的定义出处 + C9 第二层「内部性/定义不可改/不进淘汰」三过标本 + 族内基线坐标**；不是机制供给方。

- **最小验证实验**（与 ExpSeek 共用装置）：
  - **双臂/消融**：臂 A = 现有 `surprise_estimator` 信号；臂 B = 「结构化动作分布上的跨采样分歧度」（本篇形状，对同一观测采 K 次动作）。≥8 seed。
  - **判据（分档，先看分母）**：① 机制计数——分歧度信号的 **KS/AUC**（能否区分正/错帧，先修尺子）；② 行为差——被信号标记的帧是否改变动作；③ 淘汰结果（环境侧，模型外）。
  - **预期与证伪**：若分歧度 AUC 显著 >0.5 且部分 seed 改变动作 → 形状可用；若 AUC≈0.5，或「分歧度低但实际错」（一致地错）频繁 → **该形状缺锚、不可独立作 prediction_error**，退回观察员面，prediction_error 改由 EarlyExperience 式环境事实锚定。
