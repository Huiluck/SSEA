## 1. 一句话定位

- **论文主张**：把 CoT prompting 的贪心解码换成 **sample-and-marginalize**——先采样一组多样推理路径，再对最终答案**多数投票**取最一致者；四个 LLM（UL2-20B/GPT-3-175B/LaMDA-137B/PaLM-540B）上**免训练、免微调**地大幅抬升算术与常识推理（摘要 p1：GSM8K +17.9%、SVAMP +11.0%、AQuA +12.2%、StrategyQA +6.4%、ARC-c +3.9%）。
- **对 SSEA 的意义**：**不适用**——纯 NLP 推理的**解码期聚合策略**，与生存控制架构无回路接口；唯一用途是给 C9 提供「**多数投票 = 一致性信号**」的**定义出处**，并作族内基线坐标。

## 2. 问题 — 机制 — 证据

### 2.1 问题 / 2.2 核心思想
- **问题**：LLM 复杂推理弱，仅增大规模无法解决；CoT 贪心解码取单一路径，易陷入重复与局部最优（p1）。既有方案（训练 verifier / re-ranker，Cobbe 2021、Thoppilan 2022）需**额外训练或人工标注**（p2、p9 §4）。
- **核心 insight**：① 复杂问题有**多条通往唯一正确答案的推理路径**，路径越多样「多路一致」越可信（p1，引 Stanovich & West 2000）；② 把「采多路 + 取众数」当作**解码策略**——不需要 verifier、不需要训练（p2）。

### 2.3 关键机制 / 算法（零件清单）
| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| 多路径采样 | prompt+question → m 条 (rᵢ,aᵢ) | 制造多样性（temperature/top-k/nucleus） | §2 p3；§3.1 p4 |
| **多数投票** | {a₁…a_m} → `arg maxₐ Σ₁ᵐ 1(aᵢ=a)` | 选最一致答案 | §2 p3（式） |
| 加权变体（对照） | 按 P(rᵢ,aᵢ\|prompt,q) 加权 | 论文实测**纯多数投票 ≈ 归一化加权** | Table 1 p3；Eq.1 p3 |
| 一致性作不确定性估计 | 一致率 → 置信度 | 「知道自己不知道」 | §3.5 p8、Figure 5 p8 |

### 2.4 关键表示与数据结构
- 每条输出 (rᵢ,aᵢ)：rᵢ＝推理路径 token 序列，aᵢ＝从**固定答案集 A** 解析出的答案（§2 p3）；**无记忆库、无技能库、无持久态**，唯一状态是当次 m 条输出（推断：全文未见可写结构）。

### 2.6 论文自陈局限与边界条件
- **自陈局限（§5 p9）**：① **算力代价更高**；② LLM 有时生成**错误/无意义推理路径**（Table 4 p6 的 StrategyQA 例，两个人口数字都不准确），需更好 grounding。
- **适用边界**：仅适用于**答案来自固定答案集**的问题（§2 p4）；**无独立 Limitations 章节**（§5 为 Conclusion and Discussion）。

#### 3.1-专项：C9 裁决 —— 「多数投票」是不是评分函数？（对照 R-Zero 卡 §3.1-专项B，沿用既有口径，不立新口径）
**裁决：就本篇用途（推理期选答案）→ ◐，不构成 C9 违规；同一信号在 R-Zero/TTCS 的用途（驱动参数）→ ✗。差别只在「用途」，不在「信号本体」。**
1. **既有口径原文（R-Zero 卡）**：「C9 看的是『信号是不是**打分**、是否**驱动参数**』，不是『打分者是不是自己』」；R-Zero 的 p̂ 判 ✗ 因**同时**满足「连续标量奖励」与「经 GRPO 驱动权重」两条。
2. **条件①（是打分）？否**：majority vote＝`arg maxₐ Σ 1(aᵢ=a)`，是**一致性计数**、非标量奖励；Table 1 p3 正是把它与「weighted sum/weighted average」两种**打分式聚合**并列并证明纯计数≈归一化加权。**条件②（驱动参数）？否**：全篇 few-shot、**不训练不微调**（§3.1 p4），只决定当次输出答案，不进任何梯度 → **两条件均不满足**，不落入 R-Zero 卡所判的 C9 违规。
3. **但它确是「自举伪标签」的定义出处**：R-Zero 的 `p̂`/`ỹ`、TTCS 的 `s` 都建在本篇多数投票上（R-Zero 卡 §3.1-专项B 第 3 点）。**同信号，R-Zero 用它驱动权重 → ✗；本篇只用它选答案 → ◐**，与既有口径自洽：信号形态相同、用途不同、裁决不同。
4. **论文自己提出了违规的未来方向（必须点名）**：§5 p9「use self-consistency to generate better supervised data to **fine-tune** the model」——一旦照此做（用多数投票造伪标签**驱动 Δθ**），即落入 R-Zero 卡所判「自举伪标签」违规，**不得采纳**。

> **一句话判词**：多数投票是**一致性**、不是**外部评分**；是否违反 C9 取决于**被用来干什么**——选答案（本篇）不违规，驱动参数（R-Zero/TTCS）违规。SSEA 搬运时把它**钉死在观察员面**即可。

### 3.2 L1–L4 定位 / 3.3 模块映射 / 3.4 债务对应
- **L1**：无（采样算子全借用；创新是解码/聚合策略）。**L2**：「多路采样 → 一致性聚合」的信息流形状，仅可作判据形状参照（信号源须换环境事实）。**L3/L4**：无（免训练、无演化）。
- **模块映射**：多数投票 → **不落点**（若强行映射，只能是日志面不确定性指标，须与 `surprise_estimator.py` 预测误差区分）。**债务/验收实验**：**不回应任何已知债务或验收实验**；仅作 C9 判据定义出处与族内基线坐标。

## 5. 冲突、代价与风险

- **与硬约束冲突**：C1/C2/C4/C8 ✗，C9 ◐（用途决定），C3/C5/C7 —。
- **隐含假设与失效条件**：① 需**固定答案集**才可投票（§2 p4）；② **一致性 ≠ 正确性**——可能「一致地错」（论文自陈 Table 4 p6 的 StrategyQA 例推理路径本身有误）；③ 依赖预训练知识底座。
- **算力代价**：40 路 × 10 runs 采样，自陈「incurs more computation cost」（§5 p9）——与 C4 冲突。
- **退化模式**：若把多数投票引入 SSEA 控制环当**决策/门/伪标签**，会退化为**自我确认**（只巩固模型已同意的东西）→ 重演 R-Zero 卡的「自举伪标签」违规与 model collapse。
