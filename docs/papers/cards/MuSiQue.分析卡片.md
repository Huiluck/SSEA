## 1. 一句话定位
- **论文主张**：既有多跳 QA 基准可被「非连通推理」与捷径刷分；本文用 bottom–up 构造法——从大量单跳问题中系统挑选可组合对（一个的答案作另一个的 bridge entity），再严格过滤保证「不解决前一跳就拿不到后一跳答案」，造出 MuSiQue-Ans（约 25K 条 2–4 跳题）与 MuSiQue-Full（约 50K 条含不可回答对照对），人类–模型差距约为既有数据集的 3×、更抗作弊（DiRe 37.8 vs HQ 68.8 / 2W 63.4）。
- **为什么不适用**：这是**面向语言模型的多跳阅读理解基准**，其全部机制（DAG 化问题分解、F1/EM 指标、transformer 基线）都建立在自然语言问答闭环上，与 SSEA 的「生存控制环 + 非语言结构化信号」无任何接口；连「反面教材」意义也有限——不涉及自修改、基因遗传、淘汰函数或记忆读写。
## 2. 问题 — 机制 — 证据
### 2.1 论文要解决的问题
- 问题本身：如何**构造**一个「按设计即要求连通推理」的多跳 QA 数据集，而非事后过滤既有数据集。
- 既有方案缺陷：HotpotQA 直接众包 2 跳题、忽略组合难度；2WikiMultihopQA 用有限手写组合规则，大模型易解；两者均可被「只读一个支持事实」的模型高分通过（§1, §2）。
### 2.2 核心思想
1. bottom–up：从 5 个单跳数据集（SQuAD、Natural Questions、MLQA、T-REx、Zero Shot RE）取题，按 bridge entity 组合成 2–4 跳 DAG。
2. 形式化 MuSiQue condition Eqn.(2)：对每条边，模型在**遮蔽前驱答案**后不能答对；对每个子问题，**无上下文**时不能答对——用强模型探测筛选连通性（§4.2–4.3）。
3. 源头压制三类捷径：降低单跳题级 train-test 泄漏、用「正干扰段」替换全文 Wikipedia、在子问题级制造不可回答对照对。
### 2.3 关键机制 / 算法（可独立搬运的「零件」清单）
| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| 可组合性判据 | 两个 (q,a) → 2 跳候选 | a1 为命名实体且在 q2 中被提及；三重同指消歧（Spacy 类型 + Wikipedia 首结果 + Wikification） | §5:S2 |
| Disconnection Filter | 2 跳候选 → 连通 2 跳 | 头节点：遮答案后 An F1<0.5 保留；尾节点：遮 bridge 后 An F1≤0.25 或 (≤0.75 且 Sp F1<1.0) | §5:S3 |
| 抗泄漏切分 | 全部题 → train/dev/test | 以「单跳题 / 单跳答案 / 关联段落」三重重叠定义，greedy 最小化 train↔dev+test 重叠 | §5:S5 |
| 正干扰段 | 支持段 + 检索段 → 20 段上下文 | 干扰段取自被过滤单跳题的 gold 段落，避免分布偏移被利用 | §5:S6, Table 7 |
| 不可回答对照对 | 可回答实例 → 同题不可回答实例 | 随机去掉某子问题答案所在段，逼模型判上下文充分性 | §5:S8 |
### 2.4 关键表示与数据结构
- 多跳题 Q 对应 DAG G_Q，节点为单跳子问题 q1…qn，边 (qj,qi) 表示 qi 依赖 qj 的答案；a_n 即最终答案（§4.1）。
- 实例形态：MuSiQue-Ans 为 (Q,C;A,P_s)；MuSiQue-Full 增补二值 S（上下文充分性），成对评估（§7.1）。
- 规模：24,814 条 MuSiQue-Ans（Train 19,938 / Dev 2,417 / Test 2,459，Table 2）；6 种 2–4 跳推理图形状（Table 1）。

### 2.6 论文自陈局限与边界条件
- 仅限英文 Wikipedia 阅读理解设定（固定段落集 C），未涉及其他模态（§4.3）。
- 强模型筛选阈值（0.5 / 0.25 / 0.75）靠人工抽查选定，是「可作弊度 ↔ 数据规模」的权衡旋钮（§5:S3）。
- 更好的问题分解与更强 transformer 仍不足以逼近人类（§8.3）；T5 因算力成本未全面使用。
- 构造成本：众包约 11K USD，17 名合格标注员（§5:S7）。

## 5. 冲突、代价与风险
- **与硬约束的冲突**：C2/C4/C8/C9 均判 ✗——把自然语言放在闭环中心、依赖大算力、以知识语料为载体、并以外部评分函数排序模型，与 SSEA「语言只作观察员、控制环低带宽、不给知识语料、只有淘汰函数」逐条相反。
- **隐含假设与失效条件**：假设「多跳 = 单跳可组合 DAG」，即推理可完全分解为离散、可标注的跳步；对 SSEA 的连续感知—行动快环不成立。
- **算力 / 带宽 / 工程代价**：搬运无意义；若误用其 F1/DiRe 作 SSEA 判据，会引入 C9 明令禁止的外部评分。
- **仍值得保留的理由**：作**反例坐标**——示范「纯语言基准如何以外部评分 + 知识语料驱动」，正是 SSEA 要避免的形态；其「遮蔽关键输入看是否仍成功」的证伪式判据可作判据形状讨论的参照。
## 6. 组合分析
- **关系图谱**：与已有卡片无前置/互补/替代关系；既非记忆组织（Memento/FLEX/A-MEM）、非技能侧（PSN/Voyager/SkillWeaver）、非演化侧（Misevolve/Gödel Agent）。
- **推荐组合方案**：—。
- **典型角色**：可作**实验 2 判据形状的反例臂**——用「去掉 bridge 实体后仍答对」这一「看似成功实则捷径」现象，类比债务 26「判据形状错 → 技能失效被判成成功」，提醒判据必须能否证关键输入缺失。
