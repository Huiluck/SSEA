## 1. 一句话定位
- **论文主张**：构建首个中文交互式网页检索 LFQA 数据集 WebCPM（5,500 QA / 15,372 支持事实 / 125,954 搜索动作），把任务拆为动作预测、查询生成、事实抽取、信息合成四子任务并微调 PLM；纯 pipeline 答案在 32.5%（本数据集）/ 47.5%（DuReader 均值）情况下不劣于人工答案。
- **对 SSEA 的意义**：无。这是语言生成式问答基准 + 行为克隆流水线，控制对象是「答案好不好」而非「活不活得下去」，无法回溯到 C1–C10 任何一条（见 3.1）。

## 2. 问题 — 机制 — 证据
### 2.1 问题
- 中文缺「交互式网页检索→长文本答案」公开基准；WebGPT 的接口/数据/模型均不公开（§1）。
- 既有缺陷：传统 LFQA 用原问题一次性非交互检索，得到一堆未筛选信息（§1）。

### 2.2 核心思想
1. 录下「人会怎么搜」当监督信号，PLM 做行为克隆。
2. 交互式多轮检索优于一次性 TF-IDF 检索（§6.2）。

### 2.3 关键机制 / 零件
| 零件 | 输入 → 输出 | 出处 |
|---|---|---|
| 网页检索接口（10 动作） | 点击 → 记录动作/观察 | §3, Fig.1/6 |
| 动作预测模块 | 状态 S_t → 10 类动作 | §5.1 |
| 查询生成模块 | S_t → 查询串 Q_{t+1} | §5.1 |
| 事实抽取模块 | S_t, 窗口 W_t → 事实 span（只生成首尾 N_f token 再文本匹配） | §5.1 |
| 合成模型 + 噪声注入 | 问题+事实 → 答案（注入无关事实学忽略） | §5.2/§6.3 |
| 事实损坏（概率 p 擦除） | 残缺事实 → 答案（平衡抄/编） | App.F.1, Table 4 |

### 2.4 关键表示
- 实例元组 `(question, web search behavior, supporting fact, answer)`（§4）。
- 状态 `S_t={Q0, Qt, A_{t-1}, W_{t-1}, W_t, F_t, 剩余动作数}`，只留最近两窗口 W 以免超长（§5.1）。

### 2.5 实验证据
| 任务 / 基准 | 对照 | 关键数字 | 口径 |
|---|---|---|---|
| 子任务（8 个 PLM） | 横向比模型 | CPM10B 最优：动作 Mi 60.4/Ma 54.5；查询 R-L 70.0；事实 R-L 62.4；合成 R-L 61.2 | Table 2, 测试集单次（n=400） |
| 整链偏好（WebCPM） | 人工答案 | 优或平 32.5% | 8 标注员投票, Fig.4(a) |
| 整链偏好（DuReader） | 金标注 | Search 44.0% / Zhidao 51.0%（均 47.5%） | 抽 400 题, Fig.4(b) |
| 合成模型消融 | 未加噪基线 | 优于基线 43.7% / 劣于 18.0% | 投票, Fig.4(c) |
| 状态组件消融 | 移除 F_t/W_{t-1}/A_{t-1} | 动作预测最依赖 A_{t-1}（Mi 58.9→53.4）；事实抽取移除 F_t 掉 5.1 | Table 3（CPM7B） |

### 2.6 自陈局限
- 依赖：Bing 实时接口；23 名标注员 + 8 名质检的人工数据。
- 不适用：整链在检索与合成上 67.5% 情况劣于人类（p.9）；交互检索比非交互慢（App.G）；仅中文。

## 3. SSEA 立场对齐
### 3.1 C1–C10 映射（短卡主要价值：记录「为什么被排除」）
| 标准 | 判定 | 依据 | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制，非语言生成 | ✗ | 整篇是文本生成架构，目标是答案质量，无生存信号、无淘汰（§5/§6） | 不可改造，控制对象不同 |
| **C2** 语言只作观察员接口 | ✗ | 自然语言既是输入也是输出，直接进闭环（问题→查询→答案） | 不可改造 |
| **C3** 权重/记忆/技能三分离 | ✗ | 只有权重（微调 PLM）；「事实」是单题内临时缓冲，无跨会话记忆、无技能 | 无 |
| **C4** 低算力低带宽 | ✗ | CPM10B（10B）+ 实时 Bing，每题均 22.9 动作 / 2.5 查询 / 3.3 页 | 无 |
| **C5** 精准回忆历史 | ◐ | 有支持事实抽取与 S_t 内 F_t/W 局部引用，但仅单题会话内，无跨经历检索/遗忘/合并 | 仅可作「单题内事实缓冲」弱类比 |
| **C6** 可自主修改自身 | ✗ | 纯离线监督微调，运行期不自改代码/权重/边界（§5） | 无 |
| **C7** 可保存/恢复/变异/继承 | ✗ | 无基因包、无变异、无遗传；论文未提及 | 无 |
| **C8** 给基因先验，不给知识语料 | ✗ | 恰恰相反：靠 5,500 条人工知识语料微调 | 无 |
| **C9** 不设评分函数，只有淘汰函数 | ✗ | 全程外部监督：人工偏好 + Rouge-L + Micro/Macro-F1（§6.1/§6.2），正是 C9 禁止的观察员评分 | 无 |
| **C10** 创新在 L2/L3/L4 | ✗ | 创新在数据（基准）与模块切分，未触及信息流/学习/演化层 | 无 |

### 3.2 L1–L4：L1 借用现成 PLM；L2 是语言任务流水线（非控制环）；L3 仅离线监督微调；L4 —。
### 3.3 模块映射：支持事实 F_t 与 SSEA 记忆库无接口（不落盘、不跨代）；10 类动作与 FSL 动作空间无交集。
### 3.4 债务与验收实验：— 不触及 22/25–28、Gene Manager、记忆门、技能表示等任何一条。

## 5. 冲突、代价与风险
- **硬约束冲突**：C1/C2/C3/C4/C6/C7/C8/C9/C10 均 ✗（见 3.1）；核心是 **C9**——以人工偏好 + Rouge/F1 为唯一信号，与「只判合法性、不打分」直接对立。
- **隐含假设**：有实时联网搜索、「答案好坏」可由人类偏好定义——在生存域均不成立。
- **代价**：10B 级模型 + 实时检索，与 C4 背道而驰。
- **退化模式**：强行接入会把 SSEA 拖回「语言生成评分」范式，丧失生存判据。
- **为何仍留池**：它是「交互式检索 + 行为克隆」的公开中文基准，可作「语言式 agent vs 生存式 agent」对照样本，并为 C9 提供「外部评分函数长什么样」的具体反例。

## 6. 组合分析
- 关系图谱 / 推荐组合：— 与已有卡片（Dream-RSI/Memento/FLEX/PSN/MemRL/A-MEM 等）无可组合接口。
- 本篇角色：**基准对照样本**——如需为验收实验（如实验 2 判据形状）找「QA 式外部评分判据」的反例，本篇是可引用的公开中文案例。
