## 1. 判据：什么算「可用于 SSEA」

把「可用于」拆成**三层判据**，逐层收紧。

### 1.1 阶段判据（先问落点，再问好坏）

SSEA 当前是**第一阶段「最小生命体」**，生态系统本阶段**不写代码**。所以「可用于」首先要定位落点在**哪一层**：

- **快环**（`action_decoder` / `skill_runner` / `environment`）—— 改动代价最高，且受「快环零改动」纪律约束；
- **慢环**（`experience_compiler` / `plasticity` / 睡眠期）—— 当前最空；
- **验证门**（`verification_gate` 四级）—— 当前最紧（债务 25–28）；
- **Gene Manager**（**缺失**，实验 4/5 因此卡住）；
- **环境 / 生态**（第二阶段，本阶段**仅理论**）。

→ 一篇论文「相关度 5 分」但如果落点在生态，它在**本阶段兑现为零**（典型：`Genie` 落地成本 1 分；`Agent-World` / `ScaleEnv` / `GenEnv` 同属第二阶段的供给侧）。

### 1.2 立场判据（C1–C10 的实际分布）

**事实：{N} 篇里没有一篇的「立场兼容性」= 5。** 分布如下：

- 兼容性 **4**：8 篇（`A-MEM` `Genie` `LightMem` `Mem0` `Misevolve` `PSN` `SkillWeaver` `Voyager`）——**改造后可用**；
- 兼容性 **3**：17 篇；
- 兼容性 **2**：35 篇；
- 兼容性 **1**：1 篇（`CoMAS`——把奖励来源从环境挪到**同伴互评**，核心机制与 C9 不可调和，是库里兼容性最低的一篇）。

也就是说：**没有一篇可以整机采用**。这不是筛选不严，而是三条约束的必然结果——整个领域建立在**语言载体 + 外部评分 + 权重更新**之上，而 SSEA 的 C1/C2/C9 把这三样**一起**禁掉了。

> 所以「A 核心借鉴」的含义**从来不是「搬这篇」**，而是「搬它身上那一个**不依赖这三样**的零件」。卡片库里 **7 篇 A 级**（`Dream-RSI` `HarnessEval` `LLMasCode` `Memento` `Misevolve` `Ouroboros` `PSN`）全部如此。

**一条例外性的正面证据**：C2（自然语言不进控制闭环）此前被认为是**外部支持最弱**的一条——整个领域都建立在语言之上。本次在 {N} 篇里找到了**唯一一篇从架构层形式化它**的：`LLMasCode`（S15，兼容性 3）——「控制流=代码、语言退到叶调用内部」。它不改变「没有一篇能整机采用」的结论，但**改变了「C2 无外部支持」这一判断**。

### 1.3 兑现判据（本图谱新增，也是最关键的一条）

> **不要问「这篇好不好」，要问「这篇的哪一个零件，能在本阶段的哪一条债务/缺口上兑现，且前置依赖已经满足」。**

理由是：卡片的 A/B/C 分级按**与 SSEA 命题的贴合度**打分（`项目相关性` 与 `组合价值` 权重高），而**当前最紧的卡点全是「判据问题」与「缺件问题」**，与命题贴合度**不是同一根轴**。于是出现明显的序位倒挂：

- 总分最高的是 `HarnessEval`（27/30，唯一 P0），它**不提供任何算法**，只提供「如何证明自演化真的有效」；
- 总分最低档（18/30）的 `FLEX`，却是记忆写入侧唯一给出**停机判据**的一篇；
- `SEAL` 18/30、兼容性 2，它的价值是**让人决定「不开 Δθ」**——负价值也是价值。

所以把「可搬性」拆成**四种粒度**（总表第 6 列）：

| 粒度 | 定义 | 前置依赖 | 篇数 |
|---|---|---|---|
| **G1 判据/协议件** | 纯文本规格 + 常量，零算力 | **无** | **25** |
| **G2 结构/表示件** | 数据结构与不变量，小改代码 | 低 | 18 |
| **G3 机制/算法件** | 需新建通道 | 高（Gene Manager / 抽象算子 / 重放） | 7 |
| **G4 反例/负证据标本** | 价值在「不做什么」 | 无 | 6 |
| **G5 基准/对照** | 作为报告基线或被替代方 | 无 | 5 |

**第一条操作性结论**：G1 有 **25 篇**，且几乎全部**零前置**。这意味着 SSEA 现在可以立刻兑现的文献资产**比看起来多得多**——它们**不需要 Gene Manager，也不需要写任何新通道**。

## 3. 十五个槽位：真正的取舍发生在槽位内部

**先说方法论**：槽位不是我划的，是**卡片的 `§6` 自己声明的**——每张卡都用「最紧互补 X」「替代 Y」「前置依赖 Z」点名额。本图谱把这些边合并、去重，得到 **15 个功能槽位**。

槽位是**角色**，不是**分区**：一篇可以占两槽（`Agent0` 既供前沿带又当反例标本；`Dream-RSI` 既供重放又进预算槽）。总表的「槽位」列只记主槽位。

**为什么这比逐篇裁决更有用**：每个槽位里有 2–8 个候选，它们**互相不替代**（论文各自解决同一功能的不同侧面）。所以真正的决策是**「这个槽位由谁承担、其余降级为补丁/对照」**，而不是「这 52 篇里选 10 篇」。

### S1 判据健康度（8：`HarnessEval` `AutoEnv` `GenEnv` `ExperienceSynthesis` `RAGEN` `Agent0` `Aspire` `TTCS`）

这是**当前第一顺位**的一槽。三个部件不重叠：

- **归因** → `HarnessEval`（P0）：预算匹配基线 + 搜索/评测分离 + pass@1 vs pass@k。回答「增益来自更好的设计，还是多试了几次 / 过拟合了评测集」。
- **分辨力** → `AutoEnv`：差分可靠性检查（构造一个故意削弱的臂）+ Skin-Inverse 控制消融。回答「这条判据还分不分得开强弱臂」。直接针对 0.9814 饱和。
- **测量位置与样本量** → `GenEnv`：α 难度带 + Theorem 1 的样本量界。回答「把测量放在哪个难度上、放多少样本才测得出来」。
- **零算力筛选器** → `ExperienceSynthesis` 的 `V_τ`（奖励熵）：**唯一可以立刻跑**的一件——对现有每个实验情境算 `V_τ`，标出 `V_τ≈0` 的无分辨率情境，不需要 LLM。
- **动力学前兆** → `RAGEN`：方差悬崖 → 熵塌缩 → 梯度尖峰，「方差先于均值」。
- **前沿带** → `Agent0`：`frontier_band(lo=0.30, hi=0.80)` 是**债务 22（记忆二级门常量阈值）目前唯一候选的形状**。
- **产出记账** → `Aspire`：三层产出 `best evaluated / eligible / selected / retained`，且**统一以 base 为参照**（禁止以「上一 checkpoint」为参照）+ **轨迹分解**（rise / tie / fall）区分「局部上升」与「高于 base」。直接对位债务 25「记录数字不复现」。
- **无标签前沿带** → `TTCS`：以**模型自洽性 s ≈ 0.5**（`4·s(1−s)` 在此最大）作难度目标，**不需要 ground-truth**——这正是 `GenEnv` 做不到的（`GenEnv` 必须有 checker 才存在 p̂），而 SSEA 的生存域恰恰没有 ground-truth。与 `Agent0` 的前沿带**同构但信号源不同**（前者用误差分位，后者用多数投票一致率）。

**前置**：全部为零（G1）。**这一槽可以立刻落地，且应先于任何新机制建设。**

### S2 记忆组织 / 写入（9：`FLEX` `ACE` `LightMem` `Mem0` `A-MEM` `DynamicCheatsheet` `EvolveR` `Mem-alpha` `G-Memory`）

- **主干** → `FLEX`（分层库 golden/warning + 写入三分支 + **logistic 增长曲线作睡眠期停机判据**）+ `ACE`（**禁止整体重写**、非 LLM 确定性 delta 合并、坍缩监控指标）。
- **补丁** → `Mem0`（ADD/UPDATE/DELETE/NOOP 分类式 CRUD + 软冲突标记）、`A-MEM`（类型化关联边）、`LightMem`（摄入压缩 + 阈值触发巩固 + 软更新只合并不硬删）。
- **反例（不用，但价值高）** → `DynamicCheatsheet` 的 18,282→122 token 坍缩事故是「整体重写」的**事故报告**；`AutoSkill` 证明**只有合并、没有退休**不足以对抗膨胀。
- **动作空间** → `Mem-alpha`：ΔM 事务 `{INSERT, UPDATE, MERGE, SOFT_DELETE, NOOP}`。
- **纵向分层** → `G-Memory`：三层图（抽象洞察 / 查询索引 / 细粒度交互）+ **双向遍历**（向上取洞察、向下取压缩经历）+ `1-hop`、`k∈{1,2}` 纪律。其消融实测「抽象层与原始层**缺一即降、且原始经历贡献更大**」——这是 **C5（精准回忆）与 C8（抽象不取代原始）可以共存**的直接证据。

**关键**：这一槽里 `ACE` 与 `DynamicCheatsheet` **指向同一条纪律**（禁止整体重写），且后者给出了失败数字。建议把这条纪律**立即**写进慢环规范（成本为零）。

### S3 记忆检索 / 选择（6：`Memento` `MemRL` `AgentKB` `EvoRoute` `RetroAgent` `Xolver`）

这一槽的五篇**不是竞争关系，是同一条管线的四段**（每张卡的 §6 都互相点名）：

- **键扩展**（治 `retrieve` 键收窄） → `AgentKB` 的混合双通道（词法 + 语义）+ `EvoRoute` 的三面析取（角色 / 工具集 / 状态分档）；
- **选择策略** → `Memento` 的可学习 μ（强，但需训练）或 `MemRL` 的两阶段检索（保守，零成本，**推荐先做这个**）；
- **访问分布** → `RetroAgent` 的 UCB 探索项 `κ√(ln N / n_i)`——**纯计数、无外部评分、最合 C9**，直接治「少数条目被反复取用、长尾永不被取」；
- **一致性自保** → `AgentKB` 的 disagreement gate（只判一致性合法性，不排序）。
- **双记忆分层** → `Xolver`：长期 episodic 库 × 单题工作记忆 + **跨题经验累积**。与 `Memento` / `FLEX` / `AgentKB` / `ReasoningBank` 重叠度高，净增量是「跨题累积」这一形状（故 P2）。

**前置**：除 `Memento` 的 μ（G3，需训练）外全部为零。

### S15 控制流归属 / L2 结构（1：`LLMasCode`）

卡片库里**唯一一篇把 C2 形式化**的论文，也是全部 57 张卡里**唯一从架构层论证「语言不该管控制流」**的一篇：它主张主流 agent 框架把「下一步做什么、何时调工具、何时停」交给 LLM 是**类别错误**——循环、分支、顺序是**确定性工作**，而 LLM 的每次输出都是从分布中采样（包括控制流决策）。因此 token explosion、control-flow hallucination **不是实现 bug，而是架构后果**，换更强模型或更好提示都不能保证可靠。

两条**可直接搬的 L2 零件**：

1. **DAG 上下文作用域规则**（祖先链全量 + 已返回子树塌缩为摘要）——上下文长度由**调用深度 O(depth)** 而非步数 O(steps) 决定，是 **C4「缓冲不无界增长」**的实现候选；
2. **「提案 → 测试 → commit as code」**——结构改进以**可执行代码固化**，天然可打包进 `GenePackage`，是 **C7/C8 的载体形态**。

⚠️ **必须写明的限定**：其证据强度只有 **2**（7 页 workshop position 论文、单一基准 `OSWorld`、无 seed / 无消融 / 无 held-out、基线取自公共榜单且口径不齐）。**它的 A 级落在范式与 L2 零件上，不在证据上**——不写明这一点就会被误读为「实测证明了 C2」。

## 4. 七个组合方案包

每个包 = 一个可独立验收的组合。括号内是**目标缺口**。

### 包① 判据健康度包（P0，**零代码依赖、零算力**）

- **目标**：判据饱和（0.9814）、0/33 读不出差、债务 25「记录数字不复现」
- **接口形态**：作为**七条验收实验的前置检查表**，**不改任何模型代码**；`V_τ` 是唯一的可执行件
- **前置**：**零**
- **判据**：对每条现有判据给出「能否分辨强弱臂」的二值结论，并给出各情境的 `V_τ` 分布；同时落两本台账：**`Aspire` 式三层产出**（`best / eligible / selected / retained`，以 base 为锚）与 **`TTCS` 式自洽性 `s`**（`|s−0.5| ≤ δ` 才是有分辨力的情境）
- **证伪**：若绝大多数判据都能分辨强弱臂 ⇒ 饱和只发生在「危险回避率」这一条，检查表从「前置」降为「常设」

## 5. 五处跨论文矛盾与所需裁决

这五处是**跨论文的**（单张卡只能看到自己那一半），需要项目层面裁决。

### 矛盾 1 · C8 分界线（**已裁决**，此处只补第二条独立证据）

裁决见 [docs/03 §10](../../03-architecture-spec.md)。原判据来源是 `GroupEvolving` Table 3（结构迁移跨模型成立）。**本次新增第二条独立证据**：`AgentKB` Fig.6 的**跨域不对称**——reasoning 经验迁到 SWE 后仍 37.0%，而 SWE 经验迁到 GAIA 只剩 56.4%。两篇、两个团队、两种任务族，结论一致：**可迁移的是抽象后的 workflow/策略，不是具体经历。**

→ 建议在 [theory-design-plan.md](../../theory-design-plan.md) §3.4.1 补引 `AgentKB` Fig.6。**无需再裁**。

### 矛盾 2 · 经验能否内化进权重（**未裁决，且直接对立**）

- `EvolveR`：**内化有害**——把经验吸收进权重后 0.382 → 0.371（Table 11）；
- `RetroAgent`：**内化有益**——「教训内化」是其 SOTA 的组成部分，4×H200 / 14.61–16.94 h。

两篇同期、同类任务、结论相反。SSEA 默认取 `EvolveR` 侧（C3 三分离），但**默认不等于裁决**。

→ **需裁决并记录理由**，否则将来若开 Δθ，双方各能引一篇。建议的裁决口径：内化的代价是**不可检索 / 不可遗忘 / 不可回滚**（等价于 `SelfConsolidation` 的反面角色），在 SSEA 的三分离纪律下**代价高于收益**。

### 矛盾 3 · 验证信号从哪来（**需裁决「先测验证器」这一步**）

- `OpenSkill`：自建虚拟验证器（**模型可出题**）；
- `ScaleEnv`：确定性终局状态检查（**明确拒绝 LLM-judge**）；
- `Agent-World`：LLM-as-judge + 可执行 `V_code` 混合。

SSEA 只能取 `ScaleEnv` 形状（C9）。但 `OpenSkill` 指出一件 SSEA **至今没做过的事**：**测量验证器自身的假阳 / 假阴 / 一致率**。

→ 需裁决：**验证门要不要先做一次自我测量**（即门自己先过一个「能不能变红」的体检）。本图谱建议**要**——理由与债务 26 的教训同源：一个从不变红的门与一个恒为 0 的计数在观感上不可区分。

### 矛盾 4 · 第四类对象归属（**架构级裁决，零成本，且阻塞 MemSkill 全部落地**）

`MemSkill` 提出「**记忆技能**」——管记忆的程序（抽取/巩固/剪枝），由难例驱动演化。它落在 SSEA 三分离（权重/记忆/技能）的**缝里**：

- 是 ΔM 的**元层**？→ 那它随记忆一同被遗弃，且无法独立演化；
- 是 ΔR 的**一个子类**（ΔR-proc）？→ 可复用现成的规则通道，但 `rules` 目前**零消费者**；
- 还是**独立第四类** ΔP？→ 需新增结构种类，进而需改 `MUTATION_SCOPES` 与白名单。

`MemSkill` 卡片自陈建议：**独立第四类 ΔP，发布通道并入 ΔR-proc，属 GenePackage 本能段**（不并入 ΔM，不并入 ΔS）。

→ **这是本图谱认为最该先做的一个裁决**：它零成本（纯文档），但**不裁就无法判断记忆侧元程序算不算可遗传结构**，也就无法设计 §3.4.1 的跨代边界。

### 矛盾 5 · 先修「取之准」还是先修「存什么」（**需裁决优先级**）

- 主张**先修选择**：`Memento` `MemRL` `AgentKB` `EvoRoute` `RetroAgent`（五篇，且都有实测；SSEA 的 `retrieve` 命中率 0.5164 是有分辨力的现状数字）；
- 主张**先修内容**：`ReasoningBank` `ACE`（两篇，且都指出内容形态是空的）。

SSEA 现状的实际形状是：**选择侧有数字（0.5164），内容侧是空的**——债务 29 实测 `heritable()` **0/88**，且**类型判据 100% 拦截**（88 条里 0 条 RULE/SKILL）。

→ 本图谱建议**先内容后选择**，理由是：**选择器没有可选的东西，调它测不出差**。这与「先怀疑尺子」同源——但这里「尺子」的毛病在于**被量的东西不存在**。

→ 需裁决。若采纳，则包② 排在包③ 之后。

## 6. 收敛发现：五篇独立论文指向同一个缺失件

这是本次通读 52 张卡片后**唯一一个所有卡片都没写、但把它们并排就能看出来的形状**。

### 6.1 五篇独立论文都把「LLM 抽象算子」当作核心部件

| 论文 | 它的核心部件 | 卡片自陈 |
|---|---|---|
| `EvolveR` | 经验抽象算子（LLM） | 「非语言抽象算子」是**隐性高成本**，SSEA 需自建 |
| `RetroAgent` | 反思算子（LLM） | pairwise 归纳把幻觉 8.8% → 3.8%；「非语言反思算子」需自建 |
| `ExperienceSynthesis` | 经验合成器本体（LLM） | 合成器本体是 LLM，**不可搬** |
| `MemSkill` | 技能设计者（LLM designer） | 其 3–6 号建议**显式依赖缺失的 `RuleCompiler`** |
| `SkillRL` | 失败侧蒸馏（LLM） | 必须产出**结构化、非文本**的教训 |

五篇互相不知道对方，却指向同一个部件：**把「具体经历」变成「可复用结构」的那个算子**。它们的实现都是 LLM 调用——**SSEA 没有 LLM，所以这五篇最值钱的部分在 SSEA 里全部坍缩为「必须自建一个非语言版本」。**

### 6.2 把它接上本会话已有的两条发现

- **债务 29**：可继承记忆通道（`RULE`/`SKILL`）**没有生产者**。`_classify()` 的 docstring 自陈「RULE / SKILL 不由本函数产出——它们是编译产物（慢环），经 `write_item()` 直接入库」，而那条入库路径的**唯一调用方是测试**。实测 `heritable()` **0/88**。
- **`rules`(ΔR) 零消费者**：结构化规则通道存在，但没人读。
- **实验 3 的 0/33**：技能固化判据读不出差。

### 6.3 形状

> **SSEA 缺的不是「记忆」，也不是「技能」，而是中间那个把具体经历变成可复用结构的非语言算子。**
>
> 它同时是**三条卡点的共同上游**：实验 3 的 0/33、债务 29（可继承记忆无生产者）、`rules` 零消费者。

这个形状的解释力在于：它**一次说清三件看起来无关的事**——为什么记忆库能写满却一条可继承的都没有；为什么规则通道建好了没人用；为什么技能固化怎么改判据都读不出差。三者的共同上游是同一个缺失件。

### 6.4 文献给得起什么、给不起什么（**本图谱的核心判断**）

**给不起**：算子的实现。五篇的实现全是 LLM 调用，SSEA 一条都不能用。

**给得起**：算子的**接口规格**。这四件合起来已经是一个可写的规格：

- `PSN` —— 输出必须是**带契约（前置/后置条件 + 子技能调用）的可执行结构**；
- `RecordReplay` —— 输出必须**参数化**（带变量与约束，而非逐帧照定），并附 **check function** 作为边界；
- `ExperienceToStrategy` —— 抽象分**三层**：原始轨迹 → canonical path（FSM 规范化）→ 结构化策略原则；**M 层就是 `rules` 的第一个消费者**；
- `InducingProgrammaticSkills` —— 粒度契约：步数区间 + 动作白名单 + **参数只用可序列化标量**；入库三判据 + 尾随动作截断；
- `LLMasCode` —— 算子的**输出载体**有了外部先例：结构改进的固化形态是**可执行代码**（「提案 → 测试 → commit as code」），而不是文本或权重。

### 6.5 顺带得到一个判断（标记为**推断**）

它的**前置依赖最少**：不需要新概念（不像 Gene Manager 需要「个体 / 种群 / 共享」一整套语义）、不需要新通道、不受 C1–C10 任何一条新约束——它就是一个**纯函数** `trace → 候选结构`，其正确性由已有的四级验证门判定。

代价是它**没有外部对照**：五篇文献都把它交给 LLM，没有一篇给出非语言版本的可行性证据。所以这是 SSEA 里**最需要自己发明的一块**，也是最容易被跳过的一块——因为它不是一个「论文可借鉴」的对象。

## 7. 卡片集未覆盖的缺口

以下是 52 张卡（266 篇 PDF）**没有提供供给**的问题。它们**不是我们的疏漏**，而是应写进文档的**文献空白声明**——空白本身是信息：它说明这些部分**必须自建且没有外部对照**。

5. **疾病 / 衰老 / 死亡**（[plan](../../theory-design-plan.md) §3.1 / §3.5）：**0 篇**。
6. **继承的保真度**：**没有一篇测量「结构跨代传递之后还对不对」**。⇒ `GenePackage` 的验收判据**无外部参照**，必须自定。
