## 1. 一句话定位

- **论文主张**：测试时训练（TTRL）在难题上会因**多数投票收敛到错误共识**而产生噪声伪标签、且原始测试题远超模型能力而**没有可学样本**；TTCS 用**同一个预训练模型**初始化两个策略——**Synthesizer**（就每道测试题生成「结构同构、表面不同」的课程变体）与 **Solver**（在测试题 + 合成题的混合批上自演化），Synthesizer 的奖励是 **R_cap = (4·s(1−s))^γ**（s 为 Solver 的**自洽性/多数投票一致率**，γ=1.2，目标 s≈0.5），Solver 侧用 **\|s−0.5\|≤δ（δ=0.25）在线过滤**只保留前沿样本；两策略用 GRPO 迭代共演化。结果：Qwen2.5-Math-1.5B 平均 17.30 → **41.49（+24.19）**，7B 26.02 → **52.54**，Qwen3-4B-Base 34.58 → **47.21**，全面超过 TTRL / R-Zero / Self-Consistency（Table 1 p7）。
- **对 SSEA 的意义**：它把「**课程难度该定在哪**」从一个 **完全无标签**的信号（模型自洽性）里算出来——这正是 GenEnv 做不到的（GenEnv 必须有 checker / ground-truth 才存在 p̂）。SSEA 当前**没有课程**，且两条判据分别贴在**天花板**（危险回避率两臂均 0.9814 → 方差 4s(1−s)≈0.073，信号被压缩约 **13.7×**，笔算推断）与**地板**（技能固化 0/33）上；TTCS 的 s≈0.5 前沿带提供了一台**不依赖标准答案的判据分辨力校准器**。**反面**：它同时是 C9 的又一具反例标本——R_cap 是**显式奖励**、Synthesizer 被 GRPO 训练、且**被考者的成绩直接驱动下一轮任务分布**（与 GenEnv 同一条反馈通道）。

## 2. 问题 — 机制 — 证据

### 2.1 论文要解决的问题
- **问题本身**（§1 p1–2）：Test-Time Training（用测试题本身做无标签自适应）在**困难推理题**上失效。
- **它指出的既有方案缺陷**（§1 p2、Fig 1 p2）：
  1. **伪标签不可靠**：难题（如 AIME24）上多数采样回答**本身就是错的**，多数投票收敛到**错误共识**，产生系统性噪声奖励，"主动把策略引向错误的推理路径"；
  2. **缺少可学样本**：TTRL 直接优化一小撮远超当前能力的测试题，"没有中间变体搭桥，学习过程陡峭且常常爬不上去"（引 Briesch et al. 2024 自消耗训练循环）；
  3. **对既有 TTT 的批评**：AlphaProof 等虽有测试时学习潜力，但**依赖更强的 LLM 做数据合成**，不构成"完全自主自演化"（§2 p3）。

### 2.2 核心思想（关键 insight）
1. **把"出题"做成与"解题"共演化的第二条策略**：Synthesizer π_φ 与 Solver π_θ **从同一预训练模型初始化**（§4 p4），Solver 当**隐式评委**给合成题打分，Synthesizer 据此学会"出恰好难住 Solver 的题"。
2. **难度对准 = 把自洽性钉在 0.5**：`R_cap(x′)=(4·s(x′)(1−s(x′)))^γ`（Eq.7 p5），钟形、峰值在 s=0.5，同时惩罚"已掌握"（s→1）与"无望"（s→0）。
3. **为什么是 0.5（本篇的理论支柱，Appendix C.1 p16–17）**：GRPO 的更新幅度由优势 A_i 调制，二值奖励 r∈{0,1} 服从参数 p_θ 的 Bernoulli，`Var(r)=p_θ(1−p_θ)`；p→0 或 1 时优势方差塌缩 → 梯度更新消失；p≈0.5 时方差最大 → 梯度估计的期望幅度最大。**即"最大化学习信号 ≡ 把 s 推到 0.5"**（Eq.12–13 p16–17；用 Hoeffding 界证明 s 以指数速度集中到 p_θ）。
4. **信号可以完全无标签**：s 由**多数投票一致率**给出（Eq.6 p5），**不需要任何 ground-truth / checker**——这是本篇区别于 GenEnv 的唯一实质增量。
5. **"自适应 > 更强教师"**：把一个**冻结的、强得多的 Qwen2.5-14B-Instruct** 当 Synthesizer，只带来 +2.66 分；而共演化的 1.5B Synthesizer 带来 **+5.34 分**（Table 2 p8、§5.3 Q3 p8–9）——课程的可适应性比教师绝对能力更决定性。

### 2.3 关键机制 / 算法（可独立搬运的「零件」清单）
| 零件 | 输入 → 输出 | 作用 | 出处（节/式/图） |
|---|---|---|---|
| **能力自适应奖励 R_cap** | 自洽性 s(x′) → 标量奖励 | 把合成题难度钉在 s≈0.5 前沿 | Eq.7 p5；理论 Appendix C.1 p16–17 |
| **自洽性分数 s(x′)** | K 个 Solver 回答 + 多数投票 ŷ → 一致率 | **无标签**的难度观测信号 | Eq.6 p5；K=10（§5.1 p7） |
| **相似度惩罚 R_sim** | 合成题 vs 测试题 / 同批其他合成题 → 惩罚 | 防抄题、防同质化、抗 mode collapse | Eq.8 p5；R_ref Eq.14 p18；R_group Eq.15–16 p18 |
| **最终奖励 R(x′)** | I_valid·max(0, R_cap − R_sim) | 格式合规门 + 净奖励 | Eq.9 p5 |
| **在线数据过滤** | 样本自洽性 s(x) → 保留 \|s−0.5\|≤δ 的样本 | **只在前沿带内做训练**（判据分辨力的闸门） | §4.2 p6；δ=0.25 |
| **混合批构造 B_train = B_test ∪ B_syn** | 测试题 + 合成题 → 训练批 | 重采样控制测试/合成比例，**防模型崩溃** | §4.2 p6（引 Shumailov 2024） |
| **同构问题生成 Prompt 模板** | 参考题 → 结构同构、表面不同的变体 | 课程变体的数据契约（含可验证复杂度度量、单标量输出锁、fail-safe 规则） | Appendix D p20–21 |
| **双策略 GRPO 共演化** | π_φ / π_θ → 各自 GRPO 更新 | 两个玩家、两个目标 | Alg.1 p19；Table 5 p15 |
| **问题演化案例追踪** | 逐迭代合成题 → 结构/难度/领域迁移四类标注 | 课程漂移的定性监控 | §5.5 p9、Table 4 p10 |

### 2.4 关键表示与数据结构
- **两个策略** π_φ（Synthesizer）与 π_θ（Solver）**均从同一预训练模型初始化**（§4 p4）→ 出题者与被考者**同源、同规格**。
- 合成题 `{x′_i}^M_{i=1} ~ π^t_φ(·|x_test)`，M=4（§5.1 p7）；每道合成题由 Solver 采 K=10 个回答估计质量（§5.1 p7）。
- Solver 训练批 `B^t_train = B^t_test ∪ B^t_syn`，测试题**跨迭代重复采样**以控制比例（§4.2 p6）。
- 持久态：π_φ 权重 + π_θ 权重（Alg.1 p19 返回 π^T_φ, π^T_θ）。**无记忆库、无技能库、无检索结构、无基因包**（全文未见 memory / skill / genealogy 构件，推断）。
- 合成题的数据契约（Appendix D p20–21）：必须给出**唯一一个具体复杂度度量**（#cases / #factor-pairs / DOF / independent-axes / key-steps）、**最终答案锁为单标量**、禁止集合/函数/布尔/证明/子问题——即"**可验证性 + 可比性**"的双约束。

### 2.6 论文自陈局限与边界条件
- **论文无独立 Limitations 章节**（核对：p10 为 Conclusion，p11–13 为 References，p14–21 为 Appendix A–D）→ 以下为从正文假设与设置推出的边界条件，**非论文自陈**。
- **假设依赖**：
  1. **必须有可判对错的题目**（最终答案可抽取比对）：附录 A.2 p14 说明数学题用 **GPT-4o-mini 辅助判定预测答案是否与 ground-truth 匹配**——即评测端**存在观察员评分**；训练端虽无标签，但**任务域本身是可验证的**（单标量答案）。
  2. **自洽性 s 只度量"不确定"，不度量"对错"**：s=1 可以是**全体一致地错**（这正是论文批评 TTRL 的场景，Fig 1a p2）。因此前沿带 s≈0.5 是**不确定性代理**，不是能力代理。
  3. 同构性依赖**语言提示模板**（Appendix D p20–21）与 LLM 对"结构同构"的判断，**无形式化保证**（推断）。
- **明确不适用 / 未覆盖的情形**：
  - **算力/时间代价完全未报告**：全文无 wall-clock、无 FLOPs、无显存、无每步成本（**未提及**）；只有"数据效率"曲线（Fig 4 p9）。
  - **统计口径缺失**：Table 1/2/3 全为单值，**未给 seed 数、方差或置信区间**（未提及）。
  - **超参敏感性未做**：γ=1.2、δ=0.25、K=10、M=4、λ1=λ2=1.0 均为定值（§5.1 p7、Table 5 p15），**无扫描**（未提及）。
  - **被考者反向操纵难度通道的风险未分析**（未提及）：Solver 只要改变自己的自洽性，就能改变 R_cap，进而改变下一轮课程分布——与 GenEnv 同构的失效模式，论文**未讨论**。
  - **共演化崩溃风险只被间接承认**：论文明说 R-Zero "unstable under extended iterations"（§5.3 Q1 p8），并以相似度惩罚 + 混合批重采样对抗 model collapse（§4.1–4.2 p5–6、引 Shumailov 2024），但**没有给出稳定性判据或监控指标**（未提及）。
  - 域：数学/通用推理（AIME、AMC、MATH-500、Minerva、OlympiadBench、MMLU-Pro、SuperGPQA、BBEH），**非生存域**；无死亡代价、无资源约束、无个体淘汰、无遗传。

## 3. SSEA 立场对齐（核心维度）

### 3.1 C1–C10 映射
| 裁判标准 | 判定 | 依据（论文中的具体机制/数字） | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制架构，非语言生成 | **✗** | 两个策略都是 LLM（Qwen2.5-Math-1.5B/7B、Qwen3-4B-Base，§5.1 p6）；控制对象是无死亡/无资源约束的解题 | 只搬"难度档位调度律"这一条**控制律**，落到 SSEA 风格化环境的**结构化物理参数**（危险密度/资源稀缺度），载体换成非语言控制器 |
| **C2** 自然语言只作观察员接口 | **✗** | 自然语言既是题目表示又是策略本体；同构性判断与课程生成全在语言层；**评测端用 GPT-4o-mini 判分**（Appendix A.2 p14） | 难度带规则可留；语言载体与 LLM 判分一律不进控制闭环 |
| **C3** 权重/记忆/技能三分离 | **✗** | 双策略都做 GRPO **权重更新**（Alg.1 p19、Table 5 p15）；**无记忆、无技能、无分离** | 拒收权重更新；仅借"**两本账分置**"的形状（经验账 vs 档位台账），与 SSEA 的 ΔS/ΔM/ΔR/Δθ 分账同构 |
| **C4** 低算力低带宽 | **✗** | 每步：M=4 合成题 × K=10 Solver 回答（估计质量）+ G=8（难题 16）Solver rollout + 两个 LLM 的 GRPO 更新（§5.1 p7、Table 5 p15）；**成本未报告**（未提及） | 完整框架绝不进闭环；只取**不耗算力的判据规则**；且须注意：本篇的采样放大（M×K×G）**加剧**而非缓解"睡眠期预算未定义" |
| **C5** 精准回忆历史 | **—** | 无记忆库、无检索、无写入/遗忘/合并；仅"跨迭代重复采样测试题以控比例"（§4.2 p6） | 不搬；精准回忆仍走 Memento / FLEX 主干 |
| **C6** 可自主修改自身 | **◐** | 智能体不改自身代码；但**系统的任务分布由系统自身在线生成并被优化**（Synthesizer 被 GRPO 训练，§4.1 p5）→ 自修改发生在**任务生成侧/元层面** | 启发是"**慢环可以改任务分布，但不改判据**"——把提案权限定在难度旋钮上 |
| **C7** 可保存/恢复/变异/继承 | **✗** | 有迭代与权重 checkpoint（Alg.1 p19）；**无** GenePackage、无变异、无继承、无淘汰 | 不搬；仅作对照（"共演化"≠"达尔文闭环"：TTCS 有共演化但**无淘汰、无繁衍**，与 GenEnv 判定一致） |
| **C8** 给基因先验，不给知识语料 | **◐**（机制 ✓ / 载体 ✗） | **加分**：① 测试时**完全无标签**（不喂任何外部语料，§4.2 p6）；② "**自适应 > 更强教师**"（共演化 1.5B +5.34 vs 冻结 14B +2.66，Table 2 p8）→ 直接支持"不必靠更强模型/知识语料堆砌"；**扣分**：两个策略都是**预训练 LLM**（人类知识语料压缩物，同 Agent0 判定），且同构性依赖人工提示模板（Appendix D p20–21） | 前沿带**规则**可进结构性先验（难度档位调节律）；LLM 载体与提示模板语料一律不进基因包 |
| **C9** 不设评分函数，只有淘汰函数 | **✗**（主战场，但**信号源与 GenEnv 不同**，须逐层拆开——见 §5.1） | ① 无外部评分函数 ✓（s 来自模型自身多数投票，**不需要 ground-truth/checker**，Eq.6 p5）；② 但 R_cap/R_sim 是**显式奖励**，Synthesizer 被 GRPO 训练（Eq.7–9 p5、Alg.1 p19）→ **奖励塑形**；③ 被考者的 s **直接驱动下一轮任务分布**（s → R_cap → π_φ → 课程）→ **反馈通道**；④ 评测端 **GPT-4o-mini 判分**（Appendix A.2 p14）→ 观察员评分 | 见 §5.1 三步剥离：把 R_cap 从"奖励"降为**研究者侧确定性档位规则**，把 s 换成**环境侧可观测事实或诊断协变量**，**永不调节据本身**，并**禁止单个体的行为影响其自身难度档** |
| **C10** 创新在 L2/L3/L4，不在 L1 算子 | **✓** | 无新算子；GRPO（Shao et al.）、多数投票（Wang et al.）、Hoeffding 全借用（§3 p3、Appendix C.1 p16–17）。创新在：测试时课程合成的信息流（L2）、能力前沿奖励协议（L2/L3）、双策略共演化结构（L4） | — |

### 3.2 L1–L4 层级定位
| 层次 | 论文在该层提供了什么 | 对 SSEA 的价值 |
|---|---|---|
| **L1 算子层** | 无（GRPO / 多数投票 / Hoeffding 全借用） | 无；符合借用立场 |
| **L2 信息流层** | 双策略共演化回路：**s 反馈通道**（谁观测谁）、混合批构造（B_test ∪ B_syn）、在线数据过滤 | **高**：与 GenEnv 同构的一张**反例图纸**——画出"被考者成绩 → 任务难度"这条线；但 TTCS 额外证明**这条线可以只用模型内部信号接通**，这是 SSEA 必须明确"接不接、接了付什么代价"的关键判据 |
| **L3 学习层** | 前沿带奖励 + 相似度惩罚 + 在线过滤 + 重采样比例控制 | **中**：形状可借（带死区、带温度 γ 的确定性控制律），但训练对象（LLM 权重）不可搬 |
| **L4 演化层** | 把"出题"变成可演化的一极（π_φ 有自己的目标与更新）；**"自适应 > 更强教师"** | **高（双向）**：正面——课程可无人工难度表地涌现，且**不需要更强教师**；反面——这条路仍配一个外部奖励，且**自洽性不等于正确性**，无客观锚点时可能"一致地错" |

### 3.3 模块映射
| 论文构件 | SSEA 落点（现有模块 / 缺失组件 / 新增建议） |
|---|---|
| **自洽性分数 s（无标签难度观测）** | 落点：**环境侧难度代理**——对固定策略快照、在难度档 d 下跑 N 个不同 seed/初始条件的 episode，`s(d)=与多数结果一致的 episode 比例`（或存活比例）。写入「档位—s 台账」，**不给模型**。这是 SSEA 侧的 s 类比物 |
| **前沿带（s≈0.5）+ γ=1.2 温度** | 落点：**验收实验的难度档位选择器**（研究者侧）。与 GenEnv 的 α=0.5/k_min=0.1、Agent0 的 [0.3,0.8] 合并为**同一份「档位准入规则」** |

### 3.4 债务与验收实验对应
- **判据饱和（危险回避率两臂均 0.9814）** → **最直接回应**。s≈0.5 前沿带 + \|s−0.5\|≤δ 提供"把难度调到哪才有分辨力"的无标签答案（见 §8）。
- **技能固化实验 3 实测 0/33** → 间接回应：0/33 既可能是**地板压缩**（s→0），也可能是**结构性不可能**；前沿带要求先扫 d 网格看 s(d) 是否可穿过 0.5，再判定。
- **SSEA 无课程** → **直接回应**：TTCS 是"测试时动态合成难度递增课程"的可运行样本（L2/L4 图纸）。
- **「睡眠期计算预算未定义」** → **不回应，且加重**：TTCS 每步 M×K×G 采样放大，且**自身未报告成本**（未提及）→ 它给"该调到哪个难度"，不给"要花多少算力"。样本量界须另取 GenEnv 的 Theorem 1。
- **债务 22（记忆二级门用常量阈值，慢环不可调）** → 不直接回应；但提供另一种思路：**阈值不必定在 reward 上，可以定在难度档位上**（把门开/关的差异放大到有分辨力的档位去测）。
- **债务 25/26/28（判据形状错、无消费者通道报成功、技能失效被判成成功）** → 不直接回应；只借"在线过滤 + 先看分母"的工程纪律。
- **Gene Manager 缺失（实验 4/5 卡住）、DeathHook 未接、`rules` 零消费者** → **不回应**。
- **七条验收实验** → 影响**全部**：一旦引入难度档位，所有基于存活率/回避率的纵向数字必须同时记录难度坐标，否则不可比（风险见 §5.4）。

## 5. 冲突、代价与风险

### 5.1 与硬约束的冲突（C9 是主战场，且**信号源判定与 GenEnv 不同**）

**先回答「课程合成的信号来源到底是什么」——这是 C9 严格判定的关键，必须逐层拆开：**

| 层 | TTCS 的实际做法 | 是环境侧事实，还是模型自评，还是外部评分？ |
|---|---|---|
| 单次判题 | **无 ground-truth**。Solver 对合成题采 K=10 个回答，取多数投票 ŷ_i（Eq.6 p5） | **模型自评**（内部信号），不是外部评分 |
| 自洽性 s(x′) = (1/K)Σ I[y_ik=ŷ_i] | 上述多数投票的**一致率**（Eq.6 p5） | **模型自评的聚合**——**无需 checker**（这是与 GenEnv 的本质差别） |
| R_cap = (4s(1−s))^γ（Eq.7 p5） | 用 s 当**奖励**，经 GRPO 训练 Synthesizer π_φ（Alg.1 p19） | **奖励塑形**，对象是"任务生成"这一极 |
| 评测口径 | 数学题用 **GPT-4o-mini 辅助判定**答案是否匹配（Appendix A.2 p14） | **观察员评分**（评测端） |

**结论（明确判定）**：TTCS 的难度信号**不是外部评分**（不违反 C9"不设外部评分函数"的**字面**），但**是模型自评 + 显式奖励塑形 + 一条从被考者通向其自身难度的反馈通道**，构成 C9 三重违规：

1. **C9"只有淘汰函数"违反**：TTCS **没有任何淘汰函数**——无死亡、无资源耗尽、无个体淘汰。它的唯一选择压力是**被最大化的塑形奖励** R_cap。C9 要求选择压力归环境，TTCS 把选择压力交给了优化器。
2. **C9"奖励塑形一律违规"违反（最直接）**：R_cap 与 R_sim 都是**显式奖励**，用于 GRPO 训练 Synthesizer（Eq.7–9 p5）。此外 s 一旦被"最大化"，就从"观测"变成"目标"，**其定义随优化漂移**——这同时违反 C9②"内部驱动的定义不可改"。
3. **C9 精神违反（对 SSEA 最致命）**：**存在一条从被考者行为到其任务难度的显式反馈通道**。Solver 只要改变自己的自洽性，就能改变 R_cap → 改变 Synthesizer 的出题分布 → 改变自己下一轮的训练课程。这条通道在 TTCS 里是特性（自适应），在 SSEA 里是禁区。
4. **附带**：评测端用 GPT-4o-mini 判分（Appendix A.2 p14），是典型的**观察员评分**，与 C2/C9 精神冲突。

**TTCS 相对 GenEnv 的 C9 增量（必须写清楚，否则会误判为"更合规"）**：
- **好处**：s 不需要 ground-truth / checker（Eq.6 p5），所以 C9① 的"外部评分函数"**不被违反**；对**没有标准答案的生存域**，这是唯一可计算的难度代理。
- **代价**：**s 度量的是"不确定"，不是"对错"**——s=1 可能是"全体一致地错"（Fig 1a p2 正是论文批评 TTRL 的失败模式）。因此 TTCS **缺少一个客观锚点**；Agent0 靠 Python 沙盒、GenEnv 靠 checker 提供这个锚点，TTCS 没有。对 SSEA 的含义：**前沿带可以借，但必须自己补上"环境侧存活事实"这个锚**，否则校准器会在"一致地错"时给出虚假的高分辨力。

**三步剥离方案（把可搬的部分从违规外壳里取出来）**：
1. **换掉用途**：把 R_cap 从"用于训练出题器的奖励"降为**研究者侧的确定性档位选择规则**（无学习、无打分、无排序）。
2. **换掉信号源（或降级为协变量）**：s 只作**诊断协变量**，与**环境侧可观测的存活事实**（存活到 T / 资源未耗尽 / 危险未致死）**并列记录**；档位准入以**环境侧事实**为准，s 只用于解释"为什么这一档没有分辨力"。
3. **切断细粒度通道**：若档位规则要进运行时生态，只允许消费**跨代、大窗口、跨个体聚合**的统计量，使**单个体的行为无法影响它自己所在的难度档**。

**经此三步后，C9 从 ✗ 变为"研究者侧的 ◐"**：在**实验设计层**使用合规；在**运行时生态层**使用仍属高危，须先过 C9 复核。

其余冲突：**C1/C2/C3/C4** 见 §3.1——LLM 双策略载体、自然语言进控制环、权重更新、M×K×G 采样放大，四项均与 SSEA 硬约束冲突；处理方式同 GenEnv / Agent0 / WebRL：**框架不进模型，只取零件**。

### 5.2 隐含假设与失效条件
- **需要"可判对错的任务"**：TTCS 的训练端无标签，但**任务域必须存在唯一正确答案**（Appendix D p20–21 的输出锁；Appendix A.2 p14 的判分）。SSEA 的生存行为没有标准答案——剥离方案第一步必须把"档位"建立到**环境侧事实**上。
- **自洽性 ≠ 能力（本篇最隐蔽的失效点）**：s≈0.5 只说明模型"拿不准"，不说明题目"有信息量"。若 SSEA 环境的**随机性（aleatoric）**本身很大，s 也会≈0.5，此时前沿带会**误报**为"有分辨力"。**必须把"环境随机性引入的 s 下降"与"能力边界引入的 s 下降"分开**——GenEnv 的 checker 版 p̂ 没有这个歧义，TTCS 的 s 有。
- **难度漂移摧毁纵向可比性**（同 GenEnv）：一旦装上档位，判据数字会**被人为拉到 0.5 附近**，历史数字与未来数字不再可比。强制对策：把难度坐标 d 与 s 一起记录，"同一档位下的纵向比较"为唯一合法对比。
- **无客观锚点 → 共演化崩溃**：论文自己承认 R-Zero "unstable under extended iterations"（§5.3 Q1 p8），并以相似度惩罚 + 重采样比例控制对抗 model collapse（§4.1–4.2 p5–6、引 Shumailov 2024）；但**未给稳定性判据**。SSEA 若照搬"无锚点自洽性回路"，退化模式是**一致地错**而非发散。
- **超参未扫描**：γ=1.2、δ=0.25、K=10、M=4 均为定值（§5.1 p7、Table 5 p15）；前沿带的**宽度**与**温度**在 SSEA 语义下需重新标定（推断）。
- **统计口径缺失**：Table 1–3 均无 seed/方差（未提及）。

### 5.3 算力 / 带宽 / 工程代价
- **完整框架**：两个 LLM 策略 × GRPO；每步 M=4 合成题 × K=10 Solver 回答 + G=8（难题 16）rollout + 两次权重更新（§5.1 p7、Table 5 p15）→ **重资产，与 C4 冲突，不搬**。论文**未报告任何 wall-clock / FLOPs / 显存**（未提及）。
- **只搬零件（资产 1/2/3/5/6）**：代价低——只需在现有风格化环境上增加一个**连续难度旋钮 d**、一本**档位—s 台账**、一条**档位准入规则**与一个**比例闸**。无新模型、无训练、无带宽增长。
- **隐性成本（重要）**：把判据从 s≈0.98 拉到 s≈0.5，会**提高**判据的方差（Bernoulli 方差 p(1−p)/n 在 p=0.5 最大），**分离同样大小的效应量需要更多 episode**。即**难度对齐不是免费的，它用算力换分辨力**——与"睡眠期计算预算未定义"正面相撞。

### 5.4 搬运后的可能退化模式（若失败，会以什么形式失败）
1. **"环境噪声"被误读为"能力边界"（本篇特有、最危险）**：若难度旋钮实际在调"环境随机性"而非"任务难度"，s(d)≈0.5 会在**所有档位**出现 → 症状：s(d) 曲线平坦，两臂差异不随 d 系统变化。
2. **假阴性被误判为假阳性**：把难度调到前沿带后两臂终于出现差异，但差异其实是**档位引入的方差** → 症状：差异随 d 抖动、跨 seed 不重现、换邻近档位符号翻转。
3. **档位漂移污染纵向比较**：各版本在不同档位上测得的数字被当成同一指标 → 症状：存活率长期持平在 0.5 附近，但"能力"结论无法支撑。
4. **难度旋钮被反向利用**：若旋钮与个体行为挂钩，智能体学会"表现差一点换简单档" → 症状：s 稳定但**环境侧复杂度代理不升反降**。需自备一个复杂度代理指标（对标 TTCS 的"问题结构复杂度增长" Table 4 p10）。
5. **地板而非天花板**：若技能固化 0/33 是**结构性不可能**（技能表示无法表达该技能），无论 d 怎么调 s 都贴 0/1 → 症状：任何 d 都无法让 s 穿过 0.5。此时 TTCS 的带无用，应转向债务 26 与"技能表示够不够"。

### 6.1 关系图谱
| 关系 | 对象（点名） | 说明 |
|---|---|---|
| **最近亲（同构兄弟）** | **GenEnv** | 目标函数同形：GenEnv 的 `R_env=exp(−β(p̂−α)²)`（α=0.5）与本篇 `R_cap=(4s(1−s))^γ` 都是"把难度钉在 0.5"；GenEnv 的 k_min=0.1 死区与本篇 \|s−0.5\|≤δ=0.25 过滤同构。**分工**：GenEnv 提供**样本量界（Thm 1）+ checker 版 p̂**；TTCS 提供**无标签版 s**。**合并即 SSEA 的完整「档位准入 + 样本量」规则**——TTCS 单独使用缺少"要多少 episode"这一半 |
| **同构（前沿带）** | **Agent0** | Agent0 的课程奖励 = 自洽性 p̂ 接近 0.5 + 工具调用频率 − 重复惩罚（Eq.2–5），执行侧用 **[0.3,0.8] 前沿带**过滤（δ=0.25）——与本篇 R_cap + \|s−0.5\|≤δ **几乎逐项对应**。差别：Agent0 插了 **Python 沙盒**这个客观外部锚点，TTCS **没有锚点** → 对 SSEA 的启示是"**带可以借，锚必须自己给**" |
| **同族（自演化课程 / 任务从哪来）** | **WebRL** | WebRL 从**失败尝试**造任务，TTCS 从**给定难题**造"结构同构、表面不同"的阶梯变体。分工：WebRL 解决"任务从哪来"，TTCS 解决"如何为一道**已知过难**的题搭阶梯"。WebRL 的错误分类法 + TTCS 的在线过滤可合成一套失败模式台账 |
| **同族（测试时学习，机制相反）** | **EvoTest** | 同为测试时学习：EvoTest **无梯度**演化整机配置 χ + UCB 选择 + 成功/失败双记忆；TTCS **有梯度**共演化双策略权重。对 SSEA：EvoTest 的"不动权重"证据支撑 **C3**，TTCS 的权重共演化是 **C3 冲突件**——两篇并读即为"测试时学习该动什么"的正反两面 |
| **互补（合成什么）** | **Experience Synthesis（DreamGym）** | TTCS 合成**问题（课程）**，DreamGym 合成**经验（反事实状态—奖励转移）**。二者互补：TTCS 给"该出多难的题"，DreamGym 给"这道题的后果是什么"。两者的奖励熵 `V_τ` 与自洽性前沿带是**同一族难度选择器**（都挑"两臂有差别"的情形） |
| **前置/对照（自动课程）** | **Voyager** | Voyager 的自动课程是**启发式 + 语言提示**（"下一个任务该做什么"），无目标带、无理论、无样本量；TTCS 补上**目标带（s≈0.5）+ 方差理论（p(1−p)）**。反之 Voyager 有**键/值技能库**（持久技能资产），TTCS **完全没有** → 二者是"课程"与"技能"两侧的互补，且共同点出 SSEA 缺的是**课程** |
| **同族（零数据共演化）** | **R-Zero** / **Socratic-Zero** | R-Zero 是 TTCS 的基线（Table 1 p7）且被论文指出"延长迭代不稳定"（§5.3 Q1 p8）；Socratic-Zero 是数据-free 双智能体共演化。三篇同族，TTCS 的增量是"把课程难度显式对准 0.5 并给出无标签信号" |
| **风险对照** | **Misevolve** / **RAGEN** | 自演化误演化威胁模型：TTCS 的"被考者 → 自洽性 → 课程难度"反馈通道应作为 Misevolve 红队清单的**新增一条**；RAGEN 的 Echo Trap 诊断用于监控"共演化退化为自我确认（一致地错）" |
| **替代** | 人工难度档 / Voyager 式启发课程 | TTCS 的 s≈0.5 带可替换"拍脑袋定难度"与"启发式递增" |
| **同域对照（数学自演化）** | **SPICE** / **SwS** / **LADDER** | SwS 是"弱点驱动出题"、LADDER 是"递归问题分解"、SPICE 是"语料环境自博弈"——与本篇同族，TTCS 的差异化在"测试时 + 无标签 + 前沿带" |

### 6.2 推荐组合方案
1. **首选（立即可做，P1）**：**TTCS（无标签 s 前沿带 + 在线过滤）× GenEnv（α 带 + Thm 1 样本量）× Agent0（前沿带规则 + 客观锚点原则）× SEDM（A/B 准入）** → 合成「**判据分辨力校准器（无标签版）**」
   - 接口形态：`档位选择(d 网格, 目标 s≈0.5, δ=0.25) → d*` + `n_needed(Δ, δ_mis) → 每臂 episode 数`（后者来自 GenEnv Thm 1）；
   - 组合后新增能力：在**没有 ground-truth 的生存域**也能算出"哪个难度档有分辨力"；
   - 新增风险：见 §5.2 第 2 条（**环境随机性被误读为能力边界**）。
2. **省算力版**：**TTCS × Dream-RSI** —— 先用重放/模拟离线估 `s(d)`，只对落在前沿带附近的档位花真实 episode 预算。
3. **第二阶段生态（远期，须先过 C9 复核）**：**Genie（可参数化世界）× ScaleEnv/EnvScaler（可验证性）× TTCS/GenEnv（前沿带控制律，改为环境侧确定性、跨代聚合）** —— 难度由**环境自身动力学**驱动，淘汰函数仍是"存活/死亡"这一模型碰不到的事实。
4. **不推荐**：TTCS × 任何权重 RL 组合（与 C3/C4/C9 叠加冲突）。

### 6.3 本篇在组合中的典型角色
- **无标签判据分辨力校准器 / 档位准入信号源**——管"在没有标准答案时，把测量放在哪个难度上"；**不是**任务生成器，也**不是**奖励源。
- 附带身份：**C9 的第二具反例标本**——与 GenEnv 并读，界定"外部评分 vs 模型自评"两种违规形态，并说明**两者都不许进 SSEA 的淘汰面**。

## 8. 裁决与下一步

- **应用等级：B 零件采用** —— 采用「**无标签自洽性前沿带（s≈0.5）+ 在线数据过滤 \|s−0.5\|≤δ + 混合批重采样比例控制 + "自适应 > 更强教师"判决实验范式 + 难度坐标协变量记录**」这五件**不依赖权重 RL 的零件**，作为**判据分辨力校准器的无标签信号源**；**不采用** Synthesizer/Solver 权重共演化回路、R_cap/R_sim 奖励塑形、LLM 载体与语言课程生成、GPT-4o-mini 判分。
- **优先级：P1** —— 它同时回答 SSEA 当前两个最紧的诊断（**无课程**、**判据饱和**），且其**唯一实质增量（信号无需 ground-truth）**恰好绕过 SSEA 最硬的落地门槛。**注意**：须与 **GenEnv** 合并使用——TTCS 只给"调到哪个难度"，不给"要多少 episode"（无 Theorem 1 类样本量界）。

### 建议动作
1. **给风格化环境加一个连续难度旋钮 d**（危险密度 / 资源稀缺度 / 干扰强度三选一，先只加一个），并定义**环境侧可观测事实**（存活到 T / 资源未耗尽 / 危险未致死）作为主判据。
2. **定义 SSEA 版 s(d)**：对**固定策略快照**，在难度档 d 下跑 N 个**不同 seed / 初始条件**的 episode，`s(d) = 与多数结果一致的 episode 比例`（或存活比例）。**同时记录环境侧事实的 p(d)**，用于把"环境随机性"与"能力边界"分开（§5.2 第 2 条）。
3. **标定 d\***：扫 d 网格、≥8 seed，找使 **s(d\*)≈0.5** 的档位，写入「档位—s—p 台账」；\|s−0.5\|>0.25 的档位不进统计（δ 规则）。
4. **按 GenEnv Thm 1 反推每臂样本量**（TTCS 不提供此界）：`n ≥ (4.5/Δ²)·ln(4/δ_mis)`（笔算反解，非论文给出）。参考值（δ_mis=0.05）：Δ=0.1→n≈1972；Δ=0.2→n≈493；Δ=0.3→n≈219（每臂）。预算不足时保 Δ=0.3 档并明确记录检测下限。
5. **在 d\* 处重跑记忆门双臂与技能固化实验**（判决实验，见下）。
6. **把难度坐标 d 与 s 写进验收实验记录的强制字段**，并把"同一档位下的纵向比较"定为唯一合法对比方式。
7. **把"被考者 → 自洽性 → 课程难度"反馈通道加入 Misevolve 红队验收清单**，并自备**环境侧复杂度代理指标**（对标 TTCS 的"问题结构复杂度增长"，Table 4 p10）。
8. **与 GenEnv 卡片的 α 带、Agent0 卡片的前沿带合并为同一份「档位准入规则」文档**，避免三套阈值并存。

### 最小验证实验：**无标签前沿带的可用性 + 饱和判据的难度对齐判决实验**
- **目的**：先判定"**s(d) 是否是可信的难度代理**"，再判定"危险回避率两臂均 0.9814"是 **(A) 天花板压缩效应量** 还是 **(B) 门/技能表示真的没有因果作用**。
- **双臂 / 消融设置**（三步，顺序不可颠倒）：
  1. **代理校验臂（单臂，本篇独有）**：扫 d 网格、≥8 seed，同时记录 `s(d)`（自洽性）与 `p(d)`（环境侧事实成功率）。要求 **s(d) 单调、且 s(d)≈0.5 处 p(d) 的批间方差最大**；若 s(d) 平坦 → 代理失效（见证伪）。
  2. **标定臂（单臂）**：取 d\* 使 s(d\*)≈0.5，记录 d\* 与实测 n。
  3. **判决臂（双臂）**：在 **d\*** 处重跑「记忆门开 / 关」两臂（复用现有装置，只改 d）；每臂 n 由 GenEnv Thm 1 反推（目标 Δ=0.2→n≈493/arm；预算不足取 Δ=0.3→n≈219/arm），≥8 seed；并加**对照臂**：在原档位（s≈0.98）用**同样大的 n** 再跑一次双臂。
- **判据（分档，先看分母）**：
  - ① **机制计数（分母）**：落在前沿带的**可评估 episode 数**、门开启次数、技能被调用次数（先确认分母非空——对照债务 25/26/28）；
  - ② **代理有效性**：s(d) 是否单调下降、d\* 处批间方差是否最大；
  - ③ **行为差**：两臂 p 之差 Δp 及置信区间，要求**跨 seed 可重现、换邻近档位仍同号**；
  - ④ **淘汰结果**：存活时长 / 死亡率之差；
  - ⑤ **复杂度代理**（防退化）：环境侧复杂度指标须随 d 上升而非下降。
- **预期与证伪**：
  - **证实 A（天花板效应）**：s(d) 单调、d\* 明确；原始档 Δp≈0 且区间极窄；d\* 档出现稳定、跨 seed 重现的 Δp>0；对照臂（大 n、原档）仍 Δp≈0 → 难度对齐是解法，可投入建设运行时档位机制。
  - **证伪 A（问题在门/技能表示）**：在 d\*、n 已达检测力条件下两臂 Δp 仍≈0 且方向随机 → 证伪天花板解释，资源转向债务 22 与"技能表示够不够"。
  - **证伪代理（TTCS 特有）**：s(d) 在所有 d 上平坦、或 d\* 处 p 的方差并不最大 → **s 不是 SSEA 域的难度代理**（很可能是环境随机性主导）→ 本篇退化为 **D 基准对照**，须改回 GenEnv 的 checker 式或环境侧事实式难度坐标。
  - **中间态（提示地板）**：若 p 在任何 d 上贴 0（如技能固化 0/33 若为结构性）→ 先修判据形状（债务 26 类）再谈难度对齐。
- **注意**：n 估算来自对 GenEnv Eq.9 的笔算反解（推断），且该界在小 Δ 下较松——**实操以"跨 seed 可重现 + 换档同号"为准**。

### 若 E 不采用
- 不适用（本篇为 B）。但需明确：**若团队无法在 SSEA 域定义出可信的 s(d)（即自洽性无法区分"环境噪声"与"能力边界"），则本篇退化为 D 基准对照**——因为无标签前沿带的全部价值都建立在"自洽性是难度代理"这一假设上，而该假设在控制域中**比在 LLM 采样域中更可疑**。

## 9. 待确认问题

1. **C9 边界（需团队决策）**：把**模型自洽性**（内部信号，非外部评分）用作**研究者侧的档位诊断**，是否算违反 C9？建议裁决口径：**实验设计层（研究者手动选档、s 仅作协变量）合规；运行时生态层（s 自动驱动难度）违规**。需团队书面确认——这一条同时适用于 GenEnv 与 Agent0 卡片。
2. **SSEA 版 s(d) 的定义**：控制环里"自洽性"是什么？候选：跨 seed 结果一致率 / 跨初始条件一致率 / 跨策略快照一致率。需确定哪一个**既能反映能力边界、又不被环境固有随机性主导**。这是本篇能否落地的**唯一硬门槛**。
3. **aleatoric vs epistemic 的分离方法**：环境随机性会独立地把 s 压向 0.5。需设计对照（如固定 seed 重复、或对环境随机性做方差分解）来证明 d\* 处的 s≈0.5 来自**能力边界**而非**环境噪声**。论文未讨论此问题（未提及）。
4. **需人工核对的论文内部口径**：
   - **无 Limitations 章节**（p10 结论后即 References）——已核对，需确认是否有 v2 补遗；
   - Table 1–3 **无 seed/方差**（未提及）；
   - **无任何算力成本数据**（未提及）；
   - Appendix A.2 p14 的 **GPT-4o-mini 判分**是否进入训练信号，还是仅用于评测指标——需核对代码。
5. **超参敏感性缺失**：γ=1.2、δ=0.25、K=10、M=4、λ1=λ2=1.0 均为定值（§5.1 p7、Table 5 p15），无扫描。在 SSEA 语义下前沿带的**宽度（δ）**与**温度（γ）**需重新标定。
6. **与 GenEnv 的分工确认**：两篇的前沿带同形、且都指向同一判据问题。建议**只保留一份「档位准入规则」**：GenEnv 供样本量界，TTCS 供无标签信号，Agent0 供客观锚点原则——避免三套阈值并存。
7. **需补查的文献**：论文 §2 p3 点名的 **AlphaProof**（Olympiad 级 TTT，但依赖更强 LLM 合成数据）与 **R-Zero**（已在 papers 目录，尚无卡片）——后者是 TTCS 的直接基线，建议补卡以联通"零数据共演化"族图谱。另：同族的 **Socratic-Zero**、**SPICE**、**SwS**、**LADDER** 均在 papers 目录中，建议按同一纪律补卡。
