## 1. 一句话定位

- **论文主张**：把 LLM 解码建模为 MDP，用 AlphaZero 式树搜索（MCTS-α 等）配合**训练出的价值函数 v_ϕ 与结果奖励模型 ORM r̂_ϕ** 指导解码与训练，适用多任务 / 任意模型规模 / 变深度（最深 64），并迭代改进策略（p1、§3、Table 3–4）。
- **对 SSEA 的意义**：**立场上不适用**——其搜索由**训练出来的外部评分器**（v_ϕ / r̂_ϕ）驱动并据此**排序选路**，是 C9「不设外部评分函数」的典型反例；唯一可搬的是它**「搜索 vs 采样」的预算匹配对照实验设计**，可作 SSEA 慢环「前瞻预演」实验的判据参照。

## 2. 问题 — 机制 — 证据

### 2.1 论文要解决的问题
- 问题本身：ToT / RAP 用**提示 LLM 自评**当价值函数，且搜索浅（max depth 10 / 7），在 LLM 缺知识或需长程规划的任务上失效（p1、§1）。
- 既有缺陷：① 提示式自评不可靠、依赖强 LLM 与精心设计的 prompt（§4.2.1、Table 2）；② BFS/DFS/MCTS 搜索浅；③ 以 Path@N 对照忽略搜索的额外算力（§3.4）。

### 2.2 核心思想
1. 用**学习的** LLM 价值函数 v_ϕ(s) + ORM r̂_ϕ 取代提示式自评，使树搜索跨任务 / 模型规模 / 深度通用（§3.2.1）。
2. 树搜索既是解码算子、也是**策略改进算子**：搜索产出的改进轨迹反哺策略蒸馏与价值学习，循环迭代（generalized policy iteration，§3.3）。

### 2.3 关键机制 / 算法
| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| 学习价值函数 v_ϕ(s) / ORM r̂_ϕ | 状态（句末 token）→ 标量 | 搜索指导（**外部评分**） | §3.2.1、Eq.1 |
| 句子级 / token 级动作节点 | 生成 → 子节点 | 定义搜索空间 | §3.1、Fig.1 |
| MCTS-α（PUCT+价值回传）/ MCTS / MCTS-Rollout | 树 → 动作 | AlphaZero 式搜索 | §3.2.2、Eq.3、App.C.1 |
| BFS-V / DFS-V | 树 → 路径 | 按价值剪枝的束/深搜 | §3.2.2 |
| 聚合：majority-vote / ORM-Max / ORM-Vote | 多候选 → 最终答案 | 用外部评分**排序** | §3.2.3 |
| 迭代更新（策略蒸馏 + 价值评估） | 增强数据集 → 新 π/v/r̂ | 自改进（改权重） | §3.3、Eq.2 |

### 2.4 关键表示与数据结构
- 搜索树：节点=句子/token，边=生成；节点统计 (N(s,a), W, Q)（App.C.1）；两本 buffer（Value / Policy Learning Buffer，Fig.1）是**训练数据缓冲**，非可检索情景记忆。

### 2.5 实验证据
| 任务 / 基准 | 对照基线 | 关键数字 | 统计口径 |
|---|---|---|---|
| 学习 vs 提示价值函数（BFS Path@1） | 提示式 GPT-3.5 / LLaMA（ToT） | Game24：LLaMA-SFT+提示 9.2 / 21.0 → **+LLaMA-V 64.8**；GSM8K：37.4 / 45.8 → **52.5** | Table 2 p6（单值） |

### 2.6 论文自陈局限与边界条件（App.B p13）
- 无法扩展到真正大规模（节点扩展 + 价值评估的额外算力）；需 KV cache 等工程优化。
- 未覆盖全部动作空间设计（如句子级 + token 级混合树）；MCTS 聚合在大聚合数下难提升；仅做**一次**迭代更新（§4.2.4），仍未击败 PPO 策略（Table 4）。

## 3. SSEA 立场对齐

### 3.1 C1–C10 映射
| 裁判标准 | 判定 | 依据 | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制架构，非语言生成 | ✗ | 控制对象是 LLM 语言解码，状态/动作都是语言（§3.1） | 只借「搜索即预演」的信息流，控制信号换结构化生存量 |
| **C2** 语言只作观察员接口 | ✗ | 语言即动作与状态空间（§3.1） | 预演在结构化状态上做，语言不入环 |
| **C3** 权重/记忆/技能三分离 | ✗ | π_θ / v_ϕ / r̂_ϕ 三个**权重网络**；buffer 是训练数据非情景记忆（§3.2–3.3） | 预演产出走 ΔS/ΔM 分离；不接受权重共训 |
| **C4** 低算力低带宽 | ✗ | 节点扩展 + 价值评估；wall-time 2–3× CoT；MCTS-Rollout 2.27 s/题（App.D.3、Table 11） | 预演必须有预算闸；先做零 rollout 结构检查（见 SkillNet） |
| **C5** 精准回忆历史 | ✗ / — | 仅搜索树内 (Q,N) 统计，无跨 episode 检索/遗忘/合并 | 记忆侧交 Memento / FLEX |
| **C6** 可自主修改自身 | ◐ | 迭代更新改**权重**（策略蒸馏 + 价值学习，Eq.2），无四权分离 | 提案归慢环、验证归门、应用原子升版 |
| **C7** 保存/恢复/变异/继承 | ✗ | 无 GenePackage、无变异/继承（仅权重 checkpoint） | 不搬 |
| **C8** 给基因先验，不给知识语料 | ✗ | 策略 LLM 预训练于人类语料；迭代把任务知识写进权重 | 基因只放结构先验 |
| **C9** 不设评分函数，只有淘汰函数 | **✗（主战场）** | v_ϕ / r̂_ϕ 是**训练出来的外部评分器**（Eq.1）；树搜索据其**剪枝/选路**（BFS-V/DFS-V），聚合据其**排序**（ORM-Max/ORM-Vote，§3.2.3）；验证=打分排序而非合法性判定 | 价值/ORM 只作**环境侧事实**（研究者仪器侧）；预演**不得**用评分选路；选择归模型外淘汰，门只判合法性 |
| **C10** 创新在 L2/L3/L4，不在 L1 算子 | ✓ | 无新算子（MCTS/PUCT/LLaMA 全借用）；创新在 L2（树搜索解码信息流）、L3（搜索作策略改进算子） | — |

### 3.2 L1–L4 层级定位
| 层次 | 论文在该层提供了什么 | 对 SSEA 的价值 |
|---|---|---|
| **L1 算子层** | 无新算子（LLaMA2-7B / GPT-2-small、PUCT/MCTS 借用） | 符合借用立场 |
| **L2 信息流层** | 树搜索解码管线（select/expand/evaluate/backup + 聚合） | **高**：SSEA「前瞻预演」即搜索，其信息流可作形状参照 |
| **L3 学习层** | 搜索作策略改进算子 + 价值学习（改权重） | 中：提案-验证形状可参照，权重共训不可搬（C3） |
| **L4 演化层** | 无 | — |

### 3.3 模块映射
| 论文构件 | SSEA 落点 |
|---|---|
| 树搜索解码管线 | 慢环「前瞻预演」的信息流参照（非直接移植） |

### 3.4 债务与验收实验对应
- 「**睡眠期计算预算未定义**」→ **间接回应**：它把搜索的算力代价显式记账（#token / #forward / wall-time），是「预演必须先定预算」的实证（§3.4、App.D.3）；可服务慢环「**前瞻预演**」实验（若建）的**预算匹配基线**设计。判据饱和 / 技能固化 0/33 → 不直接回应；只借「公平比较下优势缩水」的纪律。

## 5. 冲突、代价与风险

- **与硬约束的冲突**：**C9（最硬）**——v_ϕ / r̂_ϕ 是训练的外部评分器，且用于剪枝/选路/排序；**C1/C2**——语言即控制对象；**C3**——三网络权重共训；**C4**——搜索算力重；**C8**——知识进权重。
- **隐含假设**：存在**可训练的价值/ORM 目标**（任务有真值或奖励，Eq.1、§E.2）——SSEA 无外部评分，此前提不成立。
- **算力代价 / 退化模式**：节点扩展与价值评估是瓶颈，论文自陈需 KV cache 等工程优化（App.B、App.D.3）；若把「预演」做成**用评分器选路**，慢环会长出模型内评分函数 → 架构变质（C9）；若只搬搜索而不设预算闸，会撞「睡眠期预算未定义」。

## 6. 组合分析

### 6.1 关系图谱
| 关系 | 对象（点名论文/方法族） | 说明 |
|---|---|---|
| **判据参照（最紧）** | **HarnessEval** | HarnessEval 提出「搜索增益 vs 设计增益必须用**预算匹配基线**分开」；本篇的 **Equal-Token + CoT-SC_ORM** 正是该原则的一个**具体、可运行的对照实验实例**，且实测出「公平比较下优势大幅缩小」（Table 3 p7）——合读：HarnessEval 给判据纪律，本篇给仪器化样本 |
| **同族（C9 违规形状）** | **EvoTest** | EvoTest 的 UCB 对平均环境分 argmax 与本篇「价值/ORM 排序选路」是**同一 C9 违规形状**（打分+排序+选择）；对照点：EvoTest **无梯度、不动权重**（C3 友好），本篇**改权重**（C3 冲突） |
| **互补（离线预演场）** | **Dream-RSI** | Dream-RSI 的「历史即重放模拟器」= 在**已记录树**上做零执行成本搜索，是 SSEA 预演的**廉价场地**；本篇提供「树搜索解码」的信息流形状；Dream-RSI 式(1)（质量−成本+并行奖励）与本篇价值/ORM 同属 C9 评分族，须同样剥离 |
| **对照（零 rollout 试组合）** | **SkillNet（离线试组合）** | SkillNet 用 **post→pre 结构匹配**判定技能可组合性（**零 rollout**）；本篇用**节点扩展 + 价值评估**（高 rollout）——两者是「离线试组合」的**低/高算力两端**，SSEA 预演应优先低端，仅在预算允许时用高端 |
| **同族（搜索空间 vs 预算）** | **TTCS** | TTCS 的「难度前沿带」回答「在哪个难度上测才有分辨力」；本篇的 width/depth 消融（Table 6）回答「搜索空间多大才有效、但增益是否只是多花 token」——两者共同界定「测量点 × 预算」二维 |

### 6.2 推荐组合方案
- **组合**：**HarnessEval（判据纪律）× 本篇（Equal-Token 仪器化样本）× Dream-RSI（重放场地）× SkillNet（零 rollout 结构检查）× EvoTest（无梯度提案对照）**
- **接口形态**：SSEA 慢环「前瞻预演」实验 = 预演臂 vs **预算匹配的采样臂**（同 #forward/token，且用**同一**信息聚合以剥离混淆）→ 报 pass@1 与 best-of → 先做 SkillNet 式零 rollout 结构筛选，再用 Dream-RSI 重放做行为验证。
- **新增能力 / 风险**：把「预演有没有用」变成可证伪的对照实验（而非「多试几次」的假增益）；风险＝若预演引入任何模型内评分/排序即违反 C9——须硬性规定预演只输出候选，**不输出分数、不排序**。

### 6.3 本篇在组合中的典型角色
- **「搜索 vs 采样」对照实验的仪器化范本 + C9 反例标本**——管「怎么证明预演增益不是多花算力买来的」，同时标记「训练评分器引导搜索」这条 SSEA 禁区。

## 8. 裁决与下一步

- **应用等级：D 基准对照** —— 理由：立场上整体不适用（C9 反面 + 语言域 + 权重共训 + 高算力），但其**预算匹配对照实验设计**（Equal-Token + CoT-SC_ORM + 单因子隔离）对 SSEA 慢环「前瞻预演」实验有直接判据价值。
- **优先级：P3** —— 备查；仅在建设「前瞻预演」实验时取用其对照设计。
- **建议动作**：① 在 experiments 的「前瞻预演」实验里**照搬 Equal-Token 三件**（报 #forward/#token、加同等预算采样臂、用同一信息聚合基线以剥离混淆）；② 把搜索空间（宽度/深度或预演步数）记为协变量（对照 Table 6）；③ 建 issue：`预演实验须有预算匹配采样臂（TreeSearchDecoding 判据）`。
- **最小验证实验（预演实验的判据参照）**：
  - **双臂 / 消融**：预演 开 / 关；**另加一臂**＝「把同等算力花在多次采样」的匹配基线；≥8 seed。
  - **判据（分档，先看分母）→ 预期与证伪**：① 机制计数（预演次数、#forward、分母 episode 数）→ ② 行为差（pass@1 单次行为 vs best-of）→ ③ 淘汰结果（模型外存活/死亡）；预期**预演臂在 pass@1 上胜出**且 #forward 匹配，**证伪**＝若增益只在 best-of 出现、或与匹配采样臂无差 ⇒ 增益来自「多试」而非预演设计（与 HarnessEval 判读一致），应弃该预演机制。
- 若 **E 不采用**：不适用（裁决 D）；**但若不做预算匹配对照，则本片退化为纯反例（E）**。
