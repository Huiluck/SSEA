## 1. 一句话定位
- **论文主张**：提出 12,500 道竞赛数学题的 MATH 基准（7,500 训练 / 5,000 测试，7 学科、难度 1–5、带 LaTeX 逐步解），并配套 23GB 的 AMPS 预训练语料；实验显示巨型 Transformer 准确率仅 3.0%–6.9%，且随规模增长极慢（推断需 ~10^35 参数才到 40%），故需算法突破而非继续扩参。
- **对 SSEA 的意义**：**基本不适用**——它是纯语言生成式推理基准，无生存控制环、无三分离、无自修改与遗传，与 C1–C10 无回溯路径；唯一用途是作为多篇已读卡片（TTCS、EvoTest、SEAL、R-Zero、Aspire）的**共同评测环境 / 对照臂**。

## 2. 问题 — 机制 — 证据
### 2.1 论文要解决的问题
- 问题本身：现有数学基准（Metamath/HOList 形式化证明、DeepMind Mathematics 的 plug-and-chug 计算题）无法衡量「分析问题、从大量可能中挑启发式、并串联成解」的问题求解能力（§1, p.1；Fig.1, p.2）。既有方案缺陷：形式化证明基准依赖 formal language；计算题只需套公式；二者都不测 heuristic 链式推理。
### 2.2 核心思想（关键 insight）
1. 用**竞赛数学**（AMC 10/12、AIME 等）填充「plug-and-chug 之上、形式证明之下」的空白，并把答案规范化为可 exact-match 的唯一形式（`\boxed{}` + 格式化规则）。
2. 每道题附**逐步解**，使模型可学「scratch space」；并配大规模 AMPS 预训练语料补基础数学。
### 2.3 关键机制 / 算法（可独立搬运的「零件」清单）
| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| 答案规范化 + exact match | 模型生成串 → 0/1 判定 | 免 BLEU，自动评分 | §3.1 p.5 |
| `\boxed{}` 定位 | 生成文本 → 抽取答案 | 从逐步解中切出终答 | §3.1 p.5 |
| AMPS 预训练语料 | 10 万 Khan + ~500 万 Mathematica → 23GB | 数学基础预训练 | §3.2 p.5–6 |
- 表示：题目/解为 LaTeX + 自然语言；图形用 Asymptote 向量语言而非位图（§3.1 p.4–5）。难度 1–5，7 学科（Prealgebra…Precalculus）。### 2.5 实验证据
| 任务 / 基准 | 对照基线 | 关键数字 | 统计口径 |
|---|---|---|---|
| MATH 平均准确率 | GPT-2 0.1B 5.4% → 1.5B 6.9%（+28%）；GPT-3 13B 微调 5.6%、175B few-shot 5.2% | 范围 3.0%–6.9% | Table 2, p.5；§1 p.2（GPT-2 均经 AMPS 预训练） |
| AMPS 消融 | 无 AMPS 的 GPT-3 13B 微调 5.2% | 0.1B+AMPS = 5.4%（≈130× 参数效果） | §4.2 p.7 |
| scratch space | 直接出终答 6.9% | 先生成逐步解降到 5.3% | §4.3 p.9（GPT-2 1.5B） |
| 训练用解 vs 仅答案 | 仅答案 6.3% | 用解 6.9%（+0.6%） | §4.3 p.9（GPT-2 1.5B） |
| 给 99% 真解提示 | 0% 提示为默认 | 仍仅 ~40% | Fig.5, p.9（GPT-2 0.7B） |
| 错误检测 | 随机 AUROC 50% | AUROC 68.8% | §4.2 p.8（GPT-2 1.5B） |
| 人类对照 | — | 非数学向 CS 博士生 8/20=40%；三届 IMO 金牌 18/20=90% | §3.1 p.5（随机抽 20 题，6 名参与者，1 小时手算） |
### 2.6 论文自陈局限与边界条件
- **规模不实用**：按 log-linear 趋势需 ~10^35 参数才达 40%（§1 p.3，推断性外推）。
- **scratch space 反效果**：模型自生成解会「滚雪球」式自误（§4.3 p.9）。
- **错误检测弱**：AUROC 68.8%，置信度严重过度自信（§4.2 p.8）。未提及：生存/控制环、记忆读写、自修改、遗传——均不在其问题域。

## 3. SSEA 立场对齐（核心维度）
### 3.1 C1–C10 映射
| 裁判标准 | 判定 | 依据 | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制架构，非语言生成 | ✗ | 全篇是语言模型生成 `\boxed{}` 答案，无生存相关结构化信号 | 无——与本立场正交，不改造 |
| **C2** 自然语言只作观察员接口 | ✗ | 自然语言/LaTeX 就是被评测的生成对象本身 | 无 |
| **C3** 权重/记忆/技能三分离 | ✗ | 只有单一参数权重（GPT-2/3）；无独立记忆库、无技能库 | 无 |
| **C4** 低算力低带宽 | ✗ | 依赖 8×A100 微调、23GB 语料、GPT-3 175B；与低算力相反 | 无 |
| **C5** 精准回忆历史 | — | 不涉及记忆机制，无检索/写入/遗忘 | 无 |
| **C6** 可自主修改自身 | ✗ | 无任何自我修改；仅外部微调权重 | 无 |
| **C7** 可保存/恢复/变异/继承 | ✗ | 无基因包、无繁衍淘汰闭环 | 无 |
| **C8** 给基因先验，不给知识语料 | ✗ | AMPS 正是**大规模知识语料预训练**，与「只给结构先验」直接对立 | 无——属反面教材 |
| **C9** 不设外部评分函数 | ✗ | exact match 准确率即外部评分函数（虽为评测基准而非训练奖励，仍与立场冲突） | 若借用其口径，只能作**淘汰式通过/不通过**，不得做奖励塑形 |
| **C10** 创新在 L2/L3/L4 | — | 创新在数据集/基准层，不在 L1 算子，亦不构成架构声明 | 无 |
### 3.2 L1–L4 层级定位 / 3.3 模块映射 / 3.4 债务与验收实验对应
- L1–L4：论文用现成 GPT-2/3（L1 借用），L2/L3/L4 均无供给。模块映射：无可用构件接入 SSEA 任何模块。
- 债务与验收：可回应的已知债务无（不触及 22/25–28/Gene Manager/记忆门/技能表示/预算 任一条）；可服务的验收实验仅作**外部对照环境**，非本地验收判据来源。

## 5. 冲突、代价与风险
- **与硬约束的冲突**：C1/C2/C3/C4/C6/C7/C8/C9 均为 ✗（见 3.1）；核心冲突是 C8——它把「大规模知识语料预训练」当作核心贡献，与 SSEA「基因只放结构先验、后天知识不跨代」正相反。
- **隐含假设与失效条件**：假设「能力可由单一大模型参数承载」「准确率是可加的连续评分」；SSEA 假设能力分散在权重/记忆/技能三处，二者不兼容。
- **算力 / 带宽 / 工程代价**：论文路线需 8×A100 级资源与 23GB 语料，落地成本极高。
- **搬运后的可能退化模式**：若误把 MATH 式 exact-match 当作 SSEA 慢环评分函数，将直接违反 C9（奖励塑形/观察员评分违规）。
- **为什么仍值得保留在论文池**：它是 TTCS、EvoTest、SEAL、R-Zero、Aspire 的共同评测基准，保留它才能读懂那几篇卡片的实验数字口径。
