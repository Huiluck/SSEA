## 1. 一句话定位

- **论文主张**：用「人类标准化考试」（高考、SAT、LSAT、司法考试、公务员考试、数学竞赛）构造双语客观题基准 AGIEval（20 任务 / 8,062 题），以准确率评测基础模型的「人类级」解题能力；GPT-4 在 SAT、LSAT、数学竞赛上超过人类平均分（SAT-Math 95%、高考英语 92.5%），但在复杂推理与领域知识上仍有短板。
- **对 SSEA 的意义**：**无**。它是「以语言答案准确率为唯一裁判」的外部评分基准，与 SSEA 的生存控制闭环无接口——正因如此，它是 C2/C9 的**反面参照**，而非可搬运资产。
- **为什么不适用（一句话）**：SSEA 是**非语言**的生存控制架构（C1/C2），不产出考试式文本答案，也不需要外部评分函数（C9）；本篇无任何可回溯到 C1–C10 的机制。
## 2. 问题 — 机制 — 证据
### 2.1 论文要解决的问题
- 问题本身：既有基准多基于人工构造数据集（SQuAD/GLUE/SuperGLUE 等），无法反映模型在真实人类认知/决策任务上的能力；需一个以官方高标准考试为源的「人类中心」基准（§1, p.2299；§2, p.2300）。
- 它指出的既有方案缺陷：MMLU 缺乏明确来源、仅英文；GPT-4 技术报告的考试评测不公开基准、输出与指标不透明（§2, p.2301）。
### 2.2 核心思想（1–3 条）
1. 直接**借用真实考试题**作为基准，其通过线由社会公认标准锚定，避免「人工造题偏置」。
2. **只保留客观题**（多选 + 填空），以便用 accuracy / Exact Match 自动打分（Appendix B, p.2308）。
3. **双语**（中/英）设计，暴露模型的语言敏感性（§4.4）。
### 2.3 关键机制 / 算法（可独立搬运的「零件」清单）
| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| 考试题集 + 答案 | 试题文本 → 基准实例 | 评测集 | Table 1/5, p.2301/2309 |
| 四种提示设置 | 题面 → 答案文本 | zero-shot / zero-shot CoT / few-shot / few-shot CoT | §4.2, p.2302–2303；Fig.2, p.2304 |

| 定量 + 定性指标 | 模型输出 → accuracy/EM；错答样本 → 理解/知识/推理/计算四维分 | 打分与能力归因 | §4.2.3 / §4.5, p.2303–2305；Fig.3 |
| 污染对照 | 2022 年后新题 → 对比准确率 | 测数据污染 | §4.6, Table 4, p.2306 |

### 2.6 论文自陈局限与边界条件
- 假设依赖：截至成稿时 SOTA 模型仅有纯文本 API，故只发布**语言版**（§6 Limitation, p.2307）。
- 明确不适用情形：多模态题被移除；主观题被移除（Appendix B, p.2308）；未定义计算/带宽预算。
- 未提及：任何控制闭环、记忆、自我修改、演化/继承机制。
## 3. SSEA 立场对齐（核心维度）
### 3.1 C1–C10 映射（短卡主要价值：记录「为什么被排除」）
| 裁判标准 | 判定 | 依据 / 为什么不适用 | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制架构 | ✗ | 全篇是语言 QA 基准，无感知—行动闭环，无生存相关结构化信号（§1–§4） | 不可改造，范式不同 |
| **C2** 自然语言只作观察员接口 | ✗ | 语言答案（accuracy/EM）**就是被评测对象**，而非仅日志面；「会说」被直接当「能力」（§4.2.3） | 无 |
| **C3** 权重/记忆/技能三分离 | — | 把模型当黑盒整体打分，不区分权重/记忆/技能，无三分离概念 | 无 |
| **C4** 低算力低带宽 | ✗ | 依赖大型基础模型 API、生成上限 2048 token、temp=0（Appendix C.1, p.2310）；无带宽/预算约束 | 无 |
| **C5** 精准回忆历史 | — | 单轮静态问答，无经历写入/检索/遗忘机制 | 无 |
| **C6** 可自主修改自身 | — | 不涉及自修改；模型为冻结推理 | 无 |
| **C7** 可保存/恢复/变异/继承 | — | 无 GenePackage、无繁衍/淘汰 | 无 |
| **C8** 给基因先验，不给知识语料 | ✗ | 恰恰相反：能力全部来自预训练语料（法律/化学等知识），无结构性基因先验 | 无 |
| **C9** 不设外部评分函数 | ✗ | 以外部 accuracy/EM 打分并**排序模型强弱**（Table 2/3），正是 C9 明令禁止的「观察员评分」 | 仅可作**反面教材** |
| **C10** 创新在 L2/L3/L4 | — | 不构成架构声明；L1 用的是借用 Transformer，创新在评测集构造（非架构层） | 无 |

## 5. 冲突、代价与风险

- **与硬约束的冲突**：C1（非控制架构）、C2（语言即评测对象）、C9（外部评分函数 + 模型排序）为硬冲突；C4/C8 次之。
- **隐含假设与失效条件**：假定「考试分数 ≈ 通用能力」，且客观题可自动打分；在无文本输出的非语言架构上完全失效。
- **算力 / 带宽 / 工程代价**：评测需调用闭源大模型 API 并生成最长 2048 token（Appendix C.1, p.2310），成本高且不可离线复现于 SSEA 快环。
- **搬运后的可能退化模式**：若强行把考试准确率当作 SSEA 判据，会引入 C9 禁止的「观察员评分」→ 判据形状错（呼应债务 25/26 同类风险）。
- **为什么仍值得保留在论文池**：作为 C2/C9 的**反例锚点**——说明「以语言准确率衡量智能」与 SSEA 的分野。

## 8. 裁决与下一步

- **应用等级**：**E 不采用**。理由：无法回溯到 C1–C10 任一条（非控制架构、语言即评测对象、外部评分排序），连可改造零件都不存在。
- **优先级**：P3（备查）。
- **建议动作**：不建 issue、不排实验；仅在「判据设计原则」文档中留一条反例引用。
- **最小验证实验**：不适用（无机制可验证）。
- **若 E 不采用**：**原因**——本篇为外部评分式语言考试基准，其核心度量（accuracy/EM + 模型排名）与 C9「不设外部评分函数」直接冲突，且不产出 SSEA 可消费的结构化控制信号。
