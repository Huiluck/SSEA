## 1. 一句话定位

- **论文主张**：把**群体（group）而非个体**作为演化的基本单位——每轮先用 Performance–Novelty 准则从档案里选出 K 个亲代，再把 K 个亲代的演化轨迹（已应用的结构 patch、对未解任务的预测 patch、执行日志、评测结果）**并集广播**给全组，各成员据此经 Reflect→Evolve 生成自己代码库上的**框架级 patch**，编译且具备基础编码功能者入档；在 SWE-bench Verified 上 71.0%（树状自演化基线 DGM 56.7%）、Polyglot 上 88.3%（基线 68.3%）（p1、p8–9）。
- **对 SSEA 的意义**：它是目前库里**唯一正面撞上 C8** 的一篇——SSEA 明令「后天知识不跨代」，本篇主张「经验跨个体共享反而更好」。本篇的真正价值不在分数，而在于逼 SSEA 回答：**共享的到底是什么颗粒度的东西**；并提供了两个可直接抄的 L4 零件：**归档准入门（合法性门，不打分）**与**祖先整合计数（演化可观测性指标）**，直接服务于缺失的 **Gene Manager**。

## 2. 问题 — 机制 — 证据

### 2.1 论文要解决的问题
- 现有开放式自演化系统（DGM、AlphaEvolve、SICA 等）沿用生物演化隐喻，**个体中心 + 树状谱系**：每轮挑一个亲代独立产生后代，**分支之间严格隔离**（p2–3、p8）。
- 缺陷：探索期产生的大量多样性**只作为"临时多样性"存在**（short-lived variants），无法成为垫脚石（stepping stones），早期在孤立分支上发现的好方向因谱系隔离而**死掉**，不能转成长期累积进步（p2、p9）。
- 论文的元论点：**「AI agents are not biological individuals; why should their evolution remain constrained by biological paradigms?」**——智能体可直接共享 trajectories、tools、learned artifacts，不必受繁殖与谱系约束（p2）。

### 2.2 核心思想（关键 insight）
1. **演化单位从个体换成群体**：亲代群体**共同**产生同规模的子代群体，经验在组内显式共享与复用（Fig.1b、p3）。
2. **共享把"瞬时多样性"转成"长期经验"**：多样性不再随分支消亡而被丢弃，而是被聚合进共享池，成为后续演化的输入（p2、p6）。
3. **共享 + 分化的组合**：所有成员吃**同一份**共享池 S，但各自**在自己的代码库上做互补适配**——既借他人经验，又保持开放探索（p6、Fig.2 说明）。
4. **值得共享的是结构而非提示**：所有性能提升型 patch 主要落在 **workflow 与 tool usage**，而非模型专用 prompting，因此能跨 GPT/Claude 系列迁移（§5.3、Table 3 p18）——这一条对 SSEA 的 C8 判定是**决定性证据**。

### 2.3 关键机制 / 算法（可独立搬运的「零件」清单）

| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| **Archive（档案）** | 演化出的智能体 → 全体集合 A | 保存所有历史个体，共享与选择的素材池；**单调增长，论文未提及剪枝/遗忘/容量上限** | §3 p3、Alg.2 line 26 p5 |
| **任务成功向量表示 z_i ∈ {0,1}^D** | 个体在 D 个探针任务上的成败 → 二值向量 | 把"个体"压缩成可比较、可算距离的**结构化指纹**（非自然语言） | §3.1 p4 |
| **余弦距离 d(i,j)**（式 1） | z_i, z_j → 距离 | 个体间差异度量 | §3.1 式(1) p4 |
| **KNN 新颖度 nov(i)**（式 2） | 距 i 最近的 M 个邻居的平均余弦距离 | 奖励"走向不同方向"的个体 | §3.1 式(2) p4–5、Alg.1 line 4–12 |
| **Performance–Novelty 亲代选择**（式 3） | score(i)=α_i·√nov(i) → top-K 亲代群 G | 性能为主、新颖性为温和偏置的利用/探索权衡 | §3.1 式(3) p5、Alg.1 line 13–17 |
| **演化轨迹采集 T_i**（四类） | 个体 → {P^Applied 已应用框架 patch；P^pred 对随机未解任务的预测任务 patch；L 执行日志（含工具调用史）；O 评测结果} | 定义"什么算一条可共享经验"的**数据契约** | §3.2 p6、Alg.2 line 6–11 |
| **群体聚合 S = ⋃_{j∈G} T_j** | K 份轨迹 → 一份共享池 | **传播**：无差别并集广播给全组每个成员 | Alg.2 line 14 p5、§3.2 p6 |
| **Reflect 模块 Δ_i = Reflect(a_i; S)** | 共享池 + 自身 → 演化指令 | **抽象**（隐式）：把原始轨迹转成针对 workflow/工具/提示策略的指令 | Alg.2 line 17 p5、Fig.2 p6 |
| **Evolve 模块 π'_i = Evolve(a_i; Δ_i)** | 演化指令 → **框架级 patch** | 变异：产出可应用的结构变更 | Alg.2 line 19 p5 |
| **ApplyPatch + ActAndEvaluate** | patch + 个体 → 新个体 + 评测 | 应用到自身实现并在基准上跑 | Alg.2 line 21–22 p5 |
| **归档准入门：Compiles ∧ BasicCodingFunc** | 新个体 → 入/不入档 | **准入**：只判**合法性**（能否编译、能否解 10 题 sanity 中的题），**不打分、不排序** | Alg.2 line 25–27 p5；§4.1 p7 |
| **分阶段评测阶梯** | 10 题 sanity → 50 题 miniset → 全量；Polyglot：10 题演化集 → >40% 才进 50 题未见集 | 用**预算分层**控制昂贵评估（计算预算的显式分配模板） | §4.1 p7 |
| **祖先整合计数（Ancestor Count）** | 最终解 → 被整合的历史个体数 | **演化可观测指标**：共享有没有真的发生 | Table 1 p10 |
| **Worst-case top-k 报告口径** | top-k 个体 → 取**最差**成功率 | 防止"只出一个离群最优"被当成整体进步 | Table 1 p10 |
| **能力项/工具级追踪（T1–T9）** | 逐个工具功能 → "已发现 / 已集成"二态时间线 | 以**能力项覆盖数**而非分数衡量演化进展 | Fig.4 p9–10 |

### 2.3b 群体共享经验的四段拆解（传播 / 去重 / 抽象 / 准入）——本篇真正的技术内核

| 环节 | 本篇怎么做 | 是否显式 | SSEA 可搬运性 |
|---|---|---|---|
| **传播（propagation）** | `S ← ⋃_{a_j∈G} T_j`，全量并集，**无差别广播**给组内每个成员；无目标寻址、无按需检索 | **显式**（Alg.2 line 14） | 高——但 SSEA 必须改成**按需拉取 + 契约寻址**（见 §5 风险：C4 带宽） |
| **去重（dedup）** | **未提及**任何语义级去重；⋃ 只在集合语义上消除完全相同的条目；同一失败模式被多个成员重复贡献时不去重 | **无** | 缺口——须由 **SEDM 的候选抽取（去重/规范化/带出处）+ Mem0 的 CRUD 分类** 补上 |
| **抽象（abstraction）** | **未提及**独立抽象步骤；由 Reflect 模块（LLM）**隐式**完成：原始 traces → 演化指令 Δ_i。产物是**自由文本指令，无契约、无类型** | **隐式/无保证** | 缺口——须由 **PSN 的"带契约可执行技能"+ SkillWeaver 的提案-练习-合成-打磨** 补上；SSEA 侧必须要求共享物是**编译后、带签名、过四级验证门**的 ΔS/ΔR |
| **准入（admission）** | **两层，但都不在"被共享的经验"上**：① 归档准入 `Compiles ∧ BasicCodingFunc`（合法性门）；② 亲代准入 `α·√nov` top-K（**评分门**）。共享池 S 里的每一条 trace **不经过任何验证**就被喂给全组 | 部分显式 | 半可用：① 直接对应 SSEA 四级验证门的 L0/L1 同构物（**C9 兼容，✓**）；② 违反 C9（**✗**）。**缺的第三层——"经验本身的准入验证"——正是 SEDM 的配对 A/B 准入** |

> **一句话判词**：GEA 验证的是「**演化后的产物**」，而不是「**被共享的经验**」。共享物在本架构里是**免检**的。这是本篇最大的工程漏洞，也是 SSEA 采用时**必须补的第一块**。

### 2.4 关键表示与数据结构
- **个体表示**：z_i ∈ {0,1}^D，D 个探针任务的成败位向量（p4）。这是全篇唯一的结构化、非自然语言表示。
- **经验表示**：演化轨迹四元组 T_i = {P^Applied_i, P^pred_i, L_i, O_i}；共享池 S = ⋃ T_j（p5–6）。**注意四类里只有 P^Applied 是结构增量，其余三类是 episode 级内容**——这个划分是 C8 判定的关键（见 §3.1）。
- **演化产物**：framework-level patch（可作用于 workflow、tool usage 或 prompting strategy，Fig.2 p6）。
- **档案条目**：智能体 +（隐含的）评测结果；**论文未提及**档案条目是否存谱系/父指针的显式数据结构（祖先计数在 Table 1 中作为分析量给出，未说明如何记录）。
- **成本表示**：显式美元成本表（附录 A.1 p17）。

### 2.6 论文自陈局限与边界条件
- **假设依赖**：① 存在可自动化、可分级评测的基准（编码任务）作为 α 与门的来源；② 个体实现可被自动修改（代码即基因组）；③ 群体内成员的差异足以产生互补（K=2 即有效）；④ 演化/反思由前沿闭源 LLM 驱动（Claude Haiku 4.5 → Sonnet 4.5 + GPT-o1 反思，§4.2 p7）。
- **明确不适用 / 未处理的情形**：
  - **档案只增不减**，未提及容量、剪枝、遗忘或淘汰机制（§3 p3、Alg.2）——开放式演化的长期膨胀问题未处理。
  - **共享物免检**：S 中 trace 无任何准入验证（Alg.2 line 14–17）。
  - **无误差棒 / seed 数未报**（主结果），仅鲁棒性实验有 5 次独立试验。
  - 只验了 **K=2、M=4**（§4.2 p7），**未做**群体规模、KNN 邻居数、共享内容（哪一类 trace 有用）的消融。
  - 评估走**分阶段子集**（10 → 50 → 全量），只有 top-2 进全量 SWE-bench（§4.1 p7）——全量数字覆盖面窄。
  - 成本与算力极高（USD 13,000/跑），且依赖闭源前沿模型。
  - **Impact Statement 自陈风险**（p12）：演化可能引入与人类意图不一致的方向、消耗大量算力、产出 patch 缺乏结构清晰度导致系统日益难懂；实验在隔离沙箱中进行。
  - 领域仅限**编码**，非生存/控制任务；论文自述可扩展到其他领域但未验证。

## 3. SSEA 立场对齐（核心维度）

### 3.1 C1–C10 映射

| 裁判标准 | 判定 | 依据（论文中的具体机制/数字） | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制架构，非语言生成 | ◐ | 演化对象是 coding agent 框架（workflow/tool/prompting），验证域是 SWE-bench / Polyglot；但**演化产物是结构 patch + 编译门**，形态上属结构演化而非文本生成 | 把「框架级 patch + 编译/功能门」搬到非语言结构（ΔS/ΔR）上；探针任务换成生存相关结构化探针 |
| **C2** 自然语言只作观察员接口 | ✗/◐ | Reflect / Evolve / Acting 三模块**全部由 LLM 驱动**（GPT-o1 反思、Claude 系列演化与执行，§4.2 p7）；运行时大量语言进出 | 语言**只许存在于慢环**（编译/反思/演化提案）；快环运行时零语言。本篇只有慢环部分可借 |
| **C3** 权重/记忆/技能三分离 | ◐ | **权重侧正确**：从不微调模型，只改框架代码，且跨模型迁移成立（§5.3）；**但记忆/技能/规则未分置**——一个 patch 可改 workflow、工具、提示中的任意东西，无分置约束 | 共享通道按 ΔS / ΔM / ΔR 三条**分线**投递，各自有独立契约与门；禁止"什么都往一个 patch 里塞" |
| **C4** 低算力低带宽 | ✗ | USD 13,000/跑、60 次基准评测、前沿闭源模型（附录 A.1 p17、§4.2 p7）；且共享是**全量并集广播**（Alg.2 line 14），带宽随群体线性增长 | 整机不可搬。只搬便宜零件（准入门、祖先计数、能力项追踪）。共享改**按需拉取 + 定长摘要**，禁止全量广播 |
| **C5** 精准回忆历史 | —/◐ | 论文**未提及**个体情景记忆的写入/检索/遗忘机制；共享池 S 是外部经验存储（形态上外置 ✓），但无索引、无检索、无精准定位 | S 不能直接当记忆用；SSEA 若借鉴，共享池只走**结构增量**通道，episode 仍留在 C5 记忆侧、不共享 |
| **C6** 可自主修改自身 | ✓/◐ | 系统自动产出并应用**框架级 patch** 修改自身实现（Alg.2 line 19–21）；**四权**：提案权 ✓（Reflect+Evolve）、验证权 ✓（Compiles/BasicCodingFunc 门在门侧）、应用权 ✓（ApplyPatch）、**边界权未提及**（无沙箱边界声明，仅 Impact Statement 提到隔离沙箱 p12） | 边界权必须显式化：patch 可改什么、绝对不可改什么，写成宪法层白/黑名单 |
| **C7** 可保存/恢复/变异/继承 | **✓/◐** | 保存 ✓（Archive）、恢复 ◐（档案可复用为亲代，未提及快照/回滚到历史版本）、变异 ✓（framework patch）、**继承 ✓✓（本篇最强项：17 个祖先被整合进最优体，Table 1 p10；8/9 项工具能力跨个体传播，Fig.4）**；**淘汰 ✗——档案只增不减，无淘汰机制** | GEA 缺的正是 SSEA 的另一半：把**淘汰**接上（不通过门/未在环境侧存活者出档），才构成达尔文闭环。GEA 是"共享强、淘汰弱"，SSEA 是"淘汰强、共享未定"——**互补性极强** |
| **C8** 给基因先验，不给知识语料 | **✗（正面冲突，本篇核心张力）** | 共享物 T_i 含四类：**P^Applied（结构增量）**、**P^pred（具体任务的预测 patch）**、**L（执行日志/工具调用史）**、**O（评测结果）**——**后三类是赤裸的具体经历（episode）**，且**免检广播**（Alg.2 line 14–17）。这是 SSEA 明令禁止的跨个体知识流动 | **裁决：SSEA 只能共享「结构性先验/技能」，不能共享「具体经历」。** 改造方案见下方 §3.1-C8 专项判定与 §5 |
| **C9** 不设评分函数，只有淘汰函数 | **✗（但有可救的一半）** | **违规部分**：score(i)=α_i·√nov(i) 用**任务成功率排序选亲代**（Alg.1 line 13–17、式 3 p5），α 直接驱动搜索方向 = 事实上的奖励塑形；Table 3 p18 的 **ΔScore** 是逐 patch 的性能增量分，用于判定"哪些改动有用"；nov 也是量化 shaping 项。**合规部分**：归档准入门 `Compiles ∧ BasicCodingFunc` **只判合法性、不打分、不排序**（Alg.2 line 25），正是 SSEA 四级验证门（格式→沙盒）的同构物；§5.2 的分析指标（工具集成数、祖先数、worst-case）是**计数/覆盖率**，不是打分函数 | ① 亲代选择：α 排序 → **从"存活集合"中按多样性抽样**（存活/淘汰是环境侧事实，不排序）；② ΔScore 一类增量分只许留在**模型外当仪器**，不得进入选择回路；③ 能力项/祖先计数作为内在多样性信号保留（计数 ≠ 打分） |
| **C10** 创新在 L2/L3/L4，不在 L1 算子 | **✓** | 无新算子；创新在 **L4（群体作为演化单位、共享式继承）** 与 **L2（共享池→反射→patch 的信息流拓扑）** | — |

#### 3.1-专项：C8 / C7 张力裁决 ——「SSEA 能否只允许结构性先验共享、禁止具体经历共享？」

**判定：能，而且本篇自己的实验恰好证明「该共享的本来就是结构」。**

判定依据（全部出自论文，非推断）：

1. **可共享的一侧有实证背书**：§5.3 与 Table 3（p11、p18）明确写到，所有性能提升型 patch「**primarily target the agent's workflow and tool usage rather than model-specific prompting**」，且在 gpt-5.1 / gpt-o3-mini / claude sonnet 4.5 上一致有效——**能跨模型迁移的东西，本质上不携带模型特定的知识内容，正是 C8 允许的"结构性先验/技能"形态**。
2. **不该共享的一侧在机制上就可疑**：T_i 中 P^pred（某具体任务的具体解）、L（工具调用史）、O（该任务成败）是**绑定具体情境的 episode**，其价值随任务分布漂移，且**免检入池**，正是 C8 防膨胀条款要拦的东西。
3. **膨胀实证**：SWE-bench 演化新增 9,663 行、Polyglot 新增 8,677 行（§5.1 p9），**档案单调增长且无剪枝/遗忘（未提及）**。群体共享 + 无界归档 = **膨胀的正反馈环**，比单体演化危险得多，直接命中 C8「防膨胀」的立法理由。

**SSEA 的改造方向（三条硬规则）**：

| # | 规则 | 说明 |
|---|---|---|
| R1 | **共享通道只载 ΔS / ΔR（结构增量），不载 episode** | 对应 GEA 的 P^Applied：工具定义、工作流、编辑原语、规则。P^pred / L / O **一律不得进入共享池** |
| R2 | **共享物必须是编译后、带契约、已过四级验证门的成品，不是原始 patch 文本** | 参照 **PSN**（技能=带契约的可执行网络 + 成熟度门控）与 **SkillWeaver**（提案-练习-合成-打磨）；原始文本 patch 一律拒收 |
| R3 | **GenePackage 定长 + 结构预算上限，入档即可能淘汰出档** | 抵消 C8 膨胀：共享带来的结构增长必须用**同额淘汰**对冲；GEA 缺的淘汰侧由 SSEA 补 |

> 一句话：**SSEA 采用"结构性共享版"的群体演化——共享的是"怎么做的形状"，不是"我遇到过什么"。** 这不是对 C8 的妥协，而是用 C8 把本篇最有价值的部分（结构能力跨个体整合）从 episode 污染中剥离出来。

## 5. 冲突、代价与风险

### 与硬约束的冲突（逐条）
1. **C8 ✗（最主要冲突）**：主张具体经历（任务 patch / 执行日志 / 评测结果）跨个体共享且**免检**——SSEA 明令后天知识不跨代。**改造**：共享通道只载编译后、带契约、过门的 **ΔS/ΔR**；P^pred / L / O 三类物理禁运（R1–R3，见 §3.1 专项）。
2. **C9 ✗**：α（任务成功率）与 ΔScore 作为**评分并驱动选择**——属奖励塑形近亲。**改造**：亲代选择改为"存活集合内按多样性抽样"；所有增量分只作模型外仪器，不进选择回路。**保留**：合法性门（不打分）与计数类指标（祖先数、能力项覆盖）合规。
3. **C4 ✗**：USD 13,000/跑 + 前沿闭源模型 + 全量并集广播（带宽随群体线性增长）。**改造**：整机不落地；只搬零件；共享改按需拉取 + 定长结构摘要。
4. **C2 ✗/◐**：三大模块全由 LLM 驱动，运行时含大量语言。**改造**：语言只在慢环编译/反思，快环零语言。
5. **C7 ◐**：档案只增不减，**无淘汰**——与 SSEA「淘汰+繁衍才构成达尔文闭环」不符。**改造**：SSEA 侧补淘汰出档；本篇只取"共享/继承"半边。

### 隐含假设与失效条件
- 假设存在**可自动化评分的基准**作为 α 与门的来源。SSEA 的生存环境**没有这样的外部评分**——把 α 换成淘汰事实后，**选择信号的强度会显著下降**，本方法的核心增益（"用更好的个体引导更差的个体"）可能大幅缩水。这是**最需要证的伪条件**。
- 假设个体实现**可被自动修改**（代码即基因组）。SSEA 的快环是毫秒级控制回路，其"实现"不是自由文本代码——结构 patch 的表示空间要重新定义。
- 假设群体内差异能提供互补。SSEA 若群体同质（同一 GenePackage 派生），共享池会**高度冗余**而本篇**无去重机制**（未提及）→ 共享退化为噪声注入。

### 算力 / 带宽 / 工程代价
- 整机：USD 13,000/跑（SWE-bench）、1,500（Polyglot），30/20 轮演化，需完整编码基准评测基建 + 闭源前沿模型。**与 C4 直接冲突，整机不可落地。**
- 零件：位向量 KNN 新颖度、祖先计数、能力项追踪、合法性门——**均为 O(N·D) 级廉价运算**，可直接在现有慢环实现。
- 共享通道：全量并集广播需改为**按需拉取 + 定长摘要**，否则带宽随群体规模线性膨胀。

### 搬运后的可能退化模式（若失败，会以什么形式失败）
1. **共享污染**：episode 级内容混入共享池 → 后代继承到绑定特定情境的行为 → 在新环境系统性误用（**C8 膨胀的具象化**）。
2. **免检注入**：因共享物无 A/B 准入验证（本篇缺口），一条坏经验可**一次性污染整个群体**——比单体演化的错误传播快 K 倍。
3. **多样性坍缩**：共享过强 → 群体趋同 → KNN 新颖度归零 → 探索停滞（本篇只跑了 K=2，无大规模坍缩证据；**未提及**群体规模消融）。
4. **档案膨胀**：无淘汰、无剪枝（未提及）→ 检索与选择成本单调上升，命中率下降（SSEA 当前记忆检索命中率 0.5164 本已偏低）。
5. **评分依赖戒断失败**：去掉 α 后选择信号过弱，演化退化为随机游走——**这是最可能的失败形式**，也是最小验证实验要优先证伪的。

### 6.2 推荐组合方案

**方案 A（推荐，直接服务 Gene Manager）：StructuralDeltaBus = GEA 共享拓扑 × PSN 技能契约 × SEDM A/B 准入**
- **组合**：GEA（群体共享拓扑 + 归档合法性门 + 祖先/能力项计数）× **PSN**（技能=带契约可执行网络 + 故障定位 + 成熟度门控 + 回滚验证重构）× **SEDM**（SCEC 打包 + 配对 A/B 准入 + 抽象后重验）
- **接口形态**：慢环内新增一条**只载 ΔS/ΔR 的共享总线**。写入侧：慢环产出的结构增量必须先过四级验证门 → 再过 SEDM 式 A/B 边际效用验证 → 才写入总线并打版本号与谱系指针。读取侧：个体**按需拉取**（非全量广播），按契约签名匹配，KNN 新颖度控制多样性。
- **组合后新增能力**：① 结构能力跨个体/跨代整合（本篇的 8/9 项工具集成效应）；② 共享物**有准入验证**（补本篇最大漏洞）；③ 有淘汰与回滚（补本篇缺失的达尔文半环）。
- **新增风险**：A/B 准入本身要双跑，占睡眠期预算（SEDM 卡片已记：自调度可回收 token）；需与本文的分阶段预算阶梯一起调度。

**方案 B：GEA × ADAS × Gödel —— 有共享的档案式自指演化**
- **组合**：ADAS 的档案/谱系/垫脚石 + GEA 的群体共享 + Gödel 的自指（让共享算子本身也可被变）
- **接口形态**：档案条目带父指针与"被整合祖先集合"；选择只走**存活集合 + 多样性抽样**（无 α 排序）。
- **新增能力**：垫脚石不再因谱系隔离而死（本篇 Fig.4 的核心论据）。
- **新增风险**：共享 + 自指 = 变更传播面极大，必须用 **Misevolve** 红队清单卡边界权。

**方案 C：廉价预筛（GEA × Dream-RSI）**
- 共享候选先入重放模拟器跑近期任务窗，通过才占真实评估预算——直接对冲 USD 13,000 的成本，也是 SSEA「睡眠期预算」的落地形态。

### 6.3 本篇在组合中的典型角色
- **L4 群体共享协议供应商 + 演化可观测性仪表**：本篇不提供 SSEA 快环任何东西，它提供的是**"慢环里多个个体之间该怎样交换结构、以及怎么知道交换真的发生了"**——即 Gene Manager 的**共享侧与计量侧**。准入侧由 SEDM 出，契约侧由 PSN 出，边界侧由 Misevolve 出。

## 8. 裁决与下一步

- **应用等级：B 零件采用** —— 采用三件：**① 归档合法性准入门（不打分、只判合法性，C9 合规）**、**② 祖先整合计数 + 能力项二态追踪（演化可观测性）**、**③ 「群体共享」的拓扑思想（但共享物限死为编译后带契约的 ΔS/ΔR）**。同时把它当作 **C8 条款的裁决依据**与**膨胀风险的对照样本**。**不采用**：α·√nov 的评分式亲代选择、含 episode 的免检共享池、整机编码基准演化流程。
- **优先级：P1** —— 理由：本篇是当前唯一逼 SSEA 写清「结构性先验可共享 / 具体经历不可共享」这一**宪法级裁决**的文献；Gene Manager 的共享侧设计在此之前无法定稿（实验 4/5 卡住）。
- **建议动作**：
  1. **写死 C8 分界线（宪法层）**：在 sse_protocols 中定义"可共享 = 结构性先验/技能（ΔS、ΔR 编译产物，带契约、过门）；不可共享 = 具体经历（episode、任务解、执行日志、成败结果）"，并注明文献依据为 GEA §5.3 / Table 3（能跨模型迁移者即为结构性）。
  2. **Gene Manager 增两条字段**：`lineage_ancestors`（被整合的祖先集合）与 `capability_flags`（能力项二态表）。**同时补 GEA 没有的淘汰出档**：不存活者出档，防止档案单调膨胀。
  3. **StructuralDeltaBus 原型**（方案 A）：只载 ΔS/ΔR；写入需过四级门 + SEDM 式 A/B 边际效用验证；读取按需拉取而非全量广播；episode 通道物理关闭（用类型系统而非约定来保证）。
  4. **共享物去重与抽象**补齐：GEA 未做（未提及），用 **Mem0 的 CRUD 分类 + SEDM 的候选抽取（去重/规范化/带出处）+ PSN 的契约**补。
  5. **睡眠期预算分层**：照抄分阶段阶梯（小集预筛 → 通过才进大集），把"睡眠期计算预算未定义"落成具体档位。
  6. **判据换口径**：把饱和的 0.9814 危险回避率与 0/33 技能固化，改为 **worst-case top-k + 能力项覆盖数 + 祖先整合数**三联判据（先看分母）。
  7. 用 **Misevolve** 红队清单为共享通道补一项新威胁：**单次注入污染全组**（GEA 无此防护，未提及）。
- **最小验证实验：结构增量共享 vs 隔离演化（服务实验 4）**
  - **三臂设置**（同一环境、同一初始 GenePackage、≥8 seed）：
    - **A 臂 结构共享**：慢环间只交换编译后带契约、已过门的 ΔS/ΔR；episode 通道关闭。
    - **B 臂 隔离演化**（对照）：无共享，等同 GEA 的 DGM 基线形状。
    - **C 臂 全轨迹共享**（**证伪对照**，验证 C8）：共享含 episode（任务解/日志/结果）的全量内容。
  - **判据（分档，先看分母）**：
    1. **机制计数（分母）**：共享通道写入条数 / 准入通过率 / **祖先整合计数** / 能力项「已发现→已集成」转化数 / GenePackage 体积增长（行/字节）。**这一档必须先跑——若 A 臂共享写入数为 0 或被门全拒，后面两档无意义。**
    2. **行为差**：技能固化命中（当前 0/33）、记忆检索命中率（当前 0.5164）、结构自愈轮数（对照 GEA 的 1.4 vs 5.0 轮）。
    3. **淘汰结果（环境侧，模型外）**：存活率 / 淘汰率 / worst-case top-5 存活。
  - **预期**：A 臂在**祖先整合计数与能力项覆盖数**上显著高于 B（对应 GEA 17 vs 9、8/9 vs 5/9），且 **GenePackage 体积增长受控**（有淘汰对冲）；C 臂体积增长失控且在新环境出现误用（C8 膨胀的具象化）。
  - **证伪条件**：① 去掉 α 排序后 A 臂与 B 臂无差异 → 说明本篇的增益**依赖评分信号**，C9 改造后收益蒸发，**降级为 C 思想启发**；② C 臂不劣于 A 臂 → C8 防膨胀条款需要重新论证；③ A 臂体积增长不受控 → 淘汰机制未接上，方案 A 不成立。
- 若 **E 不采用**：不适用。
