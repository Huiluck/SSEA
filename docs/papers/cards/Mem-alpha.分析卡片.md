## 1. 一句话定位

- **论文主张**：把「记忆构建」形式化为序贯决策问题——智能体逐 chunk 观测 `(c_t, M_{t-1})`，发出一串结构化写操作 `A_write = {memory insert, memory update, memory delete}`，用 GRPO 以「下游 QA 正确率 r1 + 工具格式成功率 r2 + 压缩率 r3 + LLM 判官内容有效性 r4」四项奖励训练写策略；在 Qwen3-4B 上训练（32×H100、3 天、205 步）后，验证集均值 0.642（Long-Context 0.588 / RAG-Top2 0.567），OOD 的 MemoryAgentBench 上 0.592（RAG-Top2 0.502），并以 ≤30k token 训练外推到 400k+（最高 474k，13×）token（Table 1–3、§4.2）。
- **对 SSEA 的意义**：它是**目前卡片库里唯一一篇把「慢环经验编译器如何产 ΔM」本身当作可学习策略来训练的工作**——动作空间、观测、奖励三件套可直接对照 SSEA 的 ΔM 通道；同时它以最清晰的方式暴露了 C9 的硬边界：**四项奖励中有三项是外部评分/奖励塑形/观察员评分**，因此只能搬「骨架」，不能搬「训练信号」。

## 2. 问题 — 机制 — 证据

### 2.1 论文要解决的问题
- 问题本身：LLM 智能体受上下文窗口限制，需要外置记忆；但现有记忆系统（Mem0 / MemGPT / MIRIX 等）**只提供预定义指令与固定工具集，不训练模型「存什么、怎么组织、何时更新」**，导致记忆构建次优与信息丢失（p1）。
- 它指出的既有方案缺陷：
  1. 复杂 system prompt 只能部分缓解，手工调 prompt 无法覆盖全部场景；小模型指令跟随弱时，复杂指令反而把模型搞晕（p1–2）。
  2. SFT 需要「记忆构建真值轨迹」，而这种监督信号**无法从任何现有模型可靠获得**（p2）。
  3. 已有的 RL 记忆工作（MEM1、MemAgent、Memory-R1、Learn-to-Memorize、REMEMBER）记忆结构过于简单（整段重写或事实列表），不足以处理长叙事、程序性规则、演化知识、多模态（p2）；且 Memory-R1 等只在 LoCoMo（<~26k token）上训练与测试，任务偏易（p3）。

### 2.2 核心思想（关键 insight）
1. **记忆构建 = 序贯决策问题**：每步对 chunk 发一串（K_t 个）写操作，奖励按最终记忆 `M_n` 与全部动作计算；直接端到端优化「最终记忆好不好用」，而非模仿人类写的记忆轨迹（p3–4、§3.1.1）。
2. **只学写侧，读侧与生成侧完全冻结**：检索器 ϕ（BM25）与生成器 g（Qwen3-32B）固定，只有 write policy 可学——显式解耦「记忆怎么建」与「记忆怎么用」（§3.1.3、p5）。
3. **记忆结构要分层才学得动**：core（≤512 token 常驻摘要，只支持 update）/ semantic（原子事实，insert/update/delete）/ episodic（带时间戳事件，insert/update/delete）；且**记忆架构与 RL 框架解耦，可整体替换**（§3.3、p5–6）。

### 2.3 关键机制 / 算法（可独立搬运的「零件」清单）

| 零件 | 输入 → 输出 | 作用 | 出处（节/式/图） |
|---|---|---|---|
| 记忆构建 MDP 形式化 | 对话/文档 chunk 序列 C={c_1..c_n} → 终态记忆 M_n | 把慢环写入变成可训练的策略问题 | §3.1.1 p3–4 |
| **动作空间 A_write** | `memory insert` / `memory update` / `memory delete`，参数为结构化 function call（record id、memory type ∈ {core, semantic, episodic}、string content） | 离散、可枚举、可审计的写入算子集合 | §3.1.1 p4 |
| **每步多动作序列** | a_t = (a_t^(1), …, a_t^(K_t))，K_t 可变 | 一个 chunk 可触发多次写入（合并/删除同时发生） | §3.1.1 p4 |
| **观测** | o_t = (c_t, M_{t-1})，M_0 = ∅ | 观测含「当前记忆状态」，使写入具有上下文 | §3.1.1 p4 |
| 状态转移 T | (M^(k-1), a^(k)) → M^(k)，递推得 M_t | 写入确定性执行，便于回放 | §3.1.1 p4 |
| **r1 正确性奖励** | 终态记忆经 RAG 答对题目的比例，r1 = (1/m)Σ I[metric(ŕ_j, r_j)] | 端到端对齐「记忆好不好用」 | §3.1.2 p4；Appendix B p18 |
| **r2 工具格式/执行奖励** | r2,t = (1/K_t)Σ 1[该次调用无错执行成功] | 唯一「合法性」性质的奖励（权重固定为 1） | §3.1.2 p4 |
| **r3 压缩奖励** | r3 = 1 − l_m/l_c（l_m 记忆总长，l_c 输入总长） | 抑制记忆膨胀（全局量） | §3.1.2 p4 |
| **r4 记忆内容奖励** | r4,t = (1/K_t)Σ 1[Qwen3-32B 判官判定该操作语义有效] | 强制操作符合语义定义 | §3.1.2 p4；Fig 7–9 p20–21 |
| 奖励组合 | r_t = r1 + r2,t + β·r3 + γ·r4,t（β=0.05, γ=0.1；论文 §4.1 处写 γ=1，见 §9） | 全局量(r1,r3) + 逐步量(r2,r4) 分层加权 | Eq.(1) p4 |
| **GRPO 优化** | 组内均值/标准差归一化优势 A_t = (r_t − µ_group)/(σ_group + ε)；目标 Eq.(2)；**丢弃 KL 项以鼓励探索** | 无 critic 的策略优化 | §3.2 p5 |
| **三层记忆实例化** | core（单段 ≤512 token，仅 update）/ semantic（原子事实句列表）/ episodic（时间戳事件列表） | 结构与更新模式的差异化（增量 vs 整体重写） | §3.3 p5–6；Fig 3 p6 |
| **解耦 RAG 评估** | 固定 BM25 检索 top-k（semantic + episodic 两个池分别检索）→ 冻结 Qwen3-32B 生成 → 与参考答案比对 | 记忆质量的可测定义 | §3.1.3 p5 |
| 训练数据集构造 | 按 MemoryAgentBench 三能力（AR / TTL / LRU）组织 8 个数据源，4,139 实例 → 分层抽样 562 实例平衡子集 | 覆盖「精确检索 / 测试时学习 / 长程理解」三种记忆场景 | §3.4 p6；Table 6 p14、Table 7 p15 |
| 通用记忆提示 | 「先更新 core → 再存 episodic / semantic」固定两步模板 + `{max new tokens}` 预算 | 统一各数据集的写入接口 | Fig 6 p19 |
| 记忆内容判官提示 | core / episodic / semantic 各一套 JSON 判定提示（Qwen3-32B） | r4 的实现 | Fig 7/8/9 p20–21 |

### 2.4 关键表示与数据结构
- **记忆状态 `M`**：三组件并列——`core`（一段持续在上下文中的持久摘要，上限 512 token）、`semantic`（离散原子事实句的可扩展列表）、`episodic`（按时间组织的带时间戳事件的可扩展列表）（§3.3 p5–6，Fig 3）。
- **动作**：结构化函数调用，参数含 `memory type ∈ {core, semantic, episodic}`、`record id`、`string content`（§3.1.1 p4）；**core 只支持 update（整体重写），semantic/episodic 支持 insert/update/delete**（§3.3 p6）。
- **训练实例格式**：每个实例由多个 chunk 组成，每 chunk 触发一次（多动作的）写操作；平均约 8–15 chunk/实例、约 0.4k–1.9k token/chunk（Table 7 p15）。
- **未提及**：记忆条目数上限、向量嵌入（检索用 BM25，非向量）、图结构、任何跨个体/跨代继承的数据结构。

### 2.6 论文自陈局限与边界条件
- **假设依赖**：① 必须有「问题 + 参考答案」才能算 r1；② 依赖 LLM 判官（Qwen3-32B）判语义有效性；③ 依赖基础模型的 function-calling 能力——**Qwen3-8B 因持续产出畸形调用（如 `memory_type='semantic memory'`）被整体弃用**（Appendix C.1 p19）。
- **明确不适用 / 主动排除**：MemoryAgentBench 第四维 **Conflict Resolution（冲突消解）被排除**，理由是「缺乏真实评测基准，现有数据集多为合成、不足以刻画真实复杂度」（§3.4 p6）。这对 SSEA 是**关键缺口**：矛盾/覆写正是记忆最需要处理的情形。
- **未做的边界**：从模拟环境走向真实应用需接真实数据库与生产系统，会带来**延迟、可扩展性、安全**三类挑战（§5 p9）；记忆架构未来拟接入 MIRIX 等更复杂系统（§5 p9）。
- **未提及**：多 seed 方差、推理延迟/吞吐、单步写入的算力开销、记忆条目数上限、灾难性遗忘的定量测度、跨个体继承。

## 3. SSEA 立场对齐（核心维度）

### 3.1 C1–C10 映射

| 裁判标准 | 判定 | 依据（论文中的具体机制/数字） | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制架构，非语言生成 | ◐ | 全部实验在文本 QA / 意图分类 / 摘要域，与生存无关；但**写入侧是「观测 chunk + 记忆状态 → 结构化写操作」的控制环形状**，与生存信号无关的部分只是数据类型 | 把 chunk 换成结构化感知帧，把三类记忆换成结构化槽位；机制（写策略 → 记忆 → 影响后续行为）保留 |
| **C2** 自然语言只作观察员接口 | **✗** | 记忆内容本身是自然语言句子；动作是自然语言 function call；r4 由 LLM（Qwen3-32B）判定语义有效性；**语言在写入闭环内部** | **只搬动作空间的「形状」**（离散三动作 + 类型化参数），实现改为结构化张量/符号写入；语言判官整体删除 |
| **C3** 权重/记忆/技能三分离 | **◐** | 有分离意识：检索 ϕ 与生成器 g **冻结**、只训写策略 θ（§3.1.3 p5），记忆外置；但**写策略就是权重**，且权重更新与记忆更新由同一 RL 目标驱动、生命周期耦合（205 步内 θ 持续变） | 拆开：写策略 θ 归入「结构性先验」通道（慢环产物，随版本发布），记忆条目归入 ΔM（每次睡眠期可增删）；**二者不得由同一个标量奖励同时驱动** |
| **C4** 低算力低带宽 | **✗/◐** | 训练侧极重：**32×H100 × 3 天**、205 步、rollout n=8（§4.1 p7）；运行侧记忆量 OOD 平均 **129K token**（Table 2），远超 SSEA 可接受的常驻带宽；正面证据仅有压缩侧（129K vs RAG 207K，≈−38%）与每步 `{max new tokens}` 预算（Fig 6） | 训练侧只能降级（小模型 + 少步 + 在重放模拟器里训）；运行侧把「记忆总 token」改成**硬容量上限**（超出才触发合并/淘汰），而不是奖励项；以每步 token 预算作睡眠期预算的可测代理 |
| **C5** 精准回忆历史 | **✓** | 原子事实条目（semantic）+ 时间戳事件条目（episodic）分池存储、BM25 分池检索；OOD 精确检索类 Single-Doc 0.740 / Multi-Doc 0.680（vs RAG-Top2 0.690/0.450） | — |
| **C6** 可自主修改自身 | ◐ | 四权拆解在本文其实很干净：**提案权**=策略输出写操作；**边界权**=工具签名固定 `A_write` 三动作与 `memory type` 取值（模型改不了）；**验证权**=执行器返回是否成功（r2）+ 判官（r4）；**应用权**=T 函数真正改 M | 保留「边界权外置、应用权确定执行」这一形状；验证权必须换成四级验证门（只判合法性），不得用判官评分 |
| **C7** 保存/恢复/变异/继承 | — | M_0 每实例从空开始，**无跨实例、跨个体复用**；无 GenePackage、无变异、无淘汰-繁衍 | 若要用于 SSEA，须自行补：把训练好的写策略 θ 打包进 GenePackage（作为结构先验），记忆内容不进包 |
| **C8** 给基因先验，不给知识语料 | **✓（且有额外价值）** | 记忆全部由交互现场构建、不跨代；更关键的是：**被学习的对象是「如何组织记忆」的策略，而非任何知识内容**——这正是 C8 想要的「结构性先验」形态 | 直接采用这一断法：**θ 可遗传，M 不可遗传** |
| **C9** 不设评分函数，只有淘汰函数 | **✗（核心冲突）** | 四项奖励中**三项违规**：r1 = 下游 QA 正确率（**外部任务评分**，且是连续量 0..1，Eq.(1) 里权重 1）；r3 = 1 − l_m/l_c（**奖励塑形**，β 需调参）；r4 = Qwen3-32B 判官打分（**观察员评分**，明令违规）。仅 **r2（调用是否无错执行）属于「只判合法性」、合规** | 见下方「改造方案」与 §5；注意论文自身证据：γ=0（去掉判官评分）时性能 0.642→0.543，说明**照搬此法而删掉评分会塌**，SSEA 侧必须自备替代信号，不能只做减法 |
| **C10** 创新在 L2/L3/L4，不在 L1 算子 | ✓ | L1 全是借用（Qwen3-4B、GRPO、BM25、verl）；创新在 L2（三层记忆架构 + 写/读解耦）与 L3（写策略可学习） | — |

### 3.2 L1–L4 层级定位

| 层次 | 论文在该层提供了什么 | 对 SSEA 的价值 |
|---|---|---|
| **L1 算子层** | 无新算子（Qwen3-4B / GRPO / BM25 均为借用） | 无（符合借用立场） |
| **L2 信息流层** | 三层记忆（core/semantic/episodic）+ 写侧可学/读侧冻结的解耦 + 类型化写操作流 | **高**：这是可直接落进 ΔM 通道的骨架 |
| **L3 学习层** | 把「记忆怎么建」变成可训练策略（GRPO + 四项奖励） | **高，但信号不可搬**；形状可搬、目标函数不可搬 |
| **L4 演化层** | 无（无保存/变异/继承，M_0 每实例置空） | **低**；唯一贡献是提示「写策略本身可以当基因先验」 |

### 3.3 模块映射

| 论文构件 | SSEA 落点（现有模块 / 缺失组件 / 新增建议） |
|---|---|
| `A_write = {insert, update, delete}` + 类型化参数 | **新增**：慢环 ΔM 的离散动作空间（替代当前「写或不写 + 常量阈值」的钝门） |
| 每步多动作序列 a_t（K_t 可变） | **新增**：一次睡眠期允许「合并 + 新增 + 删除」打包成一个 ΔM 事务，原子提交 |
| 观测 (c_t, M_{t-1}) | 对应：睡眠期输入 = 新经验帧 + 当前记忆快照（**缺失**：当前慢环是否真拿到记忆状态，需核对） |
| core（≤512 token，只 update/整体重写） | 对应：快环常驻的压缩状态 / 本能槽；**缺失**：SSEA 目前无「常驻摘要」槽 |
| semantic（原子事实，增删改） | 对应：结构化事实记忆（ΔM 主通道） |
| episodic（带时间戳事件，增删改） | 对应：事件帧记忆（与 Dream-RSI 的历史重放直接对口） |
| 冻结检索 ϕ + 冻结生成器 g | 对应：**快环只读不可变快照**（冻结侧），与 SSEA 双环结构同构——这是本篇最贴合 SSEA 的结构 |
| r2（调用无错执行） | 对应：四级验证门第一级「格式」判据（**唯一可直搬的奖励**） |
| r3（压缩比） | 改造为 **C4 硬容量预算**（超出触发整理流程），不得作奖励项 |
| r1 / r4（QA 正确率 / LLM 判官） | **不落点**：违反 C9，删除 |
| 训练好的写策略 θ | 归入 **GenePackage 的结构性先验**分支（C8 允许），与知识性的 ΔM 分置（C3 要求） |
| `{max new tokens}` 每步预算 | 对应：**睡眠期计算预算**的可测代理量（当前未定义） |

### 3.4 债务与验收实验对应

- **债务 22（记忆二级门用常量阈值，慢环不可调 / 半接线）**：本篇给出正面样板——把「开不开门、开成什么动作」变成**慢环策略的输出**；但要接受它的教训：门的输出必须是**离散动作 + 合法性判定**，不能是分数。
- **记忆门「开得准不准」的选择性缺失**：本篇的 K_t 可变动作序列 + 类型化参数是「选择性」的具体实现形态（对不同记忆类型发不同动作），可直接抄形状。
- **睡眠期计算预算未定义**：本篇提供**反向量级参照**——32×H100 × 3 天、205 步、562 实例，才训出一个 4B 写策略；SSEA 的睡眠期预算不可能接近此量级，因此**只能训极小的写策略（或只训门控的少量参数），或完全离线在重放模拟器中训练**。
- **`retrieve` 键收窄 → 召回精度上限低**：**本篇不解决**（检索器固定为 BM25，读侧不可学）。读侧需靠 Memento / MemRL。
- **可服务的验收实验**：实验 2（记忆检索命中率，现 0.5164）与实验 3（技能固化，现 0/33，本篇不直接服务）；注意**危险回避率两臂已饱和 0.9814**，若用本篇做记忆臂实验，必须换更严环境或更难的判据，否则读不出差异（见 §8）。

## 5. 冲突、代价与风险

- **与硬约束的冲突**
  1. **C9 ✗（最主要）**：r1（外部 QA 评分，连续量）、r3（奖励塑形，β 调参）、r4（观察员 LLM 判官评分）三项同时违规。这是**方法的核心**，不是边角——删掉它们，Mem-α 就不复存在。
  2. **C2 ✗**：记忆内容是自然语言、动作是自然语言调用、有效性由 LLM 判；语言在写入闭环内部。
  3. **C4 ✗（训练侧）**：32×H100 × 3 天，与「低算力」立场直接冲突。
  4. **C3 ◐**：权重（写策略）与记忆由同一奖励耦合驱动。
- **「把奖励换成什么」的改造方案**
  - **r1 → 换成环境侧二值事实，不得是分数**：慢环候选 ΔM 经四级门发布后，只回传「该个体在同一环境重放中**是否被淘汰**」这一个 0/1 事实（淘汰函数归环境，模型碰不到定义，符合 C9 第①层）。若确实需要密一些的信号，只允许用 **C9 第②层的内在驱动**（预测误差 / 惊奇度），其定义不可改、不由外部任务给定。
  - **r4（观察员评分）→ 直接删除**，其功能由两处替代：① 四级验证门的**合法性判定**（格式→沙盒→回归→环境实测，只判合法、不打分、不排序）；② **SEDM 的 A/B 配对准入**（注入 vs 不注入，比较行为差/延迟/token 差，作为准入事实而非分数）。
  - **r3（压缩奖励）→ 从奖励项改为硬约束**：设记忆容量上限，超出即触发整理流程（合并/淘汰），判据是「是否超预算」这一合法性问题，而非连续奖励；并强制**只合并不硬删除**（借 LightMem 的做法），以避免 β 过大时的塌缩。
  - **只保留 r2**：调用是否无错执行（合法性），这是唯一合规项，且论文把它的权重固定为 1 而非调参——这一点本身值得抄。
  - **必须正视的反证**：论文自己给出 γ=0 时均值 0.642 → 0.543、并称之为灾难性退化（Table 4 p9）。因此**「删掉评分信号」不是免费的**，SSEA 侧必须同时给出替代信号（内在驱动 + 淘汰事实），否则不要启动这条路线。
- **隐含假设与失效条件**：① 需要「问题-参考答案」对（SSEA 环境没有 QA 标注）；② 需要 function-calling 能力（Qwen3-8B 因畸形调用被弃用，Appendix C.1）；③ **主动排除 Conflict Resolution**，而矛盾/覆写恰是 SSEA 记忆最核心的场景；④ 记忆一旦写错只能靠后续 update/delete 修正。
- **算力 / 带宽 / 工程代价**：训练 32×H100×3 天；OOD 平均记忆 129K token/任务；每步还受 `{max new tokens}` 约束。对 SSEA 而言，**训练侧代价不可接受**，只能降级为极小策略或离线模拟器训练；运行侧必须靠硬容量预算压住 129K 量级。
- **搬运后的可能退化模式**
  1. **记忆塌缩**：压缩压力过大 → 策略学会「什么都删」（论文 β=0.2 时记忆量降到 0.4K–0.8K、性能掉到 0.176–0.401，Table 4）。在 SSEA 里表现为「历史回忆能力整体消失」。
  2. **记忆膨胀**：本文**没有 NOOP 动作**（每个 chunk 都被提示要求先更新 core 再存条目），无「不写」选项 → 噪声全部入库。SSEA 侧必须**显式补一个 NOOP**（Mem0 的四操作里有，本篇反而没有）。
  3. **判据形变**：若把 r1 换成淘汰事实后策略学不到东西，会退化成「随机写入」或「恒定写入一类记忆」，表现为命中率不升而操作数暴涨。
  4. **语言残留**：若保留自然语言记忆条目，会悄悄把语言拉回控制闭环（C2 回归）。

### 6.1 关系图谱

| 关系 | 对象（点名论文或方法族） | 说明 |

| **替代 / 升级** | **Mem0** | 论文明确把 Mem0 点名为「只给工具、不教用法」的代表（p1）。Mem-α 的 `insert/update/delete` 与 Mem0 的 `ADD/UPDATE/DELETE/NOOP` 几乎同构 → Mem-α = **把 Mem0 里由 LLM 提示驱动的 CRUD 分类，换成 RL 训出来的策略**。代价：Mem0 无评分（分类操作，C9 友好），Mem-α 引入 QA 评分与判官评分（C9 倒退）。建议：**动作分类法取自 Mem0（含 NOOP），「动作选择可学习」取自 Mem-α** |

### 6.2 推荐组合方案

- **组合 A（主推）：Mem-α（动作空间） × SEDM（准入） × LightMem（节律） × Dream-RSI（训练场）**
  - 接口形态：Dream-RSI 重放历史产生 chunk 流 → LightMem 做摄入压缩与主题分段、按阈值触发睡眠期 → 睡眠期内由**写策略**输出一个事务性 ΔM（K 个动作：insert / update / merge / noop，**delete 默认改为合并或软标记**）→ 每个候选条目先过 **SEDM 的 A/B 配对准入**（注入 vs 不注入，看行为差/延迟/token 差）→ 过四级验证门（只判合法性）→ 原子发布。
  - 组合后新增能力：**慢环第一次拥有「可学习、可审计、有预算」的 ΔM 提案通道**；记忆膨胀由容量预算 + 只合并策略双向夹住。
  - 新增风险：写策略若无合规训练信号会退化为随机写入（见 §5 退化模式 3）；A/B 准入会把睡眠期成本翻倍，需先定预算。
- **组合 B（读侧补齐）：Mem-α（写） × Memento（读 μ） × MemRL（效用更新）**
  - 接口形态：写侧只出 ΔM 事务；读侧检索门由 μ（Memento）+ 两阶段硬阈值与效用重排（MemRL）构成。两侧**分别**训练、分别发布，避免一个标量奖励同时驱动读写（呼应 C3）。
- **组合 C（对照基线）**：Mem-α × Mem0 —— 用 Mem0 的提示式 CRUD（含 NOOP）作为 Mem-α 式学得策略的对照组，用于判断「学」到底带来了多少增益（本篇 Table 3 已给出同架构下 base 0.389 → 0.642 的增益证据，可作量级参照）。

### 6.3 本篇在组合中的典型角色

- **ΔM 提案器（写入动作策略）**：负责回答「这一批经验进来后，记忆库该怎么改——新增哪条、改哪条、合并哪几条、哪些不动」。
- 它**不是**检索器（读侧归 Memento/MemRL）、**不是**准入官（归 SEDM）、**不是**节律器（归 LightMem）、**不是**训练场（归 Dream-RSI）。

## 8. 裁决与下一步

- **应用等级：B 零件采用** —— 采用「离散写入动作空间 + 三层记忆 + 写侧可学/读侧冻结解耦 + 格式奖励作合法性门 + 压缩目标改硬预算 + 写策略作为可遗传结构先验」；**拒绝**其四项奖励中的三项（r1/r3/r4）、拒绝 LLM 判官、拒绝其语言化记忆表示。
- **优先级：P1**（不是 P0 的原因：C9 冲突位于方法核心，且 SSEA 当前最紧的 Gene Manager 缺失与 0/33 技能固化问题本篇不服务；但债务 22 与「记忆门选择性」直接对口，故排在近期）。
- **建议动作**
  1. 在慢环定义 **ΔM 事务**：动作集 `{INSERT, UPDATE, MERGE, SOFT_DELETE, NOOP}` + 记忆类型槽位（常驻态 / 事实 / 事件），一次睡眠期一个原子事务，可含多个动作；**补 Mem-α 没有的 NOOP**。
  2. 把 r2 形态做成**验证门第一级判据**（调用是否无错执行、参数是否在枚举内），权重固定、不调参。
  3. 把「记忆总量 / 每步 token」从奖励改为**硬容量预算**，超出触发「只合并、不硬删」的整理流程（对冲 β 塌缩）。
  4. 明确 C8 切分并写进 GenePackage：**写策略参数可遗传，记忆条目不可遗传**。
  5. 训练信号的替代方案先做**纸面设计**再动手（r1→淘汰二值事实 / 内在驱动；r4→SEDM A/B 准入事实），并明确记录论文反证（γ=0 → 0.543）。
  6. 先补 **MemGen / MemEvolve** 两张卡，再回头定本篇与它们的关系（当前无据，不作断言）。
- **最小验证实验**
  - **双臂**：臂 A = 现状（常量阈值二级门，规则写入）；臂 B = 结构化写入策略（三/五动作 + 类型化槽位），其更新信号只来自**环境侧淘汰二值事实 + 内在预测误差**，不含任何评分。两臂读侧完全一致（冻结检索）。≥8 seed。**训练场用 Dream-RSI 重放，不用真实环境**。
  - **判据（分档，先看分母）**：
    1. 机制计数（分母）：每夜 ΔM 事务数、各动作占比、NOOP 率、记忆条目数曲线、记忆总量 token；
    2. 行为差：记忆检索命中率（现 0.5164）、「该记的记住 / 该忘的没污染」的分项召回；
    3. 淘汰结果：危险回避率（两臂现均为 0.9814，**已饱和，必须换更严环境或更难判据**，否则此档读不出差异）。
  - **预期与证伪**：预期 B 臂在「记忆总量不增长或增速更低」的前提下命中率 ≥ A 臂；**证伪条件**为——B 臂条目数暴涨（无 NOOP 的噪声入库）或记忆量塌缩（β 式过度删除，命中率随之下降），或操作数×N 而命中率不升（策略退化为随机写入）。
- 若 **E 不采用**：不适用。
