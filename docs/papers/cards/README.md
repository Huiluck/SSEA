# 论文分析卡片集

对 `../`（`docs/papers/`）中论文逐篇做多维评估，决定**能否用于 SSEA**与**如何组合**。

- 空白模板与填写约定：[`../分析卡片-模板.md`](../分析卡片-模板.md)
- 卡片命名：`<论文短名>.分析卡片.md`，置于本目录
- 评分雷达图生成（仅依赖 Pillow）：

```bash
# 在项目根目录执行
.venv/Scripts/python.exe docs/papers/cards/assets/score_radar.py \
  docs/papers/cards/assets/<短名>-radar.png "<论文短名> 六维评分" \
  项目相关性=? 立场兼容性=? 可搬运性=? 证据强度=? 组合价值=? 落地成本=?
```

## 裁决等级

- **A 核心借鉴**：思想或机制构成 SSEA 某模块骨架
- **B 零件采用**：具体算法/表示可直接用于某模块
- **C 思想启发**：思路有启发，需重新设计
- **D 基准对照**：作为基线、数据集或评测参照
- **E 不采用**：与立场冲突或无关
