## 1. 一句话定位
- **论文主张**：用 SAPS 部分替换 + 随机结构搜索生成候选，用 GNN（GNoME）预测能量并按分解能阈值过滤，把候选送 **DFT（VASP/PBE）** 算真值；DFT 结果既**验证**预测又**回填**为新训练数据，循环 **6 轮主动学习**，得 **2.2M 相对既有凸包稳定的结构、其中 381,000 个位于更新后凸包**（前人 ~48,000，近乎一个数量级），能量 MAE **11 meV/atom**、结构命中率 **>80%**（p1、p3）。
- **为什么不适用（一句话）**：它是**监督式回归器 + 人设阈值的筛选管线**，无生存控制环、无三分离、无自修改与遗传，且用 MAE 损失训练、命中率衡量（违反「不设外部评分函数」）；**唯一可回溯到 SSEA 的是验证回路形状**——用环境侧确定性真值（DFT）筛候选并回填，对 C9 友好，故取 D 而非 E。

## 2. 问题 — 机制 — 证据
### 2.1 问题
既有 ML 无法估计相对竞争相的凸包稳定性（分解能），无法指导发现；候选生成靠化学直觉，限制了多样性（p1、p2）。
### 2.2 核心思想
1. **双管线 + 神经网过滤**：结构管线（SAPS + 测试时增强 + 深度集成）与成分管线（化学式 + 松弛氧化态 + AIRSS）并行生成，统一由 GNoME 预测并设阈值（p2）。
2. **数据飞轮**：过滤候选经 DFT 算真值 → 验证预测 + 回填训练；新稳定结构**回填为可继续替换的种子**（p1 Fig 1a、p8–p9）。
3. **缩放律与 OOD 涌现**：损失随数据幂律下降；训练止于 4 元却能预测 5–6 元结构（p1、p3 Fig 1d/e）。
### 2.3 关键机制 / 算法
| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| SAPS（对称感知部分替换） | 晶体 + 替换概率 → 部分替换候选（按 Wyckoff 分组控组合） | 高多样性候选生成 | p7；381,000 中 **232,477** 源自 SAPS |
| 深度集成 + 测试时增强 | n=10 GNN → 中位数 + 四分位距界；晶格缩放 20 档（80%–120%）取最小能量 | 稳定化预测、纠正未松弛结构 | p8 |
| 阈值过滤 | 分解能 + **50 meV/atom** → 待 DFT 候选 | 提高召回 | p8 |
| **DFT 验证（VASP/PBE/PAW）** | 候选 → 松弛后真值能量 | **环境侧确定性真值** | p9 |
| **回填回路** | DFT 结果 → 下轮训练集 + 新替换种子 | 数据飞轮 | p1、p8–p9 |
| 成分哈希切分 / MLIP 预训练（NequIP） | 归约化学式 MD5 → 85/15 切分；松弛轨迹 → 通用势 | 防泄漏；下游零样本 | p9；p10、p5 Fig 3 |
### 2.4 表示与数据结构
结构模型：原子=节点、距离<4.0 Å 建边（势 5.0 Å），3–6 层消息传递后线性读出能量（p8）。成分模型：元素=节点，特征=one-hot × 化学计量比（p8）。**无** GenePackage/技能库/参数快照；「记忆」仅为 GNoME 结构数据库。
### 2.5 实验证据
| 任务 / 基准 | 对照 | 关键数字 | 口径 |
|---|---|---|---|
| 稳定性 MAE | 前人 28 | 初始 **21** → 终 **11** meV/atom | MP 2018 快照 ~69,000；p3、p8 |
| 命中率（结构 / 仅成分） | 前人 ~1% | **<6%→>80%** / **<3%→33%/100 次** | 6 轮主动学习；p1、p3 |
| 稳定材料数 / 新原型 | 既有 ~48,000 / MP 8,000 | **381,000** 新凸包项（总 421,000） / **45,500**（5.6×） | p1；XtalFinder p4 |
| 实验验证 | — | ICSD 匹配 **736**（其中 **184** 为项目期内新发现） | 2023-01 查，保守下界；p4、p9 |
| r2SCAN 复核 | — | 二/三元 **84%** 保留负分解能（MP 90%）；四元 **86.8%** 仍稳定 | p4 |
| MLIP 零样本 | M3GNet/CHGNet | 超离子导体分类误差随数据幂律降，623 个未见成分 | p5 Fig 3 |
### 2.6 自陈局限
竞争多晶型相变、动态稳定性（振动谱/构型熵）、**可合成性**未解决（p5）；AIRSS 大量初始化不收敛且**原因未知**（p7）；成分标签天然含噪（p8）；DFT/PBE 只是真值近似，r2SCAN 更准但贵 5×（p9）。

## 3. SSEA 立场对齐（核心维度）
### 3.1 C1–C10 映射（短卡主要价值：记录「为何只能作对照」）
| 裁判标准 | 判定 | 依据（机制/数字） | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制架构 | ✗ | 控制目标是分解能/命中率，非生存；无自我保护（全文） | 无生存项可借，仅作对照 |
| **C2** 自然语言只作观察员接口 | — | 全程无自然语言，纯数值/结构信号（p2、p8） | 无关（比 SSEA 更无语言，但非因立场设计） |
| **C3** 权重/记忆/技能三分离 | ◐ | 权重=GNN（每轮重训）、记忆=GNoME 数据库确实分置；但**「技能」无独立单元**，替换模式/SAPS 是固定算法 | 把「候选生成策略」重铸为 ΔS；DB 归 ΔM |
| **C4** 低算力低带宽 | ✗ | 数百万 DFT + 10× 集成 + 10⁹ 级候选（terabytes，p10） | 仅作高算力上界对照 |
| **C5** 精准回忆历史 | ◐ | 新稳定结构**回填为替换种子**（精准复用自身产出，p8–p9）；无遗忘/合并，schema 单一 | 借「回填」思想；补遗忘/合并 |
| **C6** 可自主修改自身 | ✗ | 架构固定（p3「fix this architecture」）；主动学习只改数据/候选，不改代码/权重 | 无自修改；对照四权 |
| **C7** 可保存/恢复/变异/继承 | ✗ | 无基因包、无淘汰+繁衍；每轮模型是重训产物非可遗传结构 | 不涉及演化 |
| **C8** 给基因先验，不给知识语料 | ✗ | 初始模型训练于 MP 2018 快照（~69,000 材料）= 知识语料（p3） | 与 C8 相反 |
| **C9** 不设评分函数，只有淘汰函数 | ◐→✓（限验证回路） | **验证淘汰信号来自环境真值**：DFT 算真能量，稳定/不稳定由物理裁决，模型碰不到（p9）；**但**训练用 MAE 监督损失、命中率当指标、50 meV 阈值人设 → 整体是外部评分函数，**只有「DFT 验证」子环合规** | **只搬子环**：抽象为「环境侧确定性验证 → 回填」，去掉 MAE 与命中率 |
| **C10** 创新在 L2/L3/L4，不在 L1 算子 | ◐ | L1（GNN 消息传递）借用且可替换（p3 明说 fix 架构只做 scaling）；创新在**主动学习回路**（近 L2/训练管线，非 L3/L4） | 借「回路而非算子」的取向 |
### 3.2 L1–L4 定位
L1：GNN 消息传递 + NequIP 等变势（借用、可替换，p3、p10）→ 不构成架构声明（合 C10）。**L2：候选生成 → 过滤 → DFT 验证 → 回填 回路（p1 Fig 1a）→ 唯一可借（验证—回填信息流形状）**。L3：每轮重训 GNN（监督回归），非自修改 → 无。L4：无。
### 3.3 模块映射
DFT 验证回路 → 第四级「环境实测」门（缺失 Gene Manager/实验 4/5 的对照形状）；回填飞轮 → 慢环「睡眠期离线整理」的外部真值回填变体（对照 Dream-RSI）；深度集成中位数 → 记忆门选择性（债务「开得准不准」）的对照。
### 3.4 债务与验收实验对应
可回应：**判据形状（25/26/27/28）**——「真值来自环境而非模型」的正例对照；**记忆门选择性**——「回填+命中率」作对照臂。可服务：**实验 4/5（缺 Gene Manager 未开跑）**——回路形状作参照实现。

## 5. 冲突、代价与风险
- **与硬约束冲突**：C1 ✗（无生存，只能取回路形状）；C8 ✗（初始灌知识语料）；C9 ◐（整体是外部监督评分，**只有 DFT 验证子环合规**）；C4 ✗（数百万 DFT + 10 集成）。
- **隐含假设与失效条件**：DFT/PBE 视为稳定性真值——若真值有系统偏差（r2SCAN 仅 84%/86.8% 保留），「环境真值」不纯；阈值人设，非环境涌现。
- **工程代价**：巨大（terabytes 级候选、Apache Beam 分布式），须大幅裁剪。
- **搬运后退化模式**：照搬 MAE 损失会把 SSEA 拉回「监督评分器」——正是 C9 要防的；须**只搬验证—回填环，剥离损失与指标**。

### 6.1 关系图谱

| **互补（LLM 科学发现）** | **MOOSE-Star** | MOOSE-Star 训练 **P(h\|b)** 假设生成（LLM + 外部反馈）；GNoME 是**非 LLM** 的候选—真值回路 → 构成「LLM 生成假设」vs「GNN 生成候选 + DFT 判真」对照臂；SSEA 若取 LLM 生成，须以 GNoME 式真值回路替换 MOOSE-Star 的外部反馈 |

| **替代 / 前置** | Dream-RSI 的「重放模拟器」 | GNoME 用**外部真值（DFT）**替代「自建模拟器」作验证源；用它前需先有 SSEA 的「候选提案」与「环境真值」两侧 |
### 6.2 推荐组合方案
- **组合**：GNoME 回路形状 + **ALab**（物理验证）+ **EndlessTerminals**（确定性终态判据）+ **ScaleEnv**（规则式状态判据）。
- **接口形态**：慢环产出候选 ΔS/ΔM → 过「环境侧确定性验证」→ 真值**回填**为新候选种子；验证门**只判合法/淘汰，不打分**。
- **组合后新增能力**：第四级「环境实测」门从手写 6 通道升级为**可批量、真值归环境、可回填**的候选—验证—回填环。
- **新增风险**：真值成本高 + 「阈值人设」重新引入评分函数（违 C9）。
### 6.3 典型角色
**「环境侧确定性验证」的科学域最强对照臂**（给形状，不给生存/演化/自修改）。

## 8. 裁决与下一步
- **应用等级**：**D 基准对照** —— 理由：与 SSEA 立场仅 C9 一轴相关，且**只有「DFT 验证」子环合规**；价值在于提供「候选→环境侧确定性验证→回填」的工业级形状，作第四级验证门与判据形状债务（25/26/27/28）的对照臂，而非可整体采用的机制。**优先级 P3**。
- **建议动作**：① 把「候选→验证→回填」抽为**接口草图**，与四级验证门（格式→沙盒→回归→环境实测）对齐，标出「真值来自环境」的位置；② 在实验 4/5（Gene Manager）设计中，用 GNoME 回路作**参照实现**（验证门只判淘汰、不打分）。
- **最小验证实验**：**双臂**：臂 A＝现有验证门（含模型侧评分/常量阈值）；臂 B＝「环境真值淘汰 + 回填」回路（借 GNoME 形状，去掉 MAE 与命中率）。**判据（机制计数 → 行为差 → 淘汰结果；先看分母）**：先看候选**分母**（生成数），再看验证门**淘汰率**，最后看行为是否因回填而改变。**预期与证伪**：若臂 B 的淘汰率与行为差均无变化（判据饱和，同 ScaleEnv 病灶），则证伪「回路形状本身可提升判别力」，须另补校准器。
- 若 **E 不采用**：不适用（取 D）。
