## 1. 一句话定位

- **论文主张**：树搜索（MCTS 等）能把 LLM 数学推理拉高，但「浪费式搜索」要花 **10 倍以上**于贪心解码的算力；用**动态节点选择**（Eq.2）＋**节点级探索预算**（Eq.3）＋一个**只用最终答案远监督训练**的价值网络，在 GSM8K/TabMWP 上以**竞争性精度、显著更低的 #token** 达到同等搜索效果（摘要、Table 1）。
- **对 SSEA 的意义**：**立场上不适用**（语言域、无生存控制、价值网络选路违反 C9），但它把「**用更少的节点扩展达到同等搜索效果**」做成了一套**可抄的成本控制机制 + 可填的节省数字**——正对 SSEA **C4（低算力）** 与「**睡眠期计算预算未定义**」这条硬门槛：若慢环前瞻预演要做搜索，必须先知道每步成本。

## 2. 问题 — 机制 — 证据

### 2.1 论文要解决的问题
- 问题本身：树搜索引导的 LLM 数学推理算力过重（>10× 贪心），难以落地（摘要 p1）。
- 既有方案缺陷（§1 p2）：BFS 用**恒定预算**，无视「有些节点不需多扩展」；部分 MCTS 自适应预算但需大量 simulation/rollout 才统计准，且**忽略深度（进度）信息**。

### 2.2 核心思想
1. **选择端**：用「价值（未来）＋进度（历史）」共同排序节点，优先探索更快到答案的节点（Eq.2）。
2. **扩展端**：把「每节点扩展多少子节点」做成**随价值与深度自适应**的预算 b，早探索、晚利用，避免搜索空间爆炸（Eq.3）。
3. **校准**：首几步价值方差大，用贪心轨迹价值 ˆv 校准前几步（Eq.4），弥补延迟稀疏奖励的学习不足。

### 2.3 关键机制 / 算法
| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| 动态节点选择 | 树节点集合 → 选中节点 s′ | argmax(v(S_i)+λ·p(S_i))，探索-利用平衡 | Eq.2 §3.1.1 |
| 进度项 p(S) | 状态 → 标量 | 步数/贪心总步数（d/ˆd）估计「离答案多近」 | §3.1.1 |
| **节点级预算 b** | v(S)、深度 d → 子节点上限 | b=min(⌈log(1−ϵ)/(d·log(1−v(S)))⌉,B)，含 1/d 深度惩罚 | **Eq.3 §3.1.2** |
| 价值校准 v′(S) | v(S)、贪心值 ˆv → 校准值 | (v(S)+ˆv/d)/(1+1/d)，主救前几步 | Eq.4 §3.1.2 |
| 两种扩展策略 | 预算 b → 子节点 | Incremental（省算力）/ Batch（拓宽空间） | §3.1.2 |
| 价值网络 v(S) | 状态 → [0,1] 标量 | Llama3-8B + 线性回归头；仅用答案对错做 MSE 远监督 | Eq.6–7 §3.2 |

### 2.4 关键表示与数据结构
- 搜索树：根=问题 q，节点=推理步 s_i，状态 S_i=(q,s_1,…,s_i)；S_0=q（§3.1）。无跨 episode 记忆结构。

### 2.5 实验证据
| 任务 / 基准 | 对照基线 | 关键数字（Mixtral-8×7B） | 统计口径 |
|---|---|---|---|
| GSM8K 主表 | ToT-BFS / Soft Voting@20 | **ToT-BFS .801 @2.22k → Ours(Batch) .823 @0.55k**（≈4× 少 token 且更高分）；Ours(Incremental) .797 @0.41k | Table 1 p6（单值） |
| TabMWP 主表 | ToT-BFS / Soft Voting@20 | **ToT-BFS .861 @1.45k → Ours(Incremental) .863 @0.22k**（≈6.6× 少 token） | Table 1 p6 |
| 动态预算消融 | ⇒static budget / w/o depth penalty / w/o greedy value | Batch⇒static：**.823/0.55k → .802/1.79k（≈3× 算力）**；Incremental⇒static .797/0.41k→.779/0.67k | Table 2 p7 |
| 预算上限 B 消融 | B={1,2,3,5,10} | 存在清晰「精度-成本」权衡；B≤3 时 Incremental 更省，B∈{5,10} 时 Batch 更准 | Fig.4 p7 |
| 进度估计 | 步数 vs token 数；λ={0,…,0.2} | 用步数 + λ=0.15，**牺牲 1.3 点精度省近 20% 算力**；token 数估计效果差 | Fig.5 p7 |

### 2.6 论文自陈局限与边界条件
- **引导树搜索常打不过 Soft Voting 的精度**：首几步价值方差大（第一步平均排名 3.0 vs 末步 1.4），导致高质量节点探索不足而失败（§4.5 p8–9）。
- **不计价值网络成本**：作者称回归任务成本远低于生成、可并行部署（§4.1 p5）——这是口径选择，非零成本。
- 仅数学推理两数据集；B=10、N=100、λ=0 等默认值固定；主表为单值，未报 seed/显著性。

## 3. SSEA 立场对齐

### 3.1 C1–C10 映射
| 裁判标准 | 判定 | 依据 | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制架构，非语言生成 | ✗ | 控制对象是 LLM 语言解码，状态/动作都是语言（§3.1） | 只借「预算化搜索」信息流，控制量换结构化生存量 |
| **C2** 语言只作观察员接口 | ✗ | 语言即动作与状态空间（§3.1） | 预演在结构化状态上做，语言不入环 |
| **C3** 权重/记忆/技能三分离 | ✗ | policy LLM + value 网络两套权重；无记忆/技能分离（§3.2） | 预演产出走 ΔS/ΔM 分离；价值件只作仪器 |
| **C4** 低算力低带宽 | ◐（主战场） | 全文目标是**降算力**：节点级预算 Eq.3、Incremental 省近 20%、消融显示 static 多 3× 算力；但绝对成本仍 > 贪心，且需 value 前向 | 预算机制可搬；绝对带宽仍超 C4，需换成结构化稀疏信号 |
| **C5** 精准回忆历史 | ✗ | 仅搜索树内状态，无跨 episode 检索/遗忘/合并 | 记忆侧交 Memento/FLEX |
| **C6** 可自主修改自身 | ✗ | 价值网络离线训练，运行期不改自身 | 不搬 |
| **C7** 保存/恢复/变异/继承 | ✗ | 无 GenePackage、无变异/继承 | 不搬 |
| **C8** 给基因先验，不给知识语料 | ✗ | policy LLM 预训练于人类语料，任务知识进权重 | 基因只放结构先验 |
| **C9** 不设评分函数，只有淘汰函数 | **✗（主战场）** | 价值网络是**训练出的外部评分器**，用于**选路**（Eq.2 argmax）与**阈值终止**（v>ε）；预算 b 也由 v(S) 决定（Eq.3） | 价值/预算只作**环境侧仪器**；预演只输出候选、不打分不排序；选择交模型外淘汰 |
| **C10** 创新在 L2/L3/L4，不在 L1 算子 | ✓ | 无新算子（LLaMA/树搜索全借用）；创新在 L2（预算化搜索信息流） | — |

### 3.2 L1–L4 层级定位
| 层次 | 论文在该层提供了什么 | 对 SSEA 的价值 |
|---|---|---|
| **L1 算子层** | 无新算子（Llama3-8B + 线性回归头，借用） | 符合借用立场 |
| **L2 信息流层** | select→expand（预算闸）→终止的搜索管线 | **高**：慢环「前瞻预演」信息流 + **预算闸形状参照** |

| **L4 演化层** | 无 | — |

## 5. 冲突、代价与风险

- **与硬约束的冲突**：**C9（最硬）**——价值网络是训练出的外部评分器，用于选路（Eq.2）与阈值终止（v>ε），预算 b 也由 v(S) 决定；**C1/C2** 语言即控制对象；**C3/C6/C8** 权重共训、知识进权重；**C4** 绝对算力仍 > 贪心。
- **隐含假设**：存在**可训练的价值目标**（任务有真值，Eq.6 用答案对错做远监督）——SSEA 无外部评分，此前提不成立。
- **算力 / 工程代价**：即便省算力，仍需 value 前向 + 树搜索；论文**不计价值网络成本**（§4.1），实际成本被低估。
- **搬运后的退化模式**：若把「预算 b 由价值分决定」直接搬进慢环，会长出模型内评分函数 → 架构变质（C9）；若只搬 Eq.3 而不设上限 B，会撞「睡眠期预算未定义」；Incremental 在 GSM8K 精度低 2.6 点，省钱有精度代价。

### 6.2 推荐组合方案
- **组合**：**本篇（预演预算闸公式 + 节省数字）× EvoTest（成本台账）× AgentEvolver（成本标尺）× MoreLLMCalls（预算匹配理论）× TreeSearchDecoding（对照纪律）**
- **接口形态**：SSEA 慢环前瞻预演 = 逐节点预算闸（Eq.3 形状，但 v 只作仪器不选路）+ 每步 #token/#forward 记账 → 先定预算上限 B → 报「同等搜索效果下的成本」。
- **组合后新增能力**：把「睡眠期预算未定义」变成**可填的公式 + 可对标的数字**（省近 20%、static 多 3×）。
- **新增风险**：若预演让价值分参与**选路/终止**即违反 C9——须硬性规定价值件只作环境侧仪器。

### 6.3 本篇在组合中的典型角色
- **睡眠期「前瞻预演」成本闸的形状与数字参照 + C9 反面标本**——管「预演每步该花多少算力」，同时标记「训练评分器引导搜索」这条 SSEA 禁区。

## 8. 裁决与下一步

- **应用等级：D 基准对照** —— 理由：立场上整体不适用（语言域 + C9 反面 + 权重共训 + 绝对算力仍高），但其**节点级预算公式 + 实测节省数字 + 成本记账口径**对 SSEA「睡眠期计算预算未定义」有直接参照价值。
- **优先级：P2（排队）** —— 仅在建设「前瞻预演」实验时取用其预算闸与数字。
- **建议动作**：
  1. 在慢环预演设计里，照搬 Eq.3 的**「价值 × 深度 → 子节点上限」形状**（v 只作仪器，不参与选路/终止）；
  2. 预演实验统一报 **#token/#forward**，并画**预算上限 B 的权衡曲线**（对照 Fig.4）；
  3. 建 issue：`睡眠期预演须有逐节点预算闸与成本记账（LiteSearch 参照）`。
- **最小验证实验（服务睡眠期预算定义）**：
  - **双臂 / 消融**：预演（自适应预算）/ 预演（static 固定预算）；另加「不预演」基线；≥8 seed。
  - **判据（分档：机制计数 → 行为差 → 淘汰结果；先看分母）**：① 机制计数（每步 #token、扩展节点数、预算命中率）→ ② 行为差（同等搜索效果下的成本差）→ ③ 模型外存活/死亡。
  - **预期与证伪**：预期自适应预算在**同等效果下省 ≥20% 成本**（本篇实测参照）；**证伪**＝若自适应预算省不下算力、或精度掉超过 3 点，则「动态预算」对 SSEA 预演无益，应退回固定预算或不预演。
- 若 **E 不采用**：不适用（裁决 D）；**但若把价值网络搬进慢环做选路，则本片退化为纯反例（E）**。
