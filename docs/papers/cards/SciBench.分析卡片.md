## 1. 一句话定位

- **论文主张**：现有科学推理基准多停留在高中题与四则运算，故构建大学级（数学/物理/化学）**自由作答数值题基准 SciBench**（10 本教材 + 课程考题），测得最强模型仅 **43.22%**（GPT-4 few-shot+Python，Table 3），并用 LLM verifier 把错误归入十种能力缺陷。
- **对 SSEA 的意义 / 为什么不适用**：它评的是「语言模型答对题没有」，是**外部评分函数**驱动的语言能力榜单，与控制环、生存信号、双环结构、GenePackage 全无接口；对 SSEA 唯一价值是**反例**（见 3.1 C9）。

## 2. 问题 — 机制 — 证据

### 2.1 论文要解决的问题
- 问题本身：LLM 在高中/四则运算基准上分数虚高，缺一个考察**大学级复杂科学推理 + 数值计算 + 多模态**的评测场。
- 指出的既有缺陷：ScienceQA/GSM8K 仅年级水平；MMLU/AGIEval/JEEBench 虽跨学科但只需基本四则运算；多数基准纯文本，缺图。

### 2.2 核心思想
1. 用「教材 + 课程考题」构造大学级自由作答题，答案统一为**三位小数数值**（相对容差 5%）以便自动判分。
2. 用 **LLM verifier（GPT-3.5）+ 人工抽检**把每个错解归到十种「问题求解能力」之一，产出 error profile，替代昂贵的人工错误分析。

### 2.3 关键机制 / 算法（零件清单）
| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| 数值答案归一化 | LaTeX 答案 → 三位小数 + 单位分离（`2.2e-31 m` → 2.2 与单位） | 自动判分、避免歧义 | §3 p.5 |
| 十技能错误分类协议 | (题, 正确解, 模型解) → 错误类别 1–10 | 自动化错误归因 | §5, Fig.3, C.1 p.19 |
| 提示模板族 | 题 → 解 + `\boxed{答案}` | zero/few-shot、CoT、Python、Wolfram 四设定 | §4.1, C.1 p.18–20 |

### 2.4 关键表示与数据结构
- 题目：LaTeX（Mathpix OCR + 人工校对），含**数值答案 / LaTeX 答案 / 单位（独立字段）/ 分步解**四元组。
- 十种能力标签：逻辑分解、假设识别、空间感知、因果推理、问题推演、抽象推理、科学素养、代码转换、逻辑推理、计算能力（§5）。

### 2.5 实验证据
| 任务 / 基准 | 对照基线 | 关键数字 | 统计口径 |
|---|---|---|---|
| 教材集（869 题，10 书） | 7 个单模态 LLM × 4 设定 | 最高 **43.22%**（GPT-4 few-shot+Python）；GPT-4-Turbo zero-shot 40.99%；LLaMA-2-7B 低至 1.03% | Table 3，accuracy，temperature=0，容差 5%，按题量加权 |
| 多模态子集 | GPT-4(caption+OCR) vs 4 开源 LMM | GPT-4(PoT) **13.8%** vs LLaVA-LLaMA-2-13B 7.4% | Fig.2 |
| 考题子集 | 5 模型 zero / zero+CoT | GPT-4 均分 **57.54%**；Data Mining 期中 64.44% vs 学生 80.18% | Table S2，按教师 rubric 评分 |
| 错误归因协议 | 人工抽检 151 例 | 分类正确率 **81.45%**（123/151）；约 20% 错分被人工剔除 | §D.1；10 能力源自 112 条人工错误标注 |

### 2.6 论文自陈局限与边界条件
- 假设依赖：教材集**限定单数值答案**（多子题被删或拆分），考题集才允许自由作答；依赖 GPT-3.5 作 verifier，其误判靠人工抽检兜底。多模态题被排除出「文本可解」范围（Fig.S12），生物/计算机/工程列为**未来扩展**而非本文覆盖。

## 5. 冲突、代价与风险
- **与硬约束的冲突**：C1/C2/C4/C9/C10 全线冲突（见 3.1）。它把「外部评分函数」当作评测本身，与 C9「只有淘汰函数」正面相悖。
- **隐含假设与失效条件**：假设「答案 = 三位小数」即代表「会解题」，把过程合法性完全外包给数值匹配。
- **算力 / 带宽 / 工程代价**：GPT-4 级推理 + 代码解释器，与 SSEA 低算力低带宽目标相反。
- **为什么仍保留在论文池**：作为**基准对照臂**——给 SSEA「判据形状」债务提供反面参照，避免把「数值/字符串对得上」误当成机制成功。

## 6. 组合分析
- **关系图谱**：无前置依赖、无互补、无替代；仅作**对照**对象（债务 25/26/27/28 的判据设计讨论）。
- **推荐组合方案**：— 无。与 Dream-RSI/Memento/FLEX/PSN 等主干无接口。
- **本篇在组合中的典型角色**：— 不进入任何组合；仅作为文档级「反面判据样本」。
