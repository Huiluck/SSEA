## 1. 一句话定位

- **论文主张**：发布 Natural Questions（NQ）——首个把**真实用户搜索 query** 与 Wikipedia 页面上的**长答案/短答案**高质量标注配对的大规模 QA 基准（307,373 训练 + 7,830 dev 5-way + 7,842 test 5-way，p1–2）；提出基于 5-way 标注的鲁棒度量（h_β, β=2）与「super-annotator」人类上界（长答案 90.0/84.6/87.2、短答案 79.1/72.6/75.7，Table 3 p10），并给出远低于上界的基线（DecAtt+DocReader 长答案 F1 54.8/55.0，Table 3 p10）。
- **为什么不适用**：它是**评测基准 + 数据采集/度量方法**，不含任何生存控制环、自修改、权重/记忆/技能三分离或演化结构；唯一价值是作为「QA 式判据（EM/F1 类）会饱和、且依赖人工评分」的反例臂，服务 SSEA 实验 2 的判据形状讨论。

## 2. 问题 — 机制 — 证据

### 2.1 问题
开放域 QA 缺少**真实问题 + 高质量答案标注**的端到端数据；既有数据集在问题来源、答案标注、质量度量、评测指标四处均有缺陷（p1、§2 p2–3）。它点名：SQuAD 众包问题常借用证据段、可被干扰句欺骗；MS MARCO/DuReader 用 BLEU 打分且不报告标注质量；NarrativeQA 无人类上界（§2 p2–3）。

### 2.2 核心思想
1. **问题来源真实**：题目取自 Google 搜索日志中 8 词以上、被多用户短时发起的真实 query，用启发式过滤出问句（§3.1 p4，Table 1 p4）。
2. **答案允许歧义**：同一 (q, page) 常有多条可接受答案，故用 **5-way 标注**与 h_β 判据（β=2）吸收标注者分歧（§4.4 p7、§5.1 p8）。
3. **度量需可解释的人类上界**：用 25-way 标注近似 p(l|q,d) 构造 super-annotator（§5.2 p9）。

### 2.3 关键机制 / 零件
| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| 问题启发式过滤（5 条规则） | 搜索 query 流 → 问句子集 | 剔除非问句，保留复杂长问句 | §3.1 p4，Table 1 |
| 长/短答案标注协议 | (q, page) → (long, short) | 长答案=含全部必要信息的 HTML 包围盒（段/表/列表）；短答案=实体 span/yes-no/NULL | §3.2 p4–5，Fig.1 p2 |
| 5-way 度量 h_β | 5 条标注 + 模型输出 → 0/1 | g(a)≥β 且命中任一标注，或 g(a)<β 且预测 NULL 则判对（β=2） | §5.1 Def.1 p8 |
| super-annotator 上界 | 20-way 标注 → 预测 | 近似 p(l\|q,d) 的可达人类上界 | §5.2 p9，Table 3 |
| 标注质量评估（C/Cd/W） | (q, l′) → 共识类别 | 4 位专家共识判「正确/可辩/错误」 | §4.2–4.3 p6–7，Table 2 |

### 2.4 表示与数据结构
- 四元组 `(question, Wikipedia page, long answer, short answer)`；long answer 为 HTML 包围盒或 NULL，short answer 为 span 集合/boolean/NULL（§3 p3–4）。
- 统计：49% 样本有长答案、36% 有短答案 span/yes-no（§3.3 p5）；长答案类型 73% 段落、19% 表格、1% 表行、3% 列表、3% 列表项。标注者约 50 人，平均 80 秒/题（§3.2 p4）。

### 2.5 实验证据
| 任务 / 基准 | 对照基线 | 关键数字 | 统计口径 |
|---|---|---|---|
| 标注精度 Ψ̂ | 4 专家共识 | 长答案 90%（C 59%+Cd 31%）、短答案 84%（C 51%+Cd 33%） | Table 2 p7，\|S\|=139 |
| 长答案 F1（dev/test） | DocumentQA / DecAtt+DocReader | 46.1/45.7 · **54.8/55.0**（最弱基线 First paragraph 27.8/28.3） | Table 3 p10 |
| 短答案 F1（dev/test） | DocumentQA / DecAtt+DocReader | 35.7/35.1 · 31.4/31.5 | Table 3 p10 |
| 人类上界（†5 抽自 25-way） | single annotator / super-annotator | 长答案 73.4 / **87.2** F1；短答案 57.5 / **75.7** F1 | Table 3 p10 |
| 非 NULL 子集 / 类型分解 | DecAtt+DocReader | 长答案 68.0、短答案 40.4 F1；段落 65.1%、表/行 66.4%、列表/项 32.0% | §6.4 p11 |

### 2.6 自陈局限
仅 Wikipedia 单一知识源（自承「可能有偏差」），未覆盖短 query、how-to 问句与非 Wikipedia 域（§3.1 p4）；boolean 答案留待未来工作（§6 p9）。歧义边界：25-way 中长答案最多 7 条并存（白炽灯题）、短答案最多 11 条不同但正确的答案（右心室题）（§4.4 p8）。

## 5. 冲突、代价与风险
- **与硬约束的冲突**（对应 3.1 ✗）：C2（语言进控制闭环）、C4（整页长文本高带宽）、C8（知识语料而非结构先验）、C9（外部人工评分函数）。
- **为什么仍值得保留在论文池**：它是「**QA 式判据**」的纯净标本——h_β/F1 在 NQ 上从 31.4→55.0→87.2 有清晰分档，且**依赖人工 5-way 标注**才能判对；正好论证 SSEA 实验 2 中「判据饱和 + 判据需外部评分」两重问题，保留为**反例臂**。

## 6. 组合分析
- **本篇角色**：实验 2「判据形状」的**反例臂（对照臂）**；不接入代码，仅在实验设计文档中作为「QA 式判据」参照点。
- **与已有卡片的关系**：与 **RAGEN**（B/P1，Echo Trap 诊断）对照——RAGEN 指出「EM 类奖励饱和后参数侧坍缩」，NQ 提供该饱和现象的**原始基准证据**（上界 87.2 vs 基线 55.0 的 gap）；与 **TriviaQA**（D/P3，同为 QA 反例臂）互补——TriviaQA 用 EM/F1 + 远距离监督，NQ 用 5-way + h_β，共同说明「QA 判据随标注口径变化、非环境原生」；与 **Misevolve**（A/P1）组合可论证「用静态 QA 判据替代生存淘汰函数」属违规演化路径。

## 8. 裁决与下一步
- **应用等级**：**D 基准对照** —— 理由：无任何可搬运机制，但作为「QA 式判据会饱和且依赖外部人工评分」的**反例臂**，对实验 2 判据形状讨论有对照价值；不升级为 C 是因为其思想（5-way 人工评分、整页高带宽 QA）与 SSEA 立场直接冲突。**优先级**：P3。
