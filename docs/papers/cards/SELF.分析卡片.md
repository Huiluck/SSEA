## 1. 一句话定位

- **论文主张**：提出 **SELF**——两阶段自演化框架：① **元技能学习**（用 GPT-4 标注的小规模 `D_meta` 教会模型 **self-feedback + self-refinement** 两项元技能）；② **自演化训练**（模型对无标注指令自生成回答 → 自反馈精炼 → **用自反馈过滤**保留下来的 `(p, r̂)` 作 SFT 数据 → 迭代 T 轮，每轮混入 `D_meta` 防元技能遗忘）。在数学（GSM8K、SVAMP）与通用（Vicuna testset、Evol-Instruct）域实现**无人工干预的持续自我提升**（摘要 p1、§3 p4–5、Alg.1 p17）。Vicuna-7b 上 GSM8K 16.43 → **29.64（直答）/ 31.31（推理时自精炼）**，SVAMP 36.40 → 49.40 / 49.80（Table 1 p8）。
- **对 SSEA 的意义**：**正面**——它把 Reflexion 的「语言反思外环」补上了**参数内化**这一步（反思不再只是 transient hint），给出「**元技能先学 → 迭代自训练**」的**两相位回路**，以及「**同一条自反馈既作精炼引导、又作数据筛选门**」的双用途结构；其**停机判据**（「自精炼不再带来增益即停」，A.1.3 p13–14）与 **restart 优于 continual**（Table 7 p18）是可直接引用的工程实证。**反面（决定性）**——它的**演化载体是自然语言**（反馈、精炼、训练数据、筛选判据全是 NL），其**筛选门由模型自己判定**（math: "judgment: correct"、general: rating≥7，A.8 p17），既无环境事实、又随每轮 SFT 漂移——是 **C2 与 C9 的双重硬冲突**，且其「把元技能与精炼数据内化进 θ」的路线与 **EvolveR 的 exp-absorb 负结果（0.382→0.371）正面矛盾**。

## 2. 问题 — 机制 — 证据

### 2.1 论文要解决的问题

- **问题本身**（p1）：LLM 的**自主演化路径未被探索**；人类式「初试 → 内省反馈 → 行为精炼」的学习循环能否由 LLM 模仿，从而在无人工标注下持续自我提升？
- **它指出的既有方案缺陷**（§1 p1、§2 p3）：
  1. **单轮指令微调 / RLHF**：依赖精编数据集与**外部奖励模型**，需大量资源与持续人工介入，且把 LLM 当作「被动信息容器」而非主动学习者；
  2. **在线自改进（Reflexion / Self-Refine 一类）**：需多轮推理、算力开销大，且**最致命——模型参数不变，无法阻止重复犯同样的错**（"does not prevent the model from repeating previously encountered errors, as the model's parameters remain unchanged"，§2 p3）；**标量奖励**对复杂推理「提供的洞见有限」，无法指出具体错误与优化路径（引 Lightman et al. 2023）。

### 2.2 核心思想（关键 insight）

1. **先教「元技能」，再让元技能驱动自演化**：self-feedback（评估自己的回答）与 self-refinement（据反馈改答案）不是天生能力，需用少量示例**先学**；学会后模型才能自造训练数据（§3.1 p4）。
2. **自反馈一物两用**：同一条反馈既是**精炼引导**（生成更好的 r̂），又是**数据筛选门**（`qualified(f)` 决定 r̂ 是否进 `D_evol`）——这是本篇最可搬的结构（§3.2.1 p5、A.8 p17）。
3. **自演化 = 把「生成—反馈—精炼」三步压缩进直答**：Eq.2/3 的优化等价于最小化 `KL(Ψ^{t-1} ‖ τ^t)`（Eq.4 p6），即让第 t 轮的**直接生成**去逼近第 t−1 轮的**链式过程**——能力被逐步内化。
4. **语言反馈优于标量奖励**：NL 反馈能指出具体错误与改进方向，且可跨多维度，不像标量奖励需为每个评估维度重训模型（§3 p4）。——**此条即 C9 冲突的来源**。

### 2.3 关键机制 / 算法（可独立搬运的「零件」清单）

| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| **两相位回路** | 初始 LLM → 元技能学习 → T 轮自演化训练 | 主流程 | Fig.1/2 p2–3、Alg.1 p17 |
| **元技能语料 `D_meta`** | 无标注 prompt p → `(p, r, f, r̂)` | 教 self-feedback + self-refinement | §3.1.1 p4；A.6 p15–16 |
| **元技能损失 `L_meta`** | `−E[log τ(f\|p,r) + log τ(r̂\|p,r,f) + β log τ(r̂\|p)]`（Eq.1） | 同时教反馈、精炼、直答 | Eq.1 p4 |
| **自演化数据生成** | `M^{t-1}` 对 `p_evol`：直答 r → 自反馈 f → 自精炼 r̂ | 自造训练数据 | §3.2.1 p5 |
| **自反馈过滤 `qualified(f)`** | math: "judgment: correct"→1；general: rating≥7→1（A.8 p17） | **二值筛选门**（同时是精炼引导） | §3.2.1 p5；A.8 p17 |
| **自演化损失 `L_evol`** | `−E_{p}E_{r̂∼Ψ^{t-1}}[log τ^t(r̂\|p)]`（Eq.2/3） | 把链式过程压进直答 | Eq.2–3 p5 |
| **总目标** | `L^t_self = L_evol + L_meta`（混入 `D_meta` 防遗忘） | 防元技能灾难性遗忘 | §3.2.2 p6–7 |
| **推理时自精炼** | 初答 → 自精炼一次 | 测试期增益 | §3.3 p7 |
| **停机判据** | 「自精炼不再对直答带来增益即停」 | 慢环停机条件 | A.1.3 p13–14 |

### 2.4 关键表示与数据结构

- **元技能语料 `D_meta`**：`(p, r, f, r̂)` 四元组；math 用 3.5k GSM8K + 2k SVAMP，general 用 6k ShareGPT 对话（A.3.1 p14）。
- **自演化数据集 `D^t_evol`**：`(p, r̂)`（p 来自无标注语料）；第 1 轮 math 用 4k GSM8k + 1k SVAMP，第 2/3 轮用 Self-Instruct 生成的 10k/15k；general 用 15k ShareGPT（A.3.2 p14–15）。
- **无记忆结构、无技能库、无外部知识库**（推断：全文未见 memory / skill library / retrieval 构件）——唯一持久态是**权重检查点**与每轮的 `D^t_evol`；「元技能」本身沉在权重里。
- 超参（A.4 p15、Table 5）：8×NVIDIA V100 32GB；**全参数微调**；AdamW，3 epoch，batch 128，lr 2e-5，3% warmup，max length 2048。

### 2.6 论文自陈局限与边界条件

- **无独立 Limitations 章节**（全文只有 §5 Conclusion p11 + 附录）——这是**证据纪律缺口**。散见自陈：
  1. **自演化可能到达平台期**（A.1.3 p13–14）：基于「精炼后优于初答」的假设；论文用「自精炼不再带来增益」作停机条件；
  2. **元技能语料质量敏感**：GPT-4 生成的 `D_meta` 明显优于 GPT-3.5-turbo（Table 10 p20，自精炼 +3.87%）——**能力上限依赖外部强模型**；
  3. **依赖 GPT-4 作标注者 L**（§4.2 p7、A.2 p14）——`D_meta` 是外部 LLM 产物；
  4. **统计口径**：全篇**无 seed 数、无方差、报单次结果**（实测）。
- **隐含边界（推断）**：① 全部为**可二值判定**的语言推理任务（数学有标准答案、通用用 GPT-4 裁判）；② 判分/标注环节引入 **GPT-4 外部裁判**（Fig.3 p9）；③ 未涉及具身/生存/控制任务。

## 3. SSEA 立场对齐（核心维度）

### 3.1 C1–C10 映射

| 裁判标准 | 判定 | 依据（论文中的具体机制/数字） | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制架构，非语言生成 | **✗** | 目标是数学/通用题正确率与胜率；「环境」只是数据集标签与 GPT-4 裁判（Table 1 p8、Fig.3 p9），无生存压力、无不可逆后果 | 只取「元技能学习 → 迭代自训练」的**回路拓扑**与**二值筛选门形状**，控制对象换成生存行为序列 |
| **C2** 自然语言只作观察员接口 | **✗（最重冲突）** | 语言是**演化载体本身**：反馈 f、精炼 r̂、训练数据 `(p, r̂)`、筛选判据全是 NL（§3.1–3.2 p4–5、A.8 p17）；论文明确论证 NL 反馈**优于标量奖励**（§3 p4） | 见下方 **C2 专项** |
| **C3** 权重/记忆/技能三分离 | **✗** | 只有权重一态（全参数 SFT）；**无记忆、无技能库**（推断：全文未见相关构件）；且**刻意把元技能与精炼数据内化进 θ**（Eq.2/4 p5–6、Table 3 p10） | 拆为 Δθ / ΔM / ΔS 三通道后再谈搬运；**内化路线须与 EvolveR 的 exp-absorb 负结果对质**（见 §5） |
| **C4** 低算力低带宽 | **✗** | 8×V100；**全参数微调** 7B；每轮 3 epoch、3 轮自演化 + 推理时自精炼；无标注语料每轮 4k–15k（A.4 p15、A.3.2 p14–15） | 只搬判据层零件（筛选门形状、停机判据），不搬训练栈 |
| **C5** 精准回忆历史 | **—** | 无记忆机制；`D^t_evol` 每轮**重新生成**（未提及任何记忆结构） | — |
| **C6** 可自主修改自身 | **◐**（按四权拆） | **提案权** ✓：模型自产反馈与精炼；**边界权** ✗：架构/目标/prompt 全固定；**验证权** ✗/◐：**由模型自判** `qualified(f)`（A.8 p17），无独立验证门；**应用权** ✓：SFT 更新权重 | 补边界权与四级验证门（只判合法性、不打分）；筛选门须移出模型 |
| **C7** 可保存/恢复/变异/继承 | **◐** | **保存/恢复** ◐（检查点，无跨代谱系）；**继承** ◐（`D_meta` 混入防遗忘，仅单次寿命内）；**变异** ✗；**淘汰** ✓（**样本级**：不合格 r̂ 被 `qualified(f)` 丢弃） | 用 GenePackage 替换检查点；补个体级淘汰与变异 |
| **C8** 给基因先验，不给知识语料 | **✗** | 元技能语料 `D_meta` 由 **GPT-4 从无标注 prompt 生成**（§4.2 p7）；元技能本身是**语言能力**（NL 反馈/精炼），非结构本能；底座是 Vicuna-7b 预训练权重 | 只搬回路与门形状，不搬载体；元技能须换成**结构性先验（本能）**，反馈语料不进基因 |
| **C9** 不设评分函数，只有淘汰函数 | **✗** | 见下方 **C9 专项（三条判定）** | 见下方改造方向 |
| **C10** 创新在 L2/L3/L4，不在 L1 算子 | **✓** | 无新算子：Vicuna / LLaMA / AdamW / GPT-4 标注全借用；创新在**两相位信息流（L2）**与**元技能自演化方法（L3）** | — |

#### C2 专项：语言作演化载体的冲突与去语言化方向

**裁决：✗（本篇对 C2 的冲突是全族中最深的一档——语言不只是「接口」或「动作空间」，而是「演化载体」本身）。** 逐层拆解 SELF 的语言依赖链：

| 环节 | SELF 用语言承载什么 | SSEA 要求 | 去语言化改造方向 |
|---|---|---|---|
| 元技能学习 | 反馈 f 与精炼 r̂ 都是 NL 文本，作为 SFT 目标（Eq.1 p4） | 元技能应是**结构性先验**（本能） | 元技能改为「结构化诊断能力」：给定行为轨迹输出结构化失败指纹/预测差，非 NL 描述 |
| 数据生成 | `(p, r̂)` 是 NL 问答对（§3.2.1 p5） | 训练数据应是**行为轨迹** | 自造数据改为「状态—动作—结果」结构化序列（同 STaR rationale → 结构化轨迹） |
| 筛选门 | `qualified(f)` 读 NL 反馈里的 "judgment: correct" 或 rating 数字（A.8 p17） | 门判据须是**环境侧结构化事实** | 换成环境淘汰事实（存活到 T / 危险未致死），**且移出模型** |
| 内化目标 | 把 NL 链式过程压进直答（Eq.4 p6） | 内化的是**结构**不是语言 | 内化对象改为「结构化技能/规则」（PSN 契约式） |

> **一句话判词**：SELF 把自然语言当作**从数据生成到筛选到内化的全链路载体**——只要保留这一链路，C2 无法通过局部改造解决；SSEA 只能借其**相位拓扑**，整条语言通路必须重建为结构化通路。

#### C9 专项：三条判定（针对「模型自判的二值筛选门」作内部信号）

| # | 条件 | 判定 | 依据 |
|---|---|---|---|
| **①** | **信号源在模型内部**（非外部评分/观察员） | **◐** | 自反馈由模型自产（§3.1 p4），是「内部生成」；**但**判据标准由 **GPT-4 标注**的 `D_meta` 标定（§4.2 p7、A.2 p14）→ **内部生成、外部标定**；自演化轮的判据是模型自身 "judgment: correct"（A.8 p17），无环境事实 |
| **②** | **定义不可被模型修改** | **✗** | `qualified(f)` 的判据就是**模型自己的自反馈输出**（math: "judgment: correct"；general: rating≥7，A.8 p17）；每轮 SFT 更新后该判据**随之漂移**——模型直接改写自己的筛选定义（对比 RetroAgent In-Context 变体的**人类写死子任务清单** = ✓） |
| **③** | **不进入淘汰判定** | **✗** | `qualified(f)` 直接决定样本是否进入 `D^t_evol`（§3.2.1 p5）→ **样本级淘汰**；且整条回路经 `L_evol` 驱动 SFT 权重更新（Eq.2 p5）→ 进入决策/更新回路 |

- **C9 综合裁决：✗**。三条判定为 **◐ / ✗ / ✗**。
- **在族内的坐标（关键）**：SELF 的门是**二值**（形状像 STaR 的 `I(ŷ=y)`，不是 R-Zero 的连续奖励），**但判别者不是外部 ground-truth，而是模型自己**——因此它落在 **STaR（外部二值门，C9 友好）与 R-Zero（内部自指连续奖励，C9 违规）之间**：**「内部自指的二值门」**。这说明**门是二值并不足以保证 C9 合规**——C9 还看**谁定义、模型碰不碰得到**。
- **改造方向（可救回部分）**：保留「自反馈同时作精炼引导 + 筛选门」的**双用途结构**，但把门的**判别者从模型换成环境**——即 `qualified` 的输入改为**环境侧可观测的存活/淘汰事实**（同 STaR 卡片 §3.1-专项 A 的结论），且门**只作准入、不打分不排序**；同时把「自反馈精炼」从 NL 改为**结构化诊断**（C2 专项）。

### 3.2 L1–L4 层级定位

| 层次 | 论文在该层提供了什么 | 对 SSEA 的价值 |
|---|---|---|
| **L1 算子层** | 无（Vicuna/LLaMA 骨干、AdamW、GPT-4 标注，全借用） | 符合借用立场，零价值零风险 |
| **L2 信息流层** | **两相位回路**（元技能学习 → 迭代自演化训练）；「自反馈同时作精炼引导 + 数据筛选门」的双用途结构；`D_meta` 混入防遗忘 | **中–高**：SSEA 慢环「回顾编译通路」的一个相位形状来源；「一条信号两用」是值得对照的信息流设计 |

### 3.4 债务与验收实验对应

- **判据形状错 / 无消费者通道报成功 / 技能失效被判成成功（债务 25/26/27/28）**：SELF 的 `qualified(f)` 是「**二值门**」形状的教科书案例（不打分），**但**它同时是**反面教材**——判别者是模型自己、且随训练漂移，说明「**门是二值 ≠ 门合规**」，C9 还要求判别者归环境、模型碰不到。这条对债务 25/26/28 的判据设计是**双向证据**。

- **睡眠期计算预算未定义 / Gene Manager 缺失 / `retrieve` 键收窄**：SELF 给出成本量级参照（每轮全量 SFT 3 epoch + 3 轮自演化 + 每轮 4k–15k 自造样本，8×V100，A.4 p15）；但它**无记忆、无技能、无基因**，其余缺口只能作反面界定（可遗传的只有「元技能学习回路的结构与超参」）。可服务的验收实验（推断）：实验 3（技能固化 0/33）——SELF 的「二值门形状 + 内化目标形状」可重设判据形状（但须换判别者）；实验 2（记忆召回）——SELF 无记忆，仅提供准入门的形状参照。

## 5. 冲突、代价与风险

- **与硬约束的冲突**（逐条，对应 3.1 的 ✗/◐）：
  1. **C2（最重）**：语言是**演化载体本身**（反馈、精炼、训练数据、筛选判据全为 NL），且论文论证 NL 反馈优于标量奖励——这条通路不可局部改造（见 C2 专项）。
  2. **C9（硬）**：筛选门由**模型自判**（`qualified(f)` 读模型自己的 NL 判定，A.8 p17），无环境事实、随每轮 SFT 漂移 → 三条判定 ◐/✗/✗。
  3. **C3**：只有权重一态，无记忆无技能，且**刻意把元技能与精炼数据内化进 θ**（Eq.4 p6）——与 EvolveR 的 exp-absorb 负结果正面矛盾。
  4. **C1 / C4 / C8**：非生存控制架构；8×V100 全参数微调；`D_meta` 由 GPT-4 生成、元技能是语言能力。
- **隐含假设与失效条件**：
  1. **依赖 GPT-4 作标注者 L**（§4.2 p7）——`D_meta` 的质量上限决定自演化天花板（Table 10 p20）；SSEA 无 LLM，元技能语料无从生成。
  2. **依赖「精炼后优于初答」的假设**（A.1.1 p13）——若自反馈质量不足，r̂ 可能不比 r 好；论文用停机判据兜底。
  3. **依赖可二值判定的任务**（数学标准答案 / GPT-4 裁判）——生存域成败更稀疏、且个体死亡后不再产轨迹，归因链更弱。
  4. **依赖同一 prompt 可重复自训练**——生存环境不可重放同一情境，除非有 Dream-RSI 式重放模拟器。
- **算力 / 带宽 / 工程代价**：8×V100 × 全参数微调 × 3 epoch/轮 × 3 轮 + 推理时自精炼；每轮 4k–15k 自造样本——**重资产**；判据层零件（门形状、停机判据、restart 纪律）可在现有代码廉价实现。
- **搬运后的可能退化模式**：
  1. 若照搬「模型自判 + 自造数据 + 自训练」的配置 → 重演 **RAGEN 的 Echo Trap**（内部信号自我放大 → 方差塌缩 → 熵塌缩）。
  2. 若把门实现成打分/排序 → 违反 C9；**但即使保持二值，只要判别者是模型就仍违规**（本篇的核心教训）。
  3. 若保留 NL 反馈通路进控制环 → C2 违规；若把元技能内化进权重 → C3/C8 双违规；若过滤门过窄 → 数据量骤降（论文 4K→1.8K，增益仅 +0.77%），**过滤的收益被分母缩小抵消**。

| **互补·技能侧** | **PSN**（本库 **A/P1**） | SELF 的**最大空洞**：元技能与精炼数据沉在权重里，不可检视/回滚/继承。PSN 的带契约可执行技能网络 + 成熟度门控 + 回滚验证正好补洞。合成：SELF 负责**造什么样的自训练循环**，PSN 负责**把结果固化成可继承结构**。 |

### 6.2 推荐组合方案

1. **回路去语言化 + 门外部化（SELF × STaR × PSN）**：保留 SELF 的两相位回路作**外骨架**；把「自反馈精炼」换成**结构化诊断**（非 NL）；把 `qualified(f)` 的判别者从模型换成**环境淘汰事实**（STaR 路线）；把内化产物从权重换成 **PSN 契约式技能**。→ 得到一条 **C9 合规的自训练回路**；风险是结构化诊断算子能力不足（SSEA 无 LLM，须自建）。
2. **内化路线裁决（SELF × EvolveR × SelfConsolidation）**：把「反馈/精炼是否进 θ」做成 SSEA 的对照实验（见 §8）；若采用内化，必须用 SelfConsolidation 的**有界压缩旁路**形态（可回滚、常数带宽），而非 SELF 的全参数 SFT。→ 为 C3「内化是否安全」提供可裁决的实验与安全载体；风险是内化旁路若不可定点遗忘 → 静默污染。

### 6.3 本篇在组合中的典型角色

- **语言式自训练回路的形状提供者**（两相位 + 一条信号两用）+ **C9 谱系的中间坐标**（「内部自指的二值门」，连接 STaR 与 R-Zero）+ **C3 内化争议的内化派证人**（与 EvolveR 正面矛盾）+ **Reflexion 的「内化升级版」**。
- **它不是主干**：语言载体、模型自判门、权重内化三件核心都不可搬，定位为**零件采用（B）**；主干仍由 **PSN（技能）** 与 **FLEX/Memento（记忆）** 承担。

  2. 把「**一条信号两用**」写进慢环设计：一条回顾信号既驱动 ΔS/ΔR 提案、又决定样本准入；但判别者归环境、只判合法性。
  3. 引入 SELF 的**停机判据**（自精炼无增益即停）作为慢环停机条件的候选（与 FLEX 的 logistic 曲线互补）。
  4. **写进 C3 判据文档**：记录 **SELF（内化有益/必要）vs EvolveR（内化有害）vs RetroAgent（内化有益）的三方矛盾**，把「是否允许经验进 θ」列为待裁决；SSEA 默认采 EvolveR 侧（记忆与权重分离）。
  5. **建 issue：非语言自反馈/诊断算子**——SELF 证明该算子存在且关键（元技能隐式提升直答），但 SSEA 无 LLM，需自建；与「技能表示够不够 / 0/33」合并处理。
- **最小验证实验（自训练回路 · 服务实验 2/3 与债务 25/26/28）**：
  - **双臂 / 消融设置**：A 无自训练臂（现状对照）；B SELF 式内部自判门臂（门的判别者＝**模型自身**）；C 环境判别门臂（同 B，判别者换成**环境侧二值事实**：存活到 T / 危险未致死）。≥8 seed；慢环轮数固定。
  - **判据（分档，先看分母）**：① **机制计数**——每轮自造样本数、门内/被拒样本数、固化产物大小、消耗算力/步数；② **行为差**——逐帧动作差、`retrieve` 命中率（对照现有 **0.5164**）；③ **淘汰结果**——危险回避率（注意两臂现均为 **0.9814（饱和）**，**已无分辨率**，须换更高难度环境或换指标）。
  - **预期与证伪**：预期 C 优于 B（环境判别门 > 模型自判门），且 A ≥ B 或 A ≈ B——证明「**内部自判门不带来增益甚至有害**」，支持 C9「判别者须归环境」。**证伪**：若 B > C，说明模型自判门在 SSEA 域意外有效——此时须回查「环境事实的分辨力」（呼应「retrieve 键收窄→召回精度上限低」），而非改用模型自判（仍违反 C9）。另需监控 SELF/R-Zero 式崩溃前兆：若每轮自造数据质量随轮次衰减、性能达峰后掉头，判为自训练回路不稳定，实验提前终止（对标 R-Zero Fig.3 p7、SELF A.1.3 p13）。
- **若 E 不采用**：不适用（确实有可搬零件）。

## 9. 待确认问题

1. **SSEA 的自训练回路是否允许「内化」**：SELF 证明内化（Eq.4 把链式过程压进直答）有效，EvolveR 证明内化有害（0.382→0.371）——**这是 C3 判据的悬案**。差异是否来自任务域（数学 QA vs 多跳 QA）或内化对象（全参数 vs 提示）？需团队裁决。
2. **非语言自反馈算子从哪来（最关键）**：SELF 的自反馈 = 一次 LLM 调用；SSEA 无 LLM，「行为轨迹 → 结构化诊断」用什么算子？「元技能隐式提升直答」这一结论在非语言、小容量算子上是否仍成立？
3. **「内部自指的二值门」在 C9 上的确切定位**：SELF 的门是二值（形状合规），但判别者是模型（归属违规）。SSEA 的判据文档是否明确「**判别者归属**」是 C9 的独立必要条件（门形态之外）？若是，STaR 谱系与 R-Zero 谱系的分界应由「外部/内部判别者」而非「二值/连续」划定。
4. **停机判据的等价物**：SELF 的「自精炼无增益即停」依赖可重复的自精炼过程；SSEA 生存环境不可重放，该判据是否需 Dream-RSI 式重放才能落地？
5. **需补查文献 / 团队决策**：Self-Refine（Madaan et al. 2023）、RAFT（Dong et al. 2023）、RLAIF（Pang et al. 2023）——用于确认「自反馈自训练」是否已有更早等价方案；SSEA 的 `rules` 通道当前**零消费者**，SELF 的「结构化诊断记录」是否作其内容形态之一，还是等 PSN 的契约式技能先落地？
