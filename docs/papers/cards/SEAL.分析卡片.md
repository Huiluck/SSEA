## 1. 一句话定位

- **论文主张**：LLM 不必在预训练后保持静态——SEAL 让模型**自己生成「自编辑（self-edit）」**（合成训练数据 + 可选的优化超参与工具选择），用 SFT 把这些自编辑落成**持久的权重更新**，再用「更新后模型在下游任务上的表现」作奖励、通过 **ReSTEM**（过滤式行为克隆）训练「如何生成好的自编辑」，从而学会「如何学习」（摘要 p1、§3 p3–4）。
- **对 SSEA 的意义**：它是**「模型自主修改自身权重」的当代代表作**，正面撞上 **C6（可自主修改自身）** 与 **C3（权重/记忆/技能三分离）**，且自带三条 SSEA 现在最缺的东西——① **Δθ 的算力代价标尺**（一次自编辑评估 30–45 s、一轮 ReSTEM ≈6 h / 2×H100，p9、§B.5 p21）；② **灾难性遗忘的实证**（连续自编辑下旧任务性能逐步衰退，Fig 6 p8–9）；③ **「自生成信号优于外部强教师」的证据**（SEAL 47.0% > GPT-4.1 合成数据 46.3%，Table 2 p8）。它同时是一份**警告**：SEAL 的奖励依赖「每个上下文都自带带标签的下游任务」，一旦没有外部标签，论文自己提出的出路是让模型**自己出题、自己评分**（p9）——这在 **C9** 下是明令禁止的。

> **SSEA 现状声明（写卡时必须写清）**：权重更新在 SSEA 中**是允许的目标**，但**参数侧 Δθ 仍留在 `plasticity.DEFERRED_SCOPES`**，属于「已否决 / 明确不做」项（`docs/06-status-roadmap.md` §「已否决」：「**不做参数侧 Δθ**——仍留在 `DEFERRED_SCOPES`」，并见 §附 C 第 463 行「❌ 在 `plasticity.DEFERRED_SCOPES` 里」）。本卡片的全部结论据此定位：**本篇不解锁 Δθ，而是为「将来要不要开 Δθ」提供判据与代价下限。**

## 2. 问题 — 机制 — 证据

### 2.1 论文要解决的问题
- **问题本身**：LLM 强大但**静态**，缺少把新任务、新知识、新样例转化为自身能力的机制；现有做法是「照单全收」地用任务数据做 finetune 或 ICL，而数据的**格式与体量未必适合学习**（摘要 p1、§1 p1–2）。
- **它指出的既有方案缺陷**：
  1. 数据「as-is」消费，模型无法发展出**属于自己的**转换/学习策略（p2）；
  2. 合成数据方法多依赖**静态或人工调过的启发式**生成策略，不直接最大化「用这些数据做梯度自更新后真正涨了多少」（§2 p2）；
  3. 已有自改进方法（RLAIF、self-rewarding、majority-vote、置信度作奖励）**全部受限于模型当前的评价能力与自洽性**（§2 p3）；
  4. TTT 类方法的增强/超参是**手工指定**的（§3.2 p6）。

### 2.2 核心思想（关键 insight）
1. **把「生成训练信号」本身当作可学习的动作**：不是学答案，而是学「生成什么样的自家训练数据」最能让自己涨分——外层 RL 优化 self-edit 生成策略，内层用该 self-edit 做 SFT 更新权重（§3 p3、Alg.1 p4）。
2. **用数据而非权重参数化「如何改自己」**：相比直接预测 LoRA 权重的 hypernetwork，生成合成数据的好处是——生成数据可复用于 CPT、可套到任意 base model、可随文档规模增长而调用推理与重构能力、且不绑定 LoRA（§B.8 p22）。
3. **奖励必须 on-policy，因为奖励依赖「动作发生时的 θ」**：RL 状态实为 (C, θ)，用旧模型 θ_old 收集的三元组会**陈旧失配**，因此必须同策略采样并同策略算奖励（p4）。
4. **「适合自己学的」优于「别人写得更好的」**：SEAL（Qwen2.5-7B）自生成的合成数据超过了 GPT-4.1 生成的合成数据（46.3% → 47.0%，Table 2 p8）。

### 2.3 关键机制 / 算法（可独立搬运的「零件」清单）
| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| **Self-edit（SE）** | 上下文 C → 自然语言指令（数据形式 + 可选超参/工具选择） | 「自修改提案」的载体 | §3.1 p3–4、§3.2 p5 |
| **双环结构** | 外环 RL（优化 SE 生成）＋ 内环 SFT/TTT（θ′ ← SFT(θ, SE)） | 学会学习的骨架 | §3 p3、Alg.1 p4 |
| **二元奖励定义** | r(SE,τ,θ_t) = 1 若用 SE 适配后性能提升，否则 0 | 奖励=下游成败（可改造为淘汰信号） | 式(2) p4 |
| **ReSTEM（过滤式行为克隆 / rejection sampling + SFT）** | 采样 → 只保留正奖励样本 → SFT 强化 | 稳定替代 GRPO/PPO（论文称后两者训练不稳定） | p4 |
| **on-policy 强制** | 状态 =(C,θ)，旧 θ 的三元组作废 | 防「跨版本陈旧数据」 | p4 |
| **工具集（预定义函数）** | 数据增强（旋转/翻转/反射/转置/缩放/链式/重复）+ 优化参数（lr、epochs、loss 覆盖范围） | **边界权的雏形**：可改空间是外部枚举的 | §3.2 p6、Fig.3 p5 |
| **单提案算力上限** | 丢弃需要 >375 训练步的配置 | **成本淘汰**（不是打分） | §A.2 p18 |
| **Teacher–student 解耦** | 学生被更新，教师经 RL 学「如何提编辑」 | 提案者与应用者可分离 | p4 |
| **Proxy reward（廉价代理奖励）** | GPT-4.1 按 4 类 rubric（length/diversity/quality/correctness）各打 1–5 分求和 | 用 ≈5 min 换 ≈6 h 的内环 | §B.10 p23 |
| **自动评分器** | gpt-4.1-2025-04-14 + yes/no 打分提示 | 下游表现的量尺（**C9 冲突点**） | §B.4 p21 |

### 2.4 关键表示与数据结构
- **知识融入**：SE = 一组**自然语言「implications（蕴含句）」**，由提示 “Let’s read the following passage and produce a list of implications…” 生成，按换行切分为多条训练文档，再用标准因果 LM loss 做 **LoRA SFT**（r=64, α=128，覆盖全部 MLP 与 attention 投影层；§B.2 p20、§3.2 p5）。
- **少样本（ARC）**：SE = **结构化 JSON**——{use_basic/size/chain/repeat augmentations（布尔），strategy: train_using_all_tokens｜train_using_output_tokens，learning_rate（float），num_train_epochs（int）}（§A.2 p18–19、Fig.3 p5）。
- **提示变体 7 种**：implications / implications-long / implications-very-long / implications-chain-of-thought / rewrite / self-qa / **no-prompt（让模型自己决定格式）**（§B.11 p23–25）。
- **更新载体**：LoRA 适配器（少样本侧 r=128/α=16，插在 q/v/gate/down/up_proj；§A.2 p18）。

### 2.6 论文自陈局限与边界条件
- **灾难性遗忘**（§5 p8–9）：当前训练**没有显式优化保持性**；连续自编辑下旧任务衰退。作者提出的补救是 **reward shaping（惩罚旧任务回归）**、null-space 约束编辑（AlphaEdit）、表征叠加，或把内环 SFT 换成 RL（RL forgets less）。
- **算力开销**（§5 p9）：TTT 奖励环比「人类偏好奖励（一次前向）」和「可验证答案（正则匹配）」**贵得多**；每次自编辑要 finetune + 评测整个模型。
- **上下文依赖的评测**（§5 p9）：当前实例化**假设每个上下文都配套一个显式的下游任务**（few-shot 带留出的问答对、段落自带参考 QA）。这个耦合简化了奖励计算，但**使 RL 训练无法扩展到无标注语料**。论文提出的解法是让模型**自己生成评测问题**（自写 QA / 合成测试例）来提供监督。
- **假设依赖（推断）**：需要外部可自动判分的评测（本文用 GPT-4.1 作 grader）、需要 GPU 训练回路、需要「上下文能被 base model 在上下文内读懂」的语料（§B.2 p20 明确以 SQuAD 为例）。
- **明确不适用的情形**：论文**未提及**任何 embodied / 低算力 / 无标签 / 在线控制场景；未声明在这些场景下的失效边界。

## 3. SSEA 立场对齐（核心维度）

### 3.1 C1–C10 映射
| 裁判标准 | 判定 | 依据（论文中的具体机制/数字） | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制架构，非语言生成 | **✗** | 全文是语言模型的知识融入与少样本泛化；无生存变量、无控制环、无环境实体 | 只借「双环 + 自生成→应用→验证」协议形状；控制对象换成与生存相关的结构化信号 |
| **C2** 自然语言只作观察员接口 | **◐** | 主流表示确是自然语言（implications，§3.2 p5）；但**结构化 JSON 配置**（§A.2 p18）证明自编辑不必是语言。关键反证：**让模型自己决定格式的 no-prompt 最差（13.8→18.9，Table 10 p24），预定义格式最好（rewrite 55.6）** | **这条证据支持 C2**：自由自然语言自编辑反而更差。SSEA 的自编辑必须编译为**带契约的结构化 Δ**，自然语言只留在日志/解释面 |
| **C3** 权重/记忆/技能三分离 | **✗（做法冲突）/ 高价值反例** | 目标就是**把新知识压进权重**（θ′←SFT(θ,SE)，p4；LoRA 覆盖全部 MLP 与 attention 投影，§B.2 p20）；**记忆与权重合一**。而 Fig 6（p8–9）显示这种合一的直接代价：连续自编辑后旧任务衰退、且论文未做保持性优化 | **本篇是 C3 的实证支持**：知识应走外置 ΔM，权重只承载结构性先验。Δθ 若将来开，只允许承载「怎么学」，不得承载「学过什么」 |
| **C4** 低算力低带宽 | **✗** | 每次自编辑评估 **30–45 s**；一轮 ReSTEM **750 次内环 ≈6 h（2×H100）**（p9、§B.5 p21）；ARC 侧 ≈2–3 h（p19） | 与 SSEA 量级完全不匹配。可搬的是**预算纪律**：单提案步数上限（>375 步即弃，p18）与「廉价预筛 + 昂贵实测」两档 |
| **C5** 精准回忆历史 | **◐（无机制；作为反面证据有价值）** | 论文**无**外置记忆/检索构件（未提及）；其目标恰是「不看上下文也能答」= 把记忆压进权重。结果是准确率上限低（47.0%）且随编辑次数退化（Fig 6） | 反证：权重承载记忆不如外置可检索记忆。与 Memento / FLEX / MemRL 的 ΔM 路线做对照实验（见 §8） |
| **C6** 可自主修改自身 | **◐**（按四权拆） | **提案权 ✓**：模型自己生成 SE（p4）。**边界权 ✗**：可改空间是外部预定义的工具集（§3.2 p6），模型不能扩张自己的改写空间——**自指性弱于 Gödel Agent**（后者连元算法 I 都可改）。**验证权 ✗**：无门，只有「按奖励过滤」（ReSTEM 保留正样本）与「按成本丢弃（>375 步）」；无回滚、无沙盒、无回归。**应用权 ✓**：直接 SFT 落权重（p4） | 补边界权（可改面白名单）＋验证权（四级门：格式→沙盒→回归→环境实测）＋回滚（LoRA 适配器可插拔，天然回滚单位，推断）后再谈 |
| **C7** 可保存/恢复/变异/继承 | **◐ / 部分未提及** | LoRA 适配器是小体积可插拔产物（**推断**：可保存/换回，论文未声明）；self-edit **策略**（RL 后的权重）本身是可迁移的产物（**推断**）。**论文未提及**保存/恢复/变异/继承、无种群、无代际实验 | 若将来开 Δθ：适配器作为**可保存可回滚的最小单位**；策略（「怎么学」）可入 GenePackage，知识（「学过什么」）不可 |
| **C8** 给基因先验，不给知识语料 | **◐（推断，论文未讨论继承）** | 两层要拆开看：① RL 训出的 **self-edit 生成策略 = 「怎么学」的结构性先验**，合 C8 精神；② 内环把**具体知识**写进权重，不合 C8（跨代必膨胀 + 遗忘）。论文**未提及**基因/继承，本判定为推断 | 借用其**分层直觉**：基因只装「如何生成训练信号」的策略，不装任何被内化过的知识 |
| **C9** 不设评分函数，只有淘汰函数 | **✗** | ① 奖励 = **下游性能增益**，是打分；知识融入侧还**只奖「增益最大的那一条」SE**（脚注 2 p4）——显式排序。② 答案正确性由 **gpt-4.1-2025-04-14 打分**（§B.4 p21）＝ LLM-as-grader。③ Proxy reward 用**人类 rubric 由 GPT-4.1 打 1–5 分求和**（§B.10 p23）＝观察员评分。④ 全部结果用**调优过的超参搜索空间**（Table 3/4 p20–21，p7「All results use tuned hyperparameters」）。⑤ 未来工作还要**加 reward shaping**（p9） | 可救的部分：二元 reward（对/错，式(2) p4）＋ ReSTEM「只保留成功样本」＋「>375 步即弃」＝**淘汰式过滤**，近 C9。改造：只保留**通过/不通过**的环境侧事实；**不得**用性能增益排序、不得用 LLM 打分、不得用性能驱动的超参搜索 |
| **C10** 创新在 L2/L3/L4，不在 L1 算子 | **✓** | 无新算子：LoRA、SFT、TTT、ReSTEM、Rejection Sampling 全部借用（p4、§B.2 p20）。创新在 **L3**（学会如何生成自编辑＝学会学习）与 **L2**（外 RL/内 SFT 的双环数据流、(C,θ) 状态的 on-policy 约束） | — |

### 3.2 L1–L4 层级定位
| 层次 | 论文在该层提供了什么 | 对 SSEA 的价值 |
|---|---|---|
| **L1 算子层** | 无新算子（LoRA/SFT/TTT/ReSTEM 均借用，符合 C10） | 无（正合立场） |
| **L2 信息流层** | 双环数据流（外 RL 优化提案生成 / 内环应用提案）、**状态 =(C,θ) 的 on-policy 约束**、teacher–student 可解耦（p4） | **高**：「提案的验证必须针对**当前版本**」——对 SSEA「快环只读不可变快照」是直接的陈旧性告警 |
| **L3 学习层** | **核心**：self-edit 生成策略 + 权重内化；ReSTEM（过滤式行为克隆）比 GRPO/PPO 稳定（p4） | **中—高**：SEAL 是 Δθ 路线最完整的当代实例，也是**最完整的 Δθ 风险样本**；ReSTEM 的「只保留通过的提案」可直接改造成慢环准入 |

## 5. 冲突、代价与风险

- **与硬约束的冲突（逐条）**
  - **C3 ✗**：把知识写进权重（θ′←SFT(θ,SE)），记忆与权重合一；Fig 6 显示连续写入即遗忘。**这是本篇最硬的冲突**，也是它最有价值的地方——它是 C3 的当代反例。
  - **C9 ✗**：奖励 = 下游性能增益（且只奖增益最大者＝排序，脚注 2 p4）；正确性由 **GPT-4.1 打分**（§B.4 p21）；proxy reward 用 **LLM 打 1–5 分求和**（§B.10 p23）；超参靠**性能驱动的搜索空间**（Table 3/4）；未来还要 reward shaping（p9）。**四项全部落在 C9 明令禁止的「外部评分 / 奖励塑形 / 观察员评分」内。**
  - **C4 ✗**：30–45 s/次、≈6 h/轮、2×H100——与 SSEA 的 low-compute 目标差数个量级。
  - **C2 ◐**：主流 self-edit 是自然语言（implications）。
  - **C1 ✗**：无生存控制语义。
  - **C6 ◐**：缺边界权（工具集外部预定义、模型不能扩张自己的改写空间）与验证权（无门、无回滚）。
- **隐含假设与失效条件**
  - 每个上下文**必须**自带带标签的下游任务（§5 p9）。SSEA 的环境只给**成败**、不给标签 → SEAL 的奖励在 SSEA 里**直接失去定义**。
  - 论文自陈的出路是「模型自己出题、自己评分」（p9）——在 C9 下这是**最坏的方向**（自我评分）。
  - 需要「base model 在上下文内就能读懂语料」的语料（§B.2 p20 以 SQuAD 为例）；对 SSEA 的非语言 trace 不成立。
  - 论文**未量化**自生成合成数据的幻觉/漂移率（Fig 5 p8 可见 RL 后自编辑显著变长并出现与原文无关的陈述，如 “Clearing of forests… is a major cause of deforestation”——**推断**，论文未统计）。若搬到 SSEA 的 ΔM 写入，**幻觉写入**是首要退化模式。
- **算力 / 带宽 / 工程代价**
  - 训练期：2×H100/H200、DeepSpeed ZeRO-3、vLLM；一轮 ≈6 h（§B.5 p21）。
  - 每次自编辑评估 30–45 s（p9）——即便只做 1 个提案，也远超 SSEA 慢环可接受的量级。
  - 反向参照价值：proxy 方案 5 min 换 97% 的效果（45.6/47.0）→ **廉价款几乎够用**，这本身说明真内环的边际收益很小。
- **搬运后的可能退化模式**
  1. **权重污染 + 遗忘**：知识进权重 → 旧能力衰退（Fig 6），且不可精准定位、不可删除（对比外置记忆可 CRUD）。
  2. **自编辑幻觉固化**：错误/漂移的合成数据被 SFT 内化，比外部噪声更难清除（推断）。
  3. **奖励 hacking**：以「性能增益」为目标的策略会学会产出**容易涨分但无用的**自编辑（论文未报告此现象；推断）。
  4. **跨版本陈旧**：在旧快照上验证通过的提案在新版本上失效（p4 的 on-policy 论证）。
  5. **成本失控**：每次评估都要 finetune + 评测整个模型（p9）。

## 6. 组合分析

### 6.1 关系图谱
| 关系 | 对象（点名论文或方法族） | 说明 |
|---|---|---|
| **前置依赖** | **外部带标签的下游任务 + 自动评分器** | SEAL 的奖励定义在「每个 C 配一个 τ」上（§5 p9）。SSEA 环境只给淘汰事实、不给标签 → **前置依赖在 SSEA 中不成立**，这是本篇不可直接落地的根因 |
| **同题·更强自指性** | **Gödel Agent** | Gödel 可改**策略 π 与元算法 I 本身**（运行时猴子补丁）；SEAL 只改**权重**，且改的方式被外部工具集枚举限定。**SEAL 的自指性弱于 Gödel**；但 SEAL 有实证与收敛曲线，Gödel 有形式化无门控。两者构成 C6 的**两条路径**：代码/元算法侧 vs 权重侧 |
| **互补（最紧·刹车）** | **PSN** | SEAL 缺的正是 PSN 有的：故障定位、成熟度门控、**回滚验证重构**。若将来开 Δθ，PSN 的回滚契约是必配件 |
| **替代（最紧·更划算）** | **Memento / FLEX / Mem0 / A-MEM** | 对「把新知识装进系统」这一目标，外置 ΔM 是 SEAL 的替代解，且**更便宜、可精准删除、无跨写入遗忘**。SEAL 自己的数字（47.0 上限 + Fig 6 衰退）反证替代解更优 |
| **互补（写入组织）** | **FLEX / SEDM** | 把 SEAL「自生成训练信号」的思想搬到**记忆写入**：自提案 → 结构化写库 → 只判合法性的准入（SEDM 的 A/B 准入、ARISE 的四阶段门） |
| **对照（参数侧诊断仪）** | **RAGEN** | 若将来真的训练参数，RAGEN 的 Echo Trap 诊断 + 不确定性过滤是**配套诊断仪**；SEAL 只报告结果不诊断训练动力学 |
| **对照（搜索空间形式化）** | **ADAS** | ADAS 的「代码空间 × 搜索 × 评估」可用来形式化 SEAL 的搜索空间（合成数据 × 超参 × 增强），但**评估项必须换成淘汰** |
| **同族对照（零数据端）** | **R-Zero** | 据 Agent0 卡片（Table 1 p7）：R-Zero 为 8B 数学 54.7、无工具、零外部数据。与 SEAL 相比，R-Zero **不需要外部强模型打分**，C9 洁净度高于 SEAL；但仍是「外部可验证答案 + 权重内化」，C3 冲突相同 |
| **同族对照（外部依赖端）** | **Socratic-Zero** | 据 Agent0 卡片（p7/§6.1）：依赖**外部专有模型（OpenAI API）**做推理辅助，8B 数学 56.1，被判定为「C9 外部评分的显性化版本」。**SEAL 与 Socratic-Zero 是同一类外部依赖**：SEAL 用 GPT-4.1 生成合成数据作对照、并用 GPT-4.1 当 grader |
| **同族（本篇未提及，卡片作者补充）** | **Agent0** | 同为「自演化 + 外部 judge」族；Agent0 卡片已判「应同时拒掉 Socratic-Zero 的外部模型与 Agent0 的 GPT-4o judge」——**SEAL 的 GPT-4.1 grader 应一并拒掉** |
| **风险治理** | **Misevolve** | SEAL 的「自编辑 → 权重」正是 Misevolve 威胁模型里的**模型路径误演化**；红队验收清单应覆盖「自我生成训练数据」这一条（Misevolve 原文是否覆盖此项未核对） |
| **廉价验证场** | **Dream-RSI** | 重放模拟器可替代 SEAL 昂贵的内环 TTT，作为**提案的行为验证场**（且不需要打分） |

### 6.2 推荐组合方案
1. **「SEAL 的提问方式 + SSEA 的三分离」——把自生成训练信号从 Δθ 搬到 ΔM/ΔS**
   - **组合**：SEAL（自生成训练信号的思路）× FLEX / Memento（外置记忆写入）× SEDM（只判合法性的准入）× PSN（技能契约与回滚）。
   - **接口形态**：慢环自提案 → **编译为结构化 ΔM/ΔS 写入**（非自然语言、非权重）→ 四级门只判合法性 → 环境实测。
   - **组合后新增能力**：拿到 SEAL 最值钱的那条（**自生成的信号比外部教师更适合自己**：47.0 > 46.3），而**不付** Δθ 的算力与遗忘代价。
   - **新增风险**：自生成内容的**幻觉写入**（Fig 5 显示 RL 后内容变长且出现与原文无关的陈述；推断）——须由回归门兜住。
2. **若将来开 Δθ（当前不排期）：SEAL 内环 + PSN 回滚 + RAGEN 诊断 + Misevolve 验收 + Gödel 边界声明**
   - **接口形态**：Δθ 只允许作用于**白名单内的小网络/适配器**（不动 `loco_dir` 本能权重——06 已否决）；单提案有**算力步数上限**（>上限即弃）；验证**必须针对当前版本**；适配器即回滚单位。
   - **纪律**：环境侧只给**通过/不通过**；禁止性能增益排序、禁止 LLM-as-grader、禁止性能驱动的超参搜索。
   - **新增风险**：权重污染不可逆、跨版本陈旧、奖励 hacking。
3. **睡眠期预算分级（借 Table 9）**
   - 廉价预筛（≈5 min 级）→ 昂贵环境实测（≈6 h 级）；预筛只做**合法性判定**，不做打分，避免退化成 proxy reward。

### 6.3 本篇在组合中的典型角色
- **参数侧（Δθ）的「判据库 + 代价标尺 + 风险样本」**：不是主干，是**用来决定「不开」**的那一篇；
- 同时是 **C3 三分离的当代实证反例**与 **C6「自生成优于外部教师」的证据源**；
- 在关系图谱中位于「**权重自修改**」这一格，与 Gödel Agent 的「**代码/元算法自修改**」格并列，二者共同撑起 C6 的两条路径。

## 8. 裁决与下一步

- **应用等级：B 零件采用** —— 采用它的**证据与协议零件**（Δθ 代价标尺、灾难性遗忘实证、单提案算力预算淘汰、on-policy 版本告警、ReSTEM 式「只保留通过」过滤、结构化表示的实证、自生成 > 外部教师）；**不采用**它的核心机制（知识进权重）与其奖励体系（性能增益打分 / GPT-4.1 grader / LLM rubric / reward shaping / 性能驱动超参搜索）。
- **优先级：P2** —— 因为参数侧 Δθ 仍在 `plasticity.DEFERRED_SCOPES`（06「已否决」），本篇不解锁任何当前工程；它服务的决策点在 Gene Manager 落地、记忆/技能通道跑通**之后**。
- **对「将来要不要开 Δθ」的裁决（本卡核心结论）**：
  1. **维持 DEFERRED**。SEAL 提供了三条**反对现在开**的实证：① **代价下限**——每次自编辑评估 30–45 s、一轮 ≈6 h（2×H100）（p9、§B.5 p21）；② **遗忘代价**——连续自编辑下旧任务逐步衰退且论文明确未做保持性优化（Fig 6 p8–9）；③ **收益不确定**——结构化启发式（Entigraph）在 n=2067 已反超 SEAL（48.6 vs 46.4，Table 8），说明**「学会怎么写」未必优于「结构化地写」**。
  2. **一条支持「将来可以开」的证据**：自生成信号优于外部强教师（47.0 > 46.3，Table 2 p8）——但这条**不需要开 Δθ 就能享用**（搬到 ΔM/ΔS 即可）。
  3. **一条警告（最重要）**：SEAL 明确承认——**没有外部标签，奖励就无从计算**；它提出的唯一出路是「让模型自己出题、自己评分」（§5 p9）。这在 C9 下是被禁止的方向。⇒ **SSEA 若开 Δθ，必须自带环境侧的通过/不通过事实，否则必然滑向自我评分。**
  4. **若将来开，前置条件（缺一不可）**：边界权白名单（可改面显式枚举，不动 `loco_dir`／本能）、验证权（四级门）、回滚（适配器为最小单位）、单提案算力上限、按当前版本验证。
- **建议动作**：
  1. 在 `docs/06-status-roadmap.md`「已否决」条下**补引用**本卡：维持「不做参数侧 Δθ」的判据来源（p9 算力、Fig 6 遗忘、p9 上下文依赖、Table 8 Entigraph 反超）。
  2. 把「**单提案算力上限 + 超预算即弃**」（>375 步即弃，§A.2 p18）写进睡眠期预算条目——这是**成本淘汰**，合 C9，可直接落地。
  3. 把「**提案的验证必须针对当前版本**」（on-policy，p4）写进 ChangeProposal 协议与 Gate 说明。
  4. 把「**结构化表示优于让模型自己定格式**」（no-prompt 18.9 vs rewrite 55.6，Table 10 p24）作为「技能表示够不够」债务的一条外部证据，与 PSN 的契约式技能表示互相印证。
  5. 把「**自生成 > 外部教师**」（47.0 > 46.3）登记为 C6/C8 立项论证的引用项——**无需开 Δθ**。
  6. 将来若立项 Δθ：以本卡 §6.2 方案 2 的四项前置条件为验收清单，并用 Misevolve 的红队项覆盖「自我生成训练数据」。
- **最小验证实验（判据性实验，非落地实验；Gene Manager 落地后再开）**：
  - **双臂**：A 臂 **ΔM 外置写入**（结构化记忆写入，可 CRUD、可回滚）vs B 臂 **Δθ 权重内化**（LoRA 自编辑，SEAL 式）。两臂使用**同一批自提案**与同一环境。
  - **消融**：B 臂再加两档——「带算力上限 + 按当前版本验证」vs「裸自编辑」。
  - **判据（分档，先看分母）**：① 机制计数：提案数 / 通过门数 / 写入字节数 / 单次写入耗时（建立分母，先确认提案真的产生了）；② 行为差：连续 N 次（N=1,2,4,8,16）写入后，**旧任务的成功率衰减曲线**（对应 Fig 6 的 SSEA 版本）；③ 淘汰结果：危险回避率与存活步数的变化。
  - **预期**：A 臂在 N≥8 时旧任务保持率显著高于 B 臂，且单次成本低 1–2 个数量级；B 臂「带预算+按版本验证」档的尾部风险低于裸档（类比 Gödel Agent 卡片的 14% 永久劣化率）。
  - **证伪条件**：若 B 臂在 N=16 时旧任务保持率与 A 臂无显著差异、且成本可接受，则 **C3 三分离在「知识该放哪」这一点上的理由需要修正**，Δθ 可进入候选议程（但仍须先满足 C9：环境侧只给通过/不通过）。
- **若 E 不采用**：不适用（本篇有明确可搬零件与高价值证据，不判 E）。
