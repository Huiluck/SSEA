## 1. 一句话定位

- **论文主张**：LLM 智能体终身学习只回放成功轨迹会浪费失败样本、且文本经验随历史线性膨胀最终撑爆上下文；EvoSC 用**对比式经验提取**（成功 vs 失败成对对比，抽出 error-prone 与 successful 两类文本经验，存 FIFO 队列）+ **参数化轨迹巩固 PTC**（把大量轨迹蒸馏进 20 个可学习 prompt token Pθ，使 agent 少看历史也能重建专家动作）——在 LifelongAgentBench 的 DB/OS/KG 三域全面超过 AWM / TER / SCM / A-MEM，并在基线 OOM 的大 Exp 设置下仍能工作（p1、p6–8）。
- **对 SSEA 的意义**：它是**唯一一篇把「巩固」做成可量化压缩协议**（12 条轨迹 → 20 个 token，p7）的工作，为慢环 SEL 睡眠期提供三件东西：① **teacher/student 分工**（慢环看全历史=天然 teacher，快环只看快照=天然 student）；② **重建式巩固判据**（不用打分的 token-level CE）；③ **有界 FIFO 遗忘**。但它的巩固产物落在**权重**里，与 C3 三分离正面冲突，必须换载体再搬。

## 2. 问题 — 机制 — 证据

### 2.1 论文要解决的问题
- **问题本身**：智能体「任务隔离」范式（task-isolation paradigm）——每次会话后重置，无法像人一样积累（p1）。
- 指出的既有方案缺陷（p1–2，两条）：
  1. **只看成功**：现有 replay 只存成功轨迹，丢弃失败尝试的教学价值（避免复发性陷阱的信息）；
  2. **文本经验线性膨胀**：上下文窗口固定，retrieval 时间随历史增长，且塞入过多 demonstration 会引入 contextual noise（引 Hsieh 2024 RULER、Liu 2024b Lost-in-the-Middle），稀释注意力、损害推理。
- 形式化（§3 p3）：任务流 T={t₁..t_N}；每任务最多 r 轮交互；**环境给出二元奖励 R(t_k)∈{0,1}**；目标 max Σ E[R(t_k)]（式 2）。

### 2.2 核心思想（关键 insight）
1. **成功与失败的「语义差」信息量最高**：同类任务的成功轨迹推理模式相关、失败轨迹在关键决策点分叉，把二者并列（Cs vs Cf）即可定位出错的那一步（§4.1 p4，式 3）。
2. **显式文本经验必须被「内化」**：把长而冗余的轨迹压缩成紧凑的可学习参数，转化为隐式参数记忆，从而**不占 token 槽**地利用海量历史（p2、§4.2 p5）。
3. **用「多看历史的专家」蒸馏「少看历史的学生」**：专家 A\* 由 (E_many ∪ 历史 ∪ 任务) 生成，学生 Â 只用 (Pθ ∪ E_few ∪ 历史 ∪ 任务) 重建，二者逐 token 对齐（式 5/6，p5）。——**这条是最可搬的形状**。

### 2.3 关键机制 / 算法（可独立搬运的「零件」清单）
| 零件 | 输入 → 输出 | 作用 | 出处 |
|---|---|---|---|
| **Error-Prone 对比提取** | (P_c, C_s 成功对话, C_f 失败对话) → Exp_c 文本经验 | 从成败差异抽「易错点 + 规避策略」 | §4.1 式(3) p4；模板 Fig.7/8/4 |
| **Successful 经验提取** | (P_s, 两条不同成功对话 C_s^(i), C_s^(j)) → Exp_s | 多 shot 抽象出可复用方法（抽象而非分歧） | §4.1 式(4) p4 |
| **FIFO 经验队列 Q_err / Q_succ** | 新经验入队 → 定长队列（自动剪枝过时） | 缓冲**有界**，优先近期教训 | §4.1 p4、Algorithm 1 p5 |
| **成功轨迹库 R_succ** | 通过 EnvVerify 的完整对话 H_{k,r} → 入库 | 巩固与检索的语料池 | Algorithm 1 Step 4 p5 |
| **参数化轨迹巩固 PTC** | 历史成功轨迹集 E → 可学习 prompt Pθ（长度 20） | 把显式记忆压成隐式参数，解上下文爆炸 | §4.2 p5 + p7 |
| **专家动作生成（teacher）** | (E_many, H_{k,s−1}, I_k) → A\*_{k,s} | 提供蒸馏目标（慢环角色） | 式(5) p5 |
| **学生重建（student）** | (Pθ, E_few, H_{k,s−1}, I_k) → Â_{k,s} | 用压缩载体+少量上下文复现专家（快环角色） | 式(6) p5 |
| **巩固损失 L_consolid** | −Σ_s Σ_j log Pθ(A\*_{k,s,j} \| Pθ, I_k, H_{k,s−1}, A_{k,s,<j}) | 逐 token CE，**无价值打分、只做重建** | §4.2 p6 |
| **混合注入 I_k** | Pθ ⊕ P_sys ⊕ Exp_c ⊕ Exp_s ⊕ C_s ⊕ t_k | 隐式直觉 + 显式近期经验并存 | 式(7) p6 |
| **Top-K 检索** | 经验队列 → top-K 条目 | 控制注入量 | Algorithm 1 Step 1 p5 |

### 2.4 关键表示与数据结构
- **双记忆**：短时**非参数**文本记忆（FIFO 队列 Q_err/Q_succ + 成功对话库 R_succ）+ 长时**参数化**记忆 Pθ（Fig.1 p1、Fig.3 p4）。
- **Pθ**：长度 **20** 的可学习 prompt token（p7 Implement Details），是全文唯一的「巩固产物」。
- **经验条目形态**（附录 p15 KG 示例）：`specific_question` + `successful_practices`（3–6 条单行可执行规则）；DB/OS 侧为「Mistake / Solution」或「Use `cmd` to …」的单行规则。
- **轨迹**：ξ(k) = (I_k, A_{k,1}, F_{k,1}, …, A_{k,T}, F_{k,T})（p3）。

### 2.5 自我巩固五问（SSEA 视角专项，逐条对号入座）
| 问题 | 论文答案 | SSEA 可用性 |
|---|---|---|
| **输入是什么** | 历史**成功**交互轨迹集 E={C_succ}；teacher 侧 E_many=20 条、student 侧 E_few=8 条 + Pθ；蒸馏目标 A\* 由 teacher 生成（式 5/6、p7） | 可用，但「只喂成功」有幸存者偏差 |
| **产物是什么** | **Pθ：20 个可学习 prompt token**（参数/权重类） | **✗ 冲突 C3**（记忆烧进权重）→ 需换成 ΔM 压缩旁路 |
| **何时触发** | 仅一句「**At periodic intervals**, the framework triggers a self-consolidation process」（p3）；具体周期、触发条件**未提及** | 硬缺口，SSEA 须自定 |
| **由谁触发** | 框架设计者的定时调度；**非内在驱动、非环境信号**；且 **Algorithm 1（p5）全文 4 步中根本没有巩固步骤** | ✗ 须改为慢环自持的边界权 |
| **失败怎么办** | **未提及**。无巩固失败的检测、无回滚、无 A/B 准入、无影子对照；唯一的「失败」语义是任务级 R=0 → 只进 Q_err | ✗ 须补四级验证门 + 可回滚 |

补充两点关键观察（推断）：
- 巩固**只在成功轨迹上定义**（式 5 的 H_k 明确是 "a successful trajectory"），失败轨迹**不参与参数化巩固**，只能变成文本 Exp_c。⇒ 错误模式永远进不了参数层。
- Algorithm 1 只描述推理工作流（检索→提取→执行→更新），巩固被排除在算法之外，说明**巩固与在线循环的耦合关系是论文未闭合的环节**。

### 2.7 论文自陈局限与边界条件
- **自陈局限（§7 p9，两条）**：① 经验检索机制「相对简单」，制约推理能力，未来要改进检索；② 受算力限制只做了 7B/8B 规模，70B+ 与更多架构的可扩展性待验。
- 隐含依赖（推断）：需要一个能判成败的**环境验证器** EnvVerify（Algorithm 1 p5）；需要 teacher 侧能塞下 20 条轨迹的上下文；需要冻结骨干上做 prompt-tuning 的训练算力。
- 未不适用的情形：论文未提及。但域为 DB/OS/KG 三类**语言—工具**任务，未涉及生存/控制/ embodied。

## 3. SSEA 立场对齐（核心维度）

### 3.1 C1–C10 映射
| 裁判标准 | 判定 | 依据（论文具体机制/数字） | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制架构，非语言生成 | ◐ | 目标为任务成功率最大化（式 2 p3），域是 DB/OS/KG 语言任务，非生存控制环 | 只取「巩固」这一节律，域整体替换为生存行为流 |
| **C2** 自然语言只作观察员接口 | **✗** | 经验的**载体就是文本**（Expc/Exps 为自然语言规则，附录 p14–15），且**直接拼进控制输入** I_k（式 7 p6） | 剥离文本通路：经验改为状态张量/结构化谓词；自然语言只在日志面 |
| **C3** 权重/记忆/技能三分离 | **✗（核心冲突）** | 巩固产物 Pθ 是**可学习参数**（p5、p7），即把记忆内容烧进权重；不可检索、不可精准写入、不可遗忘、不可合并 | **换载体**：Pθ 降级为 ΔM 的一个**压缩旁路**（可检索条目仍在库），或作为技能的「触发先验」；禁止其成为唯一的经验归宿 |
| **C4** 低算力低带宽 | ◐ | 正面：巩固移出实时路径、推理侧只加 20 token（p6–7）、FIFO 有界自动剪枝（p4）；负面：蒸馏需在 7–8B 冻结骨干上 fwd+bwd，实测 2×A40（p7） | 只在小骨干（GRU/Mamba 量级）上重测；设巩固批上限与「超预算降级为只合并」的开关 |
| **C5** 精准回忆历史 | ◐/✗ | 有 top-K 检索与成功库 R_succ；但**参数化部分是不可检索的黑箱**，且失败轨迹彻底不进参数层 | 参数化载体必须与可检索条目**并存**（LightMem 式条目做底账，Pθ 做加速旁路） |
| **C6** 可自主修改自身 | ◐ | 确实修改了自身参数 Pθ；但只有「提案+应用」，**无验证权/边界权**，触发者是设计者的定时器（p3）而非自身 | 纳入四权拆分：提案归慢环、边界归预算、验证归四级门、应用归原子升版 |
| **C7** 保存/恢复/变异/继承 | ◐ | Pθ 仅 20×d 参数（≈8×10⁴，8B 模型 d≈4096，推断），天然可打包进 GenePackage；但**变异/继承未提及**，且加噪声变异可能直接毁掉隐式知识 | 若遗传，只能遗传「压缩器的结构与超参」，并在沙盒内做影子验证 |
| **C8** 给基因先验，不给知识语料 | **✗（若继承）** | Pθ 承载的是**后天知识**（SQL 写法、命令用法、KG 遍历顺序，附录 p14–15） | **Pθ 内容不进 GenePackage**；跨代只传结构性先验；与 HeritableFilter 明确隔离 |
| **C9** 不设评分函数，只有淘汰函数 | ◐ | 合规面：L_consolid 是**重建式 CE、不含好坏打分**（式 p6）；R(t_k)∈{0,1} 由**环境**给出，属①层淘汰函数。冲突面：**拿环境成败当样本过滤器**——只有成功轨迹进 E 参与蒸馏（式 5 p5），失败只做文本对比 | **剥离方案**：① 巩固输入改为「所有通过合法性门的轨迹」，不以成败筛样本；② 蒸馏目标改为**内在预测误差/惊奇**（FSL 对自身下一步的预测误差），而非环境标签；③ 环境的二元判定只保留在四级验证门的「是否发布」一层，且**只判合法性、不排序** |
| **C10** 创新在 L2/L3/L4，不在 L1 算子 | ✓ | 无新算子；prompt-tuning 是借用件；创新在 L2（双记忆信息流）与 L3（巩固节律） | — |

### 3.2 L1–L4 层级定位
| 层次 | 论文在该层提供了什么 | 对 SSEA 的价值 |
|---|---|---|
| **L1 算子层** | 无新算子；Pθ 是标准 prompt-tuning | 低（纯借用，符合立场） |
| **L2 信息流层** | 非参数文本队列 ⇄ 参数化载体的**双记忆**与混合注入（式 7） | **高**：给「快环只读快照 + 压缩旁路」提供了一个具体的信息流形状 |
| **L3 学习层** | teacher(many)/student(few) 蒸馏、重建式巩固损失、周期性触发巩固 | **高**：巩固的**目标函数**与**可测判据** |
| **L4 演化层** | **未提及**（无保存/变异/继承设计） | 低（需自行补齐） |

### 3.3 模块映射
| 论文构件 | SSEA 落点（现有模块 / 缺失组件 / 新增建议） |
|---|---|
| teacher(E_many) / student(E_few + Pθ) | **慢环 SEL = teacher（可读全历史缓冲）；快环 FSL = student（只读不可变快照 + 压缩载体）**——本项目天然具备这对分工 |
| Pθ（20 token 压缩载体） | 新增：**ΔM 的压缩旁路** / 快环上下文的常数开销载体（**不可**直接写进 Δθ） |

| 对比式经验提取（Cs vs Cf） | 慢环 ExperienceCompiler 的**失败模式卡/失效指纹**生成（应债务 25/26/27） |

| 「At periodic intervals」 | 对应**睡眠期触发条件**（论文未定义 → SSEA 必须自定并写死在规则里） |

### 3.4 债务与验收实验对应
- **「睡眠期计算预算未定义」——本篇是唯一给出可量化代价模型的**（见 §5 代价估计），但仍**未定义触发者与周期**，只能补一半。
- **「技能表示够不够」（0/33）与债务 25/26/27「判据形状错」**：本篇的重建式目标提供了**形状正确、不打分的替代判据**（学生不带历史能否重建专家分布）。
- **记忆遗忘/归档策略缺失**（LightMem 卡片待确认问题 3）：FIFO 有界队列给出一版答案（定长、自动剪枝、优先近期）。
- **记忆二级门常量阈值（债务 22）**：不直接回应；但 FIFO 与 top-K 是有界化的现成写法。
- 可服务的验收实验：**实验 3（技能固化）**的判据改造；**危险回避/记忆检索**两臂已饱和（0.9814 / 0.5164），本篇无力改善饱和判据，不接这两条。

## 5. 冲突、代价与风险

### 5.1 与硬约束的冲突（逐条）
1. **C3 ✗（最硬）**：巩固产物是权重。记忆一旦烧进 Pθ，就同时失去 C5 的「可精准写入/检索/遗忘/合并」。**改造**：Pθ 只当加速旁路，可检索条目（LightMem 式）始终是权威底账，二者不一致时以条目为准并可回滚。
2. **C2 ✗（最硬）**：经验是自然语言且直接进控制输入（式 7）。SSEA 控制环只处理结构化信号。**改造**：经验改为结构化谓词/张量原型，文本只留在观察员面。
3. **C9 ◐**：以环境成败筛蒸馏样本（式 5 只取成功轨迹）。**剥离方案**见 §3.1 C9 行。
4. **C8 ✗（条件）**：若 Pθ 进 GenePackage 即构成「给知识语料」。**改造**：内容不遗传。
5. **触发者缺失**：「periodic intervals」未定义，且 Algorithm 1 无巩固步。**改造**：由慢环按缓冲/惊奇/睡眠期边界自持触发，写死在 rules 里（注意：`rules` 目前零消费者，需先接上）。

### 5.2 算力 / 带宽 / 工程代价（**可量化估计**）
论文**未给出** FLOPs、token 数或巩固墙钟时间（未提及）。以下为**推断**，仅用论文自有参数标定：
- 已知参数（p7）：teacher 上下文 = **20 条轨迹**；student 上下文 = **8 条轨迹 + 20 个 prompt token**；每任务轮数 r = 3(DB)/5(OS)/15(KG)；骨干 7–8B；实测平台 2×A40 48G。
- 代价模型：记 1 单位 = 一次 student 上下文的前向。teacher 前向 ≈ (20/8) = **2.5 单位**；student 前向+反向 ≈ **3 单位**（标准 1:2 fwd/bwd 比）。
  ⇒ **巩固 1 条轨迹 × 1 轮 ≈ 5.5 单位**；乘 r 轮与批量 K：
  - DB(r=3)：**≈16.5 K 单位**；OS(r=5)：**≈27.5 K 单位**；KG(r=15)：**≈82.5 K 单位**。
  - 相对在线重放（1 单位/轮）即 **约 5.5×/轮** 的常数倍率。
- **关键提醒（推断）**：Pθ 只有 20×d ≈ 8×10⁴ 参数，优化器状态可忽略；但**梯度必须穿过整个冻结骨干**，所以省下的是参数量/优化器显存与训练稳定性，**FLOPs 与全量微调同阶**。7–8B 模型 fp16 权重约 14–16 GB，故论文才需要 2×A40 48G。
- **C4 裁决**：这个倍率在 **7–8B LLM 档**是「重」的；SSEA 的 FSL 是 GRU/Mamba 量级，绝对量小得多，**但论文的数字不能跨档直搬，必须在 SSEA 骨干上重测**。

### 5.3 对「睡眠期预算」硬门槛的专项裁决
- SSEA 现规则：**回顾优先，预演只在回顾提交后预算有剩余时启动**。
- PTC 属于**回顾侧**（对已发生轨迹的离线蒸馏）⇒ **直接占用回顾预算**，且 5.5×/轮 的倍率**极可能吃光预算，使预演永远启动不了**——这是本篇进入 SSEA 后最主要的运行期风险。
- **可行性与落地约束**：
  1. 排在**回顾提交之后、预演之前**；设硬上限（每睡眠期至多 1 次、巩固批 ≤ N 条轨迹、轮数 ≤ r_max）；
  2. 超预算即**降级**：只做「合并/去重/抽象」（退回 LightMem 式软更新），不做蒸馏；
  3. 收益侧可记账：12 条轨迹 → 20 token（p7），快环上下文**恒定**，不再随历史线性膨胀——这正是本篇相对基线 OOM 的唯一硬证据（Table 1/2 p6–7）；
  4. **预演预算必须在巩固提交前先预留**，不能让巩固按需抢占。

### 5.4 隐含假设与失效条件
- 假设环境能给出可靠的成败判定（EnvVerify）；若环境「对无消费者通道报成功」（债务 26），则 R_succ 会被污染，蒸馏目标随之污染 ⇒ **先修债务 26，再谈巩固**。
- 假设历史轨迹与目标任务同分布（lifelong 同域流）；分布漂移时 Pθ 会固化过时策略且**无法局部遗忘**。
- 假设 teacher 的 E_many 上下文放得下；KG 类长链任务正是靠 PTC 才没 OOM（p8–9）。

### 5.5 搬运后的可能退化模式
- **静默污染**：坏经验被蒸进 Pθ，因不可检索而无法定位、无法定点删除——最坏的一种失败（对应 Misevolve 记忆路径红队清单）。
- **巩固过拟合**：周期性巩固把近期噪声固化，表现为「某一夜之后行为突变且回不去」。
- **预算饿死预演**：如上 §5.3。
- **继承膨胀**：若 Pθ 跨代累积，违反 C8 且体积随代数增长。
- **旁路漂移**：Pθ 与可检索条目给出冲突建议，快环无仲裁 ⇒ 需预先写死「条目优先、Pθ 仅加速」的仲裁规则。

## 6. 组合分析

### 6.1 关系图谱
| 关系 | 对象（点名） | 说明 |
|---|---|---|
| **最直接同工** | **LightMem** | 同为「睡眠期离线巩固」，但**产物形态正相反**：LightMem 产**非参数、可检索、可合并**的文本条目（合并不删除）；本篇产**参数化、不可检索**的 Pθ。二者应**分工而非二选一**：LightMem 出权威条目库（底账/可回滚），本篇出压缩旁路（常数带宽下发）。LightMem 缺的遗忘策略，本篇用 FIFO 有界队列补 |
| **提供重放场** | **Dream-RSI** | 本篇的 teacher 需要「拿 E_many 重新生成专家动作」，本质是一次**离线重放**；Dream-RSI 的发现历史即重放模拟器正好提供该通道，并可与本篇共享同一份睡眠期预算与调度 |
| **同类可学习参数（并存）** | **Memento** | Memento 是冻结 LLM + 案例库 + **可学习检索 μ**；本篇是冻结 LLM + 案例库 + **可学习 prompt Pθ**。μ 在**选取侧**、Pθ 在**内容侧**，两者正交、可同装一套；SSEA 中 μ 应改由惊奇/联想驱动以合 C9 |
| **补本篇最大缺口** | **MemRL** | MemRL 的「冻结库迁移验收 + 遗忘率 FR」正是本篇**没有**的巩固准入与遗忘度量；用 FR 当巩固产物的验收指标 |
| **补本篇「何时停」** | **FLEX** | FLEX 的 logistic 增长曲线作慢环停机判据——本篇「periodic intervals」未定义周期，可用 FLEX 的增长曲线导数决定**何时巩固、何时停**（顺带给出预算的停止条件） |
| **替代（SSEA 更友好）** | **EvoTest**（ICLR 2026，J-TTL；Actor/Evolver，**无梯度、无微调**，演化整个 agentic 系统配置：prompt/记忆/超参/工具例程；相对最强 prompt 演化基线 +38%、相对在线 RL +57%） | 与本篇同属「测试时自改进」，但 EvoTest **不用梯度**，产物是**可检查、可回滚的配置**——与 C3/C4/C6 天然兼容。**在 SSEA 上应优先走 EvoTest 路线**，本篇的梯度蒸馏仅作压缩旁路的可选增强 |
| **技能侧对接** | **PSN** | 若把巩固产物从 Pθ 换成「带契约的可执行技能网络」，则本篇的重建式判据可作为 PSN 成熟度门控的量化输入（故障定位/回滚验证重构） |
| **风险治理** | **Misevolve** | 睡眠期写入/参数化合并必须过记忆路径与参数路径的红队验收清单 |
| **对照** | **Reflexion / A-MEM / Voyager** |  Reflexion 是「试错-评估-反思」的外环经典形状；A-MEM 管链接拓扑；Voyager 管键值技能库——本篇与它们都不同层（本篇在「内化」层） |

### 6.2 推荐组合方案
- **组合 A（首选，低风险）**：**EvoTest（无梯度配置演化） + LightMem（睡眠期条目巩固） + FLEX（logistic 停机判据）**——本篇**不进主链**。
- **组合 B（本篇入链的形态）**：**LightMem 条目库（权威底账） + 本篇的 teacher/student 蒸馏（仅作压缩旁路） + Memento 的 μ（惊奇驱动检索） + MemRL 的 FR/迁移验收（准入与遗忘） + Dream-RSI 的重放场（提供 E_many 的专家回放）**。
  - **接口形态**：慢环读全历史缓冲 → Dream-RSI 重放生成专家动作序列 → 蒸馏出压缩载体 → MemRL 迁移验收 + FR 度量 → 过四级验证门 → 与 LightMem 条目库**双写**（条目为准）→ 原子升版；快环只读快照 + 压缩载体。
  - **组合后新增能力**：快环上下文**恒定**、不随历史线性膨胀（本篇唯一硬证据：基线 Exp≥16/32 OOM，本篇不崩，Table 1/2 p6–7）；并获得一个**不打分的重建式固化判据**。
  - **新增风险**：旁路不可解释、不可定点遗忘；巩固吃光预算饿死预演；Pθ 若被遗传则违反 C8。

### 6.3 本篇在组合中的典型角色
- **「睡眠期内化器 / 带宽压缩器」**：负责把慢环能看到的海量历史，**以常数带宽**下发到快环；同时提供**重建式固化判据**这一可量化验收件。
- **反面角色同样有价值**：它是「记忆烧进权重会付出什么代价」的现成警示样本（不可检索、不可遗忘、不可回滚、无准入）。

## 8. 裁决与下一步

- **应用等级：B 零件采用** —— 采用三件：① teacher(全历史)/student(少上下文+压缩载体) 的蒸馏形状；② 有界 FIFO 经验队列与自动剪枝；③ 重建式巩固判据。**明确不采用**：文本经验注入通路（C2）、把记忆烧进权重的产物形态（C3）、以环境成败筛蒸馏样本（C9）、周期性由设计者触发的巩固（C6）。
- **优先级：P1**（不是 P0：EvoTest 的无梯度路线对 SSEA 更友好，且本篇的收益依赖「先修债务 26」与「先定义睡眠期预算」）。

### 建议动作
1. 先在 `rules` 里写死睡眠期巩固的**触发条件与预算上限**（触发者、周期、批量 N、轮数上限、超预算降级路径），补上论文未定义的「何时/由谁触发」；注意 `rules` 当前零消费者，需先接消费者。
2. 把巩固产物**定为 ΔM 的压缩旁路**，与可检索条目双写；写死仲裁规则「条目优先、旁路仅加速」——直接守住 C3/C5。
3. 用 L_consolid 的**重建式判据**替换技能固化的旧判据（债务 25/26/27）：定义「固化后的快环在不给历史时，能否重建慢环在给历史时的动作分布」，纯行为、可量化、**不含打分**，符合 C9；重跑实验 3 看 0/33 是否变化。
4. 引入 FIFO 有界队列作为经验池的遗忘实现，并接 MemRL 的 FR 遗忘率做验收。
5. **先修债务 26**（环境对无消费者通道报成功）再启用巩固——否则 R_succ 被污染，蒸馏目标整体带毒。
6. 在 SSEA 自己的小骨干上重测 §5.2 的 5.5×/轮 倍率，**不得**直接引用 7–8B 档的数字。

### 最小验证实验（巩固旁路 · 服务睡眠期预算与技能固化）
- **双臂 / 消融**（≥8 seed）：
  - A 无巩固（快环只读快照）；
  - B 仅 LightMem 式条目合并（软更新、不蒸馏）；
  - C 条目 + 压缩旁路蒸馏（本篇）；
  - D 条目 + 蒸馏 + **超预算降级**（模拟预算被打满）。
- **判据（先看分母，分三档）**：
  1. **机制计数**：触发次数、巩固批次轨迹数、产出载体大小、消耗算力/步数（先确认分母真的非零）；
  2. **行为差**：快环在「给历史 vs 不给历史」下的动作分布差（重建误差，即 L_consolid 的 SSEA 版）——**这是主判据**；
  3. **淘汰结果**：模型外环境淘汰率（注意危险回避率已饱和 0.9814，两臂区分度不足，不可作主判据）。
- **预期**：B 与 C 的重建误差显著低于 A；C 的快环上下文长度**不随历史增长**（对应论文 p8 定性主张与基线 OOM 证据）；D 在预算打满时退化为 B 而非崩溃。
- **证伪条件**：若 C 相对 B 在重建误差上无优势（论文 Table 3 在 Llama-DB 上正是 −0.1），则本篇的蒸馏件**不进主链**，只保留 FIFO 与重建式判据；若 C 出现「一夜之后行为突变且回不去」，即触发 §5.5 的静默污染模式，须立刻加影子对照与回滚。

### 若 E 不采用
不适用（有可搬零件）。但**本篇的核心产物 Pθ 在本项目内按 E 处理**：不进权重、不进 GenePackage。
