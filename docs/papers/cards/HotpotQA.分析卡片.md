## 1. 一句话定位
- **论文主张**：构建 113k 条维基多跳 QA 数据集（112,779 有效例，Table 1），用「bridge entity
  超链接图采样段落对 + 众包提问 + 句级 supporting facts」，迫使 QA 系统跨文档推理并给出可解释支撑句。
- **对 SSEA 的意义**：**不适用**——纯语言 QA 数据集（span 抽取 + yes/no 分类），无生存控制环、
  双环、基因包或自修改，无法回溯到 C1–C10 正面路径；仅其组合检索结构可作记忆组合检索的对照口径。

## 2. 问题 — 机制 — 证据
### 2.1 论文要解决的问题
- 既有 QA 数据集不足：单文档（SQuAD）只测单句匹配；多文档（TriviaQA/SearchQA）检索事后拼上下文，
  不保证跨文档推理；KB 多跳（QAngaroo、ComplexWebQuestions）受 KB schema 限制、多样性低；
  且全部只给 distant supervision（只知答案、不知支撑句）。
- 目标：跨多文档、自然语言、不依赖 KB schema，并提供句级支撑事实强监督。
### 2.2 核心思想与关键表示
1. 用维基首段超链接有向图 G，以 bridge entity 为桥采样 (a,b) 段落对，天然保证两跳（§2, p.2）。
2. 众包必须显式用两段提问并标注 supporting facts，形成「答案 + 支撑句」双监督（§2, p.3）。
3. 数据结构：超链接有向图 G、bridge entity 白名单 B、同类实体列表 L（42 组）；每条样例 =
   2 段 + 问题 + 答案 span + supporting fact 句号集合（Figure 1：`Supporting facts: 1,2,4,6,7`）。
### 2.3 关键机制 / 算法（零件）
- **超链接图采样**（维基首段 → (a,b) 段对，保证多跳，§2 p.2）；**bridge entity 白名单 B**
  （人工策划页过滤无意义桥实体，§2 p.3）；**Comparison 问句**（同类列表 L → 比较题，§2 p.3）；
  **支撑句句级标注**（段对 → 句子下标集，可解释监督，§2 p.3）。
### 2.5 实验证据
| 任务 / 基准 | 对照基线 | 关键数字 | 统计口径 |
|---|---|---|---|
| distractor test | 自实现 Clark&Gardner 模型 | Answer EM 45.46 / F1 58.99 | Table 4, p.8 |
| full wiki test | 同上 | Answer EM 25.23 / F1 34.40 | Table 4, p.8 |
| 检索（full wiki） | bigram tf-idf | MAP 43.21 / Hits@2 38.67 | Table 5, p.8 |
| Human | 众包 | Answer EM 83.60 / F1 91.40 | Table 8（1,000 样例）, p.9 |
### 2.6 论文自陈局限与边界条件
- 假设依赖：维基首段可承载可查询信息；bridge entity 需人工白名单。
- 明确不适用：未提及生存域/控制环；仅限文本问答。full wiki 的 MAP/Mean Rank 为**上界**
  （附录 C.1, p.12，缺失金段按 |Scand|+1 计）。

## 3. SSEA 立场对齐（核心维度）
### 3.1 C1–C10 映射
| 裁判标准 | 判定 | 依据 | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制架构，非语言生成 | ✗ | 整篇是语言 QA 数据集，控制对象是文本答案（§1） | 与生存信号无接口，不可改造 |
| **C2** 自然语言只作观察员接口 | ✗ | 语言即任务本体（问题/答案/支撑句） | 反向教材：语言进入任务闭环 |
| **C3** 权重/记忆/技能三分离 | — | 不涉及三分离 | 无 |
| **C4** 低算力低带宽 | ✗ | 依赖大模型 + tf-idf 检索 500 万段（§5.2, p.7） | 与低带宽取向相反 |
| **C5** 精准回忆历史 | ◐ | 有句级 supporting facts 精准标注，但为静态数据集非可写记忆 | 仅借「支撑句集合」作检索命中判据形态 |
| **C6** 可自主修改自身 | — | 未提及 | 无 |
| **C7** 保存/恢复/变异/继承 | — | 未提及 | 无 |
| **C8** 给基因先验，不给知识语料 | ✗ | 数据集本身就是大规模知识语料 | 与 C8 直接冲突 |
| **C9** 不设评分函数，只有淘汰函数 | ✗ | 以 EM/F1/Joint F1 为外部评分函数（§5.2, p.7） | 正是 C9 明令禁止的「外部评分」范式 |
| **C10** 创新在 L2/L3/L4 | ✗ | 贡献在数据/基准，非架构声明 | 无 |
### 3.2 L1–L4 层级定位 / 3.3 模块映射
- —：L1 沿用 char-RNN+self/bi-attention，无新算子；L2/L3/L4 均无内容，无落点（见 3.1 排除理由）。
### 3.4 债务与验收实验对应
- 可回应的已知债务：无（不触及 §6 债务表任一条）。
- 可服务的验收实验：仅作对照口径——「记忆组合检索命中率」可用 bridge 式两跳检索做外标。

## 5. 冲突、代价与风险
- **与硬约束的冲突**：C1/C2/C4/C8/C9/C10 均 ✗——语言即任务、依赖大模型与大规模语料、以
  EM/F1 外部评分，与 SSEA「非语言、低算力、无外部评分、只给结构性先验」直接对立。
- **隐含假设与失效条件**：多跳有效性依赖众包与人工白名单，迁到非维基/非语言域即失效。
- **工程代价**：full wiki 检索 500 万段 + 阅读模型，远超 SSEA 快环预算。
- **搬运后退化模式**：若把 EM/F1 引入 SSEA，将违反 C9，污染验证门「只判合法性、不打分」设计。

## 6. 组合分析
### 6.1 关系图谱
| 关系 | 对象（点名论文或方法族） | 说明 |
|---|---|---|
| 前置依赖 | — | 无 |
| 互补 | **A-MEM**（Zettelkasten 链接拓扑）、**G-Memory**（多层图记忆）、**EvoRoute**（三面检索） | 本篇的 bridge「先跳 A 再跳 B」结构可作「联想式组合检索」的**外部对照臂**：三者解决「如何组合命中」，HotpotQA 提供「组合命中的可核查判据（两跳支撑句）」的语言域实例 |
| 替代 | — | 不能替换任何 SSEA 组件（仅评测口径） |
### 6.2 推荐组合方案
- **组合**：A-MEM / G-Memory / EvoRoute 检索机制（内部）× HotpotQA 的 bridge 判据（外部对照）。
- **接口形态**：在合成两跳任务上测 SSEA 记忆检索 Hits@2，与 HotpotQA 的 MAP/Hits@2 口径对齐。
- **新增能力**：为「记忆联想/组合检索」提供统一命中外标。**新增风险**：口径漂移——语言域
  Hits@2 与结构化记忆命中不可直接等同，需自定义同形判据。
### 6.3 本篇在组合中的典型角色
- **组合检索的对照基准 / 判据形态供给**（不进 SSEA 控制环）。

## 8. 裁决与下一步
- **应用等级**：**D 基准对照** —— 理由：无法回溯 C1–C10 正面路径（C1/C2/C4/C8/C9/C10 ✗），
  但「bridge 两跳 + 句级支撑事实」可作 SSEA 记忆组合检索的外部对照口径，故不降为 E。
- **优先级**：P3；**建议动作**：不改代码，讨论「记忆组合检索判据」时引用其 Hits@2/MAP 口径。
- **最小验证实验**：无（不进入 SSEA 验收链）。
- 若 **E 不采用**：原因——若严格按「与生存域无关即排除」口径亦可判 E；本卡取 D 仅因其
  组合检索口径有唯一可对照价值。
