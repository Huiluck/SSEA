## 1. 一句话定位

- **论文主张**：把智能体记忆从「参数记忆」（改模型权重，会灾难性遗忘）与「检索记忆」（外置数据库，靠上下文工程硬拼）之外的第三条路走通——用**潜空间张量**作机器原生记忆：一个 RL 训练的 **memory trigger** 监视推理核的隐藏状态、在**句子边界**（分隔符 token）上决定「此刻要不要调用记忆」，一旦调用，**memory weaver** 以当前隐藏状态为 stimulus **生成**（而非检索）一段定长潜 token 序列 M ∈ R^{K×d_model}，prepend 回推理核的隐藏状态继续生成；推理核全程冻结（p1、§4.1–4.3、p4–6）。
- **对 SSEA 的意义**：它把「记忆以**定长向量块**注入正在运行的状态流」这个**注入面**做成了可训练、可计量、低带宽的工程形状——这是 SSEA 快环向量通道目前缺的那一块；但它把记忆内容**写进 LoRA 权重**，与 C3 三分离、C5 精准回忆、C8 不给知识语料正面冲突，因此只借「门 + 注入面」，不借「记忆本体」。

## 2. 问题 — 机制 — 证据

### 2.1 论文要解决的问题
- 问题本身：智能体记忆如何成为「自演化引擎」——让智能体在与环境的交互中持续内化经验、提升解题能力，而不是只维持长对话连贯性（p1）。
- 它指出的既有方案缺陷（p1–2、§2 p3）：
  1. **参数记忆（parametric memory）**：把经验直接写进模型参数（SFT/GRPO/DPO 等），有增益但**不可避免灾难性遗忘**——侵蚀通用知识；
  2. **检索记忆（retrieval-based memory）**：把经验外置成结构化库（原始轨迹 / 高层经验 / 浓缩技能如可复用 API、MCP boxes），非侵入、避开了遗忘，但**功效被上下文工程绑死**——执行流水线僵硬，只是把检索到的上下文塞给智能体，做不到真正内化式记忆那种流动、无缝的融合；
  3. **既有潜记忆**：要么用 KV cache 维护动态记忆集（主要只解决长上下文），要么用 latent token embedding 存经验（**仍然依赖侵入式 LLM 参数更新**）；且它们**都还是检索式的**——按嵌入相似度去取，而不是**生成式地重建**成新的、连贯的洞察。
- 由此提出研究问题（p2）：*How can we architect agent memory as a dynamic cognitive faculty, capable of fluid, reconstructive processes that interweave seamlessly with reasoning?*

### 2.2 核心思想（关键 insight）
1. **记忆应该是「生成式重建」而不是「取回原文」**：M_t 不是先前内容的逐字复述，而是经 weaver 过滤、整合后的选择性重建，类比海马把回忆碎片巩固成记忆（§4.1 p5）。
2. **记忆与推理要在 token 级交织，而不是任务开始时注入一次**：既有系统「在任务起点检索一次、粗粒度拼到 query 上」，MemGen 在解码过程中逐 token 监视、按需插入，把线性展开变成「与记忆的递归对话」（§4.1 p4–5）。
3. **把「记什么」和「什么时候记」拆成两个可分别训练的模块**：weaver 负责合成（可用 SFT 或 GRPO 任意目标），trigger 负责时机（RL + 稀疏性惩罚），且**先训 weaver、冻结后再训 trigger**（§4.2–4.3 p5–6、附录 C.1 p18）。推理核 π_θ 全程冻结 → 天然规避灾难性遗忘（p1–2、§4.3 p6）。
4. **记忆功能可以自发分化**：无外部监督下，潜记忆自发形成 planning / procedural / working 三类功能簇（p2、§5.3 p9–10）。

### 2.3 关键机制 / 算法（可独立搬运的「零件」清单）
| 零件 | 输入 → 输出 | 作用 | 出处（节/式/图/页） |
|---|---|---|---|
| **Memory trigger T_trigger**（LoRA 适配器） | 隐藏状态序列 H_{t,<j} → p_j = σ(T_trigger(...))，采样 d_j ~ Bernoulli(p_j) ∈ {INVOKE, SKIP} | 元认知监视器：决定何时织入记忆 | §4.1 式(4) p5；§4.2 p5 |
| **句子粒度激活（delimiter set D）** | 仅当当前 token ∈ D（逗号、句号等）才计算 p_j，否则 p_j = 0 | 把插入对齐到语义边界、省算力 | §4.2 式(7) p5 |
| **Reward-adaptive penalty** | λ·Σ max(0, d̃_{i,j} − p̄)；p̄ = 高奖励轨迹（奖励 ≥ batch 中位数）上的平均激活概率 | 鼓励「稀疏但关键」的调用，抑制无谓激活 | §4.2 式(8)(9) p6 |
| **Memory weaver W_weaver**（另一个 LoRA） | hook H_{t,<j} ∈ R^{(j−1)×d} → M_t ∈ R^{K×d_model}（K 定长） | 生成机器原生潜记忆 | §4.3 式(5) p5–6 |
| **潜记忆注入** | M_t 的隐藏状态 prepend 到 H_{t,<j}，之后 z_{t,j} ~ π_θ(·\|s_t, z_{t,<j}, M_t) | 无缝织回推理流 | §4.1 式(6) p5 |
| **只训 θ′ 的目标（优化算法无关）** | max_{θ′} E[R(x_i, τ)]，梯度只回传到 weaver 参数 | 冻结推理核，SFT/GRPO/DAPO 皆可 | §4.3 式(10) p6；附录 B p17–18 |
| **两阶段训练协议** | 阶段 1：无 trigger，在每个标点边界（或随机子集）插入以训 weaver；阶段 2：冻结 weaver，在其上训 trigger | 解耦「合成什么」与「何时合成」 | 附录 C.1 p18 |
| **与检索记忆的拼接** | q_{t,j} = Decode(z_{t,<j}) → C_t = R(q; M_ext) → 编码为 E_t ∈ R^{L_c×d} → M_t = W([H; E]) | 内部参数记忆 + 外部文本记忆融合 | §4.3 p6–7；附录 E 式(17)–(19) p23 |
| **潜记忆功能簇的事后干预分析** | 对 M_t 取均值向量 m̄（式(20)(21)），K-means 分 N=4 簇，top-k(k=10) 近邻含目标簇心则丢弃整段 M_t（式(22)） | 定位每簇承担的记忆功能 | 附录 G.1/G.3 p29–30；§5.3 p9–10 |

### 2.4 关键表示与数据结构
- **记忆本体**：**没有条目、没有库、没有写入接口**。记忆 = weaver 的 LoRA 参数 θ′（经验「独家内化」进 θ′，§4.3 p6）；运行时产物是**瞬时**的定长张量 M_t ∈ R^{K×d_model}，用完即弃，不落盘、不索引、不可寻址。
- **hook（写入刺激）**：推理核已生成的隐藏状态序列 H_{t,<j} ∈ R^{(j−1)×d_model}——注意它天然是**张量**，不是文本。
- **容量代理量**：K（潜记忆长度，实验取 {2,4,8} p7，敏感性扫描到 2→32 p10/Fig.6 左）与 LoRA 秩（r=16, α=32, target=[q_proj, v_proj], dropout=0.1，附录 Table 2 p19）。
- **淘汰 / 遗忘 / 合并 / 版本**：**未提及**——论文没有任何容量上限、淘汰或遗忘机制。
- **外部库接口**：文本片段集合 C_t = {c_1…c_P}，编码为 E_t ∈ R^{L_c×d_model} 后与 H 拼接（附录 E p23）。

### 2.6 论文自陈局限与边界条件
- **自陈局限**：**未提及**。全文（§1–§6 结论 + 附录 A–G）未见 Limitations / Future Work 章节，也未报告 seed 数、多次运行方差或置信区间（已检索 "seed / ± / error bar" 均无命中）。
- 假设依赖（以下为**从实验设置推出的推断**，非论文自陈）：① 必须有一个可读取隐藏状态、可挂 LoRA 的自回归 LLM 作为推理核；② 必须有任务级奖励函数 R(τ)（GRPO 变体）或专家示范轨迹（SFT 变体）；③ 潜记忆的「语义」只能靠事后聚类 + 强制解码间接解释，不可直接审计；④ 生成质量与主干容量强相关（1.5B/3B/8B 三档差距显著，Table 1/3）。
- 明确不适用的情形（推断）：无 token 序列的非语言控制环；无外部奖励/示范可用的场景；需要按条精确写入/检索/删除/审计记忆的场景（论文根本没有条目与写入接口）。

## 3. SSEA 立场对齐（核心维度）

### 3.1 C1–C10 映射
| 裁判标准 | 判定 | 依据（论文中的具体机制/数字） | 若冲突：改造方向 |
|---|---|---|---|
| **C1** 生存控制架构，非语言生成 | **✗** | 域是 LLM 智能体解题（QA/数学/代码/具身文本），目标函数是任务准确率；控制对象不是生存信号（§5 p7） | 只取**架构形状**（监视→按需生成→注入状态流），丢弃任务目标；把 stimulus 换成快环状态张量、把奖励换成环境淘汰信号 |
| **C2** 自然语言只作观察员接口 | **◐（分裂）** | **正面**：潜记忆本身是非语言的——机器原生、人类不可读，注入的是隐藏状态张量而非文本（p9、式(6) p5）；hook 是张量 H_{t,<j}。**负面**：附录 E 式(17) `q_{t,j} = Decode(z_{t,<j})` —— 一旦接外部库，**必须把已生成 token 解码成自然语言查询**才能检索，语言由此进入控制闭环；且整个基底是 token 级 LLM | 走「纯参数 weaver」路径、**禁用 Decode 查询**：外部记忆库改向量检索，键用状态张量（或张量索引）而非文本；若必须保留语言查询，限定其在**慢环**执行、产物以张量形式固化后供快环只读 |
| **C3** 权重/记忆/技能三分离 | **✗（核心冲突）** | 记忆**就是权重**：「this information is exclusively internalized into the parameters of W_weaver」（§4.3 p6）；无独立记忆存储、无写入接口、无条目 | 拆成两层：**生成器参数 θ′**（可训练、可遗传的结构性部件）与**记忆内容**（显式缓存的 K×d 张量 + 键，可寻址、可删、可审计）分离；θ′ 只保留「怎么织」的能力，不保留「织了什么」 |
| **C4** 低算力低带宽 | **✓（强）** | 定长 K 个 d_model 向量注入（K∈{2,4,8}）；仅在分隔符处评估的稀疏激活（式(7) p5）；对过度激活显式惩罚（式(8) p6）；LoRA r=16 轻量（Table 2 p19）；实测时延为 Vanilla 的 24%–94%（p10） | —（直接可用，是本篇最强项） |
| **C5** 精准回忆历史 | **✗** | 记忆是**生成式重建**而非逐字复现（§4.1 p5）；无条目、无键、无地址、无删除；产物人类不可读（p9、附录 F p24–28）；「精准」无从定义与验证 | **本篇不能当 C5 主干**。C5 仍交给 Memento/MemRL/A-MEM/Mem0/ReasoningBank 的条目化记忆；MemGen 只做这些条目**注入前**的压缩/重建器（见 Table 8：仅靠织造就把 ExpeL 36.18→45.60） |
| **C6** 可自主修改自身 | **◐** | **有边界权的雏形**：梯度只回传 θ′、π_θ 冻结（式(10) p6），「只改一个隔离模块」是硬约束。**缺**：无提案权/验证权/应用权分离，无四级验证门，无原子升版与回滚，改的是权重而非发布结构新版本；修改触发源是外部梯度训练，不是自提案 | 把 Δθ′ 当作一类 **Δθ 提案**纳入慢环：慢环产出候选 Δθ′ → 四级验证门（格式→沙盒→回归→环境实测）→ 原子升版 → 快环只读不可变快照；**训练过程本身必须移出快环**（只在慢环/离线进行） |
| **C7** 可保存/恢复/变异/继承 | **◐（技术上是好载体）** | LoRA 适配器天然小、可序列化、可合并、可加载/卸载，是 Δθ 的优质打包形态（Table 2 p19：r=16, α=32, 仅 q_proj/v_proj） | 采用其**载体形态**（Δθ 通道 + 变异算子：对 θ′ 加噪即一次变异）；但准入须过 Gene Manager 与 HeritableFilter，且受 C8 过滤 |
| **C8** 给基因先验，不给知识语料 | **✗→◐（可改造）** | θ′ 里装的是**后天经验**（内化的轨迹知识），若整包进 GenePackage 就是知识跨代，违反 C8 且会膨胀 | 只遗传 **weaver 的结构与超参**（K、分隔符集、LoRA 秩/目标模块、门的结构与预算）；θ′ **重置或清零**后随包发布；确需保留的部分按 HeritableFilter 判结构性先验 |
| **C9** 不设外部评分函数，只有淘汰函数 | **✗（第二核心冲突）** | trigger 用任务奖励 R(τ) 做 RL（式(8) p6）；p̄ 由「奖励 ≥ batch 中位数」的轨迹集定义（式(9)），**按优劣排序**本身就是评分；weaver 的 GRPO 变体用组内相对奖励（式(15)(16) p18）；SFT 变体用专家示范（式(11) p17） | **剥离方案（三条）**：① 奖励换层——把 R(τ) 换成**环境持有的淘汰函数输出**（存活/淘汰二值，模型碰不到、不可塑形），不允许连续分值；② 去掉排序——p̄ 的「高奖励轨迹集」改为**存活轨迹集**（同为环境二值信号）或直接删除，稀疏性改由**激活预算上限**（如每 episode 最多 N 次调用、带宽配额）约束——预算是 C4 仪器不是价值判断；③ 示范与内在驱动——SFT 的专家轨迹属外部知识语料，改用**内在驱动**（预测误差/惊奇度）作门的目标信号，其定义不可修改 |
| **C10** 创新在 L2/L3/L4，不在 L1 算子 | **✓（强）** | 无新算子：LoRA、LLM 主干、GRPO/SFT、t-SNE/K-means 全部借用；创新在 **L2**（记忆与推理的交织信息流、注入面）与 **L3**（两阶段训练协议、只训 θ′ 的更新边界） | — |

### 3.2 L1–L4 层级定位
| 层次 | 论文在该层提供了什么 | 对 SSEA 的价值 |
|---|---|---|
| **L1 算子层** | 无（LoRA / Transformer 隐藏状态均为借用） | 无新增，符合「L1 可替换」立场 |
| **L2 信息流层** | **监视 → 边界触发 → 生成 → prepend 回状态流**的完整注入面；定长 K×d 的向量通道；外部库可拼接的 [H; E] 接口 | **高**：这是本篇最贴合 SSEA 快环向量通道的部分，形状几乎可直接对位 |
| **L3 学习层** | 两阶段训练协议（先合成器、后门）；「只更新隔离模块」的更新边界；稀疏性惩罚作为带宽约束 | **中-高**：提供了「门如何学」的范式，但训练信号源必须换血（C9） |
| **L4 演化层** | LoRA 作为 Δθ 的小型可打包/可变异载体；但无保存/继承/变异协议 | **中**：载体形态可用，协议需 SSEA 自定（Gene Manager + HeritableFilter） |

### 3.4 债务与验收实验对应
- **债务 22（记忆二级门用常量阈值、慢环不可调，半接线）**：本篇给出「门 = 可学习模块」的完整形态与训练目标，是**最直接的可回应项**。
- **记忆门「开得准不准」的选择性缺失（「不开」已修）**：Table 5 的三档消融把「开得准」变成了可量化判据（trained > all-delimiters > random），缺失的正是这样一把尺子。
- **`retrieve` 键收窄 → 召回精度上限低**：**部分缓解、不根治**。缓解路径是「宽召回 + 织造压缩成定长块注入」（Table 8：不靠参数记忆，仅织造就把 ExpeL 的 ALFWorld 36.18→45.60、PopQA 28.16→39.50）——把召回广度与注入带宽解耦；不根治是因为织造本身是**有损重建**且不可审计，精度上界仍由生成器决定，无保证。
- **Gene Manager 缺失 / Δθ 通道**：提供 Δθ 的**载体形态**（LoRA 包），但不提供管理器本身；可作为 Gene Manager 落地时 Δθ 字段的参考格式。
- **技能表示够不够（0/33 后仍未回答）**：**仅作对照/启发**。procedural memory 簇（Cluster 3）展示了一种**非符号、不可读**的技能载体，恰好是 SSEA 应警惕的反面样本——不可读即不可验证，过不了四级验证门；但「技能以定长潜块注入」仍是值得对照的候选表示。
- **睡眠期计算预算未定义**：**未回应**。本篇是实时在线插入（推理期），与睡眠期离线整理是相反的时间位置；预算定义仍需自行给出。
- **可服务的验收实验**：记忆检索命中率（当前 0.5164）与记忆门相关实验；**注意**危险回避率两臂 0.9814 已饱和，不能用作本篇相关实验的主判据。

## 5. 冲突、代价与风险

- **与硬约束的冲突（逐条）**
  - **C3（✗）**：记忆 = weaver 权重。改造后必须「生成器参数」与「记忆内容」双轨：θ′ 归 Δθ 通道（可遗传、可变异），织出的潜块归 ΔM（可寻址、可删、可审计、不跨代）。
  - **C5（✗）**：无条目、无键、无删除，产物不可读 → 无法定义「精准」。本篇**不能**承担 C5 主干，只能做条目记忆的下游压缩器。
  - **C9（✗）**：RL 用任务奖励 + 按奖励中位数排序 + SFT 用专家示范，三重违规。剥离方案见 3.1；**未剥离前不得进入任何 SSEA 实验**。
  - **C2（◐）**：附录 E 的 `Decode(z)` 查询路径让语言进入闭环；且基底是 token 级 LLM。必须切到纯参数路径或把该路径限定在慢环。
  - **C8（✗→◐）**：θ′ 装后天经验，默认不得进 GenePackage。
- **隐含假设与失效条件**：① 必须有可读写隐藏状态的 LLM 主干——SSEA 快环若不是 LLM，整条链路的「hook / prepend」需重新定义（这是最大的搬运不确定性）；② 生成质量随主干容量显著变化（1.5B/3B/8B 差异大，Table 1/3），小模型上收益依赖 GRPO 变体而非 SFT 变体；③ 潜记忆的语义只能靠聚类间接解释，无法保证「织出来的就是当时那条经验」。
- **算力 / 带宽 / 工程代价**：推理侧便宜（时延 24%–94%、LoRA r=16）；**训练侧贵**——需要 rollout + RL 基础设施、两阶段训练、且 weaver 全参微调明显优于 LoRA（Table 6：18.28→21.21 等），效果与参数效率存在直接张力。对低算力立场（C4）而言，**训练期的账单远超推理期的节省**。
- **搬运后的可能退化模式**（若失败，会以什么形式失败）：
  1. **门学成「永远不调用」或「永远调用」**——预算惩罚系数 λ 失当时，稀疏性目标压过效用，表现为调用次数塌缩而命中率不升（这正是 Table 5 三档对照要盯的分母）；
  2. **织造漂移**——生成器把不同经历织成同一个块（Latent 空间坍缩），表现为功能簇数量下降、命中率虚高但行为无改善；
  3. **不可审计的静默污染**——错误的重建以张量形式进入快环，因不可读而无法被回归门发现，只在环境实测（淘汰）阶段暴露；这是与 **Misevolve** 记忆路径红队清单直接相关的失效模式；
  4. **知识跨代膨胀**——θ′ 混入 GenePackage 后逐代累积，违背 C8 并拖垮包体（**Gene Manager 缺失**时会更难发现）。

## 6. 组合分析

### 6.1 关系图谱
| 关系 | 对象（点名论文或方法族） | 说明 |
|---|---|---|
| **最直接互补** | **Memento**（A/P1） | Memento = 冻结 LLM + 案例库读写 + 可学习检索 μ，负责「**从库里选什么**」；MemGen 负责「**选出来之后怎么变成快环能吃的定长块**」。两者拼成「条目库 → μ 选择 → 织造压缩 → 潜块注入」的完整链路，且都不动主干权重 |
| **门侧互补** | **MemRL**（B/P2） | MemRL 的两阶段检索 + 冻结库迁移验收 + 遗忘率 FR 提供**写入/迁移/遗忘**治理；MemGen 提供**调用时机**治理。一个管「存多久/搬不搬」，一个管「此刻用不用」——正是 SSEA 记忆门缺的两半 |
| **拓扑互补** | **A-MEM**（B/P1） | A-MEM 的 Zettelkasten 链接拓扑 + 近邻回写给记忆以**可寻址结构**；MemGen 的产物不可寻址。组合时应让 A-MEM 的条目作**源**、MemGen 作**编译层**，切不可让 MemGen 取代 A-MEM |
| **流水线互补** | **LightMem**（B/P1） | LightMem 管「摄入压缩 → 主题分段 → 睡眠期离线巩固」；MemGen 管「在线按需织造 + 注入」。LightMem 的**睡眠期**与 MemGen 的**在线推理**恰好占据两个时间位置：慢环出条目（LightMem），快环做织造注入（MemGen） |
| **准入治理** | **SEDM**（B/P1） | SEDM 的 SCEC 自包含打包 + A/B 准入验证是**记忆准入官**。织造产物与 θ′ 更新必须过 SEDM 的准入 A/B，否则不可审计的张量会直接进快环 |
| **内容层供给** | **ReasoningBank**（B/P1） | ReasoningBank 给出「推理单元 schema + 成功/失败双路抽取 + k=1 少而精注入预算」——它是**织造层的上游内容规范**：先按 ReasoningBank 抽成可迁移的推理单元，再由 MemGen 织成潜块。注意 ReasoningBank 的 LLM-as-a-Judge 标签源与 MemGen 的任务奖励是**同类的 C9 冲突**，两者叠加会放大冲突而非抵消 |
| **对照组（同族异路）** | **Mem-α**（PDF 在库、尚未出卡） | Mem-α（arXiv:2509.25911，Anuttacon/UCSD）用 RL 学**记忆构造策略**（选 memory tool / memory type，core+episodic+semantic 架构，奖励来自下游 QA 准确率 + 记忆质量指标）。**关键分野**：Mem-α 学的是「**怎么写条目库**」，保住了可寻址性（C5 友好）；MemGen 学的是「**怎么生成潜张量**」，放弃可寻址性换带宽（C4 友好）。SSEA 应**学 Mem-α 的写入策略、学 MemGen 的注入面**——这是本篇最重要的组合结论 |
| **同族待补** | **MemEvolve** | 仅见于 `cards/阅读统计.md`「后续批次候选」名目，**仓库内无 PDF、无卡片**。本卡不对其主张任何内容；待补读后与 MemGen 在「记忆本体如何演化」上做对照 |
| **风险治理** | **Misevolve**（A/P1） | 织造产物不可读，属「记忆路径误演化」的高风险形态；θ′ 的权重更新属「参数路径」。两者都须走 Misevolve 的红队验收清单 |
| **参数侧诊断** | **RAGEN**（B/P1） | 若 weaver/trigger 的 RL 训练出现 Echo Trap，用 RAGEN 的不确定性过滤做诊断仪 |
| **慢环节律** | **Dream-RSI**（A/P1）、**WebRL**（B/P2） | MemGen 是**在线**织造，与慢环「做梦式」离线提案验证时间位置相反；若把织造移到慢环（必须如此），可并入 Dream-RSI/WebRL 的统一离线预算 |
| **替代关系** | 软提示 / KV-cache 类潜记忆（论文 §2 点名的 MemoryLLM、M+、LatentSeek、SoftCoT、Co-processor） | 在「潜记忆载体」这一格上，MemGen 是**生成式**替代**检索式**的一档；对 SSEA 而言，它还能替代一部分「原始上下文拼接」的粗暴注入 |

### 6.2 推荐组合方案
1. **记忆主干（Memento × MemRL × A-MEM × ReasoningBank） + 织造注入层（本篇） + 巩固层（LightMem）**
   - 慢环：LightMem 做摄入压缩与睡眠期巩固 → ReasoningBank 的双路抽取产出推理单元 → A-MEM/Mem0 建链接与实体结构 → Memento 的 μ 负责选择 → MemRL 的 FR / 冻结库验收负责淘汰与迁移；
   - 快环：被选中的条目经 **LatentWeaver（本篇改造版）** 织成 **定长 K×d 潜块** → prepend 进快环状态流；
   - **接口形态**：`retrieve(宽键) → 条目集合 → weave(条目 ∪ 当前状态张量) → M ∈ R^{K×d} → 注入`。**禁止 Decode 成文本再检索**；
   - **新增能力**：召回广度与注入带宽解耦（键可放宽），注入成本恒定 K；
   - **新增风险**：织造是有损且不可审计的，任何错误重建都会静默进入快环 → 必须配 SEDM 准入 A/B + Misevolve 红队。
2. **记忆门（本篇 trigger × SSEA 常量阈值门）**
   - 把现有二级常量阈值门换成可学习门，激活预算以**带宽配额**表达（不用分值），门参数由慢环更新并随快照原子发布；
   - 验收直接照搬 Table 5 的三档对照（Random / 全边界 / 训练门）。
3. **Δθ 通道（本篇 LoRA 形态 × Gene Manager）**
   - θ′ 作为 GenePackage 的 Δθ 字段，加噪即变异；准入受 HeritableFilter 与 C8 约束（默认清空后天经验）。

### 6.3 本篇在组合中的典型角色
- **「记忆的最后一公里」——注入面与闸门**：不管上游条目库怎么组织，本篇负责两件事：**此刻该不该用记忆**（门）、**用了之后以什么形状进入快环**（定长潜块）。它不生产记忆内容，也不保管记忆内容；**它不是记忆体，是记忆体的读出口。**

## 8. 裁决与下一步

- **应用等级：B 零件采用** —— 采用三件：① 定长潜张量注入面；② 可训练稀疏记忆门（含激活预算约束与三档门质量消融）；③ LoRA 作为 Δθ 的小型可打包载体。**不采用**：记忆本体写在权重里的形态、RL 外部任务奖励、以及任何 `Decode(z)` 式的语言检索路径。判为 B 而非 A 的决定性理由是 **C3 + C5 双冲突**——它给出的「记忆」在 SSEA 定义下不算记忆（不可寻址、不可写、不可读、不可删），只能当通道与闸门用。
- **优先级：P1**（排在 Gene Manager 之后：Δθ 通道的价值要等 Gene Manager 存在才能真正落地）。
- **建议动作**
  1. 先在**不作任何训练**的前提下，把「定长 K×d 块 prepend 进快环状态流」做成注入面骨架，用现有固化记忆直接填块，验证形状与带宽（K 取 2/4/8 扫描）；
  2. 记忆门改造：常量阈值 → 可学习门，激活预算写成**配额**（每 episode 上限 / 带宽占比），**禁止**任何按「好坏」排序的信号进入门的训练目标；
  3. 建「门质量」验收：照搬 Table 5 三档对照（随机 / 全边界 / 训练门），作为记忆门「开得准不准」的常设判据；
  4. 与 Memento 的 μ 对接：μ 决定选哪些条目，织造层决定如何压成定长块；先只做「宽召回 + 织造压缩」，观察命中率（当前 0.5164）是否上升；
  5. 把 LoRA 形态登记为 GenePackage 的 Δθ 候选格式，并在 HeritableFilter 中写死「θ′ 默认清空后天经验、只留结构与超参」；
  6. **前置阻断项**：在 C9 剥离方案（奖励换层 → 环境淘汰二值信号 / 内在驱动）落地并通过评审前，不得把本篇的任何训练目标接入 SSEA 实验。
- **最小验证实验（记忆门选择性，服务债务 22 与「记忆门开得准不准」）**
  - **双臂 / 消融**：A 臂 常量阈值门（现状）；B 臂 可学习门 + 激活预算配额；C 臂 随机门（等预算，作下界对照）；D 臂 全边界门（等预算，作「只对齐边界不选择」的上界对照）。≥8 seed，同一环境、同一快照。
  - **判据（分档，先看分母）**：① **机制计数**——每 episode 的可调用位置总数（分母）、实际调用次数、调用位置的分布熵；② **行为差**——记忆检索命中率（基线 0.5164）、单 episode 生存时长；③ **淘汰结果**——模型外淘汰函数给出的淘汰率。**不得**用危险回避率（两臂 0.9814 已饱和）。
  - **预期**：B 臂在**相同调用预算**下命中率显著高于 A 臂，且调用次数分布更集中（熵更低）；D 臂应高于 C 臂但低于 B 臂（对应 Table 5 的 trained > all-delimiters > random 序关系）。
  - **证伪条件**：若 B 臂只降低了调用次数而命中率无增益 → 说明 SSEA 当前环境中「何时调用记忆」**不是**瓶颈，门的价值仅在省带宽，应把资源转去改「织什么/存什么」；若四臂在命中率上无显著差异 → 说明瓶颈在**记忆内容**而非**门**，本篇降级为 P2。
  - **额外必看**：织造漂移监控——统计潜块的功能簇数量（K-means，N=4）随 episode 的变化，簇数塌缩即为退化信号。
- **若 E 不采用**：不适用。
