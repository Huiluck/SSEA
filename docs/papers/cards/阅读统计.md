**本轮三条最重要的新增结论：**

1. **HarnessEval 判 P0（立即）**——它是「如何证明自演化真的有效」的方法论底座，直击项目反复踩的
   「判据饱和 / 指标全绿但行为没变 / 读数字读错 / 记录数字不复现（债务 25）」。建议**在七条验收
   实验继续推进之前先吸收其判据健康度检查表**（预算匹配基线 + 搜索/评测集分离 + pass@1 vs pass@k
   分母口径）。
2. **技能侧出现了外部负结果**——`SkillsBench`（D）实测**自生成技能低于无技能基线（−8.1~−11.5 pp）**、
   ≥4 技能与详尽文档增益塌陷；`RecordReplay` 判决 0/33 的失败形态很可能是「技能被写成定长动作串，
   环境一扰动即失效」。两者合起来给「技能表示够不够」提供了迄今最硬的外部证据。
3. **睡眠期计算预算终于有了可填的数字**——`EvoTest`（20–30 s / 1 次 LLM 调用，CPU 级）、
   `AgentEvolver`（100 条样本→40.3%、Steps@.9 −55%/−67%）、`MemSkill`（Table 3 唯一带数字的预算前沿）、
   `SEAL`（反面标尺：30–45 s/次评估、一轮 ≈6 h@2×H100）、`SkillRL`（间隔 5 / 失败 ≤10 / 新增 ≤3）。
