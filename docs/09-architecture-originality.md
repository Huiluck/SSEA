# SSEA v0.3.1 架构原创性说明

**文档性质**：Milestone 0 交付物之一
**对应任务书**：[07-ssea-v0.3.1-charter.md](07-ssea-v0.3.1-charter.md) 第 11 节 Milestone 0
**修订依据**：[08-dual-loop-interface-and-gap-closure.md](08-dual-loop-interface-and-gap-closure.md)
**验收标准**：明确 SSEA 是新架构，而不是现有模型应用

---

## 1. 本文要回答的问题

Milestone 0 的验收标准只有一句话，但它是一个**可被推翻**的命题：

> 明确 SSEA 是新架构，而不是现有模型应用。

推翻它最有效的方式是这样一个提问：

> 如果把 GRU 换成别的、把 RAG 换成别的、把技能库换成别的，SSEA 还剩下什么？

如果答案是"什么都不剩"，那 SSEA 就是集成工作，不是架构工作。本文用四步回答：

1. 给出创新层级定位——说清在哪一层新（第 2 节）
2. 给出六项架构主张，每项附**消融检验**（第 3 节）
3. 汇总消融表——每行说明"去掉这一层会退化成哪个已有系统"（第 4 节）
4. 明确列出我们**不**声称什么（第 5 节）—— 声明的边界越窄，声明越可信

---

## 2. 创新层级定位

"新架构"必须先说清在哪一层新。SSEA 采用四层划分：

| 层次 | 含义 | 传统 LLM | SSEA v0.3.1 | 是否创新点 |
|---|---|---|---|---|
| **L1 算子层** | 基础网络模块 | Attention / MLP | GRU / 小型 Mamba / SSM | **否** —— 借用，可替换 |
| **L2 信息流层** | 模块如何连接 | 文本 → Transformer → token | 感知 → 状态 → 记忆 → 动作 → 反馈；双环 + 结构注入面 | **是** |
| **L3 学习层** | 如何更新自身 | 喂数据 + 全量反向传播 | 记忆写入、技能固化、规则生成、局部可塑性、技能代码段 | **是** |
| **L4 演化层** | 如何保存继承变异 | 训练后固定 | 基因包、本能内化规则、变异继承、可审计 | **是** |

**SSEA 的立场**：创新在 L2 / L3 / L4。第一阶段使用 L1 已有算子，是为了降低工程风险——先用成熟引擎验证新车架的传动是否成立。

但这不等于"套壳"。区别在于**可检验性**：L2/L3/L4 的每一项都可以做消融，消融后会退化为一个**具名的已有系统**。见第 4 节。集成工作没有这个性质——把 Voyager 的技能库换成另一套技能库，系统性质不变；而把 SSEA 的结构注入面拿掉，系统就变成了另一种东西。

---

## 3. 六项架构主张

以下六项即任务书第 4 节的原创性声明，此处为每项补上最近似工作、架构级差异与消融检验。

---

### 主张一：从语言建模架构转向生存控制架构

**主张**：模型的主任务不是预测下一个 token，而是

```
感知 → 决策 → 行动 → 反馈 → 学习 → 遗传
```

**最近似工作**：World Models（Ha & Schmidhuber）、Dreamer 系列、MuZero。它们同样是 observation → action 的闭环。

**架构级差异**：

| | Dreamer / MuZero | SSEA |
|---|---|---|
| 优化目标 | 最大化累积回报 | **无回报函数**。主任务是维持生存 + 降低惊奇度 |
| 经验去向 | 回放缓冲区，训练后丢弃 | 长期记忆，可检索、可遗传 |
| 模型终点 | 训练完成的策略 | 可保存 / 变异 / 继承的生命体 |

差异不在"有没有环境闭环"（这个早有），而在**闭环的出口连到了遗传机制**，且闭环内没有评分函数（对应裁判标准 C9）。

**消融检验**：拿掉双环与结构注入面 → 退化为 Dreamer 式 model-based RL agent。

---

### 主张二：权重、记忆、技能三分离

**主张**：不把全部知识压入权重，而是

| 能力类型 | 存储位置 | 更新方式 |
|---|---|---|
| 基础控制能力 | 小型核心网络 | 少量局部更新或冻结 |
| 历史事件经验 | 外部记忆系统 | 写入、检索、合并、遗忘 |
| 可执行行为 | 技能库 / 代码库 | 生成、验证、复用、变异 |

**最近似工作**：RAG / kNN-LM（外部记忆）、Voyager skill library（外部技能）。

**架构级差异**：RAG 与 Voyager 是**语言模型的增强模块**——模型主体仍是语言模型，外部记忆只是补丁。SSEA 的三类存储各有独立的更新机制与遗传路径，且注入面与遗传面**共用同一份结构定义**（08 §2.1）：`FastLoopContext` 的内容就是 `GenePackage` 三个字段的直接来源。这意味着"学什么"和"传什么"不是两套机制。

**消融检验**：拿掉三分离 → 退化为 LLM + RAG 记忆。

---

### 主张三：动作空间不是词表，而是控制空间

**主张**：动作不是从词表采样一个 token，而是多通道结构化控制对象（连续 + 离散 + 参数化 + 技能 + 潜空间通信）。

**最近似工作**：机器人连续控制、LLM function calling、Voyager programmatic actions。

**架构级差异**：混合动作空间本身不是新东西。SSEA 的新意在两条**硬约束**：

1. **动作必须可执行** —— 协议中不允许存在无消费者的通道。这是删除 `latent_action` 的原因（08 §2.4）。
2. **技能是可逐帧执行的压缩先验，不是提示模板** —— Skill Runner 把 `action_sequence` 按帧展开（08 §2.3）。Voyager 的技能是可执行代码，但由 LLM 在提示层调用；SSEA 的技能由模型内的 Runner 执行，**查表比每步重新推理更省算力**。

第 2 条是"低算力"目标真正的落地机制，也解释了为什么技能库增长不会导致算力爆炸——技能是查表，不是搜索。

**消融检验**：拿掉 Skill Runner → 技能退化为提示模板，退化为 Voyager 的 prompt-based skill。

---

### 主张四：学习不依赖全量权重训练

**主张**：学习 = 结构注入，不是梯度更新：

```
慢环产出提案 → Verification Gate → 版本化 Structure Store → 原子切换 → 快环读取新快照
```

**最近似工作**：STaR / Quiet-STaR（自举推理）、LoRA / adapter（局部更新）。

**架构级差异**：STaR 与 LoRA 回答的是"如何更省地训练语言模型"，前提是存在损失函数。SSEA 把学习重新定义为**结构注入**：学习信号是预测误差与生存后果（不是损失），学习产物是五类结构提案（不是参数增量），应用方式是版本号切换（不是权重覆写）。

**消融检验**：拿掉版本化快照注入 → 自我修改必须依赖外部事务与沙盒，即 Darwin Gödel Machine 路线（见主张六）。

---

### 主张五：模型具有生命周期

**主张**：模型支持

```
出生 → 运行 → 学习 → 保存 → 死亡快照 → 基因提取 → 变异 → 继承
```

**最近似工作**：Weight Inheritance、NEAT / HyperNEAT、Evolutionary Model Merging。

**架构级差异**：这些都是**训练技术**——在训练管线里传递权重。SSEA 把保存 / 恢复 / 变异 / 继承做成模型的一等接口，并定义了**本能内化规则**（08 §3.4）：

> 某技能 `success_count ≥ K` 且被 Skill Runner 累计执行帧数 ≥ F → 由经验编译器提议固化为 instinct adapter，标记 `origin: consolidated_from:<skill_id>`，进入基因包可遗传。

这一条落地了 doc 01 的原始目标"内化成类似本能传递到下一代"。它此前在 v0.3.1 里只有字段、没有规则，等于目标被静默搁置。

**消融检验**：拿掉基因包与内化规则 → 退化为一次性 agent，无生命周期。

---

### 主张六：自我修改必须经过验证，且验证是架构内部必经路径

**主张**：所有自我修改必须经过

```
提案 → 格式检查 → 沙盒运行 → 回归测试 → 小范围环境测试 → 通过则应用 → 失败则回滚
```

**最近似工作**：Darwin Gödel Machine、AI Scientist、DeepSeek DSec。

**架构级差异**：这些工作把验证放在**模型外部**——沙盒 + 回归测试 + 人工把关，模型与验证器是两个系统。SSEA 把验证门做成模型内部的必经路径，且失败回滚的机制不同：

> **Gate 不通过则版本号不切换，快照继续用旧版。不存在"回滚"这个操作，因为从未应用。**

安全性来自架构形态（版本隔离），不来自外部事务。这对应任务书 4.6 的原文："这是架构的一部分，而不是外部安全措施。"

**消融检验**：同主张四。去掉版本化注入，验证门就退化成一个外部沙盒工具。

---

## 4. 消融检验汇总表

这是本文最核心的一张表。它把"SSEA 是新架构"这个命题变成**可伪证的**：每一行都说明，抽掉该层后系统退化为哪个具名已有工作。

| 若移除这一层 | 退化为 | 是否即某个已有系统 |
|---|---|---|
| 双环 + 结构注入面 | Dreamer 式 model-based RL agent | 是 |
| 权重 / 记忆 / 技能三分离 | LLM + RAG 记忆 | 是 |
| Skill Runner | Voyager 式 prompt-based skill | 是 |
| 版本化快照注入 | Darwin Gödel Machine 式外部沙盒路线 | 是 |
| 基因包 + 本能内化规则 | 一次性 agent，无生命周期 | 是 |
| 惊奇估计器（替代评分信号） | 必须引入奖励函数，违背 C9 | 是 |
| 睡眠期一等公民状态 | 固定 checkpoint 式经验回放 | 是 |

**读法**：没有任何一行退化为"通用智能体框架"。每一行都落到一个具体的、已发表的系统上。这正是架构主张与集成工作的分界——集成工作的消融结果是"换了个零件"，架构工作的消融结果是"变成了别的东西"。

## 5. 我们不声称什么

声明的边界越窄，声明越可信。以下各项 SSEA **明确不主张**：

| 不声称 | 原因 |
|---|---|
| 发明了新的神经网络算子 | State Core 用 GRU / Mamba / SSM，是 L1 借用，可替换 |
| 在智力基准上超过主流 LLM | "智力"需重新定义（doc 03 第九节：生存智力 / 工具智力 / 社会智力 / 记忆智力…）。第一阶段无此类基准 |
| 第一阶段实现了开放式演化 | 无种群、无淘汰函数、无多模型竞争。第一阶段只是最小生命体 |
| 解决了对齐与安全 | 只有分层权限 + 验证门 + 核心系统只读。这是工程缓解，不是对齐方案 |
| 潜空间通信是新技术 | 第一阶段只预留 `CommunicationSignal.signal` 接口，不实现语言演化 |
| 精准回忆已被验证 | 这是第一阶段要**检验**的命题（验收实验 2），不是已成立的结论 |
| 低算力主张已被验证 | 同理，Skill Runner 的查表机制是**设计意图**，需实验 3 的「能量消耗变化」指标证实 |

最后两行尤其重要：本文是**设计声明**，不是**结果声明**。六项主张的正确性由第一阶段六个验收实验判定，不由本文判定。

## 6. 与九篇论文的对应关系

doc 01 列出的九篇初选论文，按"借用 / 改造 / 暂不使用"分类：

| 论文 | SSEA 中的位置 | 关系 |
|---|---|---|
| Voyager | Skill Library、Skill Runner | **改造** —— 技能由模型内 Runner 逐帧执行，非提示层调用 |
| Darwin Gödel Machine | Verification Gate | **改造** —— 验证门内建于模型，失败靠版本隔离而非外部回滚 |
| The AI Scientist（v1/v2） | Experience Compiler | **借用** —— 自动提出假设并验证的思想 |
| DeepSeek DSec | 沙盒验证环节 | **借用** —— 隔离执行的最小实现（第一阶段用 subprocess） |
| Evolutionary Optimization of Model Merging Recipes | Gene Manager（v0.4+） | **暂不使用** —— 模型合并留到多模型阶段 |
| A Survey of Self-Evolving Agents | 整体参照系 | **借用** —— 概念框架 |
| STaR | Experience Compiler 的自举思想 | **借用** —— 但学习信号换成预测误差与生存后果，非损失函数 |
| Quiet-STaR | State Core 的内部思考 | **改造** —— 内部思考以 intent_vector 形式存在，不落成语词 |
| Dream-RSI | 世界模型（v0.4+） | **暂不使用** —— 第一阶段只做一阶持久化预测（08 §2.6） |

**分类的意义**：一张表里"改造"占三项、"暂不使用"占三项，说明 SSEA 不是任何单篇论文的实现，也不是论文的简单拼接。

## 7. 结论

SSEA v0.3.1 的第一阶段不是：

```
拿一个现有大脑，放入环境中生存。
```

而是：

```
设计一种新的生存式模型架构。
该架构以非语言感知-行动闭环为核心，
以权重、记忆、技能三分离为基础，
以局部学习、技能固化、自我修改和基因遗传为演化机制。
```

本文使这一定位可被检验：**创新在 L2 / L3 / L4，六项主张各可消融，消融后退化为具名的已有系统，且我们明确列出了七项不声称的事。**

第一阶段要证明的是：

> 一个模型可以不以自然语言为中心，
> 不把全部知识压入权重，
> 不依赖全量数据投喂，
> 而通过感知、行动、记忆、技能、验证和遗传形成可持续演化的生命体架构。
