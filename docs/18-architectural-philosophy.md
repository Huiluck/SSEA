# SSEA 架构思想文档

**Survival-based Self-Evolving Agent Architecture —— 设计理念白皮书**

> 本文只回答一个问题：**SSEA 想要实现的架构，背后是一套什么思想？**
> 它不汇报进度、不罗列实验数字（那是 12/14/16/17 的任务），而是把驱动这套架构的
> 根本问题、范式主张、思想支柱与它们之间的内在逻辑，一次讲清楚。
> 文中陈述的是项目的**设计立场（主张）**；这些主张是否成立，需要实验另行回答。

---

## 〇、一句话总纲

> **智能的第一身份不是「会生成语言」，而是「能在世界中维持自身存在」。**
> 因此 SSEA 不做「更小的 Transformer」，而是把架构的组织原则从**语言生成**换成
> **生存控制**：让一个智能体像生命体一样——实时地感知行动、离线地整理经验、
> 安全地修改自己，并通过**繁衍**把可遗传的先验传给后代；世界既有淘汰与生存压力，
> 也偶有令人温暖的「**偶然的美好**」；自然语言只作观察员，不进控制闭环。

十条裁判标准 C1–C10 是这套思想的可执行表达；本文按「问题 → 范式 → 支柱 →
**生态系统（生命体将要进入的世界）** → 整体逻辑 → 设计推论 → 范式分界」展开。
第一阶段只造「模型本身」，但**生态系统是原始构想的另一半**，本文一并梳理。

---

## 一、出发点：现有架构的三个根本困境

当前主流智能架构（以 LLM / Transformer 为代表）把「智能」≈「在更大语料上训练
更大的模型」。SSEA 认为这条路径在根上有三处结构性困境，且都不是「把模型调小」
能解决的。

### 困境一：记忆被权重吞掉

- 知识与经历被压进**权重**，回忆是一次模糊的「模式补全」，而不是对具体事件的
  **精准检索**；
- 记忆与权重**同生命周期**：要改记忆就得动权重，要保留权重就无法单独遗忘或更新
  某条记忆；
- 结果：上下文窗口越撑越长，内存带宽成本随能力线性甚至超线性膨胀。

### 困境二：学习等于全量重训

- 任何一点改动都近似一次全训练，**没有「局部、安全、可验证地修改自己」的结构**；
- 模型无法在运行中把成功经验固化下来、或把失效的阈值调整过来——它要么不动，
  要么整体重训。

### 困境三：没有「遗传」的位置

- 一个训练好的能力没有作为**一等公民结构**传给新个体的通道；每个新个体都几乎
  从零开始；
- 「变异—继承—选择」这条在生物智能里极其有效的累积通道，在当前架构里缺席。

**共同根因**：用「语言生成（next-token prediction）」作为智能的组织原则，使
记忆、学习、遗传三件事都没有独立的结构位置，智力被锁死在「大权重 + 长上下文」
上。SSEA 要换的不是参数，而是**组织原则**。

## 二、范式革命：从「语言生成」到「生存控制」

### 2.1 核心主张

一个系统之所以「智能」，不是因为它会说话，而是因为它能在一个有代价、有危险、
资源有限的世界里**持续维持自身存在**，并在此过程中变得更适应。语言是智能的
**产物与工具**，不是智能的**本体**。

由此得到新的主干：

```
感知 → 决策 → 行动 → 反馈 → 学习 → 遗传
```

- 世界只给两类东西：**身体状态**（能量、疲劳、损伤）与**生存后果**（活下去或被
  淘汰）；
- 系统的一切结构都围绕「在低带宽、有限资源下持续生存并自我改进」来组织。

### 2.2 自然语言降级为观察员

自然语言不消失，但被严格放在控制闭环之外，只用于：人类观察员日志、事后解释、
慢环规划候选、调试输出。它**不得**参与：感知输入、动作输出、身体控制、实时闭环。

> 语言是「观察员」，不是「操作员」。这是整套架构最反直觉、也最承重的一刀。

### 2.3 三个「不是」（自我定位）

| | 不是什么 | 是什么 |
|---|---|---|
| 1 | 不是语言模型 | 核心任务不是 next-token，第一身份是**生存代理控制器** |
| 2 | 不是简单的具身强化学习 | 多出外部记忆、技能/规则库、自我修改、基因包、变异继承、代谢约束、安全验证器 |
| 3 | 不是完整生态系统模拟器 | 第一阶段只建「能够进入生态系统的最小生命体」本体 |

## 三、十大思想支柱

每条支柱统一按「**思想内核 → 为什么 → 设计含义**」说明。C1–C10 是其编号。

### 支柱 1 ｜ 生存是组织原则（C1）

- **内核**：架构为「维持生存」而构造，不为「生成文本」而构造。
- **为什么**：生存提供了一个不依赖人类标注、天然存在、不可作弊的终极约束。
- **含义**：控制环路上只处理与生存相关的结构化信号；评估一个结构的终极语境是
  「它让个体更能活下去吗」。

### 支柱 2 ｜ 语言只作观察员（C2）

- **内核**：自然语言不进控制闭环。
- **为什么**：语言是高带宽、模糊、为交流而生的表征，让它做实时控制既贵又不可控，
  还会把「会说」误当「会做」。
- **含义**：闭环用结构化观测/动作；语言仅留在观察员面（日志、解释、调试）。

### 支柱 3 ｜ 权重 / 记忆 / 技能三分离（C3）

- **内核**：三类东西有不同的来源、生命周期与可遗传性，必须分成三个独立结构位置。

  | 层 | 是什么 | 生命周期 / 可遗传性 |
  |---|---|---|
  | 权重 | 可微的网络参数 | 个体级；不直接逐位遗传 |
  | 记忆 | 外部、可精准检索的具体经历 | 个体级；默认不跨代 |
  | 技能 | 从成功经验固化的可复用程序 | 可淘汰、可继承 |
- **为什么**：混在一起，就无法「只改记忆而不动权重」「只固化技能而不重训」。
- **含义**：记忆外置、技能独立成库；三者各有读写规则与遗传判定。

### 支柱 4 ｜ 低带宽优先（C4）

- **内核**：控制环路上流动的信息应尽量少而结构化。
- **为什么**：算力与内存带宽是智能成本的主要来源；实时控制不需要、也不应承受
  长上下文与长推理。
- **含义**：快环只取当前所需的结构化向量；不做长文本推理、不频繁改权重；缓冲
  不得在控制路径上无界增长。

### 支柱 5 ｜ 精准回忆：记忆放在外部（C5）

- **内核**：回忆应是对具体事件的可检索存取，而非权重里的模糊再现。
- **为什么**：外置记忆可精准写入、检索、遗忘、合并，并能按重要度与可遗传性
  管理，而不必动权重。
- **含义**：独立记忆系统（向量检索 + 重要度 + 容量限制 + 合并 + 可继承判定）；
  策略从不可变快照读取。

### 支柱 6 ｜ 双环：实时生存与离线整理分离

- **内核**：
  - **快环 FSL**：毫秒级实时感知—行动，低带宽、不做长推理、不频繁改权重；
  - **慢环 SEL**：离线（如睡眠期）整理经验、产出结构修改，可验证、可回滚。
- **为什么**：实时性与深思熟虑是两种不可兼得的工作模式；生命体也正是「白天
  生存、睡眠整理」。
- **含义**：慢环**不调用快环**，只发布结构新版本；快环只读当前版本，不知道
  慢环存在。

### 支柱 7 ｜ 唯一「结构注入面」与四条性质

- **内核**：双环之间只通过一个接口耦合——快环读取一份**不可变快照**
  （FastLoopContext），慢环通过结构库发布新版本。
- 四条性质由**结构事实**保证，而非调用方自觉：

  | 性质 | 含义 |
  |---|---|
  | 快环零改动 | 换版本=换句柄，快环代码不感知 |
  | 失败天然回滚 | 门不通过则版本不切换——从未应用，故无需「回滚」操作 |
  | 可遗传 | 快照内容即基因包的直接来源 |
  | 可审计 | 每次升版留完整版本与门判据记录 |
- **为什么**：把安全属性做成结构必然，比靠约定、权限或 try/except 更可靠。
- **含义**：结构库上不设 rollback/undo API——这是设计，不是遗漏。

### 支柱 8 ｜ 自主自修改与四权分立（C6）

- **内核**：模型可以提出并应用对自身结构的修改，但「自我修改」被拆成四个
  不同的问题，分属四方：

  | 权 | 回答的问题 | 归属 | 刻意不做 |
  |---|---|---|---|
  | 提案权 | 提什么 | 经验编译器 / 局部可塑性 | 不提交、不评估好坏 |
  | 边界权 | 在不在允许范围内 | 可塑性控制器（白名单） | 不可改清单先于白名单 |
  | 验证权 | 能否安全应用 | 验证门（四级） | 不打分、不碰权重、不执行代码 |
  | 应用权 | 应用否 | 结构库提交 | 拒绝时不抛异常、不改版本 |
- **为什么**：任何一方都不能独自完成一次修改，从而杜绝「自己提、自己批、自己装」。
- **含义**：修改一律走「提案 → 四级验证门（格式→沙盒→回归→环境实测）→ 原子
  升版」。

### 支柱 9 ｜ 繁衍与生命周期：保存 / 恢复 / 变异 / 继承（C7）

- **内核**：智能不止于「活下去」，还包括**繁衍**——把个体的可遗传结构打包成
  **基因包（GenePackage）**，产生可运行的后代，并经保存、恢复、变异/重组、继承
  形成谱系。
- **繁衍是「挣来的机会」，不是自动复制**：只有在生存中表现良好、赢得繁衍机会的
  个体才把结构传下去。这正是选择压力的来源——**淘汰**移除不适者，**繁衍**放大
  适应者，二者合起来才构成完整的达尔文闭环（缺一不可，见支柱 10）。
- **两条遗传通道**（原始构想）：
  1. **显性传递**：把知识、思想直接传给下一代；
  2. **内化为本能**：把反复有效的结构沉淀成类似本能的先验传下去。
  后来的 C8 对其做了**收窄**：基因里只传**本能先验**，后天**知识不跨代**（防膨胀）。
  即「通道 2」被保留为遗传主通道，「通道 1」被限定在个体之内——这是思想从 01
  到 C8 的一次成熟。
- **死亡不是信息的终点**：死亡个体的**完整快照**（数据、代码、结构）被保存，供
  追溯与重建，并据此绘制家族「进化树」；繁衍还允许**变异与基因重组**（如模型
  合并配方），使后代既相似又可不同。
- **含义**：注入面是遗传面的子集——能注入快环的结构，原则上就是能进基因包的
  结构；变异率、可继承判定与「谁有资格繁衍」的判据须在协议层先定清楚。
- **为什么**：繁衍是「有效结构跨代累积」的前提，也是把学习从单个个体延伸到
  谱系、让适应有方向的唯一通道。

### 支柱 10 ｜ 两条元约束：先验可遗传、知识不跨代（C8）；只淘汰、不评分（C9）

**C8 —— 给基因先验，不给知识语料。**

- 基因里只放**结构性先验（本能）**：如「趋近资源」「抓握」这类与生俱来的倾向；
- 后天**知识**（具体经历、世界事实）留在个体记忆里，**不跨代**——这同时是防记忆
  膨胀的永久设计。
- 推论：本能应实现为可遗传的 adapter（**加法偏置**），而不是手调的解码器权重
  （不可遗传）；也因此不接入人类知识库。

**C9 —— 不设评分函数，只有淘汰函数。**

- 世界只决定个体「活不活得下去」（淘汰），不告诉它「这一步打多少分」（无奖励、
  无评分）；
- **淘汰是演化的「负半」，繁衍是「正半」**：淘汰移除不适者，繁衍让赢得生存的
  适应者被复制与放大——只有同时存在，选择压力才成立、适应才有方向（见支柱 9）；
- 验证门因此**只判合法性、不判优劣**：一个让存活翻倍、一个让它减半的提案，只要
  都合法，一视同仁；
- 淘汰函数位于模型之外，模型物理上碰不到，故「不可修改淘汰函数」是结构事实。

### 创新的层次（C10）

- **L1 算子层**（GRU / Mamba / SSM 等）是**借用且可替换**的，不构成架构声明；
- 真正的创新在 **L2 信息流**（三分离、双环、注入面）、**L3 学习**（自修改、可塑性、
  技能固化）、**L4 演化**（基因包、变异继承）。

### 支柱 11 ｜ 与生存压力同存的「偶然的美好」（原始构想，尚待定义）

- **内核**：世界在施加**生存压力**的同时，也**偶发地**给予令个体「感到温暖」的
  **美好**；它不是生存必需品，而是与压力并存的另一面。原始构想（01）原话：
  「系统给予模型生存压力，同时又给予模型偶然的美好能令模型感受到温暖」，并注明
  「生存压力和美好需要定义」。
- **四种候选形态**（02 的初步回应）：

  | 形态 | 触发情境 | 「温暖」的体现 |
  |---|---|---|
  | 好奇与惊奇 | 探索未知、发现新规律 | 预测误差带来的「多巴胺」式惊奇 |
  | 心流 | 挑战与能力恰好匹配 | 算力/能耗上的「温暖」倾斜（更省） |
  | 社会性连接 | 分享、互助、共御灾害 | 连接被强化，催生道德与协作 |
  | 安宁的回放 | 在安全庇护所中睡眠整理 | 无损巩固记忆，过程本身即美好 |
- **为什么需要（架构功能，而非温情点缀）**：
  - 纯压力世界只会把个体压向「苟活」的防御性局部最优，**不会开放式地发展智力**；
  - 美好给出**内在动机的方向**（探索、精进、连接），与开放式演化 / 新奇性搜索相
    呼应，是智力「超越求生」而持续生长的牵引；
  - 它让生存具有正向质地，而不只是被淘汰的恐惧驱动。
- **关键张力：必须与 C9 共存，不能偷换成奖励。**
  - 美好**不能**是世界按动作发放、可累加、可被钻空子的评分/奖励——否则直接违反
    C9，并招致 reward hacking；
  - 它的设计约束是三个词：**偶然**（不随叫随到，故无法当作目标去优化）、**具身**
    （是真实结构后果——庇护所真的更低耗、心流真的让渡算力、好奇本就是预测误差
    机制的副产品——而非一个打分）、**非通货**（不可储存、交易或最大化）；
  - 它作用于**内在动机 / 情感层**，给生命以质感与开放方向，而**不进入目标函数**。
- **状态**：这是项目**明确保留、尚未定义清楚**的思想；如何在不违背 C9 的前提下让
  「美好」可感知，是与「定义生存压力」并列的开放设计问题——本支柱只负责立题，
  不冒充已解。

## 四、生态系统：生命体将要进入的世界（原始构想，v0.4+）

第一阶段只造「能进入生态系统的最小生命体」，但生态系统不是可有可无的附录——它是
原始构想的**另一半**，是赋予模型结构以意义的**选择环境**。本节梳理生态系统的设计
思想；它在 v0.4+ 才动工，但理念在 01 已经立好。

### 4.1 一个动态、非平稳的世界

- 世界有**四季变化、生存物资随季节变化、自然灾害**；资源生成率与个体代谢成本随
  季节/灾害动态改变（02：把四季和灾害转成状态张量，做「环境压力注入」）。
- **为什么**：静态资源点只能训出对固定环境的过拟合；非平稳世界逼迫**持续适应**，
  是「开放式生存」的前提。
- **第一阶段刻意不做**（11：环境复杂度会掩盖模型缺陷，无法归因是「模型不会学」
  还是「环境太难」）。

### 4.2 多种角色：野兽、同族与生态位

- 系统中存在**多个模型**，分别扮演**野兽**（捕食者/竞争者）与**同族**，彼此
  **竞争与合作**。
- 用**生态位 + 演化博弈论**刻画同族合作、野兽竞争的结构，期望自发涌现出
  **「语言」与「社会结构」**。
- **通信应能由模型自主演化**：原始构想设想模型先以高密度的二进制/结构化信号
  交流、形成自己的语言，未来为与外界交流才学人类语言；第一阶段只预留
  `CommunicationSignal` 接口，不实现编解码。
- 社会也有「美好」面：分享物资、互助、共御灾害会触发连接强化，催生**道德与
  协作**（与支柱 11 的「社会性连接」呼应）。

### 4.3 无评分、只淘汰：模拟自然演化

- **系统不设评分函数，只有淘汰函数**，模拟自然界的演化；**人类是观察员**。
- **淘汰（死亡判定）归环境**：模型侧没有判定权，按 10 的平局裁决**连只读镜像
  都不做**。
- 淘汰的候选依据（02）是「能量耗尽、环境不适配度、计算熵增」式的**自然死亡 /
  垃圾回收**，而不是给行为打分。
- **种群级淘汰**以多模型共存为前提，属 v0.4+；第一阶段只有环境桩级判定
  （energy ≤ 0 或 damage ≥ max），无种群级淘汰。
- 与繁衍合起来：**淘汰移除不适者、繁衍放大适应者**（支柱 9/10），这才是完整
  的演化闭环。

### 4.4 生存压力与「偶然的美好」并存

- 世界在施加**生存压力**的同时，也偶发地给予令个体温暖的**美好**；压力与美好
  都需要定义（01）。
- 纯压力只会得到「苟活」，美好提供开放式发展的内在动机（详见支柱 11）。
- 这是连接「世界设计」与「个体情感/动机」的桥梁。

### 4.5 人类作为观察员：可解释与防作弊

- 人类**只观察、不干预、不打分**；观察员系统（02 第五维）包括：
  - **演化图谱 / 进化树**追踪：记录每次结构改写与合并的历史；
  - **异常与作弊检测**：监控 reward hacking，以及「**寄生**」行为（如专门掠夺
    其他模型的算力/资源、自己却不进化）；
  - **自动化日志与可视化**：呈现生态的繁荣与衰退、算力曲线与智力涌现拐点。
- 自然语言形态的**观察员接口 v0.4+**，始终在控制闭环之外。

### 4.6 模型与生态系统的边界：思想上的切分

- 01 即提出：「哪些属于模型架构、哪些属于生态系统？」
- 10 给出**三测试 + 平局裁决**：随个体死亡而消失 → 模型；不随个体死亡消失且
  筛选模型 → 生态；二者同时命中 → **判为生态**，模型侧设只读镜像（淘汰函数
  连镜像都不做）。
- 归属示意：**身体、动作、繁衍、感知、大脑**属模型；**季节、灾害、资源循环、
  角色博弈、语言演化、种群淘汰**属生态。
- 这条边界使安全属性（如「不可修改淘汰函数」）由**结构事实**成立，而非靠权限。

### 4.7 生态系统的阶段安排（预告，非承诺）

- **v0.4：多模型交互与最小生态接口**——多模型共存、简单资源竞争、通信信号演化、
  同族/野兽角色、死亡与繁衍规则、淘汰函数、观察员系统、技能与基因的群体传播
  （05 §17）。
- 更往后才是完整四季生态、自然灾害、复杂资源循环、模型合并（Model Merging）等
  （10/11 的推迟清单）。
- **顺序纪律**：在「最小生命体」被验证有效之前不进入生态——环境复杂度会掩盖
  模型缺陷；生态是模型的考场，不是模型缺陷的遮羞布。

## 五、这些思想如何连成一个整体

这些支柱不是并列清单，而是一条闭环的因果链（其最外层是第四节的生态系统）：

```
   偶然的美好（支柱11）：好奇/心流/连接/安宁
   给内在动机与开放方向，防止世界只剩「苟活」
        │  牵引（不进目标函数、非奖励）
        ▼
                ┌──────────────────────────────────────────────┐
                │                                              │
            生存是目的（C1）                  淘汰（负半）＋繁衍（正半）
                │                                      ＝选择压力（C9、支柱9）
                ▼                                              │
   三分离给出可独立变化的结构位置（C3）                          │
   权重 · 记忆（外置→精准回忆/低带宽 C4/C5）· 技能               │
                │                                              │
                ▼                                              │
   双环让「实时生存」与「离线整理」分开（支柱6）                  │
   经唯一注入面安全耦合（支柱7：零改动/天然回滚/可遗传/可审计）     │
                │                                              │
                ▼                                              │
   四权分立让自我修改安全发生（C6、支柱8）                        │
   提案 → 边界 → 四级验证 → 原子升版                             │
                │                                              │
                ▼                                              │
   繁衍让赢得生存的适应者被复制/放大（C7）                        │
   基因包只传本能先验、不传知识（C8）────────────────────────────┘
```

用四句话概括这条逻辑：

1. **生存**规定了系统为何而组织；**淘汰（负半）＋繁衍（正半）**是它无法作弊的
   选择机制——不适者被移除、适应者被放大；
2. **三分离 + 双环 + 注入面**让「变化」能够局部、安全、可验证地发生；
3. **繁衍与基因包**让被证明有效的**先验**跨代累积，而把**知识**留在个体——于是
   能力沿谱系增长，内存与带宽却不随代际膨胀；
4. **偶然的美好**在压力之外给出内在动机与开放方向，使智力超越「只求苟活」而持续
   生长——但它保持偶然、具身、非通货，不沦为评分（C9）。

**低带宽（C4）不是某一个模块的要求，而是贯穿全部环节的约束与最终收益。**

## 六、从思想到设计：可操作的推论

这套思想不是停留在口号，它直接推出一组可执行的设计纪律：

1. **快环纪律**：控制环路上不出现自然语言、不做长文本推理、不频繁改权重；只处理
   结构化观测与混合动作空间（连续 + 离散 + 参数化 + 技能调用）。
2. **慢环纪律**：慢环不调用快环，只发布结构新版本；所有修改必须经「提案 → 验证门
   → 原子升版」。
3. **失败安全**：不依赖补偿式回滚——验证不通过即不应用，版本号不切换就是天然
   回滚；结构库不提供 rollback/undo。
4. **本能的正确形态**：以**加法偏置**实现、推 **logit** 而非概率、可经基因遗传；
   本能为 0 时逐位等于改动前表达式（天然对照臂）。**不**用手调权重代替本能。
5. **不引入评分/奖励**：世界只给能量与生存后果；验证门只判合法性、不打分；不做
   奖励塑形。（「偶然的美好」见第 9 条——它是真实后果而非奖励。）
6. **记忆纪律**：记忆外置、可精准检索与遗忘；**跨代不累积记忆**（永久设计，防膨胀）；
   控制路径上的缓冲必须有界，累计统计放到观察员面。
7. **边界先行**：可改/不可改清单先定，且不可改清单先于一切白名单匹配；核心安全
   机制、验证门、环境接口、基因管理底层权限、观察员接口不可被自我修改。
8. **繁衍纪律**：繁衍是与生存表现耦合的「**挣来的机会**」，不自动发生；死亡个体
   留存**完整快照**与谱系（进化树）记录；后代经基因包继承**本能先验**（知识不跨代），
   并允许变异/重组产生可运行后代。**淘汰与繁衍必须同时存在。**
9. **美好的边界**：允许好奇、心流、社会性连接、安宁回放等「偶然的美好」，但它们
   必须是**偶然、具身、非通货**的真实结构后果，作用于内在动机/情感层；**不得**
   实现为可发放、可累加、可最大化或可被钻空子的奖励/评分（守住 C9）。

## 七、与三种相邻范式的分界

| 维度 | SSEA | LLM / Transformer | 具身强化学习 | 完整生态模拟 / 人工生命 |
|---|---|---|---|---|
| 组织原则 | 生存控制 | 语言生成 | 奖励最大化 | 群体/世界演化 |
| 控制接口 | 结构化信号；语言仅观察 | 自然语言 | 状态/动作（常含奖励） | 视系统而定 |
| 记忆 | 外置、可精准检索 | 压入权重 + 上下文 | 多为权重/状态 | 多样 |
| 自我修改 | 四权分立、可验证 | 靠外部重训 | 权重更新 | 通常无 |
| 跨代累积 | 基因包，只传先验 | 无 | 通常无 | 核心是群体演化 |
| 反馈 | 淘汰＋繁衍（无评分）；偶然美好（非奖励） | 文本/任务损失 | 奖励/评分函数 | 选择压力 |

关键差别一句话：

- 对 **LLM**：SSEA 把语言从「本体」降为「观察员」；
- 对 **具身 RL**：SSEA 用「淘汰」取代「奖励/评分」，并多出外置记忆、技能库、
  自修改与遗传；
- 对 **生态模拟**：SSEA 第一阶段只建「最小生命体」，不建世界本身。
