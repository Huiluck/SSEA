## 思想层面的待完善处（这是下一步的靶子）

我把读出来的空白分成三档，按「不解决会怎样」排序：

**A. 真空白——论证缺失，会动摇主张本身**

1. **「非语言」与「智力不缩减」之间没有论证桥**。LLM 的抽象推理、规划、自我反思恰恰是在语言空间涌现的。项目说了「语言是产物不是本体」，但**没有给出去掉语言后这些能力的等价替代路径**。这是最大的理论债务，直接压在 README 那句「不缩减智力」上。
2. **淘汰函数没有形式化，且当前形态没有选择力**。自然选择的压力来自**相对适应度差异**，而现在的淘汰是绝对阈值（能量≤0）。如果所有个体都能轻松活着，淘汰就退化成「不做功的墙」。v0.4 要的多模型生态里，「有梯度但不打分」的淘汰该怎么设计，完全空白。
3. **C9 与「美好」（支柱 11）的张力只有否定性边界**。三个约束（偶然、具身、非通货）说的都是「不是什么」，没有肯定性机制。一个不能发放、不能累加、不能最大化的信号，在控制论意义上到底是什么、如何产生内在动机的方向——目前只有隐喻。
4. **C10 与 C4 潜在冲突**：如果低带宽主张实际上依赖算子的特定性质（如 SSM 的 O(N)），那 L1 就不是「无关紧要、可随意替换」的。需要澄清哪些算子性质是架构声明的必要条件。

**B. 悬置的关键参数——设计已定形，但决定成败的数没有**

繁衍资格判据、变异率与可继承判定规则、HeritableFilter 的 importance 阈值与 retrieval_count 下限、本能内化的 K/F 阈值、提案优先级策略（C9 之下没有评分，多个提案谁先提交？）、睡眠窗口是否够跑完整条慢环流程（实测睡眠只占寿命 6–12%）。这些不是实现细节——**它们直接决定「什么算值得遗传的知识」和「慢环来不来得及工作」**。

**C. 被过早关闭的设计空间——值得重新打开**

1. **Lineage（龙族血脉设定）没有被充分利用**。那份设定里有一整套精细的跨代风险模型：心核容量限制、祖魂侵蚀、记忆冲突、知识过时、血禁（不可改清单）、权限分级。而 C8 只用一句「防膨胀」就**全禁**了知识跨代。也许正确答案不是全禁，而是像龙族那样设**容量上限 + 冲突检测 + 权限分级**的「有条件跨代」。这是一块现成的、已经被想象过但没被工程化的设计空间。
2. **实验 1 缺「用语言」的对照臂**，所以「不用语言也能跑」目前无法排除「压根做不到」。
3. **技能库的表达能力上限从未被讨论**——它是「有限动作空间 vs 开放性」这对老矛盾目前唯一的折中方案，但没人问过它能长多大。
