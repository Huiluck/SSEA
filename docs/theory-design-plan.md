## 1. 本文件的自我约束（六条）

这六条不是表态，是**审查本文件自身的工具**。任一条不满足，对应设计即视为不成立。

### 1.1 每条设计必须能回溯到 C1–C10 中的至少一条

[03](03-architecture-spec.md) §1 的原文：「任何结论若无法回溯到其中至少一条，即视为偏离 SSEA 立场」。下面每节都有「承重标准」一行，**写不出具体编号的条目已删除**。

### 1.2 每条能力必须成对写出「它做不到什么」

这是项目自己的方法论纪律（[06](06-status-roadmap.md) §12「机制 ≠ 能力」）。**只写能做什么的设计是宣传，不是设计。**

### 1.3 新主张必须标证据档

沿用 [02](02-nonverbal-cognition.md) 的 A/B/C 分档：
**A** 强实证（多实验室重复 / 临床与影像双重验证 / 形式化证明）·
**B** 有实证但有争议 · **C** 仍是理论假说。
⚠️ **B 级证据可支撑设计选择，不得当作已证结论引用**——这是文档已经立过的规矩（[05](05-glossary.md)「自由能原理」行），本文件不例外。

### 1.4 边界三测试先于设计

[04](04-boundaries.md) Part B §2 的三条测试（算力/行为 → 格式 → 筛选），**先命中者定类**；
同时命中测试 1 与测试 3 时**平局裁决为生态**，模型侧设只读镜像（先例：代谢、淘汰函数）。

### 1.5 「代价化」原则（本文件新提出，从 C9 推导）

> **任何希望模型"想去做"的行为，都必须翻译成"它要花掉什么"，而不是"它能得多少分"。**

推导：C9 禁止**外部**评分函数，且淘汰函数在模型之外（模型物理上碰不到）。
于是"引导行为"只剩一条合法通路——**改变代价**。世界的计价物只有能量（与由它派生的
时间、风险、损伤）。

这条原则在项目里其实**已经在执行**，只是从未被命名：经验编译器「按**世界计价物**（净能量）
决定提不提，不按任何内部偏好排序」（[SSEA/README.md](../SSEA/README.md) §11.1）。
本文件把它提为**通用判据**，用来审查 §4 的每一条新设计——**凡是写不出代价形态的，都退回重写。**

### 1.6 标「未解」的权利与义务

**有权利**把条目留成未解——[01](01-philosophy.md) 支柱 11 已经立了先例（"只负责立题，不冒充已解"）。
**有义务**把未解项写进 §6 登记表，写明**谁定、怎么定、卡住什么**。
**"未解"不是"没写"的委婉说法**；写不出来的东西不许留在正文里假装已解。

### 3.1 身体与疾病

**原始构想**：l.54「给模型一具身体」；l.55「身体如何描述」（**已答**，`BodyState`）；
l.97「**疾病**(需要设计细菌、病毒？若否，疾病怎么产生？)」（**未答**）。

**理论设计**：

疾病**不作为实体设计**，而作为**身体状态空间上的一个慢变量**。

| | 内容 |
|---|---|
| 状态 | `infection_load ∈ [0,1]`（模型侧**可感知**的镜像，住 `BodyState`）、`immunity ∈ [0,1]` |
| 过程 | **暴露**（接触被污染对象 / 同族 / 资源）→ 载量上升；**代谢代价** = `f(load)`，由环境真实扣能量；载量达阈值 → 损伤累积 |
| 兑现 | ⚠️ **不新增淘汰条件**：疾病通过**已有的** `energy ≤ 0` 与 `damage ≥ max` 兑现（§3.6 的"单一淘汰函数"原则） |
| 感知 | 只给**症状**（疲劳上升、能量转化率下降、视野内其他个体的"病态"特征），**不给"病原体"这个符号** |

**为什么不需要设计细菌 / 病毒**——这是对原始那个问号的**正面回答**：
细菌与病毒是**符号层**的东西（需要命名、分类、指称、传播模型）。在 C2（语言不进闭环）
与 C8（不给知识语料）之下，模型只需要一条**非语言的因果链**："这个状态 → 我的能量在漏"。
给它"病原体"这个范畴，等于给它一份**人类医学的知识语料**——直接撞 C8。

> **所以原始构想的那个"若否"分支才是对的：疾病不值得作为实体设计，值得作为慢变量设计。**

**承重标准**：C2（不给符号）· C8（不给知识）· C9（不新增评分/淘汰条件）· C4（只加一个可感知标量）。

**边界归属**：**生态**（过程归环境，模型无判定权）／模型侧 = `BodyState` 上的只读镜像。
⚠️ 命中边界测试 1（消耗算力、改变行为）与测试 3（筛选模型、不随个体死亡消失）→
**平局裁决：判为生态**，与"代谢"同例。

**它做不到什么**：
- 不会产生"免疫记忆"式的适应——除非把 `immunity` 做成可遗传的先验（那属于 §3.4 基因包）。
- 观察员无法从存活数据区分"躲开了病"与"没遇到病"（**分母可能为 0**，见 §6 O-7）。
- 疾病**不能**作为选择性压力源被"调参"来优化训练——那会立刻变成外部评分。

**证据档**：C（生态学与流行病学有大量模型，但"最小生命体需要疾病吗"没有实证；**这是设计选择，不是经验结论**）。

**未解**：`f(load)` 的形状；暴露率参数；是否需要 `immunity` 的记忆项。**均未排期。**

### 3.2 生存压力（**关闭 [01](01-philosophy.md) §349 的一个开放问题**）

**原始构想**：l.23–24「系统给予模型生存压力……**生存压力和美好需要定义**」。
[01](01-philosophy.md) §349 至今写着它与"美好"并列、仍开放。

**理论设计**：

> **"定义生存压力"不是定义目标函数，是定义一组世界参数。**

压力 = 世界对个体的**三个可测梯度**，全部由环境拥有、模型碰不到：

| 梯度 | 世界参数 | 个体可测的投影 |
|---|---|---|
| **能量梯度** | 基础代谢 `base_drain`、单位动作成本、资源能量密度 | 净能量收支 `dE/dt` |
| **危险梯度** | 危险源数量、漂移速率、威胁半径与伤害率 | 期望接触率、最近威胁距离 |
| **时间梯度** | 昼夜相位、资源再生率、（v0.4+）季节 | 资源可得性的时间波动 |

**压力的"强度"可测，"方向"不由设计者给**——这是 C9 的接缝：世界只决定*多难*，不决定*往哪走*。

**承重标准**：C9（压力是环境参数，不是模型内的分）· C1（压力是组织原则的来源）· C4（三个梯度都要低带宽可感知）。

**边界归属**：**生态**（全部三组参数）。

**它做不到什么**：
- **不能保证压力"合适"**：压力过大会让个体死于随机，过小则没有学习信号。**没有自动标定机制**，
  这是设计者的责任，而且是**未解项**（§6 O-1）。
- 时间梯度在第一阶段**已实现但显式声明无后果**——`environment.py:69` 的注释自己写着
  「只驱动 `time_phase` 与 `light_level`，**不驱动生存后果**」。所以现在它**不构成压力**。

**证据档**：B（非平稳环境逼迫持续适应，是 RL/持续学习的常见结论；但"三梯度"这个划分是本文件的设计选择）。

**未解**：三梯度的**量纲统一**问题——能量是标量，危险是概率，时间是相位。怎么比较？
本文件的立场是**不比较**（它们各自独立作用，不合成一个标量），因为合成必然要权重 →
权重就是评分函数 → 撞 C9。

### 3.3 归属 / 爱 / 尊重（**不是任务，是能力有限的产物**）

**原始构想**：l.25 美好可参照马斯洛；l.63「繁衍机制，**包含马斯洛前四个需求**」。
现状：只在 [01](01-philosophy.md) §353 的引文框里活着，**没有任何设计**。

**⚠️ 先纠正一个错误 framing（本文件第一版就写错了）**：

> **归属、爱、尊重不是模型的任务，也不是要被"满足"的需求。**
> 它们的来源是：**个体能力有限 → 不得不合作 → 在合作中自然产生。**

第一版把它们写成"四类缺口"——那是**把涌现物当成了设计目标**，会立刻长出三样违规物：
模型的 objective（"去交朋友"）、声望分、以及一个假 KPI。
**这条纠正与 C9 是同一件事的两面**，不是措辞问题。

**正确形态：三段式**

#### (1) 前置条件：能力有限（**必须被设计成结构事实**）

若单个体全能，合作不必需，归属 / 爱 / 尊重不会出现。所以先要让"有限"在结构上成立：

| 有限性轴 | 现有结构支撑 | 若这条不成立会怎样 |
|---|---|---|
| 感知半径有限 | `perception_radius`（已有） | 全局可见 → 信息无需他人提供 → 无交换动机 |
| **位置唯一**（不能同时在两处） | `position` 是单点（已有） | 可分身 → 分工不必需 |
| 代谢预算有限 | 能量即预算，每个动作耗能（已有） | 能量无限 → 无需协作觅食 |
| **技艺只可有条件跨代**（不是不可跨代） | `GenePackage.skill_library` / `heritable_memory`（**已有**） | 若技艺可**无条件全量**继承 → 个体不必依赖他人 → 见 §3.4.1 |
| 单点风险 | 危险源（v0.4：灾害、捕食者） | 能独自抵御 → 无需互助 |
| 寿命有限 | 淘汰函数 | 不死 → 无代际更替 |

> ⚠️ **本文件在这里错过一次，已更正。** 第一版说「技能不可跨代传递」是合作的最强来源——
> 但查过协议后：**技能一直在基因包里**（`GenePackage.skill_library`，见 [gene.py](../SSEA/sse_protocols/gene.py)）。
> 真正制造「必须合作」的**不是**「什么都不能继承」，而是：
> **继承来的技艺是*祖先世界*的做法，而世界非平稳 → 它必然部分过时。**
> 完整推导见 **§3.4.1 末段**。这个版本更真实（人类就继承了大量过时知识），也更稳——**它不依赖一个绝对禁令**。
> 顺带修正 C8 的读法（完整措辞见 [03](03-architecture-spec.md) **§10 裁决四**）：
> **准确含义是「程序性先验可有条件跨代，符号化知识永不跨代」，不是「知识不跨代」。**

> **位置唯一 + 代谢预算有限 = 分工的结构必然性**：你不可能一边觅食一边放哨。

#### (2) 涌现机制：重复互动 + 身份可追溯

| 涌现物 | 物质基础（SSEA **已有**的结构） |
|---|---|
| **互惠** | **C5 精准回忆历史**——⚠️ 记不住"谁帮过我"，互惠就不可能。**C5 不只是个体记忆，它是社会互惠的基底。**（第一版漏了这条连接） |
| **亲属偏好** | **谱系**（§3.5）——亲属识别的物质基础 |
| **身份识别** | 对象 id / 个体标识 |
| **重复博弈** | 共处回合数（寿命长度决定） |

> **这给原始构想的「龙族血脉」意象一个功能解释**：血脉之所以承重，因为它承载**亲属选择**。
> 原始 l.63 把「繁衍」与「马斯洛前四个需求」绑在同一句话里，**不是随便绑的**——
> 繁衍正是亲属选择的物质基础。

#### (3) 明确禁止（三条，全部与 C9 / C8 同源）

归属 / 爱 / 尊重 **不得**成为：

- 模型的 **objective**（"去交朋友"）→ 外部目标，撞 **C9**
- **奖励 / 分数**（"声望分"）→ 撞 **C9**
- **验收判据** → 会造出一个假 KPI（与 §3.8「美好」同一个陷阱）

#### (4) 观察员的读数（**观察，不是验收**）

| 读数 | 形态 | 为什么算"产生了" |
|---|---|---|
| **熟识特异性** | 对熟识者的资源让渡率 > 随机匹配者 | 关系有历史，不是随机慷慨 |
| **稳定性** | 同一对个体的合作率随时间上升 | 关系在累积 |
| **位置的长期稳定** | 分工位置稳定，且与**能力差异**相关 | 这是"尊重"的可测形态（**不是声望分**） |
| **代价承担** | 个体为他人承担净能量损失 | 互惠利他的定义 |

⚠️ **四条全部是观察员面的读数**，不进控制闭环、不进验收判据。

**① 生理与 ② 安全 去哪了**：它们与 ③④ **不同类**——①②**就是淘汰函数本身**（能量 / 损伤），
不是涌现物。所以它们归 §3.2（生存压力）与淘汰函数，**不再与 ③④ 并列**。

**承重标准**：C9（三条禁止）· C8（不给"爱"这个范畴）· C5（互惠的基底）· C1（合作是生存手段，不是目的）。

**边界归属**：有限性 = **模型与生态各半**（感知半径 / 位置 / 代谢属模型；风险与寿命属生态）；
涌现物 = **生态**（多模型互动的产物）；观察 = **观察员面**。

**它做不到什么**：
- **不可设计，只可观察。** 你没法"加一个归属机制"；能做的只是**制造必需性**，然后看它出不出来。
- **第一阶段分母为 0**：单智能体，任何"合作 / 归属"的读数**都没有定义**。
- **不保证出现。** 能力有限是**必要条件而非充分条件**——也可能只出现自私的短期博弈。
- 观察判据**依赖寿命足够长**；现测寿命 66–182 帧，连一次像样的重复博弈都跑不完。

**证据档**：B（互惠利他 / 亲属选择 / 重复博弈是成熟理论）· C（"归属与尊重从功能依赖中涌现"是**推论**，无直接实证）。

**未解**：见 §6 **O-10**——"能力有限"要到什么程度才"不得不"合作，这是**标定问题**（且它是必要条件，无法由设计者直接给出）。

### 3.4 繁衍（**判据必须写在协议层**）

**原始构想**：l.63–64。现状：[01](01-philosophy.md) 支柱 9 说"变异率、可继承判定与
**谁有资格繁衍的判据须在协议层先定清楚**"——**尚未定**。`GeneManager` 缺失。

**理论设计**：

**繁衍资格 = 世界事实的组合，不是任何加权和。**

| 条件 | 形态 | 为什么合法（不撞 C9） |
|---|---|---|
| 存活到某年龄 | 世界事实 | 淘汰函数已经筛过 |
| **可支配**能量 ≥ 阈值 | **代价**：繁衍要花掉能量（§1.5 代价化原则） | 不是"得分高者获准"，是"付得起者才能付" |
| 一个在场的同族 | 世界事实 | 需要 ≥2 模型 |

**基因包的三个来源已经存在**（`GenePackage` 的 `skill_library` / `instinct_adapters` /
`behavior_policy`——[03](03-architecture-spec.md) Part II §2.1：注入面是遗传面的子集，
两套机制**共用一份结构定义**）。这仍然是全项目最漂亮的一条结构事实。

**变异与重组**：

- 变异：`mutation_rate` 作用范围**已经限定**——`architecture` 与 `core_weights` 不可变异
  （[03](03-architecture-spec.md) Part II §3.5），因为结构变异会让实验失去可比性。
- 重组：交叉算子定义在**结构类别**上（skills / rules / adapters / thresholds / retrieval），
  **不在权重上**——权重不可逐位继承、不受 C8 保护。
- ⚠️ 重组可能产生**不可运行的组合** → 必须过**同一条验证门**（[03](03-architecture-spec.md) Part II §2.1）。

**跨代不传知识**：C8 的永久设计，不做例外的口子（[04](04-boundaries.md) Part C #17）。

**速率预期（这是定标准最容易错的地方）**：
「子代能力有传递但改进很慢」**不是实现错了，是机制的理论上限**——
Oldowan 技术停滞约 80 万年。所以第 3 期的验收是
**「能力有传递、差异可追踪、且不退化」**，**不是"快速改进"**（[06](06-status-roadmap.md) §6）。

**承重标准**：C7（可保存/恢复/变异/继承）· C8（不传知识）· C9（资格不是评分）。

**边界归属**：基因包与本能 = **模型**；"何时可繁殖、如何交配" = **生态**（[04](04-boundaries.md) Part B 表已如此标注）。

**它做不到什么**：
- **无语言教学 → 棘轮慢**（mimetic 而非 mythic 速率）。
- **无法在单代内验证"更好的基因"**——选择要跨代才显形，而实验周期长。
- `HeritableFilter` 的 `retrieval_count ≥ N` **N 没有定标方法**（[02](02-nonverbal-cognition.md) §6.3）：
  理论根据（无语言条件下靠频次补偿保真度损失）已有，**数没有**。

**证据档**：B（双重继承理论、文化棘轮有实证；mimetic 速率的具体数字有争议）。

#### 3.4.1 跨代传递的边界 —— C8 的精确化（**龙族血脉的功能翻译**）

**原始构想**：[Lineage/龙族-血脉传承机制.md](Lineage/%E9%BE%99%E6%97%8F-%E8%A1%80%E8%84%89%E4%BC%A0%E6%89%BF%E6%9C%BA%E5%88%B6.md)
（容量上限 / 权限分级 / 真名 / 血禁 / 知识过时 / 祖魂侵蚀 / 记忆冲突 / 觉醒深度六层）。

**先纠正本文件的一处错误。** 第一版把 C8 读成「知识不跨代」，并据此把「技能不可跨代传递」
当成合作的前提之一（§3.3(1)）。**这个读法错了**——查协议 [gene.py](../SSEA/sse_protocols/gene.py) 之后：

`GenePackage` **已经**包含四类可跨代结构：

| 字段 | 跨代内容 | 现状 |
|---|---|---|
| `instinct_adapters` | 本能先验 | ✅ |
| **`skill_library`** | **技能** | ✅ **已设计** |
| **`heritable_memory`** | **筛选后的 RULE / SKILL 记忆** | ✅ 已设计（`is_transient` 在 `__post_init__` 里**强制**排除瞬时记忆） |
| `behavior_policy` / `metabolic_policy` / `architecture` / `core_weights` | 策略与配置 | ✅ |

**所以 C8 的准确含义不是「知识不跨代」，而是「程序性先验可有条件跨代，符号化知识永不跨代」**
（权威措辞见 [03](03-architecture-spec.md) **§10 裁决四**）：

| 类型 | 跨代？ | 依据 |
|---|---|---|
| 本能 / 技能 / 规则（procedural：**怎么做**） | ✅ | `GenePackage` 的结构 |
| 筛选后的 RULE / SKILL 记忆 | ✅ | 同上 |
| **瞬时记忆**（EVENT / BODY_EXPERIENCE） | ❌ **永不** | [04](04-boundaries.md) Part C #17、`is_transient` **结构强制** |
| **事实 / 情境 / 概念**（declarative：**是什么**） | ❌ | 需要符号，见下 |

##### 为什么「事实」不能跨代——一条能自己站住的理由

龙族的**知识类**传承（龙语、炼金、星图、地理、契约、法律、医学）**全部需要符号**。
mythic culture 之所以能把「事实」跨代传，是因为**符号让不在场的东西可以被指称**。
SSEA 放弃语言（C2），所以**事实无法跨代**——**这不是禁令，是推论。**

> **C8 因此可以精确化为：**
> **程序性先验（怎么做）可有条件跨代；符号化的知识（是什么）永不跨代。**
> 这不削弱 C8，而是**把它磨准**——原措辞会让读者以为技能也不能跨代，而协议里技能一直在包里。

##### 龙族六层觉醒 → SSEA 只能取前两层

| 龙族觉醒深度 | 内容 | SSEA |
|---|---|---|
| 一层 · 本能 | 飞行、吐息、龙语雏形 | ✅ 允许 |
| **二层 · 技艺** | 战斗、锻造、魔法 | 🟡 **有条件允许——本小节要设计的就是「条件」** |
| 三层 · 知识 | 历史、星图、契约 | ❌ 需要符号 |
| 四层 · 记忆 | 祖先人生片段 | ❌ #17 永不 |
| 五层 · 祖魂 | 祖魂附体 | ❌ 人格 |
| 六层 · 源血 | 与龙海合一 | ❌ |

##### 缺的不是「通道」，是「条件」——龙族机制的逐项落点

通道已经在包里，**判据不在**。`SkillLibrary.adopt()` 目前**把传进来的技能全收**（零筛选）：

| 龙族机制 | SSEA 落点 | 现状 |
|---|---|---|
| **心核容量** | 可继承结构的**预算上限** | ✅ **已裁决**：`floor(ρ × 父代结构数)` —— 见 §3.4.2 |
| **血脉浓度 → 权限分级** | 能访问的**谱系范围** | ✅ **已裁决**：**直系 1 代** —— 见 §3.4.2 |
| **真名（索引密钥）** | **谱系 id 作为访问密钥**——继承的不是内容，是**访问权** | ❌ 无 |
| **血禁** | 不可继承清单 | 🟡 部分 |
| **知识过时** | 继承物必须过**同一条验证门**，且在本代**可被淘汰** | 🟡 `adopt()` 过门；`prunable()` 未与继承联动 |
| **祖魂侵蚀 / 记忆冲突** | 继承物与本代结构**冲突**时的仲裁 | ❌ 无 |

> ⚠️ **「机制类天然排除」是一条结构性事实，值得点名**：验证门、淘汰函数、观察员接口、
> 环境接口、基因管理底层权限**不是五类结构之一**，所以**继承这条通道物理上碰不到它们**。
> 这比"再加一条血禁规则"强——**它是结构保证，不是约定**
>（与 [03](03-architecture-spec.md) Part II §2.1「四条性质由结构事实保证」同源）。

##### 防膨胀要升级：从「禁止进入」改成「**进入后必须能被淘汰**」

C8 原来的防膨胀理由是「不许进」。一旦允许技艺跨代，那个理由就不再充分。替代有两条：

1. **容量上限 + 下载代价**（代价化原则 §1.5）→ 不能全拿
2. **继承物进入后仍受 `prunable()` 管辖** → 进了要能出

> **第二条才是真正的升级**：因为「禁止进入」会**连带禁止掉文化棘轮**，而「**能进能出**」两者都要。
> 而这正好是**既有机制**——`SkillLibrary.prunable()` 与 `DISABLE_SKILL` 已经在。

##### 与合作前提的关系（**本小节最重要的一段**）

无条件继承会杀死 §3.3 的合作前提。**龙族那套条件恰恰是解药**：

> **纵向传递给的是「怎么做」，横向合作给的是「现在是什么情况」。**

- 继承来的技艺是**祖先世界的做法**；世界非平稳（§3.6 原则二）→ **必然部分过时**
- 当前情境只能靠**同代感知**获得，而感知半径有限 → **必须合作**

**所以合作前提不是「什么都不能继承」，而是「继承来的东西必然部分失效」。**
这个版本更真实（人类就继承了大量过时知识），也更稳——它不依赖一个绝对禁令。

**承重标准**：C8（精确化，**不放松**：declarative 仍永不跨代）· C2（事实不能跨代是**推论**不是禁令）· C7（可保存/恢复/变异/继承）· C9（容量策略不得与个体表现相关，见 §4）· C4（继承要有预算）。

**它做不到什么**：
- **不解决「继承多少合适」**：ρ **的具体取值**属标定（§3.4.2 末段），设计本身已定。
- **不保证棘轮**：mimetic 速率上限仍在（Oldowan 约 80 万年）。
- **继承冲突没有干净解**：两个祖先的技能 precondition 相同、动作序列不同——
  仲裁只能是「过门 + 本代淘汰」，**没有更聪明的办法**。

**证据档**：B（双重继承理论；黑猩猩有模仿但棘轮极弱）· C（龙族机制的翻译是设计选择）。

✅ **2026-09-28 已裁决**：C8 的措辞已按本小节精确化，权威条款在
[03](03-architecture-spec.md) **§10（裁决四）**——与 §8.1（C9 加「外部」二字）同规格。
本小节现从「提案」升级为「**设计依据**」。

> 裁决**没有**放松 C8：符号化知识仍然**永不跨代**，瞬时记忆仍然**永不跨代**（不做清单 #17 不动）。
> 它改的是**措辞**——把「只放本能」改成「程序性先验可有条件跨代，符号化知识永不跨代」，
> 而**代码本来就在这么做**。

#### 3.4.2 两条已定的数：容量按比例 ρ，范围**直系 1 代**

> **本节记录 2026-09-28 的设计裁决**，关闭 §6 的 **O-11** 与 **O-12**。

##### O-11 → 容量 = 父代可继承结构数的固定比例 ρ

   容量(子代) = floor(ρ × |父代的可继承结构|)，   **ρ = 0.3**，世界常量，与个体表现无关

**为什么「按比例」比"自己带一个硬上限"好：它会自己封顶，不需要第二个参数。**

```
|G_{n+1}| ≤ ρ·|G_n| + Δ_本代
稳态：|G| ≤ Δ / (1 − ρ)
```

只要「每代新增 Δ」有界（`SkillLibraryConfig.max_skills = 64` 已经在），继承总量就有界。
**ρ 是唯一需要定的旋钮。**

**代入 ρ = 0.3**：稳态 `|G| ≤ Δ / 0.7 ≈ 1.43 Δ`。

> 这句话值得单独读一遍：**继承池只比「一代新增」大 43%**。
> 也就是说，一个个体携带的结构**几乎全部来自它自己的这一代**，而不是来自祖先积累。
> 这正是「限制个体自身能力」在数量上的形态。

**还有一个由 `floor()` 造成的断崖**（不是精度问题，是结构后果）：

```
父代 3 条 → floor(0.3 × 3) = 0 条     ← 一代归零
父代 4 条 → floor(0.3 × 4) = 1 条
```

⇒ **继承的「最小可传量」是 4 条**。持有 ≤ 3 条可继承结构的个体**一条都传不下去**。
连续几代不传的组合会自然消失——**这又是一层不需要额外规则的稀释**。

它同时兑现了 §3.4.1 的「进入后必须能被淘汰」——**ρ < 1 意味着每一代都必然丢东西**：
稀释发生在**继承那一刻**，而不是靠某个中心机构去裁剪。

##### 为什么是 0.3：**这是能力天花板，不是纯粹的防膨胀参数**

⚠️ 这一条按设计者 2026-09-28 的裁决记录，理由比数字重要：

> **我们的模型设计上是自进化思路，前期需要限制它们自身的能力；
> 未来它们或许会更改自身的代码。**

所以 ρ 承担**两个**目的，而第二个才是主要的：

| 目的 | 机制 |
|---|---|
| 防膨胀 | 几何级数自带封顶（`1.43Δ`） |
| **能力天花板** | **个体不能靠继承变"全能"**——继承只给起点，不给自足 |

**这条理由把 ρ 与 §3.3 的合作前提直接焊在一起**：
若 ρ 接近 1，个体可以近乎完整地继承父代 → 自给自足 → **合作不必需** → 归属/爱/尊重不会出现。
**ρ 太小 / 太大，坏的都不是膨胀，是社会性。**

**ρ 住在哪里**：`ρ` 是**世界常量**，**不在五类结构之内**——
于是慢环的提案白名单（§ plasticity）**物理上碰不到它**，与淘汰函数同例。
⚠️ 这一点必须保持：若 ρ 变成模型可提案的阈值，"调高 ρ"就是一条**绕过筛选**的路径
（与「不允许模型调高自身变异率」同一条纪律，见 [04](04-boundaries.md) 易误解项）。
未来若要放开（设计者说的「它们或许会更改自身的代码」），那必须是**一次显式裁决**，
不是模型的自助操作。

##### 继承**不排序，只抽样**（C9 约束）

ρ < 1 意味着必须**选择留下哪 ρ 份**。这一步是最容易长出评分函数的地方，所以先定死：

- ✅ 按**结构类型配额**（本能 / 技能 / 规则 各占容量的固定份额）——不让一类挤掉另一类
- ✅ 同类内**确定性抽取**（seed 派生自 `agent_id`）——可复现，且与表现无关
- ❌ **不按父代的使用统计排序**（那是**跨个体**比较，是外部评分的入口）
- ❌ **不按「成功率 / 重要度」排序取前 ρ**

> **留下的判断交给本代。** 继承来的结构进了本代结构库后，与**本代自己产出**的结构
> **地位完全相同**，一起受 `prunable()` 管辖——而 `prunable()` 用的是**本代自己的**使用统计。
>
> 这给出一条好性质：**传下来但本代不用的技艺会自然消失。**
> 这正是 Tomasello 棘轮所要求的「必须被使用」，也是 §3.3 合作前提的又一层加固。

##### O-12 → 范围 = **直系 1 代**

| | 内容 |
|---|---|
| 能访问 | **父母**这一代的可继承结构 |
| 不能访问 | 祖父母及以上——**没有「祖先图书馆」** |
| 双亲 | 两侧结构**合并**后按同一个 ρ 截断（不各取一半再合并，那会让 ρ 失去意义） |
| 索引 | **「真名」退化为 `parent_ids`**（§3.5 谱系 DAG 已有字段）。1 代深时，「索引密钥」就只是父指针 |

**这一条是 SSEA 与龙族的分界线。** 龙族的「血脉浓度 → 权限分级」允许**源裔深潜**到原初龙神；
SSEA 把可访问深度压到最浅一层——**「薄血」（源血 < 10%，只能偶尔血梦）**。

**它的三条后果**（都已在别处承重，故记下来）：

1. **防膨胀**：继承深度只有 1，膨胀不可能来自「往谱系深处挖」
2. **保留合作前提**（§3.3）：**你只能拿父母那份**——祖父辈的东西，除非父母传下来了否则你没有
   → **不可能靠祖先躺赢** → 必须和同代互动
3. **给出 mimetic 速率上限的结构解释**（§3.4 末段）：信息**每代只能从父母那一层重新获取**，
   链一断就丢——**这正是 Oldowan 停滞约 80 万年的机制**。
   mythic culture 能突破它靠的是**符号**（让信息脱离个体存活）；SSEA 放弃了符号（C2）。

**承重标准**：C9（抽样不排序、ρ 与表现无关）· C8（只传 procedural）· C7（可保存/恢复/继承）· C4（继承要有预算）。

**它做不到什么**：
- **ρ = 0.3 是裁决值，不是推导值**（它由「前期限制个体能力」这个目的定，不是由公式定）。
  若将来放宽，必须有**新的裁决理由**——不能是「想让它学得更快」。
- **直系 1 代使谱系极脆**：任何一代不传，那条技艺就**永久消失**。
  ⚠️ 这是**特征不是缺陷**（它就是 mimetic 棘轮的真实形态），但它会**放大随机性**——
  某条有用技艺的丢失可能与「它没用」完全无关。
- **双亲合并 + 单一 ρ** 在两侧规模差异大时会**偏向规模大的一方**。这是已知偏差，未解决。

### 3.5 死亡与「地府」

**原始构想**：l.65「每一个死亡的模型都会被完完整整(数据、代码等等)地保存在外部硬盘……
就是"地府"。这是人类作为观察员记录模型的演化，是生态系统保存它存在过的证明。」

**现状**：意象在（[01](01-philosophy.md) 支柱 9 与 §248 的"原始意象"框）、纪律在
（繁衍纪律第 8 条）、**代码侧 `DeathHook` 默认 `None`**。

**理论设计**：

| 环节 | 内容 |
|---|---|
| 触发 | `DEATH_SNAPSHOT`——由**环境**判定死亡后触发（模型无判定权，C9） |
| 快照内容 | 完整 trace + 最终结构快照 + 基因包 + **谱系指针**（`parent_ids`） |
| 结构 | 谱系是 **DAG 不是树**——因为存在重组（§3.4），一棵树表达不了双亲 |
| 用途 | ① 观察员的**进化树唯一数据源** ② 实验 4/5 的对照材料 |
| ⚠️ 关键约束 | **快照不回流进任何控制环路。** 否则"死亡"就有了信息量，模型可能学会"死得有价值"——那是把淘汰函数变成了可优化的目标（撞 C9） |

**为什么这条值得提前**：它是**个体级**的（不是生态级），触发器与参数**已经定义在
[03](03-architecture-spec.md) Part II §2.2 里**，而它与实验 4/5 卡在同一段流水线上
（Gene Manager：`save` / `load` / `mutate`）。**「地府」= 死亡时的 `GenePackage.save()` + 谱系记录。**

**承重标准**：C5（精准回忆——死亡快照是它的极端形态）· C7（保存/恢复）· C9（死亡判定归环境，快照是观察员面产物）。

**边界归属**：**生态**（淘汰函数归环境）／快照存储 = **观察员面**（不进闭环）。

**它做不到什么**：
- **不保证可重建**：世界状态与随机流不可恢复，所以"地府"**不是复活**，是**档案**。
- 快照体积随寿命线性增长 → 需要容量策略，而**策略本身可能变成一场筛选**（撞 C9 的风险点，见 §4）。

**证据档**：C（无先例可循；`Gödel Agent` / `ADAS` 的"档案"是**工作记忆**而非**谱系**，不可直接类比）。

**未解**：快照容量上限；谱系 DAG 的存储格式；"完整"的边界（trace 要不要全存？）。

### 3.6 生态系统（**本文件的主体**）

**原始构想**：l.91–98。现状：整块只有构想梳理与推迟清单，**没有设计**。

#### 3.6.1 两条原则

**原则一：单一淘汰函数 + 多压力源。**
第一阶段的淘汰函数是 `energy ≤ 0` 或 `damage ≥ max`。**生态阶段的所有压力源都通过它兑现，
不新增淘汰条件。**

> 这不是省事，这是**让 C9 的结构保证得以延续**：淘汰函数一旦变成"能量 或 损伤 或 感染 或 声望"，
> 判定权就散开了，而"模型物理上碰不到它"这条**结构事实**会随之瓦解。

生态元素与淘汰函数的对应：

| 压力源 | 兑现方式 |
|---|---|
| 饥饿 / 资源稀缺 | energy ↓ |
| 捕食者 | damage ↑ |
| 自然灾害 | damage ↑ + 资源破坏 |
| 疾病 | energy ↓（漏）+ damage ↑ |
| 寒冷 / 季节 | energy ↓（代谢率上升） |

**所有生态压力最终都汇成两个标量。** 这是本文件对生态设计的**第一条硬约束**。

**原则二：非平稳是目的，不是副产品。**
静态资源点只能训出对固定环境的过拟合（[01](01-philosophy.md) §4.1）。四季 / 灾害 / 资源波动
**本身就是设计目标**——但它们必须**通过原则一兑现**。

#### 3.6.2 营养结构（原始 l.93）

| 要素 | 理论设计 | 现状 |
|---|---|---|
| **太阳**（相对无限能量源） | 无限的是**总能量输入**，不是可用能量——必须经生产者转化。最小形态 = 昼夜光照相位 | 🟡 已实现且**显式声明无后果** |
| **生产者**（产能有限） | 再生率 < 消费者的总消耗率 → **这就是压力的来源**，无需打分 | ⏸ 现为静态资源点（`n_resources=6`，不循环） |
| **消费者** | 模型自己 | ✅ |
| **循环资源**（水/山/土/矿） | 物质守恒：被消耗的资源回到循环池，只是位置/形态变化 | ⏸ 不做 #3 |

> **"相对无限"与"产能有限"的调和**：太阳给的是**通量**，生产者给的是**存量**。
> 通量无限而转化率有限，于是**稀缺性来自转化率，不来自总量**——这正是原始构想那句话的精确含义。

#### 3.6.3 角色与多模型

| 角色 | 理论设计 | 边界 |
|---|---|---|
| **捕食者** | 会**主动接近**的 hazard（vs 静态漂移的 hazard）。可以不是"另一个模型"，而是世界的一个过程 | 生态 |
| **同族** | ≥2 个同架构实例，共享通信通道与资源池 | 生态（规则） |
| **野兽 / 竞争者** | 与同族同构，只是**参数不同**（不同的 gene 包）——用生态位而非类型标签区分 | 生态 |

⚠️ **不要给角色贴标签**。一旦世界里有「这是捕食者」这个符号，它就成了模型可读的知识语料（撞 C8）。

⚠️ **角色的来源是能力差异，不是设计者分配的类型。** 分工位置之所以稳定，是因为**个体的能力曲线不同**
（感知 / 代谢 / 技能库 / 基因包），而 ① 位置唯一 与 ② 代谢预算有限 让「什么都自己做」在结构上不可能
（§3.3(1)）。**给角色分配类型会直接杀掉这个过程**——它把涌现物换成了标签。
角色应当**从行为差异中涌现**，由观察员事后命名（C2：命名是观察员的事）。

#### 3.6.4 生态位与演化博弈（原始 l.49 的"还原自然选择"）

用**生态位 + 演化博弈论**刻画同族合作与野兽竞争（[01](01-philosophy.md) §4.2）。
期望自发涌现「语言」与「社会结构」——⚠️ 这是**期望，不是承诺**（§5）。

**承重标准**：C1 · C4（世界也要低带宽：状态张量，不是全息世界）· C9（压力源不经评分）· C8（角色不给符号）。

**它做不到什么**：
- **生态不能用来掩盖模型缺陷**——这是顺序纪律的全部理由。
- **不能保证涌现出语言 / 社会结构**。原始构想定的这两个是**目标方向**，不是可交付物。
- 多模型的环境复杂度会让**归因**变得几乎不可能：一个行为变差，是模型的问题还是生态的问题？
  **这是第 2 期最大的方法论风险**，也是出口判据①要求"显著高于静态世界"的原因。

**证据档**：B（生态位与演化博弈论是成熟框架）· C（"涌现出语言"无先例可循）。

### 3.7 通信与语言演化

**原始构想**：l.75–78「二进制 / 自我演化出同类语言」。

**理论设计**：

- 通道：`CommunicationSignal`（潜空间向量）——**第一阶段只预留，不实现编解码**（不做 #16）。
- 立场：通信应**由模型自主演化**；人类若要读懂，**主动解码是观察员的活**（C2）。
- 第一阶段的现实：单智能体，通道只**回环**（`echo_communication=True`），目的是让这条通道
  **可被端到端验证**，否则感知编码器的 social 段永远是零——"通道存在却不可观测"。

> ⚠️ **第一阶段的回环不是"通信"，是"通道自检"。** 把两者混为一谈，就会在文档里写出
> "实现了通信"这种假话。

**它做不到什么**：
- **没有"怎么算演化出了语言"的判据**——这是真开放问题（§6 O-4）。
  一个朴素的坏判据是"向量方差下降"（那只能说明收敛，不能说明有语义）。
- 第一阶段**没有接收方**，所以任何"通信有效性"的结论都**分母为 0**。

**证据档**：C。

### 3.8 偶然的美好（**与 C9 共存的肯定性机制**）

**原始构想**：l.23–25。现状：只有三个**否定性**边界（偶然 / 具身 / 非通货）。

**理论设计**：

> **"美好"不作为信号存在，而作为"某些过程的性质"存在。**

这是本文件对这条开放问题的**核心提议**。推导：如果"美好"是一个**信号**（可发放、可累加），
它必然可被最大化 → 撞 C9 的"非通货"。所以它只能是**既有过程的性质**。

| 形态 | 具身落法 | 需要新机制吗 |
|---|---|---|
| **好奇与惊奇** | `prediction_error` 本身（**已落地**）。"美好"体现在探索时**算力/能耗的自然倾斜** | ❌ 不需要——它就是既有内在驱动 |
| **心流** | 挑战与能力匹配 → 体现在**单位任务的能耗效率**上（真实后果） | ❌ 不需要新信号，只需要**测量** |
| **社会性连接** | 分享 / 互助 / 共御灾害 → 连接被强化 | v0.4+（需多模型） |
| **安宁的回放** | 睡眠期无损巩固（**已实现**）——**过程本身即美好** | ❌ 已实现 |

**这条提议的好处**：它天然满足三个约束——
**偶然**（不是随叫随到，是过程的副产品）、**具身**（是真实结构后果）、**非通货**（不是一个可累加的标量）。

**承重标准**：C9（非通货、非外部奖励）· C2（不可叙述，故只能由观察员描述）· C1（生存之外的方向牵引）。

**它做不到什么**（**诚实地说，这条最重要**）：
- **不可验证**。"模型是否感到温暖"不是一个可检验命题。本文件**不声称**它是。
- 因此它的地位是**设计意图 / 现象学描述**，与"机制"和"能力"都不同类。
  把它写进任何验收判据都会造出一个**假的 KPI**。

**证据档**：C（甚至低于 C——它是**立场**，不是假说。本文件明确标为**不属于证据链**）。

### 3.9 观察员

**原始构想**：l.65「人类是观察员」（[01](01-philosophy.md) §4.5 展开为三件）。

| 组件 | 理论设计 | 现状 / 卡点 |
|---|---|---|
| **演化图谱 / 进化树** | 从 §3.5 的谱系 DAG 渲染 | ❌ **没有数据源**——`audit_log()` 只记**结构版本切换**，不记个体 |
| **异常与作弊检测** | 监控 reward hacking 与**寄生**（专门掠夺公共资源却不进化） | 未设计；缺少"寄生"的可操作定义 |

| **自然语言接口** | **v0.4+**，始终在控制闭环之外 | 不做 #5（永不作为主接口） |

**关键纪律**：观察员**只观察、不干预、不打分**（[01](01-philosophy.md) §4.5）。

**它做不到什么**：

  （[04](04-boundaries.md) Part A §5）。
- 作弊检测**天然滞后**：发现 hacking 时它已经影响了选择。

**未解**：「寄生」的操作定义（§6 O-6）。

### 3.10 种群、生态位与演化

**原始构想**：l.45「不设评分函数，只有淘汰函数模拟自然界的演化」＋ 种群（v0.4+）。

| 概念 | 理论设计 | 卡点 |
|---|---|---|
| **个体淘汰** | 已有（`energy ≤ 0` / `damage ≥ max`） | ✅ |
| **种群级淘汰** | ⚠️ **未设计**。候选形态：谱系灭绝（一条 DAG 分支连续 N 代无存活后代） | 需要 ≥2 代 + §3.5 |
| **生态位** | 由**资源类型 × 时空分布**定义，不由设计者指定的角色定义 | 需要 §3.6.2 的循环资源 |
| **演化博弈** | 合作与竞争的策略分布随世代变化 | v0.4+ |

**与繁衍合起来才是完整的达尔文闭环**：**淘汰移除不适者，繁衍放大适应者**——缺一不可
（[01](01-philosophy.md) 支柱 9/10）。

**它做不到什么**：
- **种群级淘汰需要一个"单位"**（是个体、家系、还是整个池？）——**未定**（§6 O-5）。
- 跨代实验的**周期极长**，且第 3 期的速率下限（mimetic）已经很低。

**证据档**：B（演化博弈论成熟）· C（对 LLM 智能体的种群级选择无先例）。

## 4. 与 C9 的逐条清算

**这一节是本文件的自我审查。** C9 禁止**外部**评分函数，而 §3 里每一个"引导行为"的设计
都可能悄悄长出一个。逐条列出风险点与处置：

| 风险点 | 它会怎么变成评分 | 处置 |
|---|---|---|
| §3.3 归属 / 爱 / 尊重 | 「需求满足度」加权和 → 繁衍资格 | ❌ 禁止加权（那会把涌现物变成 objective）；改用**世界事实组合**（§3.4） |
| §3.4 繁衍资格 | "适应度分数" | ❌ 改用**代价**（花能量）+ 存活事实 |
| §3.5 快照容量策略 | 按"价值"决定存**谁**的快照 | ❌ **跨个体排名**禁止。容量策略只能按与个体表现无关的事实（时间 / 数量） |
| §3.4.2 继承抽样 | 按父代成功率排序取前 ρ | ❌ 同上：那是跨个体比较。**已定死为「类型配额 + 确定性抽取」** |
| 个体内的结构淘汰 | —— | ✅ **合法**：`prunable()` 用的是**本代自己的**使用统计，属模型内部信号，与 `prediction_error` 同类。**分界线是「跨个体排名」而不是「用了统计」** |
| §3.6 生产者产能 | "给高分个体更多资源" | ❌ 资源投放**不得以个体为条件** |
| §3.8 美好 | 可累加的"温暖值" | ❌ 只作为**过程性质**存在（§3.8） |
| §3.9 观察员 | 观察员打分回流进选择 | ❌ 观察员在**控制闭环之外**，只读 |
| §3.10 生态位 | "适应度地形" | 🟡 **可接受但需明说**：适应度地形是**事后描述**，不是**运行时的分** |

**判据**：一个问题即可筛掉——**"这个量能不能被模型读到，并据此改变行为？"**
能，就是第三层信号（结构提案）的合法对象；不能，就是实现细节。

## 5. 本文件新增的「不声称」

[04](04-boundaries.md) Part A §5 已有八项。本文件追加五项（**声明的边界越窄，声明越可信**）：

| 不声称 | 原因 |
|---|---|
| 不声称"四类需求缺口"就是马斯洛 | 马斯洛在心理学界本身有争议；本文件只主张它是一个**可操作的分解** |
| 不声称"美好"可被验证 | 它是**设计意图 / 现象学描述**，不是假说，不属于证据链 |
| 不声称生态阶段会涌现出语言 / 社会结构 | 那是**目标方向**，不是可交付物 |
| 不声称"单一淘汰函数 + 多压力源"是唯一解 | 它是本文件的设计选择；换一种淘汰函数会牺牲 C9 的结构保证，但**在逻辑上并非不可能** |
| 不声称本文件的分期判据已被验证 | 第 2–4 期的出口判据**从来没有被任何人跑过**，它们本身是设计 |
| **不声称「归属 / 爱 / 尊重」可以被设计出来** | 它们**不可设计、只可观察**。设计者能做的只有「制造必需性」（能力有限 + 重复互动），其余是涌现物（§3.3）。把这条读成「我们设计了社会性」是本文件最容易产生的一种误读 |
| **不声称跨代传递能产生「知识」** | §3.4.1 允许跨代的是**程序性技艺**，不是知识。**事实永远不跨代**（需要符号）。把「技艺跨代」说成「知识传承」会掩盖 SSEA 与「龙族三层·知识」之间那道**结构性的墙** |

## 8. 一句话

> **生态不是"以后再加的东西"，它是给这套架构赋义的那一半。**
> 第一阶段的每一个结构（三分离、双环、注入面、基因包、验证门）**只有在生态里才有意义**——
> 没有淘汰与繁衍，记忆、技能、遗传都只是数据结构。
>
> 但顺序不能反：**先证明最小生命体有效，再给它一个世界。**
> 本文件把那个世界**设计清楚但不上电**，正是为了让第一期的证据问题保持干净。
